\section{Method}\label{sec:method}

\subsection{Problem formulation}\label{sec:setting}

Following the classical few-shot learning setup
\citep{vinyals2016matching, snell2017prototypical, finn2017maml,
brown2020language}, where a task is presented only through a small
support set and performance is measured on a disjoint query set, we
formally introduce the problem of budgeted few-shot agent
specialization. An agent executes a trajectory
$\tau=(a_1,o_1,\ldots,a_H,o_H)$ of actions and environment
observations, and a task verifier $V(x,\tau)\in\{0,1\}$ judges
whether $\tau$ solves $x$.

\begin{definition}[Budgeted few-shot agent specialization]
\label{def:setting}
Given a support set $\mathcal{S}=\{x_i\}_{i=1}^{N}$ of queries drawn
from a task distribution $\mathcal{D}$, a small student policy
$\pi_{\theta_0}$, and query access to a stronger black-box teacher
policy $\pi_\phi$ billed per emitted token under a budget $B$, we
aim to adapt the student so that the resulting agent maximizes task
performance on a disjoint query set from $\mathcal{D}$,
\[
\max_{\theta}\;
\mathbb{E}_{x\sim\mathcal{D}}\,
\mathbb{E}_{\tau\sim\pi_\theta(\cdot\mid x)}\bigl[V(x,\tau)\bigr]
\qquad\text{subject to}\qquad
\textstyle\sum_{q\in\mathcal{A}}c(q)\le B,
\]
where $\mathcal{A}$ is the set of teacher requests purchased during
training and $c(q)$ their token cost. Every teacher call is charged,
including completions that fail verification.
\end{definition}

The teacher exposes text only: for a state $s$ (task prompt plus the
history executed so far) it returns a continuation $y$ drawn from an
unknown distribution $\nu_T(\cdot\mid s)$, at a cost per emitted
token, with no logits, hidden states, or gradients. The student, in
contrast, exposes its full distribution $\pi_\theta(\cdot\mid s)$ over
complete actions $y$. The conventional approach uses a purchased
completion directly as an imitation target, which moves the student
toward $\nu_T$ wholesale: the update cannot tell which of the
student's existing behaviors should be replaced by the teacher's and
which should be kept. Our method, \emph{return-targeted distillation}
(RTD), keeps the teacher's text as supervision but installs it through
a \emph{legal probability transfer} whose teacher mass is fixed per
state and whose \emph{replacement target} among the student's own
behaviors is chosen by the realized learning return of the student
update. Three coupled decisions follow, what to buy, how to use it,
and when to stop, and Sections~\ref{sec:acquire}--\ref{sec:behavior}
treat them in turn. Before training we partition
$\mathcal{S}=\mathcal{S}_d\cup\mathcal{S}_c$; only $\mathcal{S}_d$
enters acquisition and optimization, and $\mathcal{S}_c$ is held out
for certification after the student is frozen. Within
$\mathcal{S}_d$ the support tasks are split into two folds that
rotate between rounds: an \emph{inner} fold that supplies states for
supervision and a \emph{feedback} fold that supplies only task
returns and never enters a gradient.

\subsection{Task-aware teacher acquisition}\label{sec:atoms}
\label{sec:acquire}

Teacher supervision is bought as \emph{request packages}
$q=(s,L,\bar c,\kappa)$, a state, a length cap, a public cost bound,
and a category; the teacher's response and its true cost are revealed
only after payment. In the sealed-replay protocol used here the pool
of candidate packages, their responses, and their recorded costs are
frozen in advance, the selector sees only the public view, and a hard
ledger charges the recorded cost at reveal time, so that a purchased
failure costs exactly what it cost the teacher to produce. Purchases
happen in \emph{decision windows}, at most $K$ packages per window
under the remaining authorization $B_t$, and the budget is a cap
rather than a prescribed expenditure.

\paragraph{Value of evidence as marginal gain of the joint update.}
Because purchased evidence is consumed by one student update together
with everything already owned, a package is valued by how much it
improves what the whole evidence set can achieve in the shared update
space, not by an independent insertion score. For an evidence set
$\mathcal{E}$ let $\theta_{\mathcal{E}}(0)$ be the one-step update on
$\mathcal{E}$ without source selection (Section~\ref{sec:distill}),
$\theta_{\mathrm{ref}}$ a common reference point, and
$\Delta_{\mathcal{E}}(d)=\theta_{\mathcal{E}}(0)-\theta_{\mathrm{ref}}
+\sum_i d_i v_i$ the full update including the selective term. With
the return gradient $\hat g_J$ estimated once at the reference point,
the surrogate
\[
\hat F(\mathcal{E})
=\max_{d}\Bigl[\hat g_J^{\top}\Delta_{\mathcal{E}}(d)
-\tfrac{\lambda}{2}\,\|\Delta_{\mathcal{E}}(d)\|_H^2
-\textstyle\sum_i\hat\varepsilon_i|d_i|\Bigr]
\]
is exactly the source-selection objective of
Section~\ref{sec:distill} on the full set, and on a reduced set it
also accounts for the teacher injection that would be lost, so that
uniform teacher supervision keeps its value even where selective
replacement contributes nothing. The surrogate marginal value of an
owned package is
$\hat V(q\mid\mathcal{E})=\hat F(\mathcal{E})-\hat F(\mathcal{E}\setminus\{q\})$,
where the removed package's exposure units are back-filled with
predetermined old-pool evidence so that all other weights are
unchanged; all comparisons share one reference point and one return
gradient, and no candidate is ever evaluated in the environment.

\paragraph{Pre-purchase posterior and batch purchase.}
Unpurchased responses are invisible, so a persistent posterior maps
pre-purchase information to surrogate marginal values: the package's
public features together with the current training context available
before purchase (round and step, a summary of the owned set, the
current injection profile, and the age of the last return feedback),
with strong shrinkage while predictive power is low. Realized paired
gains, the measured return difference between two independently
executed updates on a different feedback batch, are journaled only to
validate the surrogate and never feed the posterior that chose it.
Each window solves a budgeted batch selection under
$\sum_q\hat c(q)\le B_t$ and $|\mathcal{A}_t|\le K$, then executes it
through the ledger in a fixed deterministic order, reserving at the
public cap, revealing and settling at the recorded cost, and building
the training batch only from what was actually acquired. The control
arm replaces the posterior by a random draw under the same budget,
cap, and cost model.

\subsection{Teacher-scaffolded student exploration}\label{sec:explore}

Supervision is organized in \emph{exposure units}. One unit is one
state's teacher record together with two \emph{source actions}
$Y_1,Y_2$ drawn fresh from the student snapshot $p_t$ frozen at the
start of the round; a commit step trains on $E$ units (so $2E$ source
actions), at most $K$ of them from newly acquired packages and the
rest from the accumulated pool, in micro-batches of four states. The
source actions are the student's own behaviors at the supervised
state, sampled at temperature one and never cached across steps, and
they are what the transfer of Section~\ref{sec:distill} can keep or
replace. Two quantities are fixed \emph{before} the sources are
sampled and frozen for the step: the evidence weight $w_i$ of each
unit ($\sum_i w_i=1$) and the \emph{injection}
$\alpha_i=\alpha(s_i)=\sigma(\phi\cdot\chi(s_i))\in[0,1]$, how much
teacher mass the state receives, produced by a gate over
state-only features $\chi(s)$ that excludes anything about the
sampled actions. Freezing both before sampling is what keeps the
estimator below unbiased. Before any purchase the units are
reference-pool states without teacher evidence, for which
$\alpha_i=0$ and only the student's own distribution is preserved, so
training does not wait for the gate to be learned.

\subsection{Learning from student-provenance trajectories}\label{sec:distill}

\paragraph{Target distribution.}
For a unit with injection $\alpha$ and source actions $Y_1,Y_2$ we
define the \emph{source selection} $d=d(s,Y_1,Y_2)$ with
$|d|\le\min\{\alpha,1-\alpha\}$ and the target
\[
q=\tfrac{1-\alpha-d}{2}\,\delta_{Y_1}
+\tfrac{1-\alpha+d}{2}\,\delta_{Y_2}
+\alpha\,\nu_T(\cdot\mid s),
\]
a proper distribution whose teacher mass equals $\alpha$ for every
legal $d$. A positive $d$ replaces $Y_1$ more aggressively and keeps
$Y_2$; it never changes how much teacher supervision the state
receives. Neither $\alpha$ nor $d$ is tied to call errors, format
errors, or benchmark categories.

\paragraph{Estimator.}
Let $\bar G_{\mathrm{soft}}$ be the average over the two sampled
prefixes of the full-vocabulary soft source gradient (the
per-position KL between the frozen snapshot $p_t$ and the current
student), $G_T$ the gradient of the teacher text's log-likelihood, and
$G_1,G_2$ the log-likelihood gradients of the two hard samples. The
unit's update direction is
\[
\hat g_d=(1-\alpha)\,\bar G_{\mathrm{soft}}+\alpha\,G_T
-\tfrac{d}{2}\,(G_1-G_2).
\]
The first term preserves the student's own distribution and is
exactly zero at $\pi_\theta=p_t$, the second installs the teacher
behavior, and the third decides which student behavior gives way.
Because $\alpha$ and $w_i$ are fixed before sampling, $\hat g_d$ is an
unbiased estimate of the gradient toward $q$ even though $d$ depends
on both samples, and writing $G_k=u(s)+e_k$ shows that the component
$u(s)$ shared by the two behaviors cancels algebraically in
$G_1-G_2$, so the selective term acts on the difference between the
two behaviors rather than on the task dialect they share. The
selective term is re-estimated from fresh sources at every step and is
never stored as a negative-weight target.

\paragraph{Choosing the replacement by the learning return.}
On the \emph{same batch} of evidence, weights, injections, and source
samples, define the virtual reference student without source
selection and the selected student,
\[
\theta_S(0)=\theta-\eta\,P\sum_i w_i\bigl[(1-\alpha_i)\bar G_{\mathrm{soft},i}
+\alpha_i G_{T,i}\bigr],
\qquad
\theta_S(d)=\theta_S(0)+\sum_i d_i v_i,\quad
v_i=\tfrac{\eta w_i}{2}\,P\,(G_{i1}-G_{i2}),
\]
with $P$ the optimizer preconditioner; the only difference between
the two is $d$. Let $J(\theta)$ be the expected task return of the
temperature-one policy executed from the task start on the feedback
fold, and $z_i=\nabla J(\theta_S(0))^{\top}v_i$ the learning response
of unit $i$. Under local smoothness of the update path, a single
selection satisfies
$J(\theta_S(d))-J(\theta_S(0))\ge d\,z-\tfrac{L_H}{2}d^2\|v\|_H^2$,
so at equal teacher mass a small selective transfer beats the uniform
one whenever the two student behaviors respond differently. The
return gradient is noisy and $L_H$ unknown, so we do not claim
monotone improvement; instead the selection is the solution of a
local surrogate problem over all units of the step,
\[
d^{\star}=\arg\max_{|d_i|\le\min\{\alpha_i,1-\alpha_i\}}
\hat z^{\top}d-\tfrac{\lambda}{2}\,d^{\top}Kd
-\textstyle\sum_i\hat\varepsilon_i|d_i|,
\qquad K_{ij}=v_i^{\top}Hv_j,
\]
where $\hat z$ is estimated from temperature-one rollouts at
$\theta_S(0)$, $\hat\varepsilon_i$ is the standard error of $\hat z_i$
along $v_i$ from the same rollouts, $H$ is the inverse of the diagonal
preconditioner, and $K$ is normalized by its mean diagonal so that
$\lambda$ is scale free. The quadratic term is the interaction between
units: two directions that push the same way consume the update
space without proportional return. Shrinkage to $d_i=0$ is a property
of the joint problem, whose interior zero condition
$|\hat z_i-\lambda\sum_{j\ne i}K_{ij}d_j|\le\hat\varepsilon_i$ involves
the other coordinates, and no coordinate is pre-filtered by its raw
$\hat z_i$. The return gradient only sets the distillation target: the
backbone receives the distillation update $\theta_S(d^\star)$ and no
reinforcement step. The gate parameters $\phi$ are updated in a
blocked step from the return measured at $\theta_S(d^\star)$ with
$d^\star$ held fixed, and $\alpha$ and $d$ receive no gradient at
commit time.

\subsection{Training and deployment}\label{sec:behavior}

\paragraph{Training loop and stopping.}
Training proceeds in budget rounds; each round is twelve commit steps
with four decision windows at which packages may be purchased, and
the authorization at the end of a round is a fixed fraction of the
budget denominator. A decision window follows a fixed order: purchase
and reveal with the historical posterior; freeze the batch, the
weights, the injections, and the source samples; build $\theta_S(0)$
on that batch; estimate the return gradient at $\theta_S(0)$ and solve
$d^\star$; commit $\theta_S(d^\star)$ on the same batch and then update
the gate from the return at $\theta_S(d^\star)$. The acquisition
reference point and the selection reference point are journaled
separately and never substituted for one another. Between decision
windows the return gradient is reused, source directions and
$\hat\varepsilon$ are recomputed along the new $v_i$ at every step,
and the age of the feedback is recorded. Acquisition stopping and
training stopping are distinct: a window may buy nothing and train on
the accumulated pool, and exhausting the authorization never ends
learning. At the end of each round the current student is exported and
evaluated under the benchmark's official protocol as a development
result.

\paragraph{Deployment.}
The trained student is deployed alone under the benchmark's official
decoding, with the same harness, tools, and prompts as every
baseline; no teacher context or teacher call is required at test
time. The calibration split $\mathcal{S}_c$ is reserved for
certification, that is, bootstrap bounds on held-out data computed
after the student is frozen, and is never used during training.
