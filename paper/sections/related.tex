\section{Related work}\label{sec:related}
%% Structure per PI: (1) how task boundaries are determined today,
%% (2) how LLM agents are distilled today, (3) the gap that defines our

\paragraph{Determining task boundaries.}
When a served model must decide whether a request is in scope, current
practice draws the boundary in input space. Conformal methods calibrate
acceptance thresholds with finite-sample guarantees
\citep{vovk2005algorithmic, gibbs2025conditional}, and SCOPE applies such
gates to hidden activations to reject out-of-distribution requests at
serving time \citep{li2026scope}. The learnware line attaches
capability specifications to a pool of specialists so that tasks can be
routed to a matching model \citep{tan2025learnware}. In all of these, the
boundary is defined over surface representations of the query, or over a
pre-existing model pool, and it is decoupled from how the served model was
trained. Surface representations fail structurally in our setting: two
tasks can share identical query text while demanding different skills
(Section~\ref{sec:boundary}), and a serving-time gate cannot make the
student's competence stop where the boundary stops.

\paragraph{Distilling LLM agents.}
Agent distillation transfers tool-use trajectories from a large teacher to
a small student: with retrieval and code tools \citep{kang2025distilling},
with segment-specific losses over reasoning and action spans
\citep{liu2025structured}, or with trajectories selected for compatibility
with student capacity \citep{tang2026smartad}. These methods take a fixed
training set as given and maximize aggregate benchmark scores. None takes a
task specification as input, none reports what the student can or cannot do
relative to an intended domain, and capacity alignment concerns what the
student can absorb rather than what the deployment requires.

\paragraph{The gap we address.}
The two lines do not meet: boundary methods do not shape training, and
distillation methods do not know their boundary. The raw material for a
bridge exists in gradient-based analysis, where sketched gradients select
influential data \citep{xia2024less, hu2022lora}, predict per-example
behavior \citep{park2023trak}, and expose behavior clusters through sparse
decomposition \citep{rosser2026gradient}. These tools have been used to
diagnose models or to serve fixed validation sets. We use the same geometry
as the specification itself: a conformally calibrated task region estimated
from $k$ examples that simultaneously defines the boundary, predicts the
student's capability, and selects the distillation data, so that the
guarantee and the student are trained into agreement rather than assembled
afterwards.
