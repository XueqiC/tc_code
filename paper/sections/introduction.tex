Enterprises increasingly deploy language-model agents for narrow,
recurring jobs, such as operating a fixed set of applications,
handling customer requests over database-backed tools, or automating
one workflow \citep{yao2023react, trivedi2024appworld, yao2024taubench,
shridhar2021alfworld}. Serving a frontier model for a single narrow
job is rarely economical, so practice converges on specializing a
small student for that job. What the deployer actually has is a few
dozen example queries from the intended workload, a task-level check
of whether an attempt succeeded, and metered query access to a strong
commercial teacher whose weights and logits are out of reach and whose
every emitted token is billed. The question this paper studies is how
to convert a limited teacher budget into the largest possible gain in
task success for the small student.

The standard answer is imitation. One purchases teacher
demonstrations and trains the student to reproduce them, a recipe that
underlies sequence-level knowledge distillation and its agentic
refinements \citep{kim2016sequence, mukherjee2023orca,
liu2025structured, kang2025distilling}. We find that on a modern agent
benchmark this recipe does not merely underperform, it moves the
student backwards. Across seven current distillation baselines
spanning the labeling, feedback, self-knowledge, and on-policy
branches of the field's taxonomy \citep{xu2024kdsurvey}, every method
that uses teacher tokens as training targets ends below the untrained
student, and the effect is invariant to data selection, student
scale, and data volume. The mechanism is visible in the update
itself. Maximum-likelihood training on teacher trajectories descends
the gradient of the divergence between teacher and student behavior
distributions, so it conflates task-relevant capability transfer with
changes that merely make the student write like the teacher. The
task-extraneous component of this update can offset useful transfer,
and we find that its measured magnitude predicts the degradation. The same training also
erodes abilities the student already had, which we observe directly
as a drop in generic function-calling accuracy on an unrelated
benchmark.

Two further observations point to the way out. The student trained on
its own verified successes loses nothing, and the student shown a
teacher demonstration in its context, rather than as a target, solves
an order of magnitude more tasks than it can solve unaided. Together
they suggest that teacher behavior is valuable as guidance and harmful
as a target. We therefore propose budgeted verifier-guided
self-distillation with teacher context scaffolding. The procedure is
one loop. It estimates the student's remaining task deficit, buys
teacher guidance only where that deficit is large and guidance is
expected to unlock success, lets the student explore by itself and
under the purchased guidance, verifies the student's own trajectories,
updates the student on nothing but that verified self-generated
behavior, and re-prices all remaining guidance under the improved
student. As competence grows, queries stop invoking guidance and
further purchases stop paying for themselves, so the loop approaches
ordinary on-policy self-improvement and the budget is an upper bound
rather than an amount to be spent. After training, a held-out split of
the support set calibrates a conformal task boundary, and the
specialist serves only queries inside it.

Our contributions are as follows. First, a new problem. Budgeted
few-shot agent specialization asks, given only a few-shot description
of an agent task and a budget on a per-token billed black-box
teacher, for a small model that maximizes task performance. The
budget is the single constraint and held-out task performance the
single criterion; no prior work studies this combination. Second, a new method built on a mechanism
we identify and measure. Teacher-target maximum likelihood moves a
small agent toward the teacher behavior distribution as a whole, and
we quantify the task-extraneous component of this update with a
projection diagnostic; budgeted verifier-guided self-distillation
avoids it by purchasing teacher tokens only as exploration
interventions priced by the task-relevant self-supervision they are
expected to unlock, so teacher outputs never become optimization
targets. Third, results. Under matched budgets across agent
benchmarks, with separate acquisition-controlled and
training-controlled comparisons, the proposed supervision channel is
the only one that improves the base student, guided self-generation
raises the verified solution rate by an order of magnitude, and a
calibrated task-scope boundary provides an additional deployment
