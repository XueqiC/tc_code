## 6. 控制器升级(已合并主干)

默认仍是严格逐 token 蒸馏 p。两步:(1) 有限幅度候选 v = argmax ûᵀ(w−p) s.t. KL(w‖p) ≤ ρ,由 w_i(β) ∝ p_i exp(û_i/β) 上一维搜 β 得到
(ρ 默认 0.05,同报 0.01/0.2);(2) w(α) = (1−α)p + αv,α* = argmax_{0≤α≤α_max}[α(ĝ − κσ̂) − (c/2)α²],ĝ、σ̂ 来自独立的另一半反馈;
α* = 0 是一等结果。反馈设计:固定非零温度、uniform 或"信息量"采样(μ/q 权重,上界 2)、总量上限 64。
在旧证据(react7 银行 922 段,v1 反馈)上:ρ=0.05 有效片段 782,α* A→B 0 / B→A 0.003 / pooled 0 → 默认蒸馏;
与旧 softmax(β=0.01,w_max=1)对比,新控制器既不塌缩也不押注。文档 `docs/hotpotqa_weight_controller.md`。

2. **投影与直接检验反号**:Û 由 3 个有对比的父任务决定(其余 13 个贡献为零),本质上是 3 父任务估计;δ 的范数 ≈ 0.13,
   ‖ĥ‖ ≈ 273,Û 的量级(−1.3 / −4.3)相对其 bootstrap 区间很小。共享反馈作为"低成本评价多个更新"的工具,当前信息量不足以复现直接检验的方向。
3. **候选来源**:v 由已被线性化检查否定的估计器提出,本检验只能说"这份候选没有得到支持",不能说自适应分配无价值。
4. **置换与候选相当**:两者相对默认的直接差都在 1 SE 内、彼此差 −0.03 ± 0.06——与昨夜五臂里 MECH−PERM = +0.8(噪声内)一致。
