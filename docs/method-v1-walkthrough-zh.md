# 方法 v1:一次完整运行的流水账(按执行顺序,k=50, b=20000)

## 先定义会用到的概念(只有 3 个是我们自己的,其余全是标准方法)

- **梯度特征(gradient feature)**:把一条训练样例(query + teacher 的
  示范回答)喂给学生模型,做一次前向传播和反向传播但**不更新参数**,
  把得到的梯度(限 LoRA 低秩适配器的 B 矩阵部分)拼接、随机投影降维、
  归一化后得到的向量。含义:这条样例如果拿来训练,会把学生参数往
  哪个方向推——即"这条样例会教什么"。这是 LESS(Xia et al., 2024)
  等数据选择工作的标准做法。
- **稀疏字典学习(sparse dictionary learning)**:经典的信号分解方法:
  给定一组向量,学出少数几个"基向量",使每个原向量都能近似写成
  这些基向量的**稀疏**线性组合(大多数系数为零)。我们直接用
  scikit-learn 的 MiniBatchDictionaryLearning。一个向量在各基向量上
  的系数叫它的**编码(code)**。
- **【定义 1】capability atom**:对 k 条 support 样例的梯度特征做稀疏
  字典学习,得到的**每一个基向量**称为一个 capability atom。它是
  多条 query 共享的一个梯度方向,解释为完成该任务所需的一种可复用
  的底层技能。(论文中 Definition 1。)
- **【定义 2】任务需求(task demand)w**:k 条 support 样例的编码
  (取绝对值)的均值向量,归一化后表示"该任务由哪些 atom 构成、
  各占多大比重"。(论文中 Definition 2。)
- **核岭回归(kernel ridge regression)**:标准回归方法,下文用它从
  "题面的梯度特征"预测"回答的梯度特征"(因为付费前看不到回答)。
- **投影残差分数**:把一个向量投影到一个子空间后,剩余部分的范数。
  分数越小 = 越像子空间所代表的分布。conformal prediction 里的
  标准打分方式。

## 开局手里有什么

50 条 query 和它们的 teacher 示范(support set,设定给的,不花钱);
计费 teacher 的 API;没动过的 2B 学生;20000 token 预算。

---

**第 1 步:劈分 support。** 50 条固定劈成 35(fit)+ 15(cal)。
fit 用于一切拟合;cal 只用于定阈值和做探针,绝不参与拟合(防泄漏)。

**第 2 步:算 50 条梯度特征。** 每条 (query, 示范) 算两个梯度特征。
举例:query =「Janet 的鸭子每天下 16 个蛋,她早餐吃 3 个……剩下的每个
卖 2 美元,她每天赚多少?」,teacher 示范 = 一段 `def solution():`
代码。**响应视角**特征 = 只对示范代码部分的 token 计算损失再反传得到
的梯度——携带「这条例子教学生怎么解」的信息(乘法、扣减、汇总这些
技能都在解法里),后面技能记账用它。**题面视角**特征 = 只对题面文字
算的梯度——只携带「这是道什么类型的题」的信息;付费前恰好只能看到
题面,所以后面的验收门用它。

**第 3 步:学字典、开配额。** 对 50 条响应视角特征做稀疏字典学习
(基向量个数 = min(64, 样例数/2),稀疏系数 α=0.05)→ 得到
capability atoms(定义 1)。算任务需求 w(定义 2)。**每个 atom 的
token 配额 = w_a × 20000**:比如某 atom 占需求 21%,名下配额 4200
token。

**第 4 步:定验收阈值。** 目的:付费拿到新题后,验收「它是不是本
任务的题」。做法:拿 35 条 fit 的题面特征学出「本任务的题面长什么样」
(拟一个子空间);给留出的 15 条 cal 题面各打一个「离这个子空间多远」
的分;15 条真题里**离得最远那条 = 最不典型的真题**。验收规则一句话:
**新买的题,不能比最不典型的真题还不像本任务**。(松弛旋钮:阈值可
再放宽 s 个标准差——用覆盖余量把任务完整包裹,防 50 条 query 估出的
边界偏窄;s 从 0 往上扫就得到纯度-性能权衡曲线。)

**第 5 步(循环到预算花完):买一批。**
5a. 在 support + 已购样例上**重新做一遍字典学习**(数据多了,atom
    会更精细),重算需求;把已购样例的供给从配额里扣掉。供给 =
    该样例编码的原始幅度 ÷ 一个换算常数(= 已知在任务内的样例的
    平均编码幅度)。编码幅度**不做归一化**——稀疏编码给不相关样例
    的幅度天然就小,这本身是相关性信号,归一化会把它抹掉(我们
    实测过:抹掉后 97% 预算被浪费)。
5b. 用已付费的 (题面特征, 响应特征) 样本对拟合**核岭回归**
    (岭系数 λ=0.1·tr(K)/n):从题面预测响应特征。
5c. 对每个候选题面,用 5b 的回归预测其响应特征,再过字典得到
    **预测编码**(= 预测这条如果买来,会给各 atom 供多少货)。
5d. 打分:u(x) = Σ_a min(配额余量_a, 预测供给_a × t̂) / t̂,其中 t̂ 是
    已购样例的平均 token 数(首轮取 200)。u 的含义:按平均价格买
    这条,能填掉多少还没填的配额。按 u 从高到低下单;批内每下一单
    就把它的预测供给从工作配额里扣掉(否则一批相似题会重复计分);
    每轮最多 8 单。
5e. **验收**:付费拿到回答后做两个检查——(i) 回答里的代码真的能
    执行;(ii) 题面过第 4 步的阈值。不合格的样例不进训练语料
    (钱已花,记浪费),但会在第 6 步把余额重新花出去。

**第 6 步:花完余额。** 配额都填满但预算还有剩时,把余额买给
"过验收阈值且预测编码总幅度最高"的候选,直到花满。至此实购约
170-200 行,花掉 19990+/20000,浪费 2-4%。

*(实际流程里,第 5-6 步先只用一半预算 b/2 = 10000 跑完,给下面的
纠错回路留另一半。)*

**第 7 步:训练中间学生。** 用半预算买到的 ~110 行做标准 SFT:
轮数 = min(8, max(3, round(3b/实购token)))(语料少就多训几轮,
保持计算量可比),lr 2e-4,梯度累积 8。每行入选时按"编码最大的
那个 atom"打上归属标签,训练中把每行的损失记到它归属的 atom 名下
→ 免费得到**每个 atom 的损失曲线**(哪个技能学会了、哪个没学会,
全程可见)。

**第 8 步:找缺口。** 两个等效变体(选一):
- 让中间学生把种子题做一遍,代码执行判对错;错题的响应编码取均值
  = 缺口方向;
- 或者不做题,直接看第 7 步的曲线:"训练后 1/3 步的平均损失仍高于
  前 1/3 的 50%" 的 atom 算没学会,把任务需求限制在这些 atom 上
  = 缺口方向。(两版最终成绩等效,后者省一整轮学生生成。)

**第 9 步:按缺口买第二批(挑 + 造)。** 两个供给来源:
(a) **挑**:对剩余候选按 预测编码·缺口方向 从高到低买;
(b) **造**(atom 定向生成):对缺口 atom,取该 atom 编码最大的 3 条
support query 作范例,让 teacher 仿写新题并写出可执行的
`def solution()` 解答;执行验证通过才入库,生成和作答的 token 全部
计费。这一步突破候选池的质量上限——teacher 能按技能点单造货,
是大预算下超过 Self-Instruct 的关键供给。买满剩余预算为止
(全部过第 5e 验收)。

**第 10 步:训练最终学生。** 两批合并,从头标准 SFT(同第 7 步)。
训练全程每 8 步用 15 条 cal 测一次「生成的代码可运行比例」,记录
最优 checkpoint;训练结束时,**只有当最优 checkpoint 比最终状态好出
超过一道探针题(1/15)时才回滚**——真崩塌(小预算的失败模式)远超
这个余量会被救回,而大预算下最优与最终只差探针噪声、不触发回滚。
统一规则,不分预算档位。

**第 11 步:装边界、发证书。** 35 条 fit 的梯度特征拟合子空间
(保 90% 能量),15 条 cal 的投影残差分数排序取分位数(α=0.10)
= conformal 边界。部署时每个请求算特征、打分:界内 → 学生回答
(覆盖率有 Clopper-Pearson 统计下界);界外 → 拒答。

---

**数据流小结**:35 fit 只管拟合(字典、子空间、回归的初始样本对);
15 cal 只管定标(验收阈值、训练探针、conformal 分位数),从不参与
拟合;预算 b 在第 5-6 步花一半、第 9 步花另一半,探针和被拒样例
都计入 b;teacher 只在付费拿回答时被调用。
