# 方法 v1:完整流程(四个阶段,按执行顺序)

任务无关的通用叙述;示例仅为帮助理解。设定:support set S = k 条
query 及其 teacher 示范(不计费)+ 按 token 计费的 black-box teacher
+ 开源学生模型 + 预算 b。默认参数以 k=50, b=20000 为例。

## 概念定义(3 个自有概念,其余为标准方法)

- **梯度特征(gradient feature)**:把一条训练样例(query + teacher
  示范)喂给学生,做一次前向+反向传播但不更新参数,取梯度(限 LoRA
  适配器的低秩 B 矩阵)拼接、随机投影降维、归一化后的向量。含义:
  「这条样例如果拿来训练,会把学生参数往哪个方向推」。数据选择文献
  的标准做法(LESS, Xia et al. 2024)。每条样例算两个:**响应视角**
  (只对示范回答部分算损失;携带「教怎么做」的信息,技能记账用它)
  和**题面视角**(把题面文字本身当作预测目标:算学生在题面 token 上
  的下一词预测损失再反传——即「教学生生成这道题」的梯度,不需要任何
  teacher 回答;付费前只能看到题面,验收门用它)。
  例:query =「Janet 的鸭子每天下 16 个蛋…她每天赚多少?」,示范 =
  一段 `def solution():` 代码;响应视角特征在示范代码上算,题面视角
  特征在题干文字上算。
- **稀疏字典学习(sparse dictionary learning)**:经典信号分解:给定
  一组向量,学出少数基向量,使每个原向量 ≈ 基向量的稀疏线性组合。
  用 scikit-learn MiniBatchDictionaryLearning。向量在基向量上的系数
  称**编码(code)**,重构后剩余部分的范数称**重构残差**。
- **【定义 1】capability atom**:对 k 条 support 样例的响应视角梯度
  特征做稀疏字典学习得到的每个基向量。它是多条 query 共享的梯度
  方向,解释为任务所需的一种可复用技能。
- **【定义 2】任务需求 w**:k 条 support 编码(绝对值)的均值,
  归一化;表示任务由哪些 atom 构成、各占多少。
- **核岭回归**:标准回归;从题面特征预测响应特征(付费前看不到
  响应)。

---

## 阶段 I:技能提取与开账(只用 support,不花钱)

I-1. **劈分**:k 条固定劈成 70% fit + 30% cal(50 → 35+15)。fit 用于
     一切拟合;cal 只用于定阈值与探针,绝不参与拟合(防泄漏)。
I-2. **特征**:对每条 (query, 示范) 计算响应视角与题面视角梯度特征。
I-3. **字典与配额**:对 k 条响应视角特征做稀疏字典学习(基向量数 =
     min(64, k/2),稀疏系数 α=0.05)→ capability atoms(定义 1);
     任务需求 w(定义 2);**每 atom 的 token 配额 = w_a·b**。
I-4. **验收阈值(atom 原生)**:对 35 条 fit 的题面特征学一部小字典
     (同算法同参数);新题面的分数 = 稀疏重构残差 ‖x − D·code(x)‖。
     直觉:**任务边界 = 技能词汇能表达的范围**。给 15 条 cal 各算
     残差,**残差最大那条(最不典型的真题)= 验收阈值**:新买的题
     不能比它更不像本任务。可选松弛:阈值放宽 s 个标准差(覆盖余量
     包裹任务;s 扫出纯度-性能权衡曲线)。稀疏重构残差做新颖检测有
     成熟谱系,我们的新意 = 与技能字典统一为一个对象 + conformal
     校准;SVD 子空间版为消融对照。

## 阶段 II:预算采购(计费;先以 b/2 跑种子轮)

**初始化**:已购集 = ∅;账本 = 各 atom 配额;平均样例价 t̂ = 200。

II-1. **记账**:在 support + 已购上重新做字典学习(首轮即阶段 I 的
      字典;之后每轮新进样例让 atom 更精细),重算需求;把已购样例
      的供给(编码原始幅度 ÷ κ;κ = 已知任务内样例的平均编码幅度)
      从账本扣除。编码幅度不归一化——稀疏编码给不相关样例的幅度
      天然小,这是相关性信号(实测归一化会让 97% 预算被浪费)。
II-2. **预测**:用已付费的 (题面特征, 响应特征) 对拟合核岭回归
      (λ=0.1·tr(K)/n;首轮只有 k 条 support 对);对每个候选题面
      预测其响应特征 → 过字典 → **预测编码**(买它能给各 atom 供
      多少)。
II-3. **下单**:按 u(x)=Σ_a min(账本余量_a, 预测供给_a·t̂)/t̂ 从高到
      低买;批内每单即时从工作账本扣供给(防相似题重复计分);每轮
      至多 8 单;t̂ 更新为已购样例的平均 token 数。(简化版验证中:
      u'(x)=u(x)+η·每 token 编码总幅度,配额清空后 η 项自然接管
      余额购买,单公式无阶段切换。)
II-4. **验收**:回货过两关——示范可执行 + 题面分数过 I-4 阈值;
      不合格不入语料(钱记浪费,余额在 II-5 重花)。
II-5. **循环判断**:本轮预算未花完 → 回到 II-1;配额已清而预算有余
      → 按「过验收且每 token 编码总幅度最高」把余额花完,种子轮
      结束。
II-6. **缺口探测**:用种子轮语料训练**中间学生**(配方同阶段 III;
      训练中每行损失记入其归属 atom → 每 atom 损失曲线免费得到);
      缺口 = 「训练后 1/3 步均损 > 前 1/3 的 50%」的 atoms 上的
      需求(免 rollout 版,实验已定为默认;rollout 版——中间学生
      重做种子题、错题编码取均值——进消融表)。
II-7. **纠错轮**:以剩余 b/2 为预算重复 II-1~II-5,但排序改为
      预测编码·缺口方向;供给**挑为主、造补缺**:仅当某缺口 atom
      在剩余候选中的预测供给不足时,才让 teacher 照该 atom 编码
      最高的 3 条 support 仿写新题并作答(生成+作答计费,执行验证
      后入库);挑与造进同一排序统一购买。「造」突破候选池上限,
      是大预算下的关键供给来源。

## 阶段 III:蒸馏训练

全部购得样例合并,从头标准 SFT:轮数 = min(8, max(3, round(3b/实购
token)))(语料少多训几轮,计算量可比),lr 2e-4,梯度累积 8,**无
样例加权**(实验判定:在验证过的任务内语料上加权无增益)。全程每
8 步用 15 条 cal 测「生成可运行比例」,记录最优 checkpoint;结束时
**仅当最优比最终好出超过一道探针题(1/cal 条数)才回滚**——真崩塌
远超此余量会被救回,正常训练的探针噪声不触发回滚。统一规则,不分
预算档位。

## 阶段 IV:边界与证书(部署)

与 I-4 同机制、换输入:任务字典(阶段 I 在响应视角上学的那部)对
请求特征做稀疏重构,残差 = 边界分数;15 条 cal 的残差取分位数
(α=0.10)= conformal 边界。部署时请求界内 → 学生作答(覆盖率有
Clopper-Pearson 下界);界外 → 拒答。**同一部字典的六个角色至此
闭环:定义技能 → 记账需求 → 预测供给 → 观测吸收 → 命名缺口 →
划定边界。**

---

**数据流小结**:fit(70%)只管拟合;cal(30%)只管定标(阈值、
探针、分位数),从不参与拟合;预算 b 由种子轮与纠错轮各花一半,
探针与被拒样例均计费;teacher 只在付费取回答/生成新题时被调用。
