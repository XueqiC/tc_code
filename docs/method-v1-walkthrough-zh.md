# 方法 v1:学习流程(三个阶段,按执行顺序)

任务无关的通用叙述;示例仅为帮助理解。设定:support set S = k 条
query 及其 teacher 示范(不计费)+ 按 token 计费的 black-box teacher
+ 开源学生模型 + 预算 b。默认参数以 k=50, b=20000 为例。

## 概念定义(3 个自有概念,其余为标准方法)

- **梯度特征(gradient feature)**:把一条训练样例(query + teacher
  示范)喂给学生,做一次前向+反向传播但不更新参数,取梯度(限 LoRA
  适配器的低秩 B 矩阵)拼接、随机投影降维、归一化后的向量。含义:
  「这条样例如果拿来训练,会把学生参数往哪个方向推」。数据选择文献
  的标准做法(LESS, Xia et al. 2024)。每条样例算两个:**响应视角**
  (只对示范回答部分算损失;携带「教怎么做」的信息,技能记账用它)
  和**题面视角**(把题面文字本身当作预测目标:算学生在题面 token 上
  的下一词预测损失再反传——即「教学生生成这道题」的梯度,不需要任何
  teacher 回答;计费前只能看到题面,任务归属过滤用它)。
  例:query =「Janet 的鸭子每天下 16 个蛋…她每天赚多少?」,示范 =
  一段 `def solution():` 代码;响应视角特征在示范代码上算,题面视角
  特征在题干文字上算。
- **稀疏字典学习(sparse dictionary learning)**:经典信号分解:给定
  一组向量,学出少数基向量,使每个原向量 ≈ 基向量的稀疏线性组合。
  用 scikit-learn MiniBatchDictionaryLearning。向量在基向量上的系数
  称**编码(code)**,重构后剩余部分的范数称**重构残差**。
- **【定义 1】capability atom**:对 k 条 support 样例的响应视角梯度
  特征做稀疏字典学习得到的每个基向量。它是多条 query 共享的梯度
  方向,解释为任务所需的一种可复用技能。
- **【定义 2】任务需求 w**:k 条 support 编码(绝对值)的均值,
  归一化;表示任务由哪些 atom 构成、各占多少。
- **核岭回归**:标准回归;从题面特征预测响应特征(付费前看不到
  响应)。

## 阶段 I:技能提取与预算分配(只用 support,不消耗预算)

I-1. **劈分**:k 条固定劈成 70% fit + 30% cal(50 → 35+15)。fit 用于
     一切拟合;cal 只用于定阈值与探针,绝不参与拟合(防泄漏)。
I-2. **特征**:对每条 (query, 示范) 计算响应视角与题面视角梯度特征。
I-3. **字典与预算分配**:对 k 条响应视角特征做稀疏字典学习(基向量数 =
     min(64, k/2),稀疏系数 α=0.05)→ capability atoms(定义 1);
     任务需求 w(定义 2);**每个 atom 分得的 token 预算 = w_a·b**(budget allocation)。
I-4. **任务归属过滤的阈值(atom 原生)**:对 35 条 fit 的题面特征学一部小字典
     (同算法同参数);新题面的分数 = 稀疏重构残差 ‖x − D·code(x)‖。
     直觉:**任务边界 = 技能词汇能表达的范围**。给 15 条 cal 各算
     残差,**残差最大那条(最不典型的真题)= 过滤阈值**:新获取的题
     不能比它更不像本任务。可选松弛:阈值放宽 s 个标准差(覆盖余量
     包裹任务;s 扫出纯度-性能权衡曲线)。稀疏重构残差做新颖检测有
     成熟谱系,我们的新意 = 与技能字典统一为一个对象 + conformal
     校准;SVD 子空间版为消融对照。

## 阶段 II:数据获取(data acquisition;计费,先以 b/2 跑初始轮)

**初始化**:已获取集 = ∅;剩余需求向量 = 各 atom 的预算份额;平均样例开销 t̂ = 200 token。

II-1. **更新剩余需求**:在 support + 已获取样例上重新做字典学习
      (首轮即阶段 I 的字典;之后每轮新样例让 atom 更精细),重算
      需求;把已获取样例的贡献(编码原始幅度 ÷ κ;κ = 已知任务内
      样例的平均编码幅度)从剩余需求中减去。编码幅度不归一化——稀疏编码给不相关样例的幅度
      天然小,这是相关性信号(实测归一化会让 97% 预算被浪费)。
II-2. **预测候选贡献**:用已获取的 (题面特征, 响应特征) 对拟合核岭回归
      (λ=0.1·tr(K)/n;首轮只有 k 条 support 对);对每个候选题面
      预测其响应特征 → 过字典 → **预测编码**(选它能为各 atom 的剩余
      需求贡献多少)。
II-3. **选取并查询 teacher**:按效用 u(x)=Σ_a min(剩余需求_a,
      预测贡献_a·t̂)/t̂ 从高到低选取候选、向 teacher 查询其示范
      (计费);批内每选一条即从工作需求向量中减去其预测贡献
      (防相似样例重复计分);每轮至多 8 条;t̂ 更新为已获取样例的
      平均 token 数。(简化版验证中:u'(x)=u(x)+η·每 token 编码总幅度,剩余需求清零
      后 η 项自然接管,单公式无阶段切换。)
II-4. **质量与归属过滤**:取回的示范过两道过滤——执行检查(代码
      可运行)+ 题面残差过 I-4 阈值(任务归属);未通过的不入训练
      集(开销计入浪费,预算在 II-5 继续分配)。
II-5. **循环判断**:本轮预算未用尽 → 回到 II-1;剩余需求已清零而
      预算有余 → 按「通过过滤且每 token 编码总幅度最高」继续选取,
      预算用尽后初始轮结束。
II-6. **缺口估计**:用初始轮数据训练**中间学生**(配方同阶段 III;
      训练中每行损失记入其归属 atom → 每 atom 损失曲线免费得到);
      缺口 = 「训练后 1/3 步均损 > 前 1/3 的 50%」的 atoms 上的
      需求(免 rollout 版,实验已定为默认;rollout 版——中间学生重做初始轮的题、错题编码取均值——进消融
      表)。
II-7. **纠错获取轮**:以剩余 b/2 为预算重复 II-1~II-5,但排序改为
      预测编码·缺口方向;**选取为主、定向生成补缺**:仅当某缺口
      atom 在剩余候选中的预测贡献不足时,才让 teacher 参照该 atom
      编码最高的 3 条 support 生成新题并作答(生成与作答均计费,
      执行验证后入集);选取与生成的样例进同一排序统一获取。定向
      生成突破候选集的上限,是大预算下的关键增益来源。

## 阶段 III:蒸馏训练

两轮获取的样例合并,从头标准 SFT:轮数 = min(8, max(3, round(3b/实际
token)))(语料少多训几轮,计算量可比),lr 2e-4,梯度累积 8,**无
样例加权**(实验判定:在验证过的任务内语料上加权无增益)。全程每
8 步用 15 条 cal 测「生成可运行比例」,记录最优 checkpoint;结束时
**仅当最优比最终好出超过一道探针题(1/cal 条数)才回滚**——真崩塌
远超此余量会被救回,正常训练的探针噪声不触发回滚。统一规则,不分
预算档位。

---

*(学习流程到阶段 III 为止。学成的学生连同题面字典可选配一个
conformal 部署门——界外请求拒答、界内覆盖率有统计下界——那属于
部署配置,不在学习 pipeline 内,论文中单独一小节。)*

**数据流小结**:fit(70%)只用于拟合;cal(30%)只用于定标(阈值、
探针、分位数),从不参与拟合;预算 b 由初始轮与纠错轮各占一半,
探针与被过滤样例均计费;teacher 只在取示范/生成新题时被调用计费。
