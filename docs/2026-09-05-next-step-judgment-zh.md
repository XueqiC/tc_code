# 下一步判断:从"原子分解"转到"边界模式约束蒸馏"(2026-09-05 12:20)

对照 docs/2026-09-05-capability-atoms-merged-plan-zh.md §3 的六条理论结果和 9/3–9/5 的全部证据:

| 2 稀疏实现(极点 ≤ \|R\|+1 条示范) | LP 只找到 1 个零损伤正向源 | 无法在 0/1 探针下检验 |

## 2. 把三个 benchmark 的负结果读成同一件事

- BFCL:镜像蒸馏在竞争力 base 上塌(24.0/35.5/44.7),gentle 靠信任域止塌但边界反漂到过度调用(Irrel 62);P2 里 24 个单源更新的损伤全是弃答探针翻成调用。→ 损伤模式 = **调用/弃答边界**。
- ALFWorld:单事件更新 98.6% 正、rank-1 0.997,列效应 = 老师命令在基座下的概率;更新教的是"用 ACTION 命令作答而不是 256 token 的 think"。→ 损伤/收益模式 = **作答格式**。
- AppWorld:CE 在任何剂量、任何阶段覆盖下都塌成循环(0–3/57),pairwise 不塌。→ 损伤模式 = **REPL 循环/终止边界**。
- 9/3:CE vs pairwise 由"是否存在可被覆盖的胜任策略"决定;自适应锚点 Pareto;dU 用于选择不用于加权。

共同点:每个 benchmark 里小预算蒸馏的主要失效都是**一个**行为边界模式被更新幅度推过头;它是学生侧可测的(不花 teacher token)、由幅度预测、秩 1。这就是用户要的"跨 benchmark 都 work 的概念"——但内容是"一个模式 + 幅度",不是"一组原子"。

## 3. 下一步:G4 型蒸馏对照,以边界模式约束为处理

**主张(可证伪)**:显式估计每个 benchmark 的边界模式 u₀,在训练中限制沿 u₀ 的分量(理论结果 5 的退化闭式:投影 + 幅度上限),在匹配损伤预算下优于全局 KL/降 lr,并且能让本来会塌的目标(BFCL 镜像、AppWorld CE)不塌。

三步,单种子,全部三个 benchmark,hpg dept + rai 并行:

1. **估计 u₀(0 teacher token,测量层,~1 天)**
   - BFCL:P2 的 24 个 δ 已存,取损伤加权的第一主方向(等价于 B0-norm 的公共方向),核对它与 gentle 臂反漂方向的余弦。
   - ALFWorld:120 行矩阵已存,u₀ = 更新方向的总均值方向。
   - AppWorld:用 CE early 的更新减 base 的方向(已有 ckpt),核对 pairwise 更新在其上的分量小。
   - 判据:三者各自 rank-1 占比 > 0.9,且 u₀ 只用学生 rollout 就能估出(采购前可得)。
2. **干预对照(G4,每 benchmark 三臂)**
   - D0:现成最好目标(BFCL pairwise / ALFWorld CE / AppWorld pairwise-spread),已有。
   - D1:剂量匹配的全局约束(降 lr 或全局 KL),已有 lrmatch/gentle 可复用一部分。
   - D2:同一目标 + u₀ 分量投影/上限(Codex 实现:训练器里加一个 hook,K=1 的闭式 QP)。
   - 关键预测:BFCL gentle+D2 修 Irrel 不丢 NL;AppWorld CE+D2 不再循环(若成立,是比 pairwise-spread 更强的结果:CE 能用了);ALFWorld CE+D2 ≥ CE(77.9)。
   - 降级规则(§8 G4):D2 只在几乎不更新时接近 base,或 D0 降 lr 即可复现 → 归因稳定性,论文改为"受约束蒸馏 + 记账",原子/边界模式只作分析。
3. **连续边际探针(支撑,可与 2 并行)**:重建带 y^T/y^S 的探针,重评 24 源 × 32 探针似然(≈15 min B200),让理论 3/4 可检验,也给 D2 一个不依赖 0/1 的损伤度量。

不做:ALFWorld 的 P2 同协议复现(结果可预测:同一个模式,不增加信息);任何再拟合参数码的模型;加种子。

## 4. 对论文的含义

Novelty 从"能力原子 + 超可加采购"收缩为:(i) 小预算 agent 蒸馏的主要失效是单一行为边界模式被幅度推过头,跨三个 benchmark 同构、学生侧可测;(ii) 理论结果 5 给出在该模式上做投影/限幅的帕累托保证,4 给出剂量上界;(iii) 它解释并统一了 CE vs pairwise 的选择、镜像塌陷、自适应锚点;(iv) 采购侧保留"粗层可预测、细层不可"的结论,以后果优先 + frontier 选择替代超可加。诚实地放弃:互补示范、可命名原子、细粒度采购。
