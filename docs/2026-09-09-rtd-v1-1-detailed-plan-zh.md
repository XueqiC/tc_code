## 2. 蒸馏侧:来源保持项的改进(核心工作)

### 2.1 现状与理论
现来源项 = 每状态 2 个温度 1 自采样的硬 CE。期望意义上 E_{y∼p_t}[−log π_θ(y)] 在 π_θ=p_t 处梯度为零,不会自动放大错误;风险来自**用 2 个样本近似整分布再反复拟合**(样本偏差被放大,例如 10% 错误率的来源在两个样本中出现 1 个错就变成 50%)。这是可能机制,尚未证实主导;所以先做 §2.4 的嵌入式对照,不把"格式过滤"写进主方法。

### 2.2 固定门控 / 标量门控(V0、以及 R1s 型变体):软来源目标
L_src^soft = E_{Y∼p_t} Σ_j KL( p_t(·|s,Y_<j) ‖ π_θ(·|s,Y_<j) )
- 仍采样来源前缀(每状态 2 个),但每个前缀位置用**完整词表分布**(冻结来源快照 p_t 的 logits vs 当前学生 logits)。
- 可验证性质:π_θ = p_t 时每个前缀上的梯度恒为零(写成单元测试)。
- 实现:来源快照是同一 LoRA 基座的冻结权重;每槽两次 teacher-forced 前向(快照 + 当前),只在采样位置取 log_softmax,不存全词表张量;内存按 152k×序列长 流式累加。

### 2.3 完整 RTD 门控(V1/V2):控制变量估计
门控 a(s,Y) 与采样结果相关,不能直接换目标。用
ĝ_CV = (1−a) G_hard + a G_T − c_s (G_hard − G_soft),
- G_hard:来源硬样本 NLL 梯度;G_soft:同一前缀上的软分布交叉熵梯度;二者期望相等;
- c_s 用**独立来源样本或严格 leave-one-out** 估计(不与当前样本相关);标量门控取 c_s=1−a 时退化为 §2.2;
- 三条限定写进协议:方差是否下降必须实测;元梯度(门控 VJP)必须经过**新的**更新算子(不复用旧 VJP);一般形式只作刷新样本的梯度估计器,不把可能的负系数固定成多轮 signed-CE。
- 引用与定位:控制变量/条件积分是已有工具(Tucker et al. 2018 的教训:声称降方差必须核对实现与实测);我们证明的是它在来源传输目标里的具体作用,不把工具当 novelty。

### 2.4 嵌入首轮的来源项对照(不另设前置关口)
在**已购数据**上(v1.0 hpg R1 的 5 包 + 参考池),保持教师目标、门控、更新剂量与来源冻结周期不变,只换来源估计器:

| 对照 | 回答 |
|---|---|
| 原始 2 个硬来源样本 | 当前估计器的漂移有多大 |
| 软来源 / 控制变量估计 | 同一目标下能否降低扰动 |
| 8 个独立硬来源样本 | 改善是否符合"采样噪声"解释 |
| (诊断)语法过滤的硬样本 | 改善来自降噪还是额外语法监督 |

观测:梯度方差(同状态多次重采的梯度范数方差)、只做来源更新 12 步后的固定任务解析失败率、完整任务表现(官方 Overall,单点)。做在 V0 第 1 轮之前的同一 checkpoint 上,约 4–6 GPU·h(B200)。结果决定 V0/V1/V2 用哪种估计器(默认软/CV)。

## 3. 采购侧:批量决策 + 统一曝光

### 3.1 统一目标
每个决策窗口固定曝光槽 E=40:
L_S = (1 − |S|/E) L_D + (1/E) Σ_{q∈S} L_q,
最多 20 个新包,每包占一个曝光槽,其余由旧数据填充;买 0 包 = 继续训练已有证据(自然出现,不再机械地给每窗 50% empty)。
局部采购目标:max_S Σ_{q∈S} ṽ_q / E, s.t. Σ_{q∈S} ĉ_q ≤ B_t;由预测收益、预算、可用曝光共同决定购买数。
- 明确记录:联合更新的实际收益 vs 局部可加预测的误差(每窗一条)。
- 插入价值:共享参考回报梯度,按位置份额 1/E 计,与 §2 的新更新算子一致。

### 3.2 预算口径
- 分母 = recorded 内容成本 55,370 token,**明确标为"缓存内容成本实验"**,不称为完整在线 teacher-token budget;10/25/50% = 5,537 / 13,843 / 27,685。
- 每类 cap 按冻结 bank 内容认证(demo 2,048 / generator 512),**明确写成新的公开成本假设**(信息例外),selector 仍只见每类一个上界 + 总成本。
- 硬账本不变量(S+H ≤ C)、reserve/reveal/release 语义不变。

## 4. 价值模型:跨轮持续学习

- 保留跨轮价值后验与成本后验(去掉 begin_round 的重建);
- 每个价值标签保存来自反馈估计的不确定性(同一批完整任务 rollout 给多个已购包同时估插入价值及协方差,提高反馈利用率,但不假装降低统计噪声);
- 每轮用**已购参照包**重测学生变化造成的价值漂移;漂移 → 增大后验不确定性,不清空历史;
- "两组独立反馈估计"的可靠性测试只在**已购包或明确扣账的校准包**上做(对未购候选算真实 v_q 会打开封存池,不做);
- 成功标准不是"熵下降":价值不可靠时接近随机是合理行为;要验证的是可靠价值差异出现后决策是否随之改变(记录每窗价值差异的显著性与购买变化)。
