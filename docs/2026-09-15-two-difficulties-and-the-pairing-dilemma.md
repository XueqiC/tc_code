# 为什么"分数很低"和"材料不够难"同时成立
**——四格来源目标的两个任务、三种配法,与一个结构性两难**
2026-09-15 00:20 CDT。全部数字取自 LONI 作业日志与保存的逐对记录,零教师调用。
**本文先做了一次复核,纠正了我先前口头说法中的一处错误(见 §1.3)。**

---

## 0. 问题

自主答题的 EM 只有 **37.0%**,显然对模型很难;但我说"材料不够有挑战性"。
这两句话并不矛盾,因为**它们说的是两个不同的任务**,而这两个任务的难度**是脱钩的**。

---

## 1. 两个任务

### 1.1 任务一(我们真正想要的):自主执行
给一道多跳问题,模型自己决定查什么、读什么、何时结束。
**base 在 `dev_distractor_first500` 上 EM = 37.0%,完成率 67.2%。**
这是**生成/决策**任务:必须判断"手上缺什么信息、下一步该查什么"。

### 1.2 任务二(四格目标实际训练的):来源判别
给两个条件 h₁=(s₁,r₁)、h₂=(s₂,r₂) 与两个动作 a₁、a₂,判断哪个动作出自哪个条件。
训练信号是 B = (ℓ₁₁−ℓ₁₂) + (ℓ₂₂−ℓ₂₁);梯度 ∝ σ(−B/τ)。
这是**判别/匹配**任务。

### 1.3 实测:任务二对这个学生几乎没有难度

| 配法 | 对数 | B 最小 / 中位 / 最大 | margin 最小 / 中位 / 最大 | margin ≤ 0 | B ≤ 0 |
|---|---:|---|---|---:|---:|
| 随机跨父(§8.3 原方案) | 60 | 37.69 / **98.14** / 137.44 | 10.06 / 47.10 / 102.26 | **0 / 120** | 0 / 60 |
| 同父时序(progress) | 46 | 9.50 / **33.77** / 77.74 | **−10.57** / 15.16 / 52.14 | **3 / 92** | 0 / 46 |
| 按动作前状态相似跨父 | 126 | 33.15 / **94.39** / 143.41 | 9.90 / 44.92 / 104.27 | **0 / 252** | 0 / 126 |

**合计:单侧 margin ≤ 0 的只有 3 / 464;联合量 B ≤ 0 的是 0 / 232。**

> **更正**:我先前在频道里说过"三种配法下学生从来没有在来源判别上犯过错"。
> **这句话不准确** —— 同父配法里有 **3 / 92** 个单侧 margin ≤ 0(最低 −10.57)。
> 准确的说法是上面那两个比例。联合量 B 则确实一次都没有为负。

B 的量级意味着什么:B ≈ 94 时,学生给"原配对"的序列似然比"交换配对"高 e⁹⁴ 倍。
**它在任务二上基本不会错,于是 `softplus(−B/τ)` 在 τ=1 下下溢,梯度为零 —— 没有东西可学。**

**所以"材料不够难"指的是任务二不难,不是 benchmark 不难。**

## 2. 为什么两个难度会脱钩

两个任务要的能力不同:

| | 需要什么 | 可否走捷径 |
|---|---|---|
| **判别**"这个 `search[Edward Ellsberg]` 属于哪个条件" | 认出实体名/执行阶段/时序 | **可以**,表面线索就够 |
| **生成**"读完这条 observation,下一步该查什么" | 知道已获得什么、仍缺什么 | **不行**,必须真的决策 |

三次换配法,捷径也换了三次(以下是**假设**,§4 说明为何尚未被证明):
- **随机跨父**:两个条件来自毫不相关的两道题,动作里各自带着自己那道题的实体名 → 疑似**实体字面匹配**;
- **按状态相似跨父**:24 个 anchor 的动作前状态**完全同质**(全部"已做 1 次检索、0 次查词、收到 1 条 observation";
  22 个无失败检索),**阶段是常数,没有可匹配的维度**,于是仍然只剩内容差异 → B 中位 98.14 → 94.39,**几乎没动**;
- **同父时序**:h₂ 的历史里**已经包含 a₁ 及其 observation**,只要注意到"a₁ 已执行过"就能排除它 → 疑似**时序线索**。
  这是三种里唯一让 B 明显下降的(98 → 33.8),也是唯一出现负 margin 的。

---

## 3. 结构性两难:唯一有信号的那种配法,恰好是采样上不合法的那种

四格量作为**来源后验**的推导要求两个条件**事先固定、响应分别独立生成**:
p(a₁,a₂|h₁,h₂) = q(a₁|h₁)·q(a₂|h₂)。

| 配法 | 采样是否合法 | 是否有可学信号 |
|---|---|---|
| 随机跨父 | ✅ 合法(不同父任务、不同链,h₂ 不含 a₁) | ❌ 饱和(D1 损失>1e-6 仅 1/60,D2 0/60) |
| 按状态相似跨父 | ✅ 合法(同上) | ❌ 饱和(B 中位 94.39,无一 margin ≤ 0) |
| **同父时序(progress)** | ❌ **不合法**(h₂ 由 a₁ 执行后产生,条件独立分解不成立) | ⚠️ 有一些(D1 29/46,D2 4/46) |

**实测确认:46 个同父配对 100% 是 progress pair**(同链且右侧回合严格更晚;间隔 gap=1 的 34 对、gap=2 的 10 对、gap=3 的 2 对)。
两种独立方法(我的手工检查与 `tools/cr_pair_lineage.py`)结论一致。

**这就是两难**:合法的配法没有信号,有信号的配法不合法。
而且有信号的那种,其信号很可能来自**时序捷径**而不是条件理解 —— 这一点尚未被证明(见 §4)。

**必须区分两件事**(审阅意见的措辞,我采纳):
**失效的是"用四格 B 表示这套采样过程的来源后验"这一理论解释,不是"a₁ 确实来自 h₁"这个事实标签。**
因此那一轮训练应记为**经验性的时序对比变体**,不是原条件响应机制的正式检验。

## 4. 哪些是实测,哪些还只是假设

**实测(可复查)**:
- 三种配法的 B / margin 全分布(§1.3),来源:LONI 作业 1023173、1023180、1024540;
- 46 个关系全部是 progress pair,双方法一致;
- 24 个 anchor 的动作前状态完全同质(全部 1 次 search、0 次 lookup、1 条 observation;22 个无失败检索;
  题型 bridge 16 / comparison 8;前缀长度 1769–2028 token);
- base EM 37.0%(dev-500)。

**尚未证明的假设**:
- **"捷径是实体字面匹配"** —— 未做实体遮蔽消融,只是"阶段是常数、只剩内容"这一排除法推论;
- **"33.77 主要由时序捷径造成"** —— 需要额外对照才能量化。目前只能写:
  **所有同父关系都暴露了前后执行顺序,存在利用历史动作或阶段判断来源的捷径。**
  (执行过的动作也可能需要重复,检索之后也可能继续检索,所以不能直接归因。)
- **τ=20 的地位** —— 它不是"数值修复"。若教师来源后验为 σ(B_q),用 σ(B_π/τ) 时关系项的总体最优要求
  **B_π = τ·B_q**,所以 τ=20 应记为**一个新的平滑对比目标**。

## 5. 这对方法意味着什么

**核心风险已经被量化,而且正是审阅意见预警的那条**:
> **来源对应可以很容易判断,学生却仍然不会自主完成任务。**

今天两个数字并排即为证据:**来源判别上 B ≈ 94(e⁹⁴ 的似然比),自主答题 EM 37%。**
我们想教的是**决策**,但从这批素材构造出的训练信号考的是**匹配**。

**要让任务二变难,需要两个条件"表面像、该做的事不同"**:
同一道题、同样已经检索过一次、实体高度重叠,但**一支已知 A 缺 B、另一支已知 B 缺 A**。
此时实体与阶段都分不开,**必须判断"手上缺什么"** —— 那才与任务一是同一种能力。

**现有 24 条链天然造不出这种配对**:每条链只有一条时间线,24 道题互不相关,
且全部 anchor 处在同一执行阶段。**因此"材料不足"的结论只适用于这 24 条链,
不等于"合法的难关系在原理上不存在",更不等于"四格目标无价值"。**
