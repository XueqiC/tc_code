# 方法 v2.1 设计提案:把预算换成锚(2026-08-25)

## 瓶颈诊断(全部来自这两天的数据)

这轮 baseline 战役把方法的短板照得很清楚,三个瓶颈其实是同一件事:

1. **增益引擎薄**。ours .284 vs base .248,只 +.036;而 STaR(纯自产,
   零 teacher token)就有 .246。拆开看:自产锚贡献了从 .248 到 .246
   的"不伤",teacher 内容在锚保护下只贡献 +.038。四个吃 teacher
   正例的 baseline(SFT/SAD/BB-OPD/PBSD)全部钉死在 .197-.215 地板,
   说明**全行业没人能在这个台子上把 teacher 的内容学进去,大家学到
   的都是风格**;我们只是唯一不受伤的。
2. **锚的原料稀缺**。greedy 只成功 1 个任务,采样 240 次只多 4 个;
   锚机制本身已被三条定律证明有效,但它的原料(学生自己的成功)
   恰恰在学生弱的时候最稀缺。鸡生蛋问题。
3. **偏好项吃不饱**。成功轴许可是对的(风格对三次复现有害),但主
   台上合法对只有 5 对,门控偏好在 AppWorld 上等于不存在。

一句话:**防御体系(锚/门/许可)全部验证成立,但进攻端没有弹药——
预算买来的 teacher 示范无法安全转化为能力,学生自己的成功又太少。**

## 提案:teacher 出提示,学生当作者(v2.1 核心改动)

**一句话**:不再把 teacher 示范直接当训练目标,而是把它放进学生的
上下文里,让学生**自己重新做一遍**任务;verifier 通过的轨迹以
"自产"身份进锚池,失败的与同任务成功配成成功轴对;用已冻结的目标
函数训练;轮次间自然迭代,预算花完为止。

机理上这是把三条已证定律串成一个生成器:
- **出处纯度单调律**(.284 自产 > .245 混合 > .202 teacher 腔)说
  最好的训练材料是学生自己写的成功轨迹——那就把 teacher 的钱花在
  "帮学生写出成功"上,而不是"给学生抄"上。in-context 示范不产生
  梯度,风格覆写在源头就不发生,teacher 内容却通过学生的重写进了
  训练集。
- **克隆地板机制**(风格捕获)解释了为什么直接学示范必败——v2.1
  绕开它而不是对抗它。
- **aw8_r2 已有预演证据**:训练过的学生再 rollout,partial .3517、
  TGC 4/60——学生变强后成功供给显著变大,轮次迭代有真实的正反馈。
  每轮产出:更多锚 + 更多合法对(瓶颈 2、3 同时解)。

## 形式化(不引入新常数)

每轮 r:
1. 采购:对支撑集任务,买 teacher 示范作为上下文提示(照旧计费,
   v(a) 规则不变,挤出项继续承担内生截停);
2. 自作:学生在"任务 + 示范提示"下采样 k 次(k 沿用支撑集约定),
   verifier 判分;
3. 入账:成功轨迹 → 锚池(出处=self);同任务成败 → 成功轴对;
4. 训练:冻结的 L(x) 原样执行(锚 NLL + 门控偏好);
5. 停止:新一轮的边际成功增量定价进 v(a),全体 v≤0 自停——
   与现有停止条件同一条规则。

没有新超参:轮次不是常数而是由 v(a) 决定;k 是既有约定;门、掩码、
许可、平均全部不动。故事线也不变而且更顺:**预算最大化转化为
in-task 能力**——以前预算买"内容",现在预算买"学生自己的成功",
转化路径从「示范→(风格损耗)→能力」变成「示范→提示→验证成功→
能力」,中间没有折损环节。

## 最小验证实验(一天内,rai 可跑)

V1(核心,今天就能开):60 个 train 任务,teacher 示范进上下文,
4B base 采样 k=4 → 统计"带提示成功率"vs 裸采样的 ~2%。若提示把
成功率抬到 15-30%,弹药问题解决,提案成立;若抬不动,提案作废,
瓶颈改判为"4B 容量不足",主配置该讨论换学生。
V2:round-1 全流程(带提示自作 → 锚池扩容 → 冻结目标训练 ×3 种子)
vs 现 ours .284±.037。
V3(若 V2 正):round-2 迭代,画预算-成功供给曲线,进 RQ5。

## 风险与后路

- 主要风险:4B 连"看着示范做"都做不到 → V1 一天内就能证伪,损失
  极小;后路是主文换 9B 或加 turn 级提示(teacher 每步提示,费用
  更高但成功率上限更高)。
- 与 Table 1 的关系:baseline 全部不动;只有 Ours 行在 v2.1 验证
  通过后替换,方法节的 Stage II"买什么"的叙述改一段(买提示而非
  买标签),其余机理段落全部保留——防御三件套原封不动。
