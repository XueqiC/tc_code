# Method

## 1. Problem Setup

We consider few-shot task specialization under a limited teacher budget. Given a small set of task queries

[
S={q_1,\ldots,q_n}\sim P_{\mathcal T},
]

a generic student policy (\pi_{\theta_0}), a binary task verifier (V(q,\tau)\in{0,1}), and access to a stronger teacher, our goal is to obtain a specialized student (\pi_{\theta^\star}) that maximizes task success under the deployment distribution while using as few teacher tokens as possible.

The straightforward solution is teacher imitation: query the teacher for successful trajectories and train the student to reproduce them. This approach, however, conflates two roles of teacher supervision. A teacher trajectory may expose behavior useful for solving the target task, but using that trajectory as a training target also directly pushes the student toward the teacher's output distribution.

For a fixed query (q), let (p_T(\tau\mid q)) denote the teacher trajectory distribution. Maximum-likelihood training on teacher trajectories induces the expected ascent direction

[
u_T(q)
======

\mathbb E_{\tau\sim p_T(\cdot\mid q)}
\left[
\nabla_\theta \log \pi_\theta(\tau\mid q)
\right]
=======

-\nabla_\theta
\mathrm{KL}
\left(
p_T(\cdot\mid q)
|
\pi_\theta(\cdot\mid q)
\right).
]

Thus, teacher-target training necessarily moves the student toward an external behavior distribution. Part of this movement may correspond to capabilities required by the task, while another part may reflect source-specific regularities that are not required for task success. This distinction is particularly important when the student is substantially smaller than the teacher.

Our method starts from a different principle:

> **The teacher should help the student discover successful behavior, but the teacher's behavior need not be the behavior that the student is trained to reproduce.**

We therefore separate the *exploration source* from the *training source*. Teacher outputs are used only as temporary context for student exploration. Parameter updates are derived from verifier-evaluated trajectories generated by the student itself.

This produces a budgeted self-distillation loop in which the teacher provides exploration scaffolds, the student provides behavioral samples, and the verifier determines which behavior is useful.

---

## 2. Estimating Task Demand

Teacher supervision is valuable only insofar as it helps the student acquire capabilities required by the target task. We therefore first construct a representation of task demand from the few-shot queries themselves.

### 2.1 Gradient representation

For each query (q), we extract a gradient feature (g(q)) from the current student. Concretely, we compute gradients with respect to a fixed trainable parameter subset, apply the optimizer preconditioning used during training, and project the resulting high-dimensional vector through a fixed random projection.

We use two complementary views when available: a prompt-side view that characterizes the behavior elicited by the task input, and an outcome-side view obtained from verified student interaction. A coupled sparse dictionary

[
D={d_1,\ldots,d_m}
]

is fitted to recurring directions across these views, with a view-availability mask for queries for which outcome-side information is unavailable.

Each query is represented by sparse coefficients

[
c(q)
====

\arg\min_c
|g(q)-Dc|_2^2
+
\lambda_c|c|_1.
]

The dictionary is not assumed to contain intrinsically distinct "capability" and "mismatch" atoms. Instead, it provides a common basis in which task demand and supervision-induced updates can be measured.

### 2.2 Task-demand subspace

Before any teacher acquisition, the support set is partitioned into a demand split (S_d) and a held-out calibration split (S_c):

[
S=S_d\cup S_c,
\qquad
S_d\cap S_c=\emptyset.
]

Only (S_d) participates in task estimation, teacher acquisition, and training. The role of (S_c) is reserved for post-training calibration in Section 9.

The aggregate activation of dictionary directions on (S_d) defines the task demand. Let (r_a\ge0) denote the estimated demand for direction (d_a). The directions with non-negligible demand span an estimated task-demand subspace

[
\mathcal C_{\mathcal T}.
]

This representation lets us distinguish task alignment from update energy unexplained by the estimated task demand. For an expected supervision-induced update (u),

[
u
=

\Pi_{\mathcal C_{\mathcal T}}u
+
(I-\Pi_{\mathcal C_{\mathcal T}})u.
]

We refer to these terms as the **task-aligned** and **task-extraneous** components, respectively. A corresponding diagnostic is

[
R_{\mathrm{ext}}(u)
===================

\frac{
|(I-\Pi_{\mathcal C_{\mathcal T}})u|*2
}{
|\Pi*{\mathcal C_{\mathcal T}}u|_2+\epsilon
}.
]

This quantity does not assume that all task-extraneous updates are harmful. Rather, it measures how strongly a supervision source moves the student in directions not supported by the observed task demand. We later test whether this quantity predicts degradation under different supervision sources.

The task-demand representation also provides the basis for deciding where limited teacher tokens are most useful.

## 3. From Self-Generation to Task-Directed Learning

The motivation above suggests avoiding direct teacher-target training. A natural alternative is to train on trajectories generated by the student itself.

For a student-generated trajectory

[
\tau\sim\pi_\theta(\cdot\mid q),
]

the score-function identity gives

[
\mathbb E_{\tau\sim\pi_\theta}
\left[
\nabla_\theta\log\pi_\theta(\tau\mid q)
\right]
=0.
]

Self-generated data therefore does not, by itself, create a systematic update toward another behavior distribution. Pure self-imitation, however, also provides no direction for improvement.

The task verifier supplies the missing signal.

Define the success objective

[
J_q(\theta)
===========

\mathbb E_{\tau\sim\pi_\theta(\cdot\mid q)}
[V(q,\tau)].
]

Its gradient is

[
\nabla_\theta J_q(\theta)
=========================

\mathbb E_{\tau\sim\pi_\theta(\cdot\mid q)}
\left[
V(q,\tau)
\nabla_\theta
\log\pi_\theta(\tau\mid q)
\right].
]

Given (K) student rollouts, an unbiased Monte Carlo estimator is

[
\hat g_q
========

\frac{1}{K}
\sum_{j=1}^{K}
V(q,\tau_j)
\nabla_\theta
\log\pi_\theta(\tau_j\mid q).
]

The verifier therefore turns otherwise zero-mean self-generation into a task-directed learning signal without introducing an external trajectory distribution as the target.

This observation motivates the central supervision rule of our method:

[
\boxed{
\text{teacher: exploration context}
\qquad
\text{student: behavioral provenance}
\qquad
\text{verifier: learning signal}.
}
]

---

## 4. Teacher Context as an Exploration Scaffold

The previous objective is effective only when the student occasionally succeeds. For a weak initial student, however,

[
P_{\pi_{\theta_0}}
\left(
V(q,\tau)=1
\right)
\approx 0
]

for many task queries. In this cold-start regime, self-generated verifier reward is sparse or entirely absent.

We use the teacher specifically to overcome this exploration barrier.

For a selected query (q), we purchase a verified teacher demonstration (d_q) and transform it into a guidance context

[
h_q=h(d_q).
]

Rather than optimizing the likelihood of (d_q), we condition the student on (h_q) and ask the student to generate a new trajectory:

[
\tau
\sim
\pi_{\theta_r}
(\cdot\mid q,h_q).
]

The resulting trajectory has student provenance. The teacher demonstration itself receives no gradient weight.

The value of a teacher demonstration is therefore not the number of target tokens it provides. Its value is the extent to which it increases the probability that the student can discover successful behavior:

[
\Delta_{\mathrm{guide}}(q)
==========================

## P_{\theta_r}(V=1\mid q,h_q)

P_{\theta_r}(V=1\mid q).
]

This interpretation changes the teacher from a target generator into an **exploration scaffold**.

Importantly, the scaffold is temporary. Once the student can solve the corresponding region without (h_q), the teacher context is no longer used for collection.

---

## 5. Budgeted Acquisition of Teacher Context

Because teacher tokens are limited, we should purchase demonstrations only when they are expected to unlock useful student-generated supervision.

Let (S_{r,a}) denote the amount of verified student capability already observed along task-demand direction (a) by round (r), and let (r_a) denote its target coverage. The remaining deficit is

[
\delta_{r,a}
============

(r_a-S_{r,a})_+.
]

For a candidate demonstration (d_q), let (\hat s_a(d_q)) denote its predicted supply along direction (a). Its marginal demand coverage is

[
C_r(q)
======

\sum_a
\min
\left(
\delta_{r,a},
\hat s_a(d_q)
\right).
]

The cap prevents repeatedly purchasing demonstrations for capability directions that have already been sufficiently covered.

Coverage alone is insufficient. A demonstration is useful only if its context is likely to unlock successful student behavior. We therefore estimate

[
\hat\rho_r(q)
\approx
P_{\theta_r}
\left(
V=1\mid q,h_q
\right),
]

or the corresponding increase over unguided success when both estimates are available.

Before guided observations are available, candidates share a fixed prior for (\hat\rho_r), so initial acquisition is driven primarily by task-demand coverage and cost. Later rounds update the estimate using observed guided outcomes.

Let (\hat t(q)) denote predicted teacher-token cost and (I_r(q)) an interference-risk estimate obtained from free reference tasks. We score candidate (q) by

[
v_r(q)
======

\frac{
\hat\rho_r(q),C_r(q)
}{
\hat t(q)
}
-

\lambda_I I_r(q).
]

The quota-capped coverage term exhibits diminishing returns: supplying a capability direction becomes less valuable as its deficit is filled. This structure motivates greedy acquisition under the remaining teacher budget. We do not assume that the complete penalized utility retains the approximation guarantees of the pure submodular coverage term.

At each acquisition step we select the feasible candidate with the largest positive marginal value. Acquisition stops when either the teacher-token budget is exhausted or

[
\max_q v_r(q)\le0.
]

Thus the teacher budget is treated as an upper bound rather than an amount that must be spent.

---

## 6. Graduated Student Exploration

Teacher contexts are used only when the current student cannot solve a query independently.

At round (r), for each training query (q), we first sample (K) unguided trajectories

[
\tau_{1:K}
\sim
\pi_{\theta_r}(\cdot\mid q).
]

If these rollouts produce verified success, collection remains entirely unguided.

If all unguided attempts fail and a teacher context (h_q) has previously been acquired, we activate that context and collect additional trajectories from

[
\tau
\sim
\pi_{\theta_r}(\cdot\mid q,h_q).
]

If no context has been acquired, the query remains unguided until a later acquisition round determines that teacher spending is worthwhile.

This protocol creates a competence-dependent curriculum without prescribing a teacher-annealing schedule. Early in training, many difficult queries may require guidance. As the student internalizes successful behavior, those same queries begin producing verified unguided rollouts and automatically stop invoking teacher context.

The collection distribution therefore evolves naturally from

[
\text{guided-heavy}
\rightarrow
\text{mixed}
\rightarrow
\text{unguided}.
]

Teacher usage decreases because the student no longer needs it, rather than because a predetermined schedule removes it.

---

## 7. Learning a Deployment Policy from Guided Discoveries

Guided exploration introduces an important distributional distinction. A guided trajectory is generated by the behavior policy

[
\mu_r(\tau\mid q)
=================

\pi_{\theta_r}(\tau\mid q,h_q),
]

whereas deployment uses

[
\pi_\theta(\tau\mid q).
]

Simply removing (h_q) from the training input would incorrectly treat the guided trajectory as an on-policy sample from the deployment context.

We instead record the behavior-policy likelihood for every collected trajectory. For unguided collection,

[
\mu_r(\tau\mid q)
=================

\pi_{\theta_r}(\tau\mid q),
]

while for guided collection,

[
\mu_r(\tau\mid q)
=================

\pi_{\theta_r}(\tau\mid q,h_q).
]

For a fixed behavior policy (\mu_r), the deployment-policy reward gradient can be written as

[
\nabla_\theta J_q(\theta)
=========================

\mathbb E_{\tau\sim\mu_r}
\left[
\frac{
\pi_\theta(\tau\mid q)
}{
\mu_r(\tau\mid q)
}
V(q,\tau)
\nabla_\theta
\log\pi_\theta(\tau\mid q)
\right],
]

provided the behavior policy covers the support of the deployment policy.

Thus a trajectory may be **discovered under teacher guidance while still contributing to an update defined with respect to the unguided deployment policy**.

In practice, full trajectory-level importance ratios may have high variance. We therefore use a clipped ratio

[
\bar w_\theta(\tau,q)
=====================

\min
\left[
\frac{
\pi_\theta(\tau\mid q)
}{
\mu_r(\tau\mid q)
},
c
\right].
]

The positive update is

[
\hat g^+
========

\frac{1}{|\mathcal B_r|}
\sum_{(q,\tau)\in\mathcal B_r}
\bar w_\theta(\tau,q)
V(q,\tau)
\nabla_\theta
\log\pi_\theta(\tau\mid q),
]

where (\mathcal B_r) contains the actual student rollouts collected during the round.

Clipping trades unbiasedness for variance reduction. Accordingly, we treat the practical update as a clipped importance-weighted approximation to the deployment-policy reward gradient rather than as an exact on-policy estimator.

Crucially, no likelihood term is ever evaluated against a teacher-generated trajectory. Teacher outputs influence where the student explores, but not which external behavior distribution its parameters are trained to reproduce.

## 8. Localized Learning from Student Failures

Positive verifier reward identifies behavior that should become more likely. Failed student trajectories provide additional information, but naively treating an entire failed trajectory as negative evidence can suppress many decisions unrelated to the failure.

We therefore use failures only through **outcome-localized student preference pairs**.

Suppose the student produces a verified successful trajectory (\tau^+) and a failed trajectory (\tau^-) for the same query. We retain a pair only when the two trajectories admit a shared environment history up to a first action divergence

[
t^\star
=======

\min
{t:a_t^+\neq a_t^-}.
]

Because the trajectories share the preceding state, the divergence provides local evidence that the subsequent decision may be relevant to their different outcomes.

The negative preference loss is therefore masked before (t^\star). In addition, we activate the pair only when the successful branch is sufficiently learnable under the current student. Let

[
\ell^+(q)
=========

-\frac{1}{|\tau^+|}
\log\pi_\theta(\tau^+\mid q).
]

We maintain a moving threshold (\eta_r) over positive-trajectory NLL and admit a pair only when

[
\ell^+(q)\le\eta_r.
]

This prevents the model from receiving strong negative pressure before it can represent the corresponding successful alternative.

The negative channel therefore obeys three constraints:

1. both alternatives are generated by the student;
2. the pair differs in verifier outcome under a shared context;
3. negative pressure begins only at the first action divergence and only after the positive alternative becomes learnable.

We combine this localized preference objective with the positive verifier-reward objective,

[
\mathcal L
==========

\mathcal L_{\mathrm{positive}}
+
\lambda_{\mathrm{pref}}
\mathcal L_{\mathrm{pref}}.
]

The preference term is secondary. Its role is to localize evidence from failures, not to define the primary target distribution.

## 9. Iterative Repricing and Endogenous Stopping

The value of teacher guidance changes as the student learns. A context that is valuable for the initial model may become unnecessary after its corresponding behavior has been internalized.

We therefore recompute acquisition values after every student update.

At round (r+1), new unguided rollouts update both the observed success rates and the estimated remaining task-demand coverage. For capability direction (a),

[
\delta_{r+1,a}
==============

(r_a-S_{r+1,a})_+.
]

If the student has acquired the corresponding capability, then

[
S_{r+1,a}>S_{r,a},
]

which reduces the marginal coverage value of demonstrations supplying the same direction.

At the same time, successful unguided exploration reduces the need for guidance on those queries.

The resulting loop is

[
\boxed{
\text{estimate deficit}
\rightarrow
\text{buy context}
\rightarrow
\text{self-explore}
\rightarrow
\text{verify}
\rightarrow
\text{update}
\rightarrow
\text{re-price}.
}
]

Teacher acquisition terminates when no remaining candidate has positive estimated value,

[
\max_q v_r(q)\le0,
]

or when the budget is exhausted.

Training terminates when the student reaches the predefined convergence criterion under unguided evaluation.

This produces two forms of endogenous annealing. First, individual teacher contexts disappear from collection as soon as their associated queries become solvable without guidance. Second, new teacher acquisition stops once additional contexts are no longer expected to unlock sufficient task-relevant self-supervision.

In the limiting regime in which all collected trajectories are unguided,

[
\mu_r(\tau\mid q)
=================

\pi_{\theta_r}(\tau\mid q),
]

and the procedure reduces to on-policy verifier-guided self-improvement.

Thus the method is not strictly on-policy throughout training. Rather, teacher context provides a temporary off-policy exploration scaffold that asymptotically disappears as the student becomes self-sufficient.

## 10. Task-Boundary Calibration

Specialization should not imply that the resulting student is trusted arbitrarily far outside the few-shot task region.

We therefore reserve (S_c) exclusively for post-training task-boundary calibration. It is not used for dictionary fitting, teacher acquisition, training, checkpoint selection, stopping, or construction of the final routing score.

After training is complete, we freeze the student and fit the final prompt-side task representation using only admissible training-side information. For an input query (q), let

[
R(q)
====

|g_p(q)-D_pc(q)|_2
]

denote its reconstruction residual under the frozen prompt-side dictionary.

Only after this score function has been fixed do we evaluate it on (S_c). The calibration residuals determine a split-conformal threshold

[
\gamma_\alpha.
]

Under the standard exchangeability assumption, this yields finite-sample marginal coverage at the calibration level supported by (|S_c|).

At deployment, the specialist is invoked only when

[
R(q)\le\gamma_\alpha.
]

Queries outside this estimated task region can instead be rejected or escalated to a general-purpose model.

This calibration stage is deliberately separated from learning so that the same few-shot examples are not simultaneously used to construct and certify the specialization boundary.

---

## 11. Overall Algorithm

The complete procedure can be summarized by three recurring operations: **buy, explore, and internalize**.

**Buy.** Estimate the student's remaining task-demand deficits and purchase only teacher contexts with positive expected value per teacher token.

**Explore.** Let the student attempt every query without guidance first. Activate a purchased teacher context only when unguided exploration fails.

**Internalize.** Train exclusively from verifier-evaluated student trajectories. Successful trajectories provide the primary reward signal, guided trajectories are importance weighted toward the deployment policy, and failed trajectories contribute only through localized outcome contrasts.

The process then repeats with the updated student.

Conceptually,

[
\boxed{
\begin{array}{c}
\text{Teacher context}
[-2pt]
\downarrow
[-2pt]
\text{Student exploration}
[-2pt]
\downarrow
[-2pt]
\text{Verified student behavior}
[-2pt]
\downarrow
[-2pt]
\text{Student update}
\end{array}
}
]

replaces the conventional distillation path

[
\boxed{
\text{Teacher behavior}
\rightarrow
\text{Student parameters}.
}
]

The distinction is the central design choice of the method. The teacher may change which successful behaviors the student can discover, but the teacher never defines the behavioral distribution that the student is optimized to imitate.

As learning progresses, successful guided discoveries become successful unguided behaviors, teacher contexts lose acquisition value, guidance usage declines, and the method approaches ordinary on-policy self-improvement.

We therefore view the method as **budgeted, verifier-guided self-distillation with teacher context scaffolding**: teacher supervision is spent to overcome the student's exploration barrier, while task specialization itself is learned from the student's own verified behavior.
