# 互补组合检验(拟作为行为原子 P2 的第一道机制关口)

目的:检验"最小有效教学单位是一组互补示范"这一机制(附件方案 §开头的两示范例子),用最便宜、最尖锐的实验先于任何极点/低秩机器。

## 设计
- 学生:Qwen3.5-4B base(BFCL,竞争力 base;后续在 ALFWorld 不会做的 base 上复现)。
- 单元:纠正样本 c(v3t 池中 teacher_authored 调用事件,base 错、teacher 对)、锚点样本 r(base 正确的弃答/调用行为,来自 anchors_single_base.jsonl 或校准外的官方题),按 API 家族配对成 (c, r_match);随机锚点 r_rand(不同家族)。
- 四臂 × 每对独立 micro-update(存 δ,同一初态,固定剂量:总有效 token 与步数匹配,合训臂每样本半剂量):
  1. c 单训;2. r_match 单训;3. c + r_match 合训;4. c + r_rand 合训。
- 探针:32 个固定 frontier 探针(P_disc),teacher 侧边际变化 + 0/1 结果;保留集 = 同家族弃答/调用探针。
- 指标:目标收益 Δ⁺(缺失行为探针)、保留损伤 Δ⁻(保留探针),配对差与分组 bootstrap CI;可加性检验 Δ(3) vs Δ(1)+Δ(2);随机锚点对照 Δ(4)。
- 判决:合训净收益 > 两单训之和且 > 随机锚点合训(CI 不含 0)→ 互补机制成立,进入配方/极点阶段;合训 ≈ 单训之和 → 可加、无互补,原子退化为"受约束蒸馏";随机锚点同样有效 → 只是剂量/正则效应,不支持细粒度组合。
- 规模:12 对 × 4 臂 = 48 个 micro-update(每个 ~1 min 训练 + 32 探针评估 ~2 min),单 GPU ~3 h;hpg 两 group 分摊 ~1.5 h。0 teacher token。
