## 一、方法 v1.2(已定稿,15 格终审)

**总原则**:学生先试,验证器免费打分,只在学生自己失败处花钱买监督;
学生自身分布必须在训练分布中有锚。

**四组件与证据**(2B×20k,GSM8K 官方外部 200 题,3 种子):

| 组件 | 判定 | 关键数字 |
|---|---|---|
| 双视图耦合字典(替代 ridge 桥) | 转正 | 精度持平(.645≈.667 噪声内);**浪费减半**(2.0k vs 3.1k tok);**未满足需求减半**(8.6k vs 18.3k);入库 +10% |
| NLL 门控统一 ORPO(替代分段偏好) | 转正 | .660 ≈ 分段最优 .668;胜无门 .630 配对 3/3;0.8B 压力测试系列最高 .600 |
| 权重平均(SWA,探针信任域) | 转正 | 配对 +.058;种子极差 .080→.013 |
| 归属门(环内验货) | 转正 | off-task 残留 **0.000**(×4 预算 ×3 种子);开门实测 in-task 代价 ≈0(.642 vs .645)→ 零泄漏免费 |

**主表位置(gsm)**:所有顶配(ours .643-.668 / selfinst .648-.670)在
.64-.67 统计平局带;我们的臂方差最小(极差 .010)+ 零泄漏 + 半浪费。
gsm 的 in-task 已饱和,"明显赢"的战场在 AppWorld。

## 二、消融台账(每条都有机制数据)

- ridge 桥:per-atom 可靠度仅 0.08-0.105(响应结构不进拟合目标)。
- 分段偏好剂量曲线:4 步 +.032 / 6 步 -.026 / 12 步崩(.31,且一题
  之差骗过探针)→ 孤立偏好阶段结构性不稳。
- 无门统一:.630,3/3 输给门控——早期无差别施压有害。
- 自放大(对题当正例):±0;**同一 rollout 错题当负例 +.032**。
- 草稿桥、定向生成、需求加权、curriculum、absorption-focus、
  R=4 交替、单 atom 探针:全部中性/负,各有机制解释。
- 教训:可运行率探针对正确率崩塌失明 → 换执行正确率探针(金标免费)。

## 三、AppWorld 战役(4B/9B,dev40×24,修复版 harness)

**基础事实表**:

| 配置 | 部分得分 | TGC |
|---|---|---|
| 9B base | .303 | 2/40 |
| 9B random@20k | .250 | 0 |
| 9B atoms@20k | .197 | 0 |
| 4B base | .282(重评 .277-.282 稳定) | 0 |
| 4B atoms@20k | .202 | 0 |
| 4B 全池 2506 行(125×数据) | .197 | 0 |

**发现链**:
1. harness eos bug(合并模型丢停止 token→幻觉后续轮次)真实但边缘,
   修复后聚合分几乎不变;
2. **示范克隆系统性有害**:两个规模上 base > 一切克隆臂;加 125 倍
   数据不救;random > atoms 说明病在"克隆"不在"选择";
3. 机制 = 风格捕获:纯代码零解说的 teacher 示范磨掉 base 的任务级
   规划。

**aw7 处方实验**(4B):

| 臂 | 部分得分 |
|---|---|
| 克隆(对照) | .197-.202 |
| C:token 级选择损失(Rho-1 式) | .197(无效) |
| **A:自解锚(99% 示范 + 19 条学生自解轨迹)** | **.287 / .245 / .319,均值 .284** |

A 臂三种子均值 .284 ≈ base .282,**比克隆 +.08**;即混入 ~1% 学生
自身轨迹就完全挡住风格崩塌、回到 base 水平(尚未稳定超越,dev40
噪声下三种子极差 .074)。

## 四、核心洞见(跨数据集,论文主论点候选)

**监督应落在学生自身策略欠缺处,且学生自身分布必须在训练分布中有锚。**

三次独立跨域验证:
- gsm:错题负例 +.032 vs 对题正例 ±0(欠缺处才有信息);
- gsm:孤立偏好崩、并入 SFT 循环稳(SFT 梯度 = 锚);
- AppWorld:克隆崩、混 1% 自解行稳(自解行 = 锚);token 掩码无锚
  则无效——锚是必要成分,不是可选优化。

理论对应:持续学习的少量 replay 防灾难性遗忘;on-policy 蒸馏的
分布匹配动机。
