# Learning-Kernel 重构:一个对象统一 T、C、粒度与选择

2026-08-10,回应 PI 批评:"E2 的混合解法和粗细粒度混合都不够 elegant"。
批评成立——之前的方案是拼积木。以下是单一原理的重构。

## 0. 一句话

定义查询之间的**学习核**(learning kernel):
```
K(q, q′) = ⟨ g(q), g(q′) ⟩,   g(q) = ∇_θ ℓ(τ(q); θ₀)(随机投影后)
```
即"教会模型 q 和教会模型 q′ 所需的参数移动的相似度"。
**T 的边界、C 的预测、蒸馏数据选择、粒度问题,全部是这同一个核上的
四种标准操作。** 不再有并列的机制、不再有混合权重。

## 1. 四个推论(全部免费导出)

**T = 核空间中的密度区域。**
few-shot {q_i} 在 RKHS 里张成的区域;谱子空间 = kernel PCA(我们已做的
就是它的显式版),conformal 半径不变。"边界适度外扩保证 topic 覆盖"
= 核带宽这**一个**连续参数,不是粗/细两套系统。

**C = 核预测的能力(E2 的 elegant 解)。**
一阶(near-lazy)近似下,在数据 D 上训练后,query q 的函数变化由
Σ_{x∈D} η·K(q,x)·(−∇ℓ_x) 给出——**学生会什么,由"它从训练数据经核
收到了多少质量"直接预测**,不需要任何事后残差范数。E2 的问题从
"找一个会说话的代理"变成"核的预测有效性"(precisely TRAK 的问题设定,
理论现成)。行为测量不再是被代理的对象,而是核预测的**验证集**。
- v1/v2 失败的解释也统一了:残差范数根本不是这个理论里的量;
  风格漂移 = 用错参考点,exposure bias = 残差不在预测式里。
- **零成本验证方案**:E3 正在produce六个 (训练集, 逐题成败) 对——
  用核从各条件的训练集**预测**逐题能力,和实测成败对比。
  不用训任何新东西,明天就能测。gate 语义:核预测 AUROC ≥ 阈值。

**选择 = 核覆盖最大化(E3-D 的重述)。**
预算内选 D 最大化对 T 区域的核质量、最小化对外部的核质量
(facility-location 目标,子模,贪心近似最优有保证)。
当前的"按投影分排序取前缀"是它的一阶特例——形式化升级,实现不变。

**粒度 = 核的聚合结构(粗细混合的 elegant 解)。**
关键恒等式:整轨迹梯度 = 逐 token 梯度之和,g(q) = Σ_t g_t(q)。所以
- 粗核 K = ⟨Σg_t, Σg_t′⟩:先求和再内积——跨技能的交叉项互相淹没
  (域内细分失败的原理性解释);
- 细核 K_align = Σ_匹配 ⟨g_t, g_t′⟩:先对齐再内积(soft-alignment /
  OT 核,PSD 可保证)。
  **粗与细不是两套系统,是同一求和的两个位置**;之前 per-line 切块 +
  max/mean 聚合是这个核的粗糙手工近似,SQL 单行退化的原因也自明
  (无处可切 ≠ 无处可对齐——token 级永远可对齐)。

## 2. 数学地基与诚实边界

- 依赖 near-lazy 假设(小步数 LoRA SFT 近似成立;E3 是 162-189 步,
  近似质量本身可测:核预测 vs 实测的 gap 就是 lazy 偏离度的度量,
  报告它而不是假设它)。
- K 的 PSD 性、随机投影的 JL 保证、kernel PCA 与现有实现的等价性:
  全部标准结果,无新数学风险。
- conformal 仍是唯一的统计包装,但现在只包装**一个**对象。

## 3. 论文叙事的升级

之前:"我们把 T 和 C 放进同一个空间"(空间是舞台,机制是拼的)。
现在:"**一个学习核,四个推论**"——边界、能力预测、数据选择、多粒度
全部从 K 导出;LESS(核内积选数据)、TRAK(核预测正确性)、我们的
子空间(核 PCA)成为同一框架的三个投影。这是 ICLR 级的形式化。
