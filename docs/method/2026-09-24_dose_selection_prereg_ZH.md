# 训练量选择的预登记（2026-09-24，在看到任何 HotpotQA 结果之前写定）

## 背景
预登记的第一天判读 = NO_RELATION：用支持集 CV 选**材料**没有信号，这条线收住，不再展开新的材料选择机制。
剩下要回答的问题是：**支持集 CV 选"训练量"，有没有超过简单训练量策略的额外价值**；还是说我们只是发现原来的训练量不足。
ALFWorld 上已看过的结果只作探索证据；**确认用尚未查看的 HotpotQA 结果**，规则在下面冻结，之后不再依据 HotpotQA 的最终成绩改动。

## 坐标
训练量的主轴 = **累计监督 token**（包括每回合的结束 token）。每个 checkpoint 同时记录实际遍数（token ÷ 该银行每遍 token）和优化器更新数。
CV 折训练与最终训练用**同一个 token 坐标**（折银行更小，所以同一 token 对应更多遍）。**未训练的 base 是 token = 0 的候选。**

## HotpotQA（确认）
- 材料固定：K=32 支持集的 D0（每题唯一的已验证轨迹，19/32 题有示范，如实报告）。
- 候选 token 点：T = {0, 2,465, 7,395, 12,325, 24,650, 49,300}（= 全量银行的 0 / 1 / 3 / 5 / 10 / 20 遍）。
- CV：4 个冻结折（`artifacts/hotpotqa_k32_folds.json`），每折用其余 3 折的示范训练到上述 token 点，在留出的 8 道支持题上跑 agent，
  **cv(t) = 4 折留出 EM 之和（0–32）**；t = 0 用 base 的留出 EM。
- **选择规则**：t\* = argmax cv(t)；**平手取 token 更少者**（早停惯例，少训练即少成本）；若 t\* = 0，如实报告该设置没有获得适配收益。
- 最终模型：D0 在全部 32 题上训练到 t\*，dev-500 EM，与下列简单策略比较（同一评测、同一机器）：
  1. **固定当前训练量**：10 遍（24,650 token），即 SFT baseline；
  2. **固定最大训练量**：网格最大值（49,300 token）；
  3. **各 K 统一监督 token**：K=8 / 16 也训练到 K=32 的 token 数；
  4. **支持集 CV 选择**：t\*。
- **判读**：只有当 CV 选择的 dev EM 高于策略 1 和 2 中较好者、且差距超过 dev-500 的配对标准误时，才认为 CV 有额外价值，值得写成方法；
  否则采用最简单的固定训练量策略，并如实报告 CV 没有带来额外价值。

## ALFWorld（探索，部分结果已看）
- 小 K 训练量对照（最高优先）：K=8 / K=16 普通 CE 训练到 **96,490** 监督 token（与 K=32 相同），2 个 seed，
  沿途存 K 自身 10 遍（K8 13,990、K16 34,970）以及 28,947 / 48,245 的 checkpoint。
  - 小 K 在 96,490 明显恢复 → 原 K 曲线混合了支持任务数与训练量的影响；
  - 仍明显较差 → 训练量不足不能充分解释，任务覆盖或材料仍然重要。
  这是普通 CE 的补充对照，三个正式 baseline 保持原实现。
- 剂量曲线：ALT1 / rnd1 已在跑，**补全池 SFT**（全部 87 条）；token 点 {28,947; 48,245; 67,543; 96,490; 144,735; 192,980}，外加 base（token = 0）。
- 若曲线在考察范围内基本单调上升 → 先采用固定训练量策略；
  若不同 K 或环境的最佳训练量明显不同 → 再补**一个固定材料方案（全池）**的四折剂量 CV，不展开材料维度。
