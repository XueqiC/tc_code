# 主方法:用学生在其他任务上的学习收益选择教师轨迹(支持集内跨任务评分)

> 方法线按用户 09-23 13:13 指令只押这一条。

## 1. 要解决的问题

同一个支持任务往往有多条通过验证的教师轨迹。已有证据(ALT1 vs 1min vs D0)表明:
**同一个候选池里,每个任务选哪条轨迹,能让最终学生摆动约 10 个任务(140 局)**——
而学生 NLL、扫描占比、长度、重访次数都**不能**事先判定哪条好。

**问题**:给定一个新候选池,怎样**只用 K 个支持任务**、稳定地选出有用的蒸馏材料?

## 2. 方法(四步)

**输入**:K 个支持任务;每个任务若干条教师轨迹(候选池)。

1. **构造候选训练集。** 每个候选集为每个任务指定一条轨迹,**任务覆盖完全相同**。
   本轮:3 个随机集(rnd1/2/3)、1 个 NLL 选择集(nll1:每题取学生逐 token 平均 NLL 最低的一条)、
   以及两个已知锚点(1alt:每题最大 id;1min:每题最小 id)。
2. **支持集内跨任务评分。** 把 K 个任务按类型分层分成 4 折(seed 4242,每折 8 题)。
   对第 k 折:用该候选集在**其余三折**上的轨迹,按已验证的 CE 配方训练学生
   (**与最终训练同一个终点**,96,490 监督 token,同更新数);再让训练好的学生在**第 k 折的 8 个任务**上贪心执行,计成功数。
   轮换四折:**cv_score = 四折留出成功数之和 ∈ [0, 32]**。
3. **选材。** 取 cv_score 最高的候选集。
4. **最终蒸馏。** 用选中的完整训练集、同一 CE 配方训练最终学生。

**隔离原则**:整个选择过程**只接触 K 个支持任务**;seen / unseen 评测**从不参与**材料打分。

**为什么是"材料组合"而不是逐轨迹打分**:按组合评估控制实现复杂度,也把"不同示范一起训练时的相互作用"算进去;
本轮不做逐轨迹效用模型(用户指令)。

### 3.1 预先登记的判读规则(2026-09-23 16:13 CDT 写定并提交 4edf14fb,**此时还没有任何 cv 分**)

脚本:`tc-alignment-baselines/tools/cv_verdict.py`(先用合成数据核对过置换 p:n=6 时 ρ=0.829 → p=0.029,ρ=0.771 → p=0.051,与 §4.1 表一致)。

- **主统计量**:6 个候选集的 cv_score 与 **hpg 上最终 140 局成绩均值**的 Spearman ρ,单侧精确置换 p(全部 n! 种排列)。
  最终成绩只取**所有候选集都有的 seed(s0、s1)**,使每个点的噪声水平相同;1alt / 1min 的 s2 与 rai 成绩只作旁证。
  **修订(16:20 CDT,仍在任何 cv 分出来之前)**:最终成绩**只用在 hpg 上训练的 adapter**。原先 1alt / 1min 的最终模型是在 rai 上训的
  (torch 2.13 / cu130),rnd / nll1 与所有 cv 模型则在 hpg B200 上训(torch 2.11 / cu128)。训练平台若有系统偏移,
  会直接让 1alt / 1min 显得更好或更差,污染相关。为此补提 hpg 训练的 1alt / 1min 最终模型各 2 个 seed(评测标签 `hpg_ALT1HT_s*`、`hpg_ALT1MINHT_s*`);
  rai 训练的成绩(ALT1 85/85/88、1min 79/85/…,均在 hpg 上评)只作旁证,顺便直接测出训练平台偏移。
- **选择结果**:cv 分最高的集合(并列取均值)的最终成绩,对比随机集最终成绩的均值和 nll1。
- **读法**:
  - **ADVANCE(推进)**:p ≤ 0.05,且 cv 选中集的最终成绩 ≥ 随机集均值,且 ≥ nll1;
  - **DIRECTIONAL(方向一致,分辨率不够)**:ρ > 0,且选中集 > 随机集均值,但达不到 ADVANCE;
  - **NO_RELATION(无关系 → 停止扩展)**:ρ ≤ 0,或选中集 ≤ 随机集均值。
- **补充统计(16:29 CDT 登记,此时仍无任何 cv 分;只报告、不改变判读)**:
  ① 留出任务的平均步数(失败记 40,越低越好)与最终成绩的 Spearman——比 0/1 成功更连续,分辨率可能更高;
  ② **四折之间对候选集排序的一致性**(Kendall W,置换检验)与每折各自选出的最优集合——直接回答"能否**稳定**选出更好的材料":
  若各折各选各的,则 cv 总分的排序主要是噪声。
- **同时报告**:随机集之间最终成绩的 SD 对比 seed 噪声 SD(Q1)。如果随机集之间的差别本身不超过 seed 噪声,
  说明在这个银行里"选哪条轨迹"几乎不影响结果,任何选择信号都无从体现——这本身就是一个结论,要单独说。

## 4. ⚠️ 最大的风险:评分分辨率可能不够

每个候选集的 cv_score 只基于 **32 个留出任务结果**(每折 8 题)。仅任务抽样一项:

| 情形 | 两个集合需相差多少才能在 95% 上区分 |
|---|---|
| 独立比较(p≈0.65,SD≈2.7) | **约 7.5 个任务**(≈23 个百分点) |
| 配对比较,6 个不一致任务 | **约 4.8 个任务** |
| 配对比较,10 个不一致任务 | **约 6.2 个任务** |

而我们想区分的差异——ALT1(86.7)对 1min(≈81)——在 140 局上约 6 个百分点,**折算到 32 个支持任务只有约 2 个任务**。
这还没算训练 seed 噪声(同配方不同 seed 在 140 局上曾差 8 题)。

**含义**:第一天很可能得到"cv 分与最终成绩无显著关系"——**但原因可能是分辨率不够,而不是方法错了**。
这两种情况必须分开读。若出现这种结果,可行的补救(需要你定):
- 每折多训几个 seed 取平均,压训练噪声;
- 增加候选集数量,用排序相关而非两两比较;
- 用 rollout 的连续信号(如步数、回退率)补充二值成功。

### 4.1 第二个限制:只有 6 个候选集,排序相关的门槛很高

第一天的判定本质是"6 个候选集的 cv 分与最终成绩是否同序"。用精确置换分布:

| 候选集数 n | 单侧 p ≤ 0.05 所需的 Spearman ρ |
|---:|---:|
| 5 | ≥ 0.900 |
| **6(本轮)** | **≥ 0.829** |
| 7 | ≥ 0.714 |
| 8 | ≥ 0.643 |

**两个限制叠加**:每个候选集的 cv 分本身有约 2.7 个任务的抽样噪声(§4),又只有 6 个点做相关。
所以**即使 cv 分与最终成绩确有中等强度的关系,本轮也很可能读成"不显著"**。

**可选的加强(需要你定)**:再加 2 个随机候选集(rnd4/rnd5)→ n=8,门槛降到 0.643。
代价是 8 个 cv 训练 + 4 个最终训练,会和现有 41 个作业抢 hpg,可能把结果推到午夜后。
**不加的话**,本轮更适合读成"方向是否一致"而不是"是否显著"。

### 4.2 第三个隐患:cv 模型与最终模型的"剂量"不同(16:31 CDT 记录,尚无 cv 分)

cv 模型与最终模型训到**同一个 token 终点(96,490)、同样 184 步**,但 cv 银行只有全量银行的约 3/4,
所以每条示范被看到的次数不同:**cv 模型 9.3–14.1 遍,最终模型 7.8–9.0 遍**(来自 hpg preflight 的银行 token 数)。
ALFWorld 上的剂量-效果此前是**非单调**的(崩塌 → 恢复 → 大幅提升),所以"cv 分预测最终成绩"可能被剂量差削弱。
这是设计上的取舍:固定 token 终点保证优化轨迹(步数、学习率日程)一致;固定遍数则会让 cv 模型少训约 1/4 的步数。**本轮不改**,判读时一并考虑。

同一原因还带出一个**零成本的对手规则**:固定 token 预算下,**更短的银行 = 更多遍数**。若"选更短的轨迹"与最终成绩的相关不输 cv 分,
cv 的整套训练就没有带来额外价值。已作为补充统计登记(`cv_verdict.py --bank-tokens`,全量银行 token:
1alt 11,285 / 1min 12,039 / nll1 10,780 / rnd1 10,960 / rnd2 12,355 / rnd3 12,172)。
