# 完整 story:预算受限的 few-shot 黑盒 agent distillation(2026-09-11,综合 GPT-6 建议)

## 0. 修正我上一版框架里的两点
- 不预设"三篇必然失败"。正确的说法是:它们没有直接优化我们设定最需要的量;数据充分、教师行为
  适合学生时它们可以很好。我们要做的是把这个量说清、优化它、并在匹配剂量下证明差异。
- 对标不止三篇轨迹蒸馏:SOPD(在学生访问的状态上逐步查询黑盒教师)、FutureBridge-OPD(教师桥接 +
  检查后续学生轨迹)、GAD(判别器作为随学生演化的 on-policy 奖励,复用已购教师文本)已经占掉
  "on-policy""教师接管""看后续轨迹""复用已购文本"这几个单独的创新点。我们的贡献必须是**构造本身**。

## 1. 现有 agent distillation 怎么做
- 轨迹模仿一族:SmartAD(学生 NLL 选易学的正确教师轨迹,强调 action/decision 片段)、
  SAD(按轨迹结构分片段分别监督)、Agent Distillation/Kang(教师工具交互轨迹 + first-thought 前缀 +
  自洽动作生成)。目标分布 = 教师轨迹,训练 = 最大似然;区别在选哪些、片段多重、怎么改写。
- on-policy 黑盒一族:SOPD(学生状态上查教师,逐步文本蒸馏)、FutureBridge-OPD(教师桥接 + 后续检查)、
  GAD(判别器奖励,复用教师回答)。监督落在学生状态上,但"学什么"仍由教师侧信号决定
  (教师文本本身、判别器的"像不像教师")。

## 2. 收窄到一个最根本的问题
**它们都不直接优化"一份教师指导经过蒸馏后,给学生完整任务能力带来的净提升"。**
监督由教师侧信号(正确性、结构、学生似然、像教师程度)构造;参数共享下,一次更新在某状态替换学生的
全部行为——包括本来胜任的那些——而伤害是全局的。理论上:降低模仿损失不等于提高任务回报;小幅更新后
的回报变化取决于更新方向与任务回报梯度是否一致,而不只取决于教师答案是否正确。
**在 few-shot + 预算下这个问题更严重**:
1. 状态少、样本少,单次更新的干扰没有大规模多样数据去平均,Damage 占比更大;
2. 预算有限,买不到覆盖学生分布的教师文本;若不按"学习收益"定价,购买集中在学生已会的状态(D≈0),
   Gain 没有、Damage 照付;
3. 黑盒无 logits,它们只能整体替换分布,没有更细的自由度。
我们的经验证据(全部已在手):示范正确但训练无益甚至有害(BFCL 基线低于 base 2–5);纠正片段 CE 装上
"总想调用"反射;每档剂量都伤 Irrel;ΔU≈0 的示范仍能教会行为(当前动作替换收益不能做硬筛);梯度指纹能
预测部分迁移但原子分解无稳定增量;有限自采样目标会强化错误格式;AppWorld 扩数据无稳定改善。
一句话:**教师执行得好、教师能救活一条轨迹、学生学了教师之后变强,是三个不同的问题;我们攻第三个。**

## 3. 我们的方法:由学习收益决定的选择性行为替换(RTD 收敛后的形态)
在学生实际遇到的状态上,用完整任务反馈学习:把学生哪些行为的概率转移给教师指导、转移多少;再把
这个目标蒸馏进小模型。
- 目标分布 q_a(y|s) = p_0(y|s)[1−a(s,y)] + 1[y=y^T]·E_{u∼p_0} a(s,u):从不同学生行为上取走不同的概率,
  统一转给教师行为。a≡0 是原学生;a 全同是普通混合(严格消融对照);a 依赖行为才是新的自由度。
- 系数信号 z(s,y) ≈ −η h^T P (g_T − g_y):增加该替换后,蒸馏更新使完整任务回报升还是降(含其它
  任务上的损伤)。与 ΔU 的区别:ΔU 问"现在替换动作能否成功",z 问"改变监督后学生是否更容易成功"。
- 更新:局部收益 + 变化惩罚(KL 上界:D_KL(q_a‖q_b) ≤ E_{p_0} D_KL(Bern(a)‖Bern(b)))⇒ 闭式
  a_new = σ(logit a_old + z/τ)(对角情形);带交叉项的联合 QP 是它的推广(我们已有)。
- 蒸馏:保留项用冻结学生的软分布,选择性替换用采样估计(回应 v1.0 的两条自采样问题)。
- 采购:一份指导的价值 = 加入后能否提供当前池没有的、有正学习收益的替换机会;采购与蒸馏共用同一
  价值对象;购买前只用可见信息。
- 冷启动:反馈不可靠时保留非零初始教师监督,不因估计收益为零而停学(写进方法)。
- 复用:已购教师文本跨轮复用(GAD 的做法),新查询受总预算约束。
**创新点**:黑盒预算受限 agent distillation 下,由学习后任务收益驱动的行为概率替换算子,使教师剂量、
学生行为保留与购买价值共享同一优化对象,并给出可高效实现的局部更新。

## 4. 用户提出的两个延伸
### 4.1 trace 内部的各组件要不要一致对待?(组件级替换)
不应一致对待,而且我们的算子天然支持:把"行为"从整条回复细化为 reason / act 两个可生成的片段
(observe 由环境给出,不可替换),每个片段各有替换份额 a^c(s,y)。
- act 片段:任务回报最敏感,替换收益最直接;
- reason 片段:模仿它容易学到"风格而非能力"(Gudibande 2023),我们的 atoms 研究也显示行为模式
  = 一个边界/格式模式 × 幅度,没有可复用的推理原子——所以 reason 片段的默认份额应更低,由回报决定。
这把 SAD 的"分片段监督"从手工权重升级为"由学习收益决定的分片段替换",并给出一个可测的消融:
片段级份额 vs 整条份额 vs 状态级混合,匹配剂量比较。风险:片段级估计更嘈杂(每片段的 g_T−g_y 更小),
需要更多反馈或摊销预测器。建议作为 D3 之后的第二阶段(D4)。
### 4.2 "code is agent language"能用上吗?
CodeAct 一类工作表明可执行代码作为动作空间能提升 agent(统一、可组合、可验证);Kang 的设定也是代码/检索工具。
在我们这里有两种用法:
- 表示层:把 act 片段统一成可执行代码/结构化调用(BFCL 已是函数调用),使"替换单元"边界清晰、可静态检查
  (语法/参数),替换算子能在 token 序列之外按可执行单元操作。ALFWorld 的文本命令也能映射成一个
  小 DSL。收益:替换粒度更稳、伤害可定位;代价:改学生的动作语法 = 改协议,基座要重测。
- 新 benchmark:若加一个代码工具型 agent benchmark(与 Kang 同域),故事更完整,但当前算力下不建议。
建议:作为 4.1 的实现载体(act 片段 = 可执行单元)写进方法的一段,不作为独立卖点;本轮不改动作语法。

## 5. 实验形状(更新)
- 主表:三个 benchmark(ALFWorld / BFCL / 第三个待定),同预算:SmartAD、SAD(文本适配版并标注)、
  Agent Distillation、SOPD、GAD、STaR(零教师参照)、RTD 状态级混合(D2)、RTD 行为级选择性替换(D3)。
- 关键实验:相同教师数据、相近教师剂量与策略变化幅度下,行为级"替换哪种学生行为"是否优于
  状态级"教师占多少"(D3 vs D2);加替换信号置换(D3-shuffle)与同等环境反馈权限的简单对照。
- 报告:总分之外,各类别相对 base 的伤害;每笔购买的边际收益与失败购买记账。
- 顺序:先固定教师池验证蒸馏机制(P1,正在跑),再训练购买前价值预测器(P2)。
