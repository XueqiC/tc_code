# 方法的逻辑与机理(v2.0,2026-08-23)

## 零、一句话与一个敌人

**方法一句话**:预算化蒸馏——一本"能力原子账本"在三个粒度上使用:
Stage I 从 k 条例子建账,Stage II 按账花钱且每笔采购预收伤害费,
Stage III 用一个目标函数把买来的监督刻进学生、并在 token 粒度守住
学生已有的能力。

**一个敌人**:整个方法只防御一种失败——**克隆覆写**。黑盒蒸馏失败
不是因为 teacher 的监督差,而是因为照抄 teacher 输出时,梯度里最强
最好学的信号是 teacher 的表面规律(格式、口癖、篇幅),学生先学会
的是风格;而吸收风格的过程会覆写学生自己的分布,连带冲掉 base 模型
本来就会的东西。我们实验里它表现为"克隆地板":五种选数方法训出来
全在 .200-.215(base 是 .248),换选数方法、换模型规模、加 125 倍
数据都救不了——**病根在训练侧,数据侧治不了**。方法的每个部件,
都是对这次覆写在不同粒度上的一道防御。

## Stage I · 确定任务(建账)

**要回答四个问题**:任务由哪些能力构成?每种要多少?任务边界在哪?
训练它会把邻近任务带向何方?核心动作是用**一个拟合对象**同时回答
四个问题,后面所有决策都只是读这个对象的坐标,不再有独立模块。

### 1. 为什么用梯度不用文本

表示必须让"教同一件事的例子长得像"。文本做不到:同一道题用两种
解法解,要学的东西完全不同,但任何文本函数都区分不了它们。梯度
可以——一条例子在学生初始点诱导的梯度,记录的恰是"这个学生要从
它学什么"。所以每条例子表示为它的梯度特征(Adam 预条件的 LoRA
梯度,随机投影压缩,保内积)。

每条例子有两个视图:**response 视图**(在 teacher 解答上算,记录
"怎么解",买了答案才有)和 **prompt 视图**(只在题面上算,买之前
就有)。整个方法用 prompt 视图做规划、用 response 视图记账——这是
"花钱前就能估值"的来源。

### 2. 为什么稀疏性给原子"身份"

相关例子的梯度特征会复用少量反复出现的方向,就像菜谱复用少量基本
操作。用稀疏字典学习恢复这个结构,稀疏性是关键:主成分子空间对基
的旋转不变,任何单个方向都没有身份;而旋转会破坏编码的稀疏性,
所以稀疏惩罚只让"反复出现、自足"的梯度模式存活——每个存活方向
命名的是一个可复用的技能单元,而不是一条被记住的例子。

### 3. 为什么是双视图耦合字典

计费协议要求"一道题行使哪些能力"必须在买答案之前可估。所以把
prompt 和 response 当作同一潜在能力剖面的两个投影,学一部耦合字典
[D_p; D_r],强制**每条例子用同一个稀疏码同时重构两个视图**。这样
response 信息在拟合时塑造字典,而新候选只用 prompt 视图解码就能
继承它——不需要任何额外学习的"桥"。字典先在支撑集上拟合,随采购
积累而重拟合,词表随证据变锐。

### 4. 三种读数(一物多用)

**读数一,需求配额 r_a**:把支撑集整体分解到原子上,每个原子的
编码质量就是任务对它的需求。配额给"买多少数据"一个**内生答案**:
某原子的监督在配额满前有价值、满后一文不值——数据量由任务自己
决定,不由数据集大小常数决定。

**读数二,任务边界**:一条 query 属于任务,当且仅当能力词表能表达
它。机理比公式重要:稀疏编码只在"某原子能降低重构误差"处分配系数
质量,所以任务外的 prompt 在需求原子上的编码质量趋零,它在 Stage
II 的估值**自动**归零。边界不是买家前面一道带阈值的过滤器,而是
表示本身的性质——所以守边界在任务内零代价("门免费",实验:关掉
门 in-task 几乎不变),任务外零泄漏(残留 0.000)。

**读数三,耦合预报**:两个任务通过共享原子相关,两个视图区分两种
不同的"共享"。prompt 视图重叠 = **混淆度**(一个任务的题会不会被
错认成另一个);response 视图重叠 κ^r = **干涉度**(训练 A 的梯度
会不会搬动 B 的行为)。机理:训练更新沿被行使原子的 response 方向
行走,凡坐在这些方向上的能力会被一起带动。一阶定律
ΔL_off ≈ −η·Σ_a S_a·⟨d_a, ∇L_off⟩,内积同号则建设性、反号则破坏
性、共享为零则解耦。实验三分型全中:sql(κ_r=0)解耦、pandas 底座
建设性迁移、cot(16 个共享原子)破坏性 +.38——**方向全部在花钱前
被预报命中**。

## Stage II · 训练数据(花钱)

**整个阶段是一条决策规则**。对每个候选动作 a(买示范、买对失败
尝试的最小纠正、保留自解轨迹、或停止):

v(a) = [Σ_c min(r_c, ŝ_c(a)) / t̂(a)] −
[λ_anc·Δ_anchor(a) + Σ_{c∈shared} ŝ_c(a)·κ^r_c]

每轮取 argmax,全体 v≤0 即停。

### 收益项的机理

候选的价值 = 它能填补的**未满足配额** ÷ token 开销。min 截断让
超配供给一文不值,由此:(a) 边际递减内置,停止条件内生——账填满,
价格归零,采购自停,无数据量超参;(b) min 恰是使隐式覆盖目标单调
次模的凹帽,贪心继承经典近似最优保证。

### 挤出成本项的机理

候选的真实代价不止 token 价:若训练它会拖动学生已有的能力,伤害
也要计入价格。κ^r 项按字典**预报的干涉**给候选降价——把"保护已有
能力"从训后修复前移为**买前避买**;Δ_anchor 项对学生自己的已验证
行数做同样的事,保住 Stage III 依赖的锚占比。

### 其余机构皆为推论

自解轨迹零成本,单位价值天然最高 → **学生总是先自己试,再付钱给
teacher**;成员门就是 Stage I 的边界命题,任务外候选没有编码质量、
永远赢不了 argmax;纠正轮次、从示范到纠正的转移、最终停止,全部
随学生状态演化自然涌现(缺口衰减、失败集中、继续克隆的挤出成本
上升)。规则没有轮次结构、没有剂量常数、没有阶段边界。

## Stage III · 蒸馏(刻账)

Stage III 不做自己的决策,只执行采购写好的账本。设计完全由克隆
失败的机理倒推。目标函数一个:

L(x) = NLL(y⁺|x) + β·1[y⁻ 存在]·ℓ_OR(y⁺ ≻ y⁻ | x)

三道防御:

### 防御一:锚(保分布)

学生自己已验证成功的行,按普通似然训练。它的作用是**分布性的而非
信息性的**:只要训练分布里始终有"学生自己的成功方言",teacher 的
监督就落成缺口填补,而不是分布覆写。这解释了三条锚定律为何长这样:
出处纯度单调(.284 自产 / .245 混合 / .202 teacher 风格——锚越像
学生自己,锚定越强);剂量 ×1 饱和(锚是分布标记不是数据增强,
在场即可,加倍无益);无锚崩塌(两个台上拿掉锚全部塌回克隆地板)。
锚的占比在 Stage II 买入时就已被 Δ_anchor 保护。

### 防御二:门(保时序)

带配对失败的行加偏好项 ℓ_OR(免参考模型的 odds ratio,因为黑盒
teacher 不给 log-prob)。机理:学生还写不出正例时就施压,概率质量
只能向下无处可去,整体分布塌陷(实验:无门 .630)。所以偏好项按
正例 NLL 的滑动均值门控,只在"正例已学会"后激活——在**一次连续
训练里自动复现"先 SFT 后偏好"的课程时序**,无需切阶段(门控 .660
平分显式两阶段 .668,3/3 种子)。

### 防御三:对比轴(保方向)

偏好对只有在**成功轴**上分歧才许可(同 prompt、verifier 打分不同)。
机理:一对样本的差异轴就是目标函数学到的判别方向——风格对教的是
风格判别,恰恰训练锚要防的漂移(AppWorld 风格对 −.087);成功对
教的才是内容正确性(gsm 内容对 +.032)。同理,偏好损失只从**首个
分歧 token** 起算,共享前缀不受似然挤出压力——这是挤出成本思想在
最细粒度的翻版。

收尾:近优 checkpoint 权重平均(平坦极小值,免费收紧种子方差)+
仅越过一题裕度才回滚的保险。逐例损失按主导原子聚合成吸收曲线,
免费回喂 Stage II 的缺口读数。

## Stage IV · 证书(说清楚交付了什么)

部署请求没有 response,所以边界判定生活在 prompt 特征空间,复用
Stage I 的成员机构。D_p 重构残差作 nonconformity 分数,在不相交
校准集上取 conformal 阈值,得到无分布假设的覆盖保证;学生在边界
两侧行为评测,给出 in-task 覆盖的有限样本下界和 off-task 泄漏的
上界(Clopper-Pearson)。部署时同一机构给活流量把关,证书描述的
恰是学生将见到的流量。

## 附:逻辑链小抄(电梯版)

1. 克隆必败,病根是风格捕获覆写学生分布,数据侧治不了 →
   必须改训练,且最好买前避害。
2. 要买前避害,必须在花钱前知道"这条数据行使什么能力、会拖动
   什么" → 需要 prompt 视图可估值的能力表示 → 双视图耦合字典。
3. 有了字典,需求/边界/耦合都是读数 → 采购归结为一条边际价值
   规则,收益填缺口、成本收伤害费,停止内生。
4. 买回来怎么刻不覆写?锚保分布、门保时序、对比轴保方向、分歧
   掩码保 token——同一个"填缺口不覆写"原则在 token 粒度的执行。
5. 最后用 conformal + Clopper-Pearson 把"交付了什么"说成有限样本
   的有界主张,而不是一个分数。
