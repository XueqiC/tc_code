# 方法全流程记录(v2.0,2026-08-23)

## 我们要解决的问题

手里有四样东西:某个任务的 k=50 条示例查询(任务的全部暴露面)、
一个按 token 计费的黑盒 teacher(只给文本,不给 log-prob)、一个
开源 base 学生模型、一笔 token 预算 b。要产出的是:在这笔预算内,
让学生在这个任务上变得尽可能强。

这件事最直接的做法是拿 teacher 的示范做 SFT,但我们实验发现它不
成立:学生会优先拟合 teacher 输出里最好学的表面规律(格式、口癖、
篇幅),在吸收真正的任务能力之前,先把自己原有的分布覆写掉,结果
训完反而低于不训练的 base(五种选数方法全落在 .200-.215,base 是
.248;换规模、加 125 倍数据都一样)。所以整个方法要做的事情可以
说成一句话:**把预算尽可能多地换成任务内能力,同时不把学生已有的
能力换掉**。下面按流水线顺序,一步一步记录我们是怎么做的。

---

## 第一步:把每条例子变成"该学什么"的向量

我们对每条例子在学生初始点做一次反向传播,取 LoRA 梯度(Adam 预
条件,随机投影压缩,内积保持),作为这条例子的表示。选梯度而不选
文本嵌入,是因为我们需要"教同一件事的例子长得像":同一道题用两种
解法解,要学的东西不同,文本嵌入区分不了,而梯度记录的恰好就是
"这个学生要从这条例子学什么"。

每条例子算两份:只用题面算的 **prompt 视图**(买答案之前就有),
和用 teacher 解答算的 **response 视图**(买了才有)。后面全程用
prompt 视图做买前规划,用 response 视图做买后记账。

## 第二步:把向量分解成"能力原子",建一本账

我们把支撑集所有例子的两个视图放在一起,学一部双视图耦合字典
[D_p; D_r]:每条例子必须用同一个稀疏码同时重构它的两个视图。学出
来的每个码字就是一个**能力原子**,同时有"题面上长什么样"和"解答里
怎么行使"两张脸。

这一步里两个设计各管一件事。稀疏惩罚让原子有身份:主成分子空间
可以随意旋转、任何方向都没有含义,而稀疏性只让反复出现、自足的
梯度模式存活,存活下来的方向对应可复用的技能单元。双视图耦合让
估值可以前置:response 信息在拟合时进了字典,新候选只拿题面做一次
lasso 解码,就能估出它行使哪些原子——这正是计费协议需要的"花钱前
估值"。字典先在 k 条支撑上拟合,之后随采购积累重拟合,词表越用越准。

## 第三步:从账本上读出三个数

账本建好后,我们不再学任何新东西,只做三次读数。

**读数一,需求配额**。把支撑集整体分解到原子上,每个原子分到的
编码质量就是任务对它的需求量,乘上预算得到每个原子的 token 配额。
从此"买多少数据"有了内生答案:某原子的监督在配额满之前有价值,
满了以后一文不值。

**读数二,任务边界**。一条 query 属于任务,当且仅当这套原子词表
能重构它。稀疏编码只在能降低重构误差的地方分配系数,所以任务外的
prompt 在需求原子上的编码质量天然趋零,后面估值时自动没有价值。
边界因此不是一道需要调阈值的过滤器,而是表示自带的性质。实验上它
的两个表现:任务外残留 0.000,把边界判定显式关掉 in-task 也几乎
不变。

**读数三,耦合预报**。两个任务通过共享原子发生关系,两个视图给出
两种不同的关系:prompt 视图重叠是混淆度(题会不会被认错),
response 视图重叠 κ^r 是干涉度(训练一个任务的梯度沿共享原子的
response 方向走,坐在这些方向上的另一个任务会被一起带动,同向则
受益、反向则受损、不共享则不动)。这让我们在花钱之前就能预测训练
这个任务会把周边任务带向哪边。受控实验三种情形全部预报命中:sql
不共享而解耦,pandas 共享底座而受益,cot 十六个共享原子而受损。

## 第四步:按边际价值花钱

采购阶段只有一条规则。每一轮,对每个候选动作 a(买一条示范、买
一条对失败尝试的最小纠正、把一条学生自解成功的轨迹收进池子、或者
停止),我们算它的边际净价值:

v(a) = 填补的未满足配额 ÷ 预计 token 开销
       − λ_anc·锚稀释量 − Σ 共享原子供给量 × κ^r

然后执行 argmax,买入后更新账本(配额缺口缩小),直到所有候选的
v 都不再为正,采购自动停止。

前一半是收益:一条候选值多少钱,取决于它能填多少还没填满的配额,
min 截断让超出配额的部分不计价,边际递减和停止条件都由此内生
(顺带,这个截断恰好让目标单调次模,贪心有经典的近似最优保证)。
后一半是代价:如果训练这条候选会拖动学生已有的能力(κ^r 预报的
干涉)或者稀释学生自己的成功轨迹在池中的占比,这些伤害预先从价格
里扣掉。于是"保护已有能力"发生在买之前,而不是训坏了再修。

这条规则跑起来后,原来需要手工设计的机制全部自己出现:学生自解
零成本,单位价值天然最高,所以总是学生先试、失败了才买 teacher;
任务外候选没有编码质量,永远赢不了 argmax;随着缺口收窄、失败
集中,采购自然从示范转向纠正,最后停下。全程没有轮次、剂量、阶段
这些常数。

## 第五步:用一个目标函数训练

训练阶段不做新决策,只执行采购写好的账。每条训练行都带着"这是谁
的行为"的标签,目标函数只有一个:

L(x) = NLL(y⁺|x) + β·1[y⁻ 存在]·ℓ_OR(y⁺ ≻ y⁻|x)

具体展开是四条:

学生自己验证成功的行按普通似然训练。它们的作用是分布性的:训练
分布里始终有学生自己的成功方言,teacher 的监督就落成缺口填补而
不是分布覆写。这也解释了我们测到的三条规律:锚越接近学生自产,
效果越好(.284/.245/.202 单调);锚放一份就饱和,加倍无益(它是
分布标记,不是数据增强);拿掉锚,一切退回覆写失败。

带配对失败的行在似然之外再加偏好项(免参考模型的 odds ratio,
因为 teacher 不给 log-prob)。这一项按该行正例的滑动平均似然门控,
只在学生已能写出正例后激活:在此之前施压,概率质量只能整体下压,
分布会塌(实测无门 .630);门控后一次连续训练自动复现了"先似然
后偏好"的时序,和显式两阶段打平(.660 对 .668)且无需切换点。

偏好对只许可"同一题面、verifier 打分不同"的成功轴配对。一对样本
差在哪个轴上,目标函数就学会判别哪个轴:风格配对教风格判别,恰好
训练出我们要防的漂移(实测 −.087);成功配对教内容正确性(实测
+.032)。同理,偏好损失只从两条回答的首个分歧 token 起算,共享
前缀不受任何压力。

训练收尾做近优 checkpoint 权重平均(落到更平的极小值,种子方差
免费收紧),配一道只在超过一题裕度时才触发的回滚保险。逐例损失按
主导原子聚合成吸收曲线,免费回喂第四步的缺口读数。

## 第六步:交付时把话说满

部署请求只有题面,所以边界判定复用 prompt 视图的成员机构:D_p
重构残差作分数,在不相交校准集上取 conformal 阈值,得到无分布
假设的覆盖保证。然后在边界两侧分别做行为评测,给出 in-task 覆盖
的有限样本下界和 off-task 泄漏的有限样本上界(Clopper-Pearson)。
上线后同一机构给活流量把关:界内给学生,界外拒答或升级给 teacher,
证书描述的恰好就是学生将实际见到的流量。

---

## 全流程串起来

一次反向传播给出表示;一部字典把表示分解成账本;三次读数给出
配额、边界、预报;一条 argmax 规则把预算换成数据;一个目标函数把
数据刻进权重;一套证书说清楚交付了什么。所有阶段共用同一本账:
第四步的"挤出成本"、第五步的"锚、门、成功轴、分歧起算",是同一个
原则(填缺口,不覆写)分别在样本粒度和 token 粒度的执行。方法里
没有任何一个数字是拍出来的:数据量由配额内生,停止由价格内生,
时序由门控内生,边界由表示内生。
