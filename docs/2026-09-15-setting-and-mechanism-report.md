### 2.1 剂量变体(10 遍;lr 1e-5 与 3e-5)

同六格、同银行,只改曝光遍数与学习率(LONI `tc-hotpotqa-scan2`,作业 1024756 / 1024757)。dev-500 配对 Δ vs base(±SE):

| 格 | 3 遍 1e-5 | 10 遍 1e-5 | 10 遍 3e-5 |

## 3. 教师格式失败与修复(react7)

原池 113 条验证轨迹的 403 步中 **237 步(59%)** 主回复为裸字符串(如 `Paddington (2014)`),由 harness 兜底解析;

| | react6 | react7 |
|---|---|---|
| 主回复格式合规 | 5.5% | **100%** |
| 兜底步 | 79.1% | 0% |
| 验证成功 | 55% | 55% |
| 平均步 / 每次尝试输出 token | 4.55 / 1,020 | 3.25 / 283 |
| 20 题总量(in / out) | 288k / 20k | 69k / 5.7k |
