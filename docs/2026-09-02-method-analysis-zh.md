# 方法分析 v5:以 capability atom 为轴的整套方法(数据获取 → 蒸馏学习)、证据、文献与改进(2026-09-02)

## 1. 设定与目标

给定从任务分布 D 抽出的 support 集 S(只有 query)、小学生 π_θ0、按输出 token 计费的黑盒 teacher π_φ,
在预算 B 内改造学生,使其在 D 的不相交 query 侧上成功率最大(论文 Definition 1;每一次 teacher 调用含失败都计费)。
few-shot 实例化:support = 池的 5% 截到 [50,250],80/20 分 S_d/S_c,按 benchmark 各自实例化(BFCL 实际用 50、
ALFWorld 178、AppWorld 50、τ² 50;BFCL 与论文表的 235 需对齐)。主实验 Qwen3.5-4B + DeepSeek-V4-Pro,四台官方 harness。

## 2. 整套方法:capability atom 是贯穿两段的账本

### 2.0 atom 是什么,为什么它是方法的轴

学生"会什么"不能从 query 文本看出来,只能从**它的参数会怎么变**看出来。对每条 query(或每条候选轨迹)做一次反传,
取 Adam 预条件后的梯度、随机投影压缩,得到一个梯度指纹;对一批指纹做稀疏字典学习,字典的每个方向就是一个
**capability atom——一种反复出现的参数变化方向,对应一种可复用的能力**(证据:sql-join 判别原子的 top 块全是 JOIN 语句;
细粒度判别 AUROC 0.906,密子空间只有 0.615;翻转 5/128 个原子就能翻转行为)。

有了原子,三个量都有了公共语言:
- **需求向量 r**:support 的规格在各原子上的质量——任务要求哪些能力、各要多少;
- **供给向量 s(x)**:一条轨迹能给各原子多少学习信号;
- **缺口 δ = (r − s_已验证)_+**:哪些能力还欠、欠多少。

数据获取就是"为欠供的原子买供给",蒸馏学习就是"让梯度只流向欠供原子、不碰已饱和原子"。
两段共用同一本残差账本。行为侧的 p̂(学生在题上的成功率)是把"行为缺口"叠到原子上的桥:一个原子的失败质量
= 落在它上面的题的失败率加权和。当前 BFCL 实现用的是它的廉价代理——梯度签名簇(簇数由置换检验选)+ 题级 p̂。

### 2.1 数据获取:为欠供原子买供给

**第一步,画需求与缺口。** support 指纹 → 需求向量 r;学生在 support 上按信息价值 rollout(Beta 后验,决定不变就停),
得到 p̂ 与自验证轨迹;p̂ 投到原子上得每个原子的失败质量。这一步还给出**双视图耦合**:题面视图 κ(与参照任务的可混淆度,
决定门要挡多少)、响应视图 κ(共享原子上的干扰潜力,决定训练会伤谁)——都在花钱之前算出来。
服务同一性是前提:p̂ 必须在部署路径上测,否则整本账错定向。

**第二步,估值每一笔候选采购。** 候选是 query 不是示范(示范买了才知道)。对候选 x:
期望解锁覆盖 C(x) = Σ_a min(δ_a, ŝ_a(x))(封顶 → 饱和原子边际收益递减),
期望学生解锁率 ρ̂(x)(带示范后学生能做对的概率),期望成本 ĉ(x)(含失败也计费),干扰 I(x)(对参照原子的梯度冲突)。
U(x) = ρ̂·C/ĉ − λ_I·I。贪心买正边际价值的候选,每买一笔更新 ŝ、ρ̂、δ;max U ≤ 0 或预算尽即停——
预算是上界不是指标。**残差账本本身就是采购单**。

**第三步,三种供给形式,按原子选形式。**
- teacher 示范:给缺口原子最直接的供给,但学生未必能在自己的状态里复现 → 只作探索脚手架;
- guided rollout:学生带示范在**自己的轨迹**上重走,带重要性比——供给落在学生实际会经过的状态上;
- 生成:对欠供原子,从"该原子载荷最高的池内 prompt + 需求最重的 spec query"中按载荷加权抽样,让 teacher 造变体/新 episode,
  由 benchmark 自带 judge 验证,后验饱和即停。生成是**按原子定向**的供给,不是按计分类别撒网。
买示范、买修复、收免费自解、开生成,哪种形式由同一个边际净值 v(a) = 预测增益 − 预测耦合成本 决定,
"示范→修复→自解→停"的演化自动涌现,没有阶段边界。teacher 可示范性 T 与解锁率 U 为零的原子写不可教凭证。

**第四步,入池审计。** 轨迹拆行,带题、轮次、p̂、行为概率与原子载荷;审计渲染一致、长度、覆盖不变量
(每个原子/每道题要么有供给要么有凭证)。

### 2.2 蒸馏学习:让梯度按账本流动

**行权重 = 原子级缺口。** (1−p̂) 是题级代理;正确的量是这一行供给的原子的剩余缺口——同一原子内证据汇聚,权重更稳,
"缺口"从题级抬到能力级(当前 cluster credit 即此代理)。全部缺口为零时更新为零,是安全点。

**课程 = 原子的组合层级。** 多轮技能由前缀原子组合而成;长上下文的行在前缀原子稳定前只会学到噪声,
所以按轮深分位数逐 epoch 放开——本质是按原子依赖顺序学。

**干扰控制 = 在原子子空间上做。** 响应视图告诉我们哪些原子是与已掌握区共享的:
(a) 锚——学生自己在高 p̂ 题上的验证轨迹进 KL/复述项,零成本、on-policy,钉住共享原子上的分布;
(b) 梯度手术——把每步更新投影到"已掌握原子子空间",阻尼该分量、保留缺口分量(标量 λ 保留项的方向版,
剂量曲线证明标量版是用收益换的)。

**行为计时与证书。** 几何只负责选,行为负责判:训练中每若干步行为探针,保留最好检查点;训后逐类别对 base 的 Δ 表 +
Clopper-Pearson 界;任何 base 强类别掉出噪声不发布。

### 2.3 理想方法与当前 BFCL 实现的差距(改进的入口)

| 环节 | 理想(原子账本) | 当前实现 | 差距 |
|---|---|---|---|
| 需求/缺口 | 字典原子 + p̂ 投影 | 梯度签名簇 + 题级 p̂ | 簇是硬划分,无载荷;p̂ 未投到簇上做需求 |
| 采购估值 | U = ρ̂·C/ĉ − λ_I·I,残差账本 | 疑点排序 + 决策驱动观测 | 无 C(x) 封顶、无 ĉ、**无干扰项 I** |
| 生成定向 | 按欠供原子抽 prompt 造变体 | 按 seed 题形状/计分类别造 | 生成没看账本,可能给饱和原子供货 |
| 供给形式选择 | 边际净值 v(a) 自动切换 | 固定顺序:demo→guided(→修复) | 无 buy-vs-ask 计算 |
| 行权重 | 原子剩余缺口 | (1−p̂) / 簇失败率 | 不随采购与训练更新(静态) |
| 干扰控制 | 锚 + 原子子空间梯度手术 | λ 保留项(标量) | 用收益换保护,不叠加 |
| 计时/证书 | 行为探针保留最优 ckpt | 固定 3 epoch | 可能过训 |

## 3. 证据回看(用原子账本解释)

**BFCL**(base 46.27;课程 38.30 > 课程+λ 37.74 > 簇 37.47 > 课程+簇 37.29 > v9 36.70 > 修复 36.34):
- 课程只帮 stateful、簇权重只帮单轮:两者改的是**不同原子**的供给节奏与权重——各自成立;
- 组合不叠加:课程、簇权重、λ 都作用在同一批多轮行的有效梯度上,而账本没有把它们分到不同原子上;
- 仍低 base 8 分:Live/Web Search 失血 = 共享原子上的干扰无人管(锚缺席),Web Search 疑似不可教原子却照样投预算;
- 修复臂无效:35 行供给不到任何原子的缺口量级。
**AppWorld**:旧 harness 让 C∩T 为空,账本里没有"已掌握原子",所以"不破坏"无从检验;官方脚手架下 base 14–16%,才有账可算。
**ALFWorld**:丢目标句 = 需求向量测的是另一个任务,整本账无效;修后 teacher 3/3,池 3,743 行,ours 今日出分。
**τ²**:双边观测成本翻倍,账本要连 user-sim 一起记;暂无分数。
**跨台**:第二段(生成)只在 BFCL 有;其余三台目前只能检验蒸馏侧。

## 4. 文献(2025–26)与改进:整套流程逐环节,围绕 atom

调研范围:on-policy/黑盒蒸馏、技能分解、agent 数据合成、干扰/遗忘控制、多轮 credit 与课程(约 40 篇,2025–26 为主)。
下面按我们流程的环节列"文献怎么做 → 我们的证据说明缺什么 → 改进"。每条改进标 [获取] 或 [蒸馏]。

### 4.1 需求与缺口的估计(atom 账本本身)

- **STAT: Skill-Targeted Adaptive Training**(2510.10023):强 teacher 给每题标"需要哪些技能",从学生答错处建
  Missing-Skill-Profile,再按缺失技能重加权(STAT-Sel)或合成(STAT-Syn),MATH +7.5、OOD +4.6。
  这是与我们"探测 → 缺口 → 采购"最接近的已发表工作,区别是它的技能由 teacher 标注、我们的原子由梯度指纹无监督得到。
- **Skill-it!**(NeurIPS 2023)/ **SkillMix**:技能图 + 按目标技能损失在线调采样比例;组合技能是 OOD 杠杆。
- **RODS: Reward-Driven Online Data Synthesis**(2606.19047):用 rollout 奖励**方差**识别"边界任务"(p̂≈0.5),
  而不是失败任务(p̂≈0)。

**我们的证据**:BFCL 上 (1−p̂) 权重把大量质量给了 p̂≈0 的题(Web Search、MT miss-param),这些恰是 teacher 也难示范的原子;
修复臂 35 行无效也说明"边界"没选对。
**改进 A [获取]:缺口估计从"失败质量"改为"边界质量 × 可教性"。** 每个原子记三量:失败质量、p̂ 方差(边界密度)、
teacher/guided 通过率 T·U;采购与生成优先 p̂ 方差高且 T·U>0 的原子,p̂≈0 且 T·U≈0 的原子写不可教凭证。
额外用 teacher 给 support 题打技能标签(STAT 式),作为梯度签名簇的外部校验——簇与标签的一致性可直接放进论文。

### 4.2 供给形式:买示范、买修复、还是让学生自己走

- **SCoRe: Reinforced Distillation of LLM Agents**(ICML 2026, 2509.14257):学生自己走,teacher 只改**最早的错误轮**,
  在纠正后的前缀上继续;7B 在 12 个 agent benchmark 上追平 72B teacher。
- **SAGE-OPD / Guided-OPD**(2606.19659, 2606.15912):teacher 只在看到环境反馈后的选定轮介入,按 teacher 置信度加权,
  介入概率按计划衰减到零。
- **Rethinking / Revisiting OPD**(2604.13016, 2603.25562):OPD 只在 teacher 真有新能力且思维模式兼容时有效;
  p̂≈0 的地方要先用示范冷启动,中段 p̂ 才用 on-policy 引导。
- **RL's Razor / Retaining by Doing**(NeurIPS 2025 / ICML 2026):遗忘量由新任务上对 base 的 KL 决定,
  **on-policy 数据**是遗忘少的原因,不是 KL 惩罚。

**我们的证据**:guided rollout 在 BFCL 上确实是唯一让 Live 不掉的供给(b12),而整条 teacher 示范喂给 4B 学生带来单轮轴失血;
on-policy 修复臂方向对但剂量太小(35 行)。
**改进 B [获取]:按原子的 p̂ 自动选供给形式。** p̂≈0 的原子买完整示范(冷启动);0<p̂<0.7 的原子只买"最早分叉轮的纠正"
(SCoRe 式,每题成本降一个量级,把失败钉到单个原子);p̂≥0.7 的原子只收学生自验证轨迹当锚。介入概率随该原子 p̂ 上升而衰减
(SAGE-OPD 式)。这正是我们边际净值 v(a) 规则的可实现版本,不需要新旋钮。

### 4.3 生成:给哪个原子造题、怎么保证可验证

- **APIGen-MT**(NeurIPS 2025 D&B):先定 blueprint(真值动作序列)再生成对话,执行验证 + 评审委员会。
- **Skill Self-Play**(2607.22529):出题者/解题者/技能控制器,题目**以技能 ID 为条件**生成,验证结构不变而多样性增加。
- **SENTINEL: failure-driven RL**(2606.12908):从失败轨迹里挖错误模式,Proposer 针对性写可执行任务;
  Qwen3-4B 在 τ²-Retail 66.4→74.9——与我们设定几乎相同。
- **COVERT**(2604.09813):保持真值的增强(干扰工具、歧义 query、脏工具输出),BFCL v3 56.5→59.9。
- **Self-Challenging / Agent-World**(2506.01716, 2604.18292):每道生成题自带验证函数和至少一个反例。

**我们的证据**:v9 生成按"seed 题形状/计分类别"造,没看账本——有可能给已饱和原子供货;四类边界行为(收尾、拒绝、静默轮)
全是失败解剖出来的,本质上就是 SENTINEL 的"错误模式 → 造题"。
**改进 C [获取]:生成以原子为条件、以边界任务为种子。** 生成器的输入从"类别"改成"欠供原子 ID + 该原子载荷最高的种子题
(p̂ 方差高者优先)",teacher 造结构匹配的变体(同 API 拓扑/依赖深度,RODS 式),每题自带 checker 与一个反例,
过不了 judge 不进池。**改进 D [获取]:真值保持的增强**——对 BFCL/τ² 现有任务加干扰工具、歧义 query、脏输出
(COVERT),零 teacher 成本,直接供给 irrelevance / 静默轮这类"鲁棒性原子"。

### 4.4 蒸馏目标:权重、奖励、轮级 credit

- **GAD: Black-Box On-Policy Distillation**(2511.10643):训练一个"teacher vs 学生"判别器当 on-policy 奖励,无需 logits。
- **ROPD: Rubric-based OPD**(2605.07396):从 teacher–学生对比蒸馏出结构化 rubric 当打分层,黑盒可用,样本效率至 10 倍。
- **SOD**(2605.07725):按每步的学生–teacher 分歧重加权,抑制工具错误的级联漂移。
- **GiGPO**(NeurIPS 2025):按共享状态前缀分组得步级优势,ALFWorld +12;**Turn-level credit / Turn-PPO**:以轮为单位。
- **TurnOPD**(2607.05804):自适应 rollout 深度预算,不在低信号尾轮上花钱。

**我们的证据**:行权重 (1−p̂) 是题级、静态的;guided 行的重要性比不随轮变化;MT 失败主因已是"动作错→状态错"(465/672),
即错误发生在某一轮之后级联。
**改进 E [蒸馏]:轮级、原子级的权重。** 分叉轮之后的轮按分歧衰减权重(SOD),按共享前缀分组算步级优势(GiGPO),
权重随采购/训练更新账本而变(不再静态)。**改进 F [蒸馏]:黑盒 on-policy 奖励。** 用 demo 池训练每个原子簇的
teacher-vs-学生判别器或 rubric(GAD/ROPD),给 guided rollout 打分替代手设的重要性比——这是把"黑盒 teacher"从限制变成方法特色的机会。

### 4.5 干扰控制:锚、投影、隔离

- **SDFT: Self-Distillation Enables Continual Learning**(2601.19897):以示范为条件的模型给自己出 on-policy 目标,累积技能不倒退。
- **LoRA Learns Less and Forgets Less**(TMLR 2024):低秩本身就保 OOD;可按原子簇分 adapter 再合并。
- **Gradient orthogonality for data selection**(2602.06359)/ **SafeGrad**(2508.07172):把 PCGrad 式投影从优化器挪到**选数据**——
  在训练前丢掉与锚集梯度冲突的样本,不用每步做手术。
- **Mechanistic origins of forgetting: RL vs SFT**(2605.28860):电路级脆弱度诊断,SFT 更伤电路。

**我们的证据**:λ 保留项的剂量曲线证明标量保护是用收益换的;组合不叠加说明干扰发生在共享原子上;
响应视图 κ 已能在花钱前指出哪些原子共享。
**改进 G [蒸馏]:自蒸馏锚 + 选数据时做梯度冲突过滤。** 锚项用更新前学生在高 p̂ 题上的自蒸馏目标(SDFT),
每个原子簇记录对 base 的 KL 作为干扰门(RL's Razor);采购到的每行先与锚集梯度做冲突检查,冲突者降权或丢弃
(2602.06359)——比每步梯度手术便宜 3 倍,且与我们的指纹基础设施同源。

### 4.6 课程与计时

- **TCOD**(2604.24005):逐步增加 rollout 深度,修复轨迹级 KL 不稳定,ALFWorld/WebShop/ScienceWorld 最高 +18。
- **AgentPRM / PAIR**(WWW 2026 / 2605.17877):步级"进展"过程奖励;隐状态探针可当廉价步奖励。

**我们的证据**:按轮深课程是 BFCL 六臂里最有效的单项(+3 MT),与 TCOD 一致;固定 3 epoch 无行为计时。
**改进 H [蒸馏]:课程按原子依赖顺序(单原子题 → 多原子组合题),深度计划与 KL 稳定度指标照 TCOD;
训练中每若干步行为探针保留最优检查点(方法规格里本来就有,BFCL 实现没用)。**
