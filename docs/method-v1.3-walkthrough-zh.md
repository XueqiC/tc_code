# 方法 v1.3:学习流程(耦合感知版;四个阶段,按执行顺序)

**大故事线**:budget 被尽可能地用来提升 in-task performance。off-task
的走向不是我们优化的对象——它由任务对的耦合几何决定,方法只保证
不为界外能力花钱,并能在花钱之前**预报**耦合后果。

**总原则(一句话)**:学生先试,验证器免费打分,只在学生自己失败的
地方花钱买监督;学生自身分布必须在训练分布中有锚。

设定:support set S = k 条 query 及其 teacher 示范(不计费)+ 按 token
计费的 black-box teacher(无 logprobs)+ 开源学生 + 预算 b。
标注:【已验证】= 多种子外部评测证据;【验证中】= 实验在跑。

## 四个阶段,各一句话

- **阶段 I(确定任务)**:用学生自己的梯度几何把任务分解成能力词汇、
  需求剖面与任务边界,并顺带给出与任何 off-task 的耦合预报。
- **阶段 II(按规格购数据)**:在视图不变的稀疏编码上贪心最大化预算
  受限的次模能力覆盖——学生先试,自解免费,失败才买。
- **阶段 III(on-policy 蒸馏)**:训练信号按学生策略状态分层,合成
  单一 verifier 锚定目标一次优化;终态取探针信任域内的权重平均。
- **阶段 IV(认证部署)**:同一套边界机制经 conformal 校准给出有限
  样本双侧证书,部署时按证书路由。

## 核心对象:双视图耦合字典(定义 1)【已验证】

一部字典两个视图块 [D_p; D_r],每条已知样例用同一稀疏编码 c 同时
重构题面特征(≈cD_p)与响应特征(≈cD_r):
min ‖X_p−CD_p‖² + ‖X_r−CD_r‖² + λ‖C‖₁。
原则:能力剖面视图不变。候选题仅凭题面对 D_p 块 lasso 即得预测供给
(共享编码替代回归桥)。**一个对象七用**:atoms、需求、供给预测、
边界、缺口诊断、吸收观测、**耦合预报**(新,见下)。
效率证据:对 ridge 桥浪费减半(2.0k vs 3.1k tok)、未满足需求减半、
入库 +10%,精度持平。

## 耦合预报(v1.3 新增)【实证成立,定律验证中】

对任务对 (T, T'),两个视图各给一个重叠度 κ:
- **题面 κ = 可混淆度**:决定门需要拦多少(sqljoin 题面 κ=.23,基线
  因此漏买;门在题面视图工作正中要害);
- **响应 κ = 干扰潜力**:决定训练会伤谁(gsm-cot 响应视图 16 个共享
  原子且风格冲突 → 破坏性;sqljoin 响应 κ=0 → 解耦)。
实测三分型(Δloss vs base,9 run 均值):解耦(sql ≈0)/ 建设性
(pandas -.16~-.33,走低于原子分辨率的底座层,免费副产品)/
破坏性(cot +.15~.18,base cot 能力 .5→0)。
一阶定律(验证中):ΔL_off ≈ -η·Σ_a S_a·⟨d_a, ∇L_off⟩——off-task
走向是 in-task 优化的可推导自然延伸;预算扫描(2k→40k)检验斜率,
锚探针检验"混入 off 方向分量可中和破坏项"。

## 阶段 I:确定任务(只用 support,不消耗预算)

I-1. 劈分:70% fit / 30% cal(cal 只定标,绝不拟合)。
I-2. 双视图梯度特征(响应视图 = 教什么;题面视图 = 计费前可得)。
I-3. 耦合字典 → atoms(定义 1)、需求 w(定义 2:编码均值归一化,
     90% 质量截断)、每能力预算 w_a·b。
I-4. 边界 = 题面块重构残差,阈值 = 最不典型 cal 题(conformal;
     松弛 s 可选,实测 s≤1 纯度不掉【已验证】)。
I-5.(可选)对给定 off-task 参照集输出双 κ 耦合预报。

## 阶段 II:按规格购数据(计费;×R 轮,R 稳健【已验证 R=1≈R=2】)

一句话:贪心最大化 F(A)=Σ_a min(w_a·b, Σ_x s_a(x))——modular 供给过
凹截断,单调次模,u(x)=Σ min(r_a, ŝ_a)/t̂ 即代价归一化边际增益,
继承 (1−1/e) 型近优保证。
II-1. 每轮重拟合字典(词汇随证据变细:k=50 恢复 67%→一轮购后 84%)。
II-2. 候选题面 lasso → 预测供给(编码幅度不归一化——幅度即相关性)。
II-3. 按 u(x) 购买,批内工作需求即时扣减;需求清零后按编码密度续购。
II-4. 验货:执行检查 + 题面残差过阈值;拒收计浪费(实测 2-4%),
     预算回环内继续分配——环内门+回购 = 零残留机制(0.000×4 预算
     ×3 种子,v1.2 字典下同样成立【已验证】;开门实测 in-task 代价
     ≈0【已验证】→ 零泄漏免费)。
II-5. 训练插曲读缺口(每能力损失曲线,免费)。
II-6. 纠错轮先试后买:自试 3/3 一致 → 自解免费入库;失败才买
     (示范或对学生错解的最小修复);失败尝试自动配偶好对。
     候选枯竭时定向生成兜底。

## 阶段 III:on-policy 蒸馏

一句话:训练信号按学生策略状态分层——自解处保留自己的行为、失败处
用正解压自己的错解、无尝试处克隆示范——合成单一目标:
L(x) = NLL(正解|x) + β·1[有学生错解]·(分歧掩码 odds 项,NLL 门控)。
- **NLL 门**(odds 项仅在该行正解 NLL 低于运行均值后激活,"先学会
  再区分")【已验证:.660 平分段最优,胜无门 3/3;孤立偏好阶段
  剂量曲线 4/6/12 步 = +.032/-.026/崩,判死】。
- **锚定(跨域三证)【已验证】**:gsm 偏好项靠共训 SFT 梯度锚;
  AppWorld 克隆崩(base .28 > 克隆 .20,加 125 倍数据不救),混 ~1%
  学生自解轨迹即回 base 水平(.284);token 级掩码无锚则无效(两台
  皆 .197)——锚是必要成分。破坏性耦合的 off-task 同理可用少量
  off 方向锚中和(锚探针验证中)。
- 权重平均 + 一题边距回滚【已验证 +.058,种子极差 .013】;
  正确率探针(金标免费)替代可运行率探针【已验证:后者对崩塌失明】。

## 阶段 IV:认证部署

题面块残差 + disjoint cal 的 conformal 阈值 → 覆盖 ≥1−α 的边界预测器;
学生行为在边界两侧测量,Clopper–Pearson 双侧证书;部署时界内路由
学生、界外拒绝/升级——证书描述的恰是学生将见的流量。
