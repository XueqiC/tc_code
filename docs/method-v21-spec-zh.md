# 方法 v2.1 完整流程规范(2026-08-25)

一句话:预算不再购买"供克隆的标签",而是购买"供阅读的示范";学生
在示范提示下自己重做任务,verifier 验收,训练集全部由学生自产的
已验证轨迹构成,再用冻结的锚定目标函数训练;轮次与停止由边际价值
规则内生决定。

---

## 0. 记号(Notation)

**任务与数据**
- $\mathcal{T}$:目标任务;$P_\mathcal{T}$:其查询分布。
- $S=\{q_1,\dots,q_k\}\sim P_\mathcal{T}$:支撑集,$k=50$;任务的
  全部暴露面。
- $q$:一条任务查询;$\tau=(m_1,m_2,\dots)$:一条多轮轨迹,
  $m_i$ 是带角色的消息,助手轮记为 $y_i$。
- $V(q,\tau)\in\{0,1\}$:官方验证器判分(AppWorld 为该任务单元
  测试的多数通过;各台用各自官方判据)。

**模型与预算**
- $\pi_T$:黑盒 teacher,只产文本,按输出 token 计费。
- $\theta_0$:开源 base 学生;$\theta_r$:第 $r$ 轮训练后的学生。
- $b$:总 token 预算;$B_r$:截至第 $r$ 轮的累计花费。

**能力账本(Stage I 的对象)**
- $g(x)\in\mathbb{R}^d$:样本 $x$ 的梯度特征(Adam 预条件 LoRA
  梯度,随机投影压缩);prompt 视图 $g_p$(只用题面),response
  视图 $g_r$(需要解答)。
- $[D_p;D_r]$:双视图耦合字典;码字即**能力原子** $a$。
- $c(x)$:样本的稀疏码;$|c(x)|_a$:样本行使原子 $a$ 的强度;
  未购样本只用 $D_p$ 块 lasso 解码。
- $w$:任务需求(支撑集码的归一化聚合);$r_a = w_a\cdot b$:
  原子 $a$ 的 token 配额;$\hat s_a$:已供给量。
- $\kappa^p_{c}$/$\kappa^r_{c}$:与参照任务在 prompt/response 视图
  的原子重叠(混淆度/干涉度)。

**采集与训练**
- $d_q$:teacher 为 $q$ 生成的示范轨迹;$h(d_q)$:注入用示范块
  (示范中含解答的末段助手轮,去重拼接)。
- $k_s$:每任务采样条数(沿用少样本约定,现取 4);$T_s$:采样
  温度(常规值 0.7);两者为实现常数,列于 appendix。
- $\mathcal{A}_r$:第 $r$ 轮锚池(已验证自产轨迹的逐轮训练行);
  $\mathcal{P}_r$:成功轴偏好对集合。
- $\mathcal{L}(x)$:训练目标(见 §4);$\beta$:odds-ratio 权重
  (v1.2 审定常数 0.25);EMA:门控用的正例 NLL 滑动均值
  (0.99/0.01)。

---

## 1. Stage I·建账(与 v2.0 相同,不变)

对支撑集每条查询做一次反向传播得 $g_p(q)$;对已有解答的样本另取
$g_r$。求解

$$\min_{D_p,D_r,C}\ \|X_p-CD_p\|_2^2+\|X_r-CD_r\|_2^2+\lambda\|C\|_1$$

得到耦合字典与每样本共享稀疏码。三种读数:
1. **需求配额** $r_a=w_a\cdot b$,其中 $w=\frac1k\sum_{q\in S}|c(q)|$
   归一化并保留 90% 质量的原子;
2. **边界**:prompt 在 $D_p$ 下的重构残差,以最不典型校准查询为
   阈;任务外样本码质量趋零,在后续估值中自动无价值;
3. **耦合预报**:对每个参照任务读出 $\kappa^p,\kappa^r$,预测训练
   将把它带向何方(一阶定律
   $\Delta L_{\text{off}}\approx-\eta\sum_a S_a\langle d_a,\nabla L_{\text{off}}\rangle$)。

## 2. Stage II·预算采购(v2.1 的核心改动)

候选动作从"买 $q$ 的示范当训练标签"改为**"买 $q$ 的示范当阅读
提示"**。对每个候选动作 $a$(为任务 $q$ 购示范、或停止),估值

$$v(a)=\underbrace{\frac{\rho(q)\cdot\sum_c\min(r_c-\hat s_c,\ c_c(q))}{\hat t(a)}}_{\text{单位开销的期望配额填补}}\;-\;\underbrace{\lambda_{\mathrm{anc}}\Delta_{\mathrm{anchor}}(a)+\sum_{c\in\text{shared}}\hat s_c(a)\,\kappa^r_c}_{\text{挤出成本(预算效率闸)}}$$

与 v2.0 的两点差异:
- 收益里多了 $\rho(q)$:该任务"提示下自作成功"的经验概率,由已完成
  任务的命中率在线估计(初始用 V1 测得的总体率),失败过的任务其
  $\rho$ 下调——钱流向最可能转化为锚的示范;
- 期望填补用 $c_c(q)$(任务的 prompt 码)而非示范的 response 码,
  因为最终进入训练的是学生自产轨迹,示范只是催化剂。

执行仍是贪心 $\arg\max_a v(a)$、买入更新账本、全体 $v\le 0$ 内生
停止。挤出项的已判定角色(预算效率闸,自动截停)原样保留。

## 3. Stage III·提示自作采集(新)

对每个已购示范的任务 $q$:
1. **注入**:构造 $h(d_q)$ = 示范轨迹中含解答的末段助手轮(相邻
   去重,保留末 6 轮、6000 字符内),以"专家示例,请自行逐步解决"
   的措辞并入系统提示;
2. **采样**:当前学生 $\theta_r$ 在注入上下文下以 $T_s$ 温度独立
   采样 $k_s$ 条完整轨迹,轨迹全程记录;
3. **验收**:每条轨迹交官方验证器,得 $V(q,\tau_j)$;
4. **入账**:
   - 每个任务取一条成功轨迹(如有),**剥离注入的示范块**后,其
     每个助手轮展开成一条训练行(上下文=该轮之前的消息),出处
     标记为 self,进入 $\mathcal{A}_{r+1}$;剥离保证训练上下文与
     部署上下文一致(部署时没有提示);
   - 同任务"成功首轮 vs 失败首轮"构成成功轴对,进入
     $\mathcal{P}_{r+1}$(同策略、同上下文、verifier 判分不同,
     满足许可条件);
   - 该任务的实测命中率回写 $\rho(q)$,供 Stage II 重定价。

## 4. Stage IV·训练(冻结目标,不变)

在 $\mathcal{A}_{r+1}\cup\mathcal{P}_{r+1}$ 上以单一目标训练:

$$\mathcal{L}(x)=\mathrm{NLL}(y^+\,|\,x)\;+\;\beta\cdot\mathbb{1}[y^-\text{ 存在}]\cdot\ell_{\mathrm{OR}}(y^+\!\succ y^-\,|\,x)$$

四条执行细则:
- **门控**:偏好项仅当该行正例 NLL $\le$ 全局 EMA 时激活(先学会
  正例,再施加对比压力);
- **分歧掩码**:$\ell_{\mathrm{OR}}$ 只从 $y^+,y^-$ 的首个分歧
  token 起算,共享前缀不受压力;
- **许可**:$\mathcal{P}$ 中的对必须同上下文且 $V$ 判分相异
  (成功轴);风格轴对一律拒绝;
- **收尾**:近优 checkpoint 权重平均;仅当探针题(示范执行免费
  产生金标)退步超过一题裕度时回滚。

LoRA r16、3 epochs、学习率等通用常数沿用全项目约定,列 appendix。

## 5. Stage V·轮次与停止(内生)

训练得 $\theta_{r+1}$ 后回到 Stage II:$\rho(q)$ 已更新(学生变强
→ 更多任务可命中),配额缺口缩小,示范单价不变——继续采购直到
全体 $v\le 0$。轮次数不是常数,是价格归零的时刻;预算计费包含全部
teacher 输出(示范 + 若用 teacher 兼任 user-sim 的评测台,其 token
同样入账)。

## 6. 部署与证书(不变)

边界判定用 $D_p$ 重构残差 + 不相交校准集上的 conformal 阈值;交付
质量以 Clopper-Pearson 给 in-task 覆盖下界与 off-task 泄漏上界;
上线后同一机构路由:界内给学生,界外拒答或升级 teacher。
