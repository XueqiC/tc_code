# CRCD — Canonical Method Document (skeleton v0.1, 2026-09-04)

Status legend: **[impl]** implemented in this repo · **[prop]** proposed, not yet implemented · **[val]** empirically validated (official protocol) · **[neg]** tested and falsified / downgraded.

## 1. Problem
Input (S_few, π0, T, V, B): few-shot task spec, pretrained small LM (Qwen3.5-4B, LoRA r=8) under a fixed agent scaffold, black-box text-only teacher T, executable verifier V with bounded trajectory utility, teacher-output-token budget B. Objective: maximize expected trajectory utility of the scaffolded student subject to TeacherTokens ≤ B; output also a certificate (representation coverage, atom-wise residual risk, selective-deployment risk). The student deploys without the teacher.

## 2. Notation (authoritative)
x_i task instance · s_i full decision state · y_i^S / y_i^T student / teacher continuation at s_i · Q_i^S, Q_i^T posterior expected terminal utility after the respective intervention · ψ_i Fisher-whitened teacher–student differential gradient fingerprint · u_k atom, U = [u_1..u_K] dictionary, z_i sparse composition, span(U) capability subspace · J_k(π) atom-weighted probe performance · ρ_k required level · r_k = [ρ_k − J_k]_+ residual. Ownership superscripts T/S only (never y+/y−); teacher behaviour is not assumed better.

## 3. Block I — Capability atom discovery
- Event e_i = (s_i, y_i^S, y_i^T, O_i) with matched continuation outcomes. **[impl]** BFCL single-turn / stateful miners, ALFWorld demo-replay miner (K continuations per branch), unified schema **[impl, T1]**.
- Fingerprint: length-normalised ∇ log π(y|s) at θ0 for y^S and y^T over LoRA params, diagonal empirical Fisher from student rollouts, ψ̃ = F^{-1/2}(g^T − g^S), fixed random sketch, unit-normalised, versioned. **[impl, T1]** Baselines A1/A2/A3 (Adam-whitened, unnormalised) **[impl]**.
- Sparse dictionary min ½n⁻¹‖Ψ − UZ‖² + λ_z‖Z‖₁, ‖u_k‖ = 1 (soft coding; PCA / k-means / semantic / category / random baselines). **[impl, T2]**
- Transfer prediction: continuous first-order η z_j^T U^T U z_i vs measured change. **[impl, T2]** Against the gate-v2 arm-level target (8 clusters × 8-sample pass rates) neither A3 nor Fisher ψ beat category/side labels **[neg, low power]**. Against the controlled single-event transfer matrix (BFCL r2, 120×210, T6) ψ·ψ predicts measured transfer with off-diagonal Spearman 0.67 and sign AUROC 0.77 vs 0.61/0.61 for the category label (paired CIs exclude 0); the sparse dictionary equals ψ·ψ (0.69) and PCA-32 is worse (0.53); after double centring ψ = category (interaction structure is category blocks) **[val]**. Robust to the update size (lr 5e-5 replicate, 0/40 saturated rows: AUROC edge +0.14, CI excludes 0). Side decomposition: the student-side push-down is a category block plus a student-length effect (labels win on ρ); the teacher-side transfer (whether y^T becomes more likely on other events) is where ψ keeps its sign/ranking edge (AUROC 0.65 vs 0.56, CI excludes 0) — the paper should define transfer prediction on the teacher-side target.
- Sparse dictionary atoms: reconstruction coverage never exceeds PCA at any K on BFCL or ALFWorld (dev 0.55 vs 0.55; 0.84 vs 0.84), atoms reduce to a finer category partition, and transfer prediction gains nothing over ψ·ψ **[neg]**. Working formulation: capability subspace = whitened gradient subspace (PCA/raw ψ), residuals and constraints defined on it; the dictionary is retained as an optional interpretable basis only.
- Atom inference q_φ(z|s, y^S), atom performance J_k, coverage, LCB, residual r_k **[prop]**.

## 4. Block II — Budgeted acquisition
Query q = (s, L) (continuation length as a decision variable); counterfactual outcome posterior with matched continuations and shared randomness **[impl for ALFWorld/BFCL branch outcomes]**; ΔU = Q^T − Q^S is a derived random variable only — no hard ΔU>0 filter, no raw-ΔU weighting, ΔU=0 not discarded, ΔU<0 not reversed **[neg: all four tested and rejected, see ledger]**. Acquisition objective: expected posterior residual reduction per teacher-output token; offline replay first **[prop]**. Sequential unlocking: reachability must be re-estimated under the current student **[val: ALFWorld depth-1 reachability 0.03 → 0.68 after acquisition]**.

## 5. Block III — Capability-constrained mirror distillation
Constrained objective: min E_s KL(π_θ‖π0) + κ Σ d_k ξ_k s.t. J_k(π_θ) ≥ ρ_k − ε_k − ξ_k; primal-dual with logged λ_k, J_k, r_k, ξ_k, mastered-state KL. Mirror target q_i(y) ∝ π0(y|s_i) exp(Λ_i Q_i(y)/η) over a candidate set with length-normalised scores; Λ_i = Σ_k λ_k z̄_ki / Σ_j z̄_kj; loss Σ_i KL(q_i‖π_θ) + γ_⊥‖(I − UU⁺)F^{1/2}Δθ‖² + γ_probe E KL(π_θ‖π0). **[impl, T3 — smoke only]**. Required limiting behaviours: log q(y^T)/q(y^S) = log π0(y^T)/π0(y^S) + (Λ_i/η)(Q^T − Q^S); large unsatisfied atom → teacher-like target; satisfied atom → vanishing dual pressure. Baselines: CE/SFT, base-centred pairwise, reference-free pairwise, CE→pairwise, KL-regularised CE, global mirror (K=1), ablations **[impl for CE/pairwise/ref-free/CE→pair; others prop]**.

## 6. Block IV — Certification **[prop]**
Representation coverage on held-out fingerprints; atom-wise (d_k, LCB[J_k], ρ_k, UCB[r_k], n_k) with simultaneous bounds; acquisition stopping with shadow price ν; selective deployment (risk–coverage, realised vs nominal risk).

## 9. Teacher-token accounting (authoritative, 2026-09-04)
Teacher = deepseek-v4-pro(-FC) via ollama for the main protocol (gpt-5.4 via Azure for ablations/AppWorld demos). Only the teacher's **output** tokens count; verifier calls (BFCL AST/exec checker, ALFWorld/AppWorld environments) are free by the problem statement. Per benchmark:
- **BFCL**: (i) demonstrations on the 40 official demand tasks: exact, 1,233,607 output tokens over 3 attempts, 34 verified (`results/analysis/bfcl_teacher_tokens.json`); (ii) synthesised task pools (gen_pool*/gen_oos/gen_stateful*, the source of r1–r4 events): usage was not logged before 2026-09-04, estimated ≈143k output tokens by re-tokenising the stored teacher-authored fields (×1.3 prose factor; lower bound); every call is now appended to `data/teacher_ledger/bfcl_generation_usage.jsonl`. Official-task y^T must come from a verified demo (miner `--teacher-demos`); benchmark GT is never a teacher continuation. Calibration ids are never mined. Each arm reports cumulative teacher output tokens (pool synthesis in full + demo campaign in full if any demo row is used).
- **ALFWorld**: replayed verified gpt-5.4 demos; tokens in `data/teacher_ledger/alfworld.jsonl`; no new tokens for the regression suite.
- **AppWorld**: 40 archived gpt-5.4 demos (`results/bfas/appworld/collect_shared/demos.json`); ledger `data/teacher_ledger/appworld.jsonl`.

## 10. Revision 2026-09-05 — behaviour-defined atoms (supersedes §3's dictionary definition)
Evidence (09-04): single-event transfer matrices are near rank-1, symmetric and dominated by the student-side push-down; fingerprints add information only on the teacher side (sign/rank); sparse dictionaries equal PCA on BFCL and ALFWorld; capability-constrained mirror distillation collapses or does not learn on the competent BFCL base (24.0 / 35.5 / 44.7; trust-region controls 46.9 with a boundary flip, lr-matched 45.9) and gives only a small gain on the incompetent ALFWorld base (14.3 vs CE 77.9) **[neg]**; offline acquisition replay on the old pool is flat at equal rows and random wins at equal tokens **[neg, pool cannot test selection]**.
New definition (docs/2026-09-05-atoms-rethink-zh.md): a capability atom is a principal direction of the **teacher-side behavioural response operator** R: δ ↦ (Δ margin of probe j)_j in the H = diag(F)+εI metric — the reduced-rank regression / CCA between legal source updates δ_i (saved LoRA parameter differences, not fingerprints) and fixed development-probe responses; hierarchical (rank-1 call/abstain boundary mode + API-family blocks + residual); the student-side erasure is a separate coordinate. Three axioms, tested in order: predictable (held-out sources, P2), intervenable (real parameter interventions reproduce sign and dose, P3), composable (additivity within a trust region, P3). Atoms are used only for budget allocation and trust-region shaping — never as a loss target. Cross-benchmark claim: parametric atoms do not transfer (ALFWorld ψ on the BFCL basis covers 0.11 = random); what transfers is the factor taxonomy (boundary / family / state / termination) and the derivation procedure, to be replicated per benchmark. Governing brief: docs/2026-09-05-crcd-behavior-atom-execution-prompt.md.
