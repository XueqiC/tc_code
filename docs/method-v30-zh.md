# 方法 v3.0:能力-方言分解驱动的预算化蒸馏(2026-08-25)

**一句话**:我们证明并测量"任何监督的参数更新都分解为能力分量与
方言分量,唯一方言免税的通道是验证过的自我生成",据此把预算全部
用于购买提升自产成功率的上下文,用一条离策略修正的验证策略梯度
(带保护负通道)训练,轮次、停止、退火全部内生。

---

## 0. 记号与协议常数

**任务与数据**。目标任务 $\mathcal{T}$,查询分布 $P_\mathcal{T}$。
支撑集 $S=\{q_1,\dots,q_k\}\sim P_\mathcal{T}$,$k=50$,是任务的
全部暴露面;开跑前一次性切分为需求集 $S_d$($|S_d|=40$,用于
需求估计与采购)与校准集 $S_c$($|S_c|=10$,用于边界校准与回归
探针),全程不相交。轨迹 $\tau$ 为多轮交互,助手轮 $y_i$;在
AppWorld 中助手轮是代码块,环境轮是执行输出。verifier
$V(q,\tau)\in\{0,1\}$ 为官方判分。(开发期实验用过 60 任务无切分
的旧设置,冻结时按 40/10 重跑。)

**模型与预算**。teacher $\pi_T$:黑盒 API,只出文本,按输出
token 计费。学生初始化 $\theta_0$,第 $r$ 轮后 $\theta_r$。预算
$b$,累计支出 $B_r$。学生侧采样与示范重放只花本地算力,不入账。

**示范与提示**。$d_q$:teacher 为 $q$ 生成的完整轨迹(交付时执行
核验,失败记浪费);一次购买永久持有,后续轮免费复用。
$h(d_q)$:提示块 = 示范中含解答的末段助手轮(相邻去重、末 6 轮、
6000 字符内),并入系统提示。

**采集与训练**。每任务采样条数 $k_s=4$、温度 $T_s=0.7$(实现
约定,appendix);$\mathcal{A}_r$:锚集(学生自产已验证轨迹的
训练行);$\mathcal{P}_r$:结果对比偏好对集;$\rho(q)$:提示下
自作成功概率的在线估计;$\beta=0.25$:偏好权重(审定常数);
门控 EMA 衰减 0.99。

**测量仪器**。梯度特征 $g(x)$:学生初始化处 LoRA 的 Adam 预条件
梯度经固定随机投影;prompt 视图 $g_p$ 的 backward 目标是**查询
文本自身的自回归 NLL**(空上下文,购前可得),response 视图
$g_r$ 以解答为目标。双视图耦合字典 $[D_p;D_r]$ 的行是**能力
原子**;稀疏码 $c(x)$;缺视图样本只贡献所在视图的重构项(可用性
掩码)。需求 $w$、配额 $r_a=w_a b$、供给按 token 摊派
$s_a(x)=t(x)|c_a(x)|/\sum|c(x)|$;参照任务重叠 $\kappa^p$(混淆)
与 $\kappa^r$(干涉)。

---

## 1. 核心机制:监督更新的能力-方言分解

任何监督源给学生的期望更新可以写成两个正交分量之和:落在任务
需求原子上的**能力分量**,与落在分布错配原子上的**方言分量**。
三条陈述构成机制的骨架:

**(i) 模仿目标必缴方言税。** 训练目标 $y\sim q_T$(teacher 文本)
时,期望更新沿 $\nabla\mathrm{KL}(q_T\|\pi_\theta)$ 方向;其方言
分量随师生分布距离增长,在小学生上占主导。表面统计(格式、口癖、
篇幅)的梯度信号最强、最易学,因此先被吸收,并覆写学生原有分布。

**(ii) 自产目标零漂移。** 目标取自学生自身分布 $y\sim\pi_\theta$
时,score function 的期望为零:$\mathbb{E}[\nabla\mathrm{NLL}(y|x)]=0$。
自产数据在期望上不移动参数——方言分量按构造为零。

**(iii) verifier 使漂移恰为成功率梯度。** 只保留 $V=1$ 的自产
样本再训练,期望更新变为
$\nabla\,\mathbb{E}_{y\sim\pi_\theta}[V(y)]$(REINFORCE 恒等式)。
唯一的系统性漂移方向就是任务成功率的上升方向:能力分量满格,
方言分量为零。

字典把这个分解变成可观测:方言分量住在分布错配原子上,能力分量
住在需求原子上,两者的范数比可以对任何监督源直接测量(实验 T1),
并可用于预测各监督形态的损伤排序(实验 T3)。一阶耦合定律
$\Delta L_{\mathrm{off}}\approx-\eta\sum_a S_a\langle d_a,\nabla L_{\mathrm{off}}\rangle$
是该分解在 off-task 方向上的显式形式。

三条推论决定方法的全部形状:
- **推论 1(通道)**:外部行为只允许进入上下文,永不做梯度目标;
- **推论 2(更新)**:合法更新族 = 自产已验证样本上的(离策略
  修正)策略梯度,负方向需要保护(见 §4);
- **推论 3(预算)**:钱只该买"提升 $\mathbb{E}[V]$ 的上下文",
  因为买任何"目标"都要缴方言税,买"上下文"免税。

## 2. 测量与需求(建立坐标系)

支撑集每查询一次 backward 得 $g_p$;字典在"当时有特征的一切样本"
上拟合并随证据重拟合:支撑查询(仅 prompt 视图)、已购示范
(双视图)、累计的自产已验证轨迹(双视图)、参照任务语料(双视图,
免费外部数据,供 $\kappa$ 估计)。三种读数:需求配额
$r_a=w_a b$(其中 $w=\frac{1}{|S_d|}\sum_{q\in S_d}|c(q)|$ 归一化
留 90% 质量);边界(D_p 残差 + $S_c$ 上的 conformal 阈);耦合
预报($\kappa^p,\kappa^r$)。

## 3. 预算采购(推论 3 的执行)

候选动作 = 为尚无示范的需求集查询购买示范(作提示用),或停止。
估值

$$v(a)=\frac{\rho(q)\cdot\sum_{a'}\min(r_{a'}-\hat s_{a'},\ s_{a'}(q))}{\hat t(a)}-\Big(\lambda_{\mathrm{anc}}\Delta_{\mathrm{anchor}}(a)+\sum_{a'\in\mathrm{shared}}s_{a'}(a)\,\kappa^r_{a'}\Big)$$

供给一律按 token 摊派($s_a$ 定义见 §0),收益以"期望被转化为
自产成功的配额填补"计;右侧挤出项的实证角色是价格随边际效用
衰减而全面下压,令支出在全体 $v\le 0$ 时内生停止。$\min$ 截断
使覆盖目标单调次模,贪心继承经典近似保证。

**轮次边界**:一轮 = 采购阶段(贪心至全体 $v\le0$)→ 采集阶段 →
训练阶段;训后以 $\theta_{r+1}$ 重估 $\rho$ 与配额缺口,有动作
回正则开下一轮,否则终止。轮数不是超参。

## 4. 采集与更新(推论 1、2 的执行)

**毕业式采集**:每轮先用无提示的 $\pi_\theta(\cdot|x)$ 采样;仅当
无提示全部失败时,才对该任务启用已持有的提示 $h(d_q)$。学生变强
后任务逐个"毕业"到纯 on-policy 采集,提示使用份额自然衰减,采集
分布收敛到部署分布。毕业条件即"无提示已能成功",零退火常数。

**入账**:每任务保留**最短**的已验证轨迹一条(剂量 ×1 饱和),
剥离提示块(训练上下文=部署上下文)后逐助手轮成行,出处=self,
入 $\mathcal{A}_{r+1}$;同任务成功与失败轨迹在**首个分叉助手轮**
处构造偏好对(环境确定 ⇒ 相同动作前缀 ⇒ 相同上下文),入
$\mathcal{P}_{r+1}$;实测命中率回写 $\rho(q)$。

**更新规则**(单式):

$$\mathcal{L}=-\,\mathbb{E}\big[w(\tau)\cdot\mathbb{1}[V{=}1]\cdot\log\pi_\theta(\tau|x)\big]\;+\;\beta\cdot\mathbb{E}\big[\text{门控}\cdot\ell_{\mathrm{OR}}(y^+\!\succ y^-|x)\big]$$

第一项是验证奖励的策略梯度;当样本来自带提示的行为策略时乘截断
重要性比 $w(\tau)=\min(\pi_\theta(\tau|x)/\pi_\theta(\tau|x,h),1)$
(两个密度都是学生自己的,黑盒约束不破;截断 1 为 V-trace 约定)。
第二项是负方向的**保护版估计器**:朴素负优势(GRPO 式组基线)
会 token 均匀下压失败轨迹,重新引入方言税(实证 .630 塌、风格对
−.087);保护三件套将其修正为——只在正例已可学后激活(正例 NLL
$\le$ EMA 门),只从首分叉 token 起算(分歧掩码),只允许同上下文
且 verifier 判分相异的对(结果对比许可)。收尾:近优 checkpoint
权重平均;回归探针($S_c$ 查询 + 重放其示范免费得到的参照结果)
退步超一题裕度才回滚。

## 5. 迭代与停止

训练得 $\theta_{r+1}$ 后重定价:$\rho$ 上升(更多任务可转化)、
缺口缩小(供给累计)。有动作回正 → 下一轮;否则终止。全部
teacher 输出 token 入账(示范,及 teacher 兼任 user-sim 的台子上
模拟器 token)。极限形态:提示全部毕业后,循环退化为纯 on-policy
的验证策略梯度——方法的终态就是标准 on-policy learning,提示只是
冷启动脚手架。

## 6. 证书与部署

边界:$D_p$ 残差 + $S_c$ 上 conformal 阈,in-task 覆盖
$\ge 1-\alpha$ 无分布假设;off-task 泄漏在参照任务语料(免费)上
评,报 Clopper-Pearson 上界;in-task 覆盖报下界。部署时同一边界
路由:界内给学生,界外拒答或升级 teacher。

## 7. 机制的证据与预测(实验映射)

已有证据(全部可复述为定理的推论):克隆地板 .197-.215 三不变
(方言税来自目标分布,选数躲不开);出处纯度单调 .284/.245/.202;
剂量 ×1 饱和(驻点性质);V1 通道对比 33% vs .215(同内容,免税
vs 满税);BB-OPD .197(状态修复不减方言税);无门 .630 / 风格对
−.087(负通道的方言税);vdisp 选择失灵但内生停止成立。

待补(定理的直接验证):**T1** 克隆梯度与自产梯度的方言/能力
分量范数比(字典投影,主图);**T2** teacher 目标占比 0→1 扫描,
损伤随方言分量单调;**T3** 用 round-0 测得的方言分量预测七个
baseline 的下沉排序(预测性检验)。方法侧在跑:round-1(V2)
×3 种子;待接线:$\rho$ 在线定价、首分叉配对、40/10 切分、
$w(\tau)$ 修正(D1)、毕业式采集(D2)、GRPO 对照(D3)。

## 8. 与既有工作的边界(novelty 声明)

现象层面 Gudibande 2023 观察过模仿的虚假承诺,SDFT 用改写弥合
分布差,context distillation 提供了名字,ReST/RFT 提供了批式骨架,
这些都未陈述:(a) 监督更新的能力-方言正交分解及其原子坐标系下的
**可测化**;(b) 自产目标的零漂移性质与 verifier 过滤后"漂移=成功
率梯度"的恒等式作为**设计原理**;(c) 由此生成(而非拼装)通道、
更新、预算三条推论的完整方法;(d) 用分量测量**预测**七种监督
形态的损伤排序。novelty 集中在机制与可测性,组件仅是推论的执行。
