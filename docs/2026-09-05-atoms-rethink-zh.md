# 能力原子应该怎么定义、怎么得到——一次理论上的重想

2026-09-05 01:30,基于 9/4 全部实验证据(迁移矩阵 210×210、稀疏字典两 benchmark 负结果、mirror 三臂 + 两对照、AppWorld 首分歧失败)。

## 1. 今天的数据在说什么

把单个事件单独训 3 步、量所有其他事件的 log π(y^T)−log π(y^S) 变化,得到的响应矩阵 T 有四个硬性质:
1. **近秩 1**:第一奇异值占 86% 能量,是一个"所有事件同向"的公共模式;
2. **对称**(0.87):事件 i 对 j 的作用 ≈ j 对 i,说明它主要是梯度内积结构,而不是有方向的"教会 A 才能做 B";
3. **学生侧主导**:corr(T, −Δlogp^S)=0.94,即公共模式基本是"把学生当前答案压下去",这是遗忘/擦除模式,不是能力;
4. **交互结构 = 类别块**:双中心化后指纹和类别标签打平;指纹的增量只在 teacher 侧(让 y^T 变得更可能)的符号/排序上。

结论:**从单事件梯度指纹做无结构稀疏编码,得到的"原子"= 一个全局擦除模式 + 类别分块,再加噪声**。稀疏性不带来任何东西,因为真实结构本来就是"1 + 块",不是"K 个稀疏可组合方向"。

## 2. 定义上的三个错位

**错位 A:参数方向 ≠ 能力。** 我们把原子定义成参数空间(LoRA 梯度)里的方向。但参数方向在 LoRA 下有规范自由度(A、B 的重参数化),而且同一个行为改变可以由很多不同参数方向实现。能力是**行为空间**的对象:在一组固定探针上产生特定变化模式的干预等价类。参数方向只是它在局部线性化下的坐标。所以"原子"应先在行为响应上定义,参数方向由响应算子的奇异分解**导出**,这正是新任务书 P2.3 的做法——但要把它当定义,而不是当一种拟合技巧。

**错位 B:似然 ≠ 结果。** 能力 = 任务成功,是似然边际经过阈值的非线性函数。设探针 j 的成功概率 p_j = Φ((m_j + g_j·δ)/σ)(m_j 为当前边际,g_j 为探针梯度)。同一个参数方向 δ,对边际远离 0 的探针几乎没有结果级效应,对边际靠近 0 的探针效应最大。这意味着:结果级的"原子结构"一半来自"哪些探针在决策边界附近",一半来自方向本身。设计上必须(i)选边际接近阈值的探针(frontier probes)才有统计功效,(ii)在连续边际响应上定义原子,再通过阈值链接到 0/1 结果,而不是直接在稀疏的 0/1 矩阵上做低秩。

**错位 C:teacher 侧 ≠ student 侧。** 一次更新同时做两件事:提高 y^T 的概率(学),压低 y^S 的概率(忘)。后者是公共模式,和内容几乎无关(只和类别、学生续写长度有关)。原子只应定义在 teacher 侧响应上;student 侧作为一个显式的"擦除坐标"单独建模或回归掉,否则任何字典都会被这个秩 1 模式吞掉——今天稀疏字典 = PCA 就是这个原因。

## 3. 一个干净的定义:响应算子的典型方向

局部线性化下,源更新 δ_i 对探针 j 的 teacher 侧响应是 M_{ji} = g_j^T δ_i(g_j 为探针 j 的 teacher 续写梯度),用 H = diag(F)+εI 做度量。定义:

- **响应算子** R: R^d → R^m,R δ = (g_j^T δ)_j,限制在合法源更新的张成空间上;
- **能力原子** = R 在 H 度量下的主右奇异向量 u_k(要动的参数方向)与配对的左奇异向量 b_k(它改变的探针模式),即 min_{rank K} Σ_i ‖M_{·i} − R x_i‖² 的解——这等价于源梯度空间与探针梯度空间之间的 **CCA/降秩回归**:原子是"从教学信号到探针行为迁移最大的典型方向"。
- 秩 K 由交叉验证决定;如果真相是"1 + 块",这个定义会自动给出秩 1 + 块,而不会强行制造 32 个稀疏方向。

这个定义有三个可检验的公理,缺一则"原子"不成立:
1. **可预测**:留出源的行为响应能由其编码 x_i 预测,且超过公共方向/类别/PCA 基线(P2);
2. **可干预**:沿 u_k 施加真实参数变化,产生 b_k 预测的探针变化,符号和剂量一致(P3);
3. **可组合**:u_a + u_b 的响应 ≈ 两者之和(在信任域内),否则只能是"局部梯度坐标",不能叫单元(P3 组合臂)。

## 4. 结构先验:tool-calling agent 的原子长什么样

从今天的失败模式反推,行为因子至少有四个层次,矩阵的块结构也对得上:
1. **调用/弃答边界**(全局 1 维):所有 BFCL 臂的 Irrel/Rel 一起反向漂;
2. **API 家族的参数模式**(类别块):simple_python 块主导秩 1;
3. **状态跟踪/多步推进**(有状态):MT/Memory 轴独立于单轮轴变化;
4. **终止**(complete_task):AppWorld 的循环失败就是这个因子缺失。

所以更合适的模型不是无结构稀疏字典,而是**分层低秩**:R = 全局边界模式(秩 1)+ 按家族的块方向 + 稀疏残差,每层都用 P2 的响应数据拟合、用 P3 的干预验证。原子的"名字"是行为因子,参数方向只是其坐标。

## 5. 怎么得到:一套可执行的流程

1. **探针设计**:32–64 个固定 development probes,按上面四个因子分层,优先选当前边际接近阈值的题(用 base 的 K 次采样通过率在 0.2–0.8 之间);探针与源无父任务/轨迹/模板重叠。
2. **源设计**:除了单事件,加**对比源**——同一 prompt 配调用目标 vs 弃答目标、同一 API 家族配不同参数形式、有状态事件配 t 早/晚——用来把边界模式、家族模式、阶段模式各自分离出来(这是从矩阵结构里"分离因子"的关键,单事件源分不开)。
3. **测量**:每个源从同一初态独立 micro-update,存真实 δ_i(不是指纹),量所有探针的 teacher 侧边际变化 + 0/1 结果;student 侧单独记录。
4. **拟合**:H 度量下的降秩回归(= CCA),先 K=1,再加家族块,最后看残差;用 B-null/B0/B1/B3 对照和分组交叉验证;主指标是留出源的行为响应误差与净收益排序。
5. **验证**:沿 u_k 及其组合做真实干预(P3),测符号、剂量、可加性、负迁移。
6. **使用**:原子只用于两件事——(a)预算分配:哪个因子的残差最大、每 token 能买到多少预测收益;(b)信任域整形:把更新限制在"原子张成 + 全局边界模式"内并单独控制边界模式的幅度。**不用原子做 loss 目标**(mirror 的教训:压力型目标在竞争力 base 上只会把边界推翻)。

## 6. 对新任务书的两点修改建议

- P2.3 的最小响应模型改成**分层**:先 rank-1 公共项,再按家族块,再残差;并把 student 侧作为独立坐标而不是混在 diff 里。这样 P2 的判决会更有信息量(是"没有原子",还是"只有边界 + 家族两层")。
- 源集合加对比源(同 prompt 不同目标),否则边界模式和家族模式在单事件源上是纠缠的,秩 1 会把一切吞掉。

## 7. 我对结局的预期(写下来防止事后改口)

最可能:秩 1 边界模式 + 家族块通过公理 1、2,组合可加性在小剂量内成立、在大剂量失败;细粒度残差不可预测。这已经是有用的结果:它把"原子"从 32 个稀疏方向收缩为"1 个全局边界 + 少数家族方向",并给出了预算分配和信任域整形的直接用法。若连秩 1 + 块都过不了干预关(P3),那原子这条线在 BFCL 4B 这个测试床上就该停,转到有 headroom 的 ALFWorld/AppWorld 重测。
