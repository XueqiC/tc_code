## v1.1 修订(2026-09-05 13:30,采纳外部建议后)

结论措辞收窄(替换 §1/§6/§9 中相应句子):
- P2 最可靠的负结果是:**在当前训练器、剂量、编码和探针下,没有发现超过公共响应与更新幅度的、可泛化的行为预测信息**。不写"可行更新集的极点没有出现"——集合非空则极点存在;没找到的是有额外预测与教学价值的原子结构。
- 留出源在训练基上的残差 ≈ 0.99 是关键限制:留出更新的大部分内容根本没进入预测器,低秩预测失败同时检验了"参数输入能否泛化"与"行为响应有没有结构",不能只归因于后者。δ_i = u + σe_i 且 Ge_i = 0(事件特有分量占主要范数、公共分量 u 决定行为)与全部观察相容。
- B0-norm 损伤 AUROC 高但净收益 Spearman −0.35:只作对照,不是可用的选择器或剂量控制器。
- 0/1 保留探针下 B_R w ≥ 0 只能要求"选中事件在保留探针上没有负响应",矩阵里没有正数可补偿;LP 实际是"筛出单训时没有可见失败的事件",不能检验"锚点增加保留余量以抵消损伤"。
- 联合检验判决改为:**少数组合有用(src_17+弃答锚点 (2,0)、src_04+同家族 call 锚点 (1,0)),但目前没有可泛化的选配规则;现有测量与样本量不足以确认系统性补偿。**"只稀释"降为候选解释。
- T9 ALFWorld 是旁证不是同协议复现(剂量、响应对象、lr 都不同);rank-1 0.997 与去均值后 0.68 同时报。
