## 0. 一页总览

**问题**:给定少量目标任务示例、黑盒文本 teacher 和 teacher 输出 token 预算,把小模型蒸馏成更好的 agent。核心子问题:蒸馏时如何组合已有 teacher 证据,以及该买什么证据。

**定义**:能力原子 = **可由当前 teacher 证据通过正常训练实现、具有明确行为作用、与保留要求相容的最小教学更新单元**,记为三元组 𝔞_k=(a_k, u_k, b_k):配方(用哪些示范、什么比例)、参数方向、行为模式。原子是"低秩化的可行更新集"的极点;行为模式 b_k 是跨任务可复用的对象,配方 a_k 是它在当前池中的实现。

**机制主张**:最小有效教学单位可以是一组**互补**示范(单独训会伤或没用,合训才有净收益),因此数据价值超可加;蒸馏 = 求配方权重(缺口残差 + 保留约束 + 信任域)后做加权监督;采购 = 补全尚不可实现的原子。

**证据三条腿**(缺一则降级):理论(表达力、稀疏实现、局部保证)、机制(互补组合可复现且简单基线解释不了)、性能(匹配 teacher 成本与剂量后优于调好的 CE / pairwise / 梯度约束 / 普通重加权)。

**已知事实约束设计**(9/4 全部实验):单事件更新的响应矩阵近秩 1、对称、学生侧擦除主导、交互 = 类别块;指纹只在 teacher 侧有排序信号;稀疏字典 = PCA;压力型目标(mirror)在竞争力 base 上塌、在不会做的 base 上远逊 CE;等 token 采购启发式互相抵消;参数级原子不跨 benchmark(ALFWorld ψ 在 BFCL 基上覆盖 0.11)。

## 1. 设定与记号

- 学生 π_θ,LoRA 参数 θ∈R^d,基点 θ0。度量 H = diag(F)+εI,F 为 θ0 处学生 rollout 的经验 Fisher;‖δ‖_H² ≈ 2·KL。
- teacher 证据 i=(s_i, y^T_i, Q_i, c_i):状态、续写、验证效用、teacher 输出 token 成本。
- 统一监督损失 ℓ_i(θ) = −log π_θ(y^T_i | s_i)(或 base-centred pairwise;第一版理论用固定预条件一步更新)。
- 单元更新 d_i = −P∇ℓ_i(θ0),D=[d_1..d_n];可实现更新 δ = Dw, w ≥ 0(非负:只能"正学"示范,不能反向学)。
- 行为:固定探针集,J_j(θ) 为探针 j 上的期望表现(真实任务结果,或其边际的平滑版);G = [∇J_j(θ0)]_j;局部 J_j(θ0+δ)−J_j(θ0) = g_j^T δ + O(‖δ‖²)。
- 行为映射 B = G D(探针 × 证据):证据经训练后对各行为的一阶作用。缺失集 M(要提高)、保留集 R(不能退化),缺口 r = [ρ_M − J_M]_+。

## 2. 定义

**可行配方集** 𝒜 = {a ≥ 0 : 1^T a = 1, B_R a ≥ 0};**可行更新集** 𝒰 = {Da : a ∈ 𝒜}。

**低秩化**(B 方的贡献):B 由有噪声的 micro-update 估计,高维下极点数量多且不稳定。先在 H 度量下把 B 拟合为分层低秩 B̂ = b_0 u_0^T + Σ_f B_f U_f^T + 残差(全局调用/弃答边界模式 + API 家族块 + 残差,teacher 侧靶,学生侧擦除作为独立坐标),再用 B̂ 定义 𝒜。行为上可区分的极点数由响应秩与活跃保留约束数控制。

**原子** := 𝒰(低秩化后)的非零极点,𝔞_k = (a_k, u_k = D a_k, b_k = B̂ a_k)。

**不变性**:在 LoRA 重参数化 θ = Tφ 下,H 度量的白化使 x = C^T H δ、B̂、b_k 不变,u_k 协变——原子是行为空间对象,参数只是坐标。

## 3. 理论结果(第一版要写严谨的部分)

1. **表达力**:局部线性模型下,任何由现有池实现且满足保留约束的更新可写成原子的非负组合 δ = Σ c_k u_k(凸几何,Minkowski/Carathéodory)。目的不是重构梯度方差,而是保留可行蒸馏更新的表达能力。
2. **稀疏实现**:每个极点存在一个使用 ≤ |R|+1 条示范的实现;更紧的界 = 活跃独立保留约束数 + 1。教学组合的大小由需协调的行为约束数决定,而非手设 K。
3. **正向学习方向存在性判据**:存在可行 Dw 使 r^T B_M w > 0 ⇔ 当前池在保留要求下有正向局部学习方向;否则应买互补证据 / 改监督长度 / 调保留容忍,而不是加压。
4. **有限步长界**:若 J_j 局部 L_j-光滑,J_j(θ0+ηu)−J_j(θ0) ≥ η g_j^T u − (L_j/2)η²‖u‖²;保留损失 ≤ ε_j 给出剂量上界;一阶零损伤不保证二阶零损伤——方向与剂量必须一起设计。
5. **信任域整形 ≥ 全局 KL(帕累托)**:设训练器提出 δ0 = C x0 + δ⊥。原子约束更新解 min ‖x−x0‖² − αJ⁺(x) s.t. J⁻(x) ≤ τ, ‖x‖²+‖δ⊥‖_H² ≤ ρ²(K 维 QP,闭式)。在任一损伤预算下其预测收益 ≥ 全局 KL 缩放解;严格大于 iff x0 在损伤模式上有分量。损伤集中在秩 1 边界模式时退化为"单独限制 u_0 幅度"(= 9/3 自适应锚点臂的经验机制)。
6. **采购超可加**:V(S) = 用已购集合 S 在保留条件与统一剂量下的最优收益;两示范例子 V({1})=V({2})=0 < V({1,2}),故数据价值不可加、无递减保证;一步查询价值非正不是停止证书;购买目标可以是补全未实现原子。粗层(边界/家族)在购买前由状态可预测,残差层不可——细粒度原子对采购无用。

## 4. 估计(测量层,沿用任务书 P0–P2 纪律)

- **源**(24 正式 + 4 pilot + 2 no-op):单事件 / 固定小包 / **对比源**(同 prompt 调用 vs 弃答目标、同家族不同参数形式、同任务早/晚阶段)。对比源是识别性的必要条件:没有它,边界与家族模式共线,只能识别其和(今天的秩 1 现象)。
- **探针**(32 固定 P_disc):按四因子分层——调用/弃答边界、API 家族参数模式、状态推进、终止——优先 frontier(base 通过率 0.2–0.8),与源无父任务/轨迹/模板重叠;P_confirm 另留;65 道官方校准题永不参与选择。
- **micro-update**:每源从同一初态独立训练(固定剂量,存真实 δ、优化器/RNG 恢复),记录更新范数、有效 token、步数、策略 KL;pilot 先校准剂量(高于 bf16 底噪、有可测行为变化、无大范围弃答偏移),正式剂量冻结。
- **响应**:确定性解码 0/1 结果 + teacher 侧 / 学生侧似然边际,分别记录;NA 不填 0。
- **拟合**:H 度量下分层降秩回归(rank-1 → 家族块 → 残差),对照 B-null / B0(公共方向、类别/长度/范数)/ B1(PCA)/ B3(置换);按父任务分组交叉拟合;指标为留出源的行为响应误差、净收益排序、损伤识别、分组 CI。

## 5. 算法

### 5.1 原子发现
不枚举极点。在低秩空间求 LP/QP:给定缺口 r 与保留集,找当前最有用的可行配方 a*(最大化 r^T B̂_M a s.t. a ∈ 𝒜),记录活跃约束,得到一个原子;沿缺口残差迭代得到少数原子;每次更新后重估局部几何。

### 5.2 蒸馏(配方 NNLS + 信任域)
  min_{w≥0} ½‖[r − B̂_M w]_+‖² + (λ/2)‖Dw‖_H²  s.t. B̂_R w ≥ 0, ‖Dw‖_H ≤ ε。
解出 w 后做 ℒ = Σ_i w_i ℓ_i(θ)(加权监督)一段短训练;剂量 ε 由 §3.4 界与 pilot 校准;控制发生在训练器提出增量之后(§3.5 的 QP 是同一件事的实现版);累计漂移超出校准范围则刷新几何或回退。改变的不是 loss 形式,而是:哪些示范必须合训、比例、剂量、何时停。

### 5.3 采购
先验证超可加(§6 G5);再以"补全未实现原子"为目标:对每个缺口因子,估计需要补的互补证据类型(边界层/家族层由状态可预测),在真实 query/output 预算下与随机状态 + 短续写、覆盖、便宜优先、行为预测采购比较。

## 6. 实验计划(关口顺序,单种子探索;每关有明确降级规则)

- **G0 审计**(P0,进行中):运行有效性、302 行池逐行核对、split 交叉、成本账本、底噪/no-op 单测。
- **G1 互补组合检验**(最便宜、最尖锐,先做):12 对(纠正 c,同家族锚点 r_match,随机锚点 r_rand)× 4 臂(c 单训 / r 单训 / c+r_match 合训 / c+r_rand 合训),匹配剂量,32 探针量目标收益与保留损伤。通过:合训净收益 > 两单训之和且 > 随机锚点(CI 不含 0)。可加 → 无互补,降级为"受约束蒸馏";随机锚点同效 → 只是剂量/正则效应。
- **G2 响应模型竞赛**(P2):24 源 micro-update,分层 B̂ vs B0/B1/B3;判决 GO-candidate / SIMPLIFY / NO-GO / INCONCLUSIVE。
- **G3 干预与可加性**(P3):沿 u_0、家族方向、B̂ 预测方向及组合做真实参数干预,0.5×/1×/2× 剂量,no-op 与匹配范数随机方向对照;P_confirm 冻结确认。
- **G4 蒸馏对照**(P4):D0 调好的训练器 + 全局 KL;D1 PCA 方向 + 控制器;D2 原子配方/QP 控制器;D3 置换映射。固定池、初始化、次序、种子、有效 token、信任域、调参预算;主指标学习–保留帕累托;先单种子,最终两臂补两个配对种子。
- **G5 采购**(P5):先验证 V 超可加;再最小对照(随机状态 + 短续写 / 覆盖 / 正确成本口径的便宜优先 / 行为预测采购),真实 query/output 预算,端到端与摊销曲线分开报。
- **跨 benchmark**:BFCL(竞争力 base)→ ALFWorld(不会做的 base,ψ 近一维,预期只有边界模式)→ AppWorld(终止因子;先做 early-vs-spread 覆盖对照)。检验的是同一程序复现同样的层级结构与同样的机制(互补、帕累托),参数方向不共享。

## 7. Novelty 定位(明确不据为己有的部分)

已有:LESS(梯度/优化器信息选目标相关数据)、GRAD-MATCH(子集 + 权重匹配有用更新)、GEM(局部梯度约束减少旧任务损伤)、任务向量(参数差,无行为配对)、影响函数(标量归因,无基)、CCA/降秩回归(统计工具)。
主张的贡献:**把能力原子定义为可由 teacher 证据实现的基本教学更新(配方–方向–行为三元组),证明证据的互补关系如何同时决定蒸馏(配方权重与剂量)与购买(补全未实现原子、超可加),并给出使之稳定、可复用、跨 benchmark 的估计层(H 度量分层低秩响应)。**

## 8. 失效方式与降级规则(写在前面)

- G1 不通过(无互补 / 随机锚点同效)→ 论文改为"受约束蒸馏 + 剂量控制 + 记账",原子只作分析。
- G2 = SIMPLIFY(rank-1 + 家族块已解释)→ 原子收缩为"边界模式 + 少数家族方向",保留 §3.5 的用法。
- G3 可加性在 1× 剂量失败 → 只能宣称局部梯度坐标,不宣称"能力安装"。
- G4 D2 只在几乎不更新时接近 base,或 D0 调低 lr 即可复现 → 归因稳定性,不归因原子。
- 数值底噪主导(bf16)→ 先修测量,不用不可靠矩阵训练。

# v1.1 修订(2026-09-05 08:20,采纳方案 A 作者的第二轮意见,docs/2026-09-05-atoms-alt-author-reply-2.md)

**主线收敛为:A 的可实现配方定义 + 满足参数响应一致性的 B 估计器 + 估计误差与剂量控制 + 改正后的受约束互补实验。** 以下逐条替换 v1 中的对应内容。

1. **G1 通过标准改写。** 互补性指"受保留约束的学习价值"互补,不是原始响应超线性。标准:在统一的保留损伤上限与训练资源预算下,联合配方是否扩大了可达到的目标收益(比较"最佳已测可行收益",不称全局 V)。配方比例与剂量在 development 数据上定,在 P_confirm 上评。新增控制:纠正样本单独降剂量(匹配联合训练中的纠正曝光)、纠正 + 替代锚点。r_match 定义为"预测能补偿该纠正方向损伤"的锚点,同家族匹配只作简单基线。"随机锚点同效"首先否定的是细粒度匹配的必要性,不直接归因剂量/正则。
2. **G1 并入 P2 的测量,先单后合。** 先独立测量单源响应(24 源含纠正与候选锚点),拟合 B̂ 并在公共模式之外寻找可辨识的**补偿方向**(b_R > 0 且 b_M ≥ 0 的方向);有补偿方向才组联合配方做少量 pilot(≤ 8 次训练),可复用结果进入响应矩阵,不再做 12×4 = 48 次。尖锐推论:若真实"收益–损伤"响应只有一个冲突方向,任何组合都改不了比例——已有的"log-odds 迁移近秩 1"未证明真实行为响应也如此,因此本轮重点是找补偿方向,而非再提高总体相关性。
3. **主蒸馏算法 = 配方蒸馏**(δ = Dw, w ≥ 0,固定预条件一步/短块协议,几何随训练刷新);参数投影/整形只作独立对照或后续扩展。Adam(Σ w_i g_i) ≠ Σ w_i Adam(g_i),多步 micro-update 的 δ 不自动是加权监督的线性单元——理论与实现用同一协议。
4. **B 估计器须满足参数响应一致性**:B̂ = R C^T H D(同一参数更新 ⇒ 同一行为预测);分层结构施加在响应算子 R 上,不允许源类别标签绕过参数更新直接决定响应。三种输出分开:真实任务行为响应(主)、teacher 侧似然、student 侧似然;teacher 侧优势只作辅助表示线索。
5. **删除"极点数由响应秩控制"**(反例:二维响应空间上的正 N 边形)。改为"用低秩行为估计器定义约束的 teacher 可实现更新集";响应秩限制行为变化维数,活跃约束数限制某极点的稀疏实现,二者不给原子总数上界。增加**估计误差与可行性**:若 |B_ji − B̂_ji| ≤ E_ji,则 w ≥ 0 下 B_R w ≥ (B̂_R − E_R) w,用保守约束 (B̂_R − E_R) w ≥ 0;误差界的紧度有限样本下待验证。参数极点与行为极点不混用;b_k 的跨实例复用作为待验证性质。
6. **H 不变性降调**:理想理论(度量、更新规则、估计器都按变换规则)下行为映射坐标一致;实际用对角 Fisher + 固定阻尼,不满足严格变换,重参数化稳健性由实验检验;‖δ‖_H² ≈ 2KL 是需校准的近似,策略 KL 独立测量。
7. **§3.5 帕累托命题降为可行集包含陈述**:若整形可行集包含全部合法缩放候选且优化同一收益目标与约束,则整形最优预测收益不低于缩放;删除"闭式 QP"与"iff"表述,不作核心创新。
8. **采购**:"超可加"改为"可能存在严格互补,一般无次模性保证";删除"粗层可预测 ⇒ 细粒度原子对采购无用"的推论(需额外假设/实验)。
9. **实验设计修正**:分层低秩只是候选估计器,与非分层比较,不预设各 benchmark 都有"边界 + 家族"结构(ALFWorld PC1 大 ≠ 语义是调用/弃答);探针保留已稳定掌握的题以测遗忘,确定性单次结果不是 0.2–0.8 的概率;同 prompt 的调用/弃答"对比源"若目标错误只作诊断,不进 teacher 可实现集,优先用"正确决策因状态而异"的配对任务;G3 某剂量不可加只否定该剂量的线性近似,不否定能力安装(由真实任务表现判断)。
