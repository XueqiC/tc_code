## 0. 最重要的一句话:结论要从"negative"改为"实现受限,未构成检验"

我在 18:10 报给你的判断是"**negative,不是 INCONCLUSIVE**",依据是两个关系臂都拿到了充分监督
(46 个唯一关系全部 live)。**那个依据不足,判断要更正。**

拿到监督 ≠ 学到东西。把训练日志打开看,三个臂的实际情况是:

| 诊断量 | D0_s0 | D1_s1 | D2_s0 |
|---|---|---|---|
| teacher CE step 1 → 24 | 1.940 → **1.926** | 2.072 → **2.100** | 1.940 → **1.927** |
| relation loss step 1 → 24 | 0(无此项) | 0.284 → **0.283** | 0.055 → **0.054** |
| **reference KL(相对 base)step 24** | **0.00030** | 0.00028 | 0.00027 |
| anchor 梯度范数(中位) | 5.909 | 4.573 | 5.344 |
| relation 梯度范数(中位) | 0 | 1.095 | 0.662 |
| **实际参数更新范数(24 步总和)** | **0.00004** | **0.00004** | **0.00004** |

**梯度是健康的(中位 5~7),但 24 步累计的参数更新范数只有 4×10⁻⁵,
训练结束时策略与 base 的 KL 只有 0.0003 nats/token,而且没有任何一个损失下降过。**

**模型基本没有动。** 因此这一轮**没有检验四格目标的价值,它检验的是一个无法推动模型的剂量。**
按任务书 §13,这属于"**确认实现缺陷 → 结果受缺陷影响 → 修复后按统一规则重跑**",
不是"negative"。**这是我今天第三次更正自己,但证据是明确的。**

## 3. 为什么是负 —— 逐层排除

### 3.1 不是"素材里没有关系可学"(这一条已被排除)
训练前实测:同父配对下 46 个关系**无一退化**,平均 |m1| 19.06、|m2| 16.23、|B| 34.32。
τ=20 下 **D1 与 D2 都是 46/46 唯一关系 live**,D1 的关系损失约 0.28–0.47、D2 约 0.05–0.15,
**都是非平凡量级**。关系项确实参与了每一步。

### 3.2 不是"跨父配对的字面捷径"(已在训练前修掉)
跨父配对下 B 中位 **98.14**、最小 margin 10.06、**D2 损失 > 1e-6 的关系 0/60** —— 完全饱和,
照原计划跑会让三臂**按构造相同**。改同父配对后 B 中位降到 **33.77**,首次出现负 margin(−10.57)。
**这一步是有效的,并且是在烧 GPU 之前用一个 GPU 小时测出来的。**

### 3.3 **真正的原因:更新量本身接近零**
- **24 步累计参数更新范数 = 4×10⁻⁵**(三个臂都是);
- 训练结束时**策略与 base 的 KL = 0.0003 nats/token**;
- **teacher CE 从头到尾没降**(1.940→1.926;D1 甚至 2.072→2.100);
- **relation loss 从头到尾没降**(D2 0.055→0.054,D1 0.284→0.283);
- 结果:每个臂与 base **90–91% 的答案逐字相同**。

梯度是正常的(anchor 中位 5.9,relation 中位 0.66–1.10),**但优化器把它们变成了几乎为零的更新**。
剂量是 `fixed_preconditioned_single_step` + RMS 对角预条件 + lr 1e-5 + LoRA r16 + 24 步。

### 3.4 由此推出的一个更大的问题
**同一个剂量正是 Table 1 三个基线用的剂量。** 归档结果:base 38.2、SmartAD 37.8、SAD 37.4、Kang 37.2 ——
全部**低于** base,极差 1.0 点。结合今天测到的"该剂量下参数几乎不动、90% 答案与 base 相同",
最简洁的解释是:**这三个基线也没有被真正训练,它们与 base 的差异同样是解码噪声。**
这与 09-14 早些时候的另一个发现完全一致 —— 三个基线逐题结果 475/500 相同、行为指标近乎一致。

**如果这个解释成立,那么整条 Table 1 线比较的是几个几乎未改变的模型。**
这需要一次独立验证才能定论(见 §5),但它现在是最有解释力的假设。

### 3.5 次要因素(存在,但不足以解释)
- **单/双种子不对称**:D1 只有 seed 1。削弱主比较,但 D2−D0(两臂都双种子)同样是 −0.10 [−1.50, +1.30]。
- **种子噪声 ≈ 臂间差异**:D2 两个种子之间 93.6% 答案相同,而 D0 与 D2 之间 91.6% —— **同臂不同种子的
  变异与不同臂之间的变异同量级**,任何真实臂效应都被埋在里面。
- **留出集太小**:n=32,一题 3.125 点。
- **环境漂移 −1.2 点**:对所有臂相同。

## 4. 能写的 / 不能写的

**能写:**
- 跨父配对使四格来源目标完全饱和(B 中位 98.14,D2 live 0/60),同父配对将其降到可学区间(B 中位 33.77);
- τ=1 在该 margin 分布下**数值上不可训练**(校准失败于非有限梯度);
- 在 doseB 下,24 步累计更新范数 4×10⁻⁵、策略与 base 的 KL 0.0003 nats/token、各损失不下降;
- 各臂与 base 90–91% 答案逐字相同,配对区间全部跨零。

**不能写:**
- ❌ "联合四格目标无效" —— **模型没被训动,这一轮没有检验它**;
- ❌ "条件来源监督对自主执行没有帮助" —— 同上;
- ❌ 用 n=32 上的 −6.25 说 D2 损害泛化(2 道题);
- ❌ 把 −1.2 点漂移当作我们落后基线的原因(漂移对所有臂相同)。

## 5. 下一步(按优先级,均不需要教师调用)

1. **先验证剂量能不能推动模型**(最高优先,便宜):用同一批素材,把 lr 放大若干个量级或改用标准 AdamW,
   跑 1–2 个格子,**只看 teacher CE 是否下降、参数更新范数是否离开 10⁻⁵ 量级**。
   若 CE 能降而任务成绩仍不变,那才是关于方法的结论;若 CE 也降不下来,问题在优化器/剂量而非目标。
2. **同日复测三个归档基线**(消除 1.2 点漂移,并直接检验 §3.4 的假设):
   若它们今天同样与 base 90% 答案相同,则"Table 1 比较的是几乎未改变的模型"得到证实。
   **必须复制 checkpoint 到新目录,不碰 `archive/` 与 `results/paper_baselines/`。**
3. **修间歇性数值不稳定**:致命的 score_consistency 记录应先落盘再抛(现在 D1_s0 的 161 条记录里
   没有一条超过软容差,却因 8.965 而死);四格打分处的有限性断言保留。
4. 只有 1 得到解决之后,重跑 D0/D1/D2 才有意义。
