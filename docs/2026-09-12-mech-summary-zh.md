## 0. 结论
**靶向练习(D)相对通用局部练习(C)没有可重复的净收益。** 首轮 D 领先 8 题,换一个训练种子后领先消失(R1 两种子 pooled D−C = 0);
把练习池从 22 条扩到 64 条、加上两侧条件覆盖与 multi_turn 快照重建之后,D 仍只领先 3 题(单种子),同样落在训练随机性之内。
两臂对 base 的平均提升约 +4~+6 题(+2 pp),也在噪声内。**局部层(held-out 练习)在七次评测里始终是 17–21/33,没有任何臂真正改变它**,
确认集(独立父任务、两侧条件配对)C/D 都只比 base 多 1 题。按用户 07:45 CDT 备忘的判定表,这属于"D 的优势在重复或扩展后消失 → 当作不稳定信号,不扩大叙事"。

## 1. 设计与实际执行
核心问题:同样的教师预算与训练暴露下,围绕学生诊断缺口生成的短练习(D)是否比通用局部练习(C)更能提升未见完整任务?
- 划分:support 24 题(5 seed rollout,19/24 成功 → 5 个失败 seed 诊断)、calibration 16 题、评测子集 256 题(分层)。
  第 3 层排除 web_search 10 题(项目无 SERPAPI key,所有模型恒 0;官方 checker 也不认裸类别)→ **246 题**。
- 训练前登记的缺口:seed_0/3 archival 检索(memory_kv,notetaker/healthcare 场景)、seed_2 并行调用单位(live_parallel)、
  seed_1/4 多轮前置条件与收尾(multi_turn)。
- 练习方向:`condition`(关键条件变→正确行为变,并校验确实变了)、`surface`(表面变→决策不变)、`neighbour_correct`(邻近正常情境→保留原本正确的行为)。
- R1:每臂 22 条(两条 multi_turn 诊断 0 条,执行器快照不可用);R2:保留 R1 的 22 条 + 两侧覆盖 + 按正确行为去重 + multi_turn 快照重建(重放前几轮 ground-truth 调用),
  得到 C 63 条(触 24k 共同输出上限,实花 21.0k token)、D 64 条(9.7k token)。
- 训练(两臂完全一致):LoRA r16/α32,AdamW lr 1e-4,512 监督 token/步,目标 = 0.5 teacher one-hot + 0.5 冻结 base 全词表;
  总监督 token ≈15.9k(R1:611/pass × 26 pass = 52 步;R2:1,585/pass × 10 pass = 40 步,另存中点 checkpoint)。
  注:方案原定"单 pass、lr 1e-5"在 BFCL 上只有 611 监督 token / 2 步,等于没训练,故按 ≤16k 上限调整剂量并已告知。
- 评测:贪心(T=0.001,top-k 1);base 重复评测 246 题只翻 1 题,评测噪声可忽略。
- 教师花费:R1 诊断+练习 ~9.3k 输出 token,R2 练习 30.7k,确认集少量,合计 < $2。GPU3 约 20 小时。

### 2.4 loss 分项审计(R1 四个 adapter,nats/token,监督 token 加权)
| 臂 | 监督 token | base argmax 已对 | teacher NLL 前→后 | base 熵下界 | KL(base‖student) 后 | argmax 后 |
|---|---|---|---|---|---|---|
| C 种子 0 / 1 | 611 | 95.9% | 0.638→0.048 / 0.037 | 0.0041 | 0.033 / 0.035 | 97.5% / 99.3% |
| D 种子 0 / 1 | 706 | 95.5% | 0.855→0.047 / 0.042 | 0.0092 | 0.037 / 0.045 | 97.5% / 97.9% |

在**教师强制**(teacher forcing,即给定教师提供的正确历史)条件下,base 已在 ≈96% 的监督位置给出教师 token,训练后升到 97.5–99.3%。
**修订说明(2026-09-12 16:40 CDT,采纳评审意见)**:这组数字**不能**读成"学生已经掌握 96% 的行为",也不能推出"只有 4% 的 token 带教学信号"或"LoRA 只能改十几个决策"。
理由:(a) 给定正确前缀预测下一 token,与从任务起点自主生成完整行为,是两个不同的问题;(b) argmax 正确时概率仍可从 0.6 变到 0.95,梯度不为零;
(c) 训练集上翻转的 token 数无法外推到未见任务上可改变的行为数。
这组数字真正支持的、且待检验的解释是:**在正确前缀下,这批练习可能过于容易,没有充分暴露学生自主执行时的困难**。
"loss→0.001"仍然不能当作收敛证据,因为混合目标的第二项下界是 base 的熵。

## 3. 判断(对照方案第 9 节判定表)
1. **"D 的优势在重复后消失"**:R1 pooled D−C = 0,成立。R2 单种子 +3 题、CI 跨 0,不足以翻案。→ 不稳定信号。
2. **"全任务小幅改善、局部始终不变"**:两臂对 base 都有 +4~+6 题,但 held-out 七次不动、确认集只 +1。
   不能宣称"补上了局部缺口再迁移回完整任务";更像十几个 token 决策的重排在 246 题上的随机涨落。
3. **64 条 vs 22 条**:C 从 165(R1 两种子均值)到 164.5(R2 两种子均值),**多样性本身没有带来收益**;D 从 165 到 168(单种子),仍在噪声内。
4. **根因未定**。曾把它归结为"能改的决策只有十几个",该推断已在 §2.4 撤回:教师强制下的 argmax 一致率不能外推到自主执行时的行为量。
   目前能说的是两点:臂间差异与该子集上 ±8 题的种子波动同量级;且训练本身可能塌缩(§4),使机制判断被稳定性问题污染。

## 4. 正式结果:R2 D 种子 1 训练塌缩(不作为异常种子剔除)
同一批 64 条练习、同一剂量,仅换训练种子,D 的 adapter **退化为重复输出**:在 multi_turn 任务上反复发同一个工具调用直到 4096 token 上限
(例:连续重复 `get_stock_info{symbol:"NVDA"}`),单条耗时从 1.4 秒涨到 100–190 秒,评测被拖长数小时。其训练 loss 收到 0.0003(C 为 0.034)。
该臂评测按统一资源上限终止(记录见 `runs/mech_bfcl_r2/evaluation/D-s1/TERMINATION.json`):3 小时内生成 198/263 题,469 条记录的补全里 **102 条打满 4096 token 上限**,已评分 197 条,**不报告该臂的第 3 层分数**。
**修订说明**:塌缩证明当前配方不稳定,但**尚不足以把根因定为"训练过量"**——学习率、重复次数、片段结束方式、目标构造与格式处理都可能参与;
尤其"反复输出同一个调用"需要先确认监督目标里"一个工具动作之后应当停止生成并等待 observation"这一边界是否被正确编码(见 §6 核查)。
这一格是正式结果,不作为异常种子剔除;同时**不得**用"挑中点 checkpoint 更好"来宣布机制成立。

## 5. 结论与下一步(2026-09-12 16:40 CDT 修订,采纳评审意见)
本轮结论的准确表述是:**在当前生成协议与训练配方下,未观察到靶向练习相对通用练习的稳定收益**;并且**训练稳定性已经影响到机制判断**。
不把根因归结为"有效 token 太少"——那是尚未证实的推断。

立即完成:
1. 塌缩臂的评测已按统一资源上限终止并留档(§4)。
2. 三项针对性实现核查(§6),结果落在 docs/2026-09-12-mech-implementation-audit.md。
3. 暂停继续堆同类练习,也不扩到其他 benchmark。若核查发现实现缺陷,先修正,再只重跑必要的配对实验;**不得用实现问题导致的结果否定机制**。

若实现无误,仍要给专项训练一次有信息量的机会,应当**改练习的起点,而不是只改监督 mask**:
- 从关键选择发生之前的**真实学生状态**出发,不给暗示工具/参数/下一步的教师前缀;
- 学生自主生成一个完整动作并接收真实 observation,教师针对这次自主尝试给出简短纠正或下一组练习;
- 新练习改变关键条件,迫使学生重新判断;蒸馏目标保持稳定统一。
- 例:并行调用缺口,不让模型在函数名与大部分参数已写好的情况下补全,而是从用户请求与工具文档出发,自己决定调用几个函数、各自服务哪个子请求。
- **先不训练,先用推理验证这些新练习能否重现原缺口**;若不能重现,继续训练它们的依据就很弱。这一步只花推理,远比再跑一批 adapter 便宜。

由此得到的研究问题比原命题更具体:**专项练习是否有效,可能首先取决于它是否保留了学生必须自主作出的关键选择,而不是它在文字上是否围绕某个"能力缺口"。**

不建议的做法:直接"删掉 base 已正确的 token、只训练剩下 4%"。argmax 一致无法可靠区分"无用语法"与"重要决策";删除大量位置后按剩余 token 重新归一化会放大每个位置的更新,可能加剧当前的不稳定,并引入"有效剂量被改变"这一无法排除的解释。

## 6. 三项实现核查(进行中)
1. **教师目标的回合结束与工具调用边界**:局部截断不得被标成完整回答,必要的停止标记不得丢失,目标须编码"工具动作后应停止生成、等待 observation"。
2. **冻结学生软分布的计算**:须来自未截断的全词表 logits、使用训练目标自身的温度,而非继承评测解码的 T=0.001 / top-k 1。
3. **实际曝光与 loss 归一化**:按真实计数核对每步有效 token、尾批、pass 数与各损失项,解释 52×512、40×512 与 15.9k 的差异,
   并确认两臂是否真的曝光匹配(R1 中 C 611/pass 与 D 706/pass 不同,须给出共同上限的作用层级与实际错配量)。
## 7. 可写进论文的收获
- **评估协议**(§3、§4):246 题子集上单种子差异可达 ±8 题,训练还可能塌缩,因此任何臂间比较至少要两个训练种子,且塌缩运行必须作为结果报告而不是剔除。
  同样的教训在基线曲线上复现了:SAD 在训练数据完全相同的两格上得到 60.7 与 54.3。
- **练习设计**(§5):待检验的解释是"练习在正确前缀下过于容易,没有保留学生必须自主作出的关键选择";这个问题可以只用推理来检验,成本远低于再训一批 adapter。
