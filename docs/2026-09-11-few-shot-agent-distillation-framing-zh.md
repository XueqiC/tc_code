# 收窄设定:few-shot budgeted agent distillation(2026-09-11,回应用户)

## 1. 设定(一句话)
给定一个 agent 任务的少样本描述(几十条示例 query + 任务级 verifier)、一个只吐文本、按 token
计费的黑盒教师、一个小学生和一个教师预算 B,求在 B 内让学生任务成功率最大化的方法。
**唯一约束是 B,唯一指标是 held-out 成功率。** 对标对象只限 agent distillation 这条线。

## 2. 三个对标工作在做什么(都基于 reason–act–observe trace)
| 工作 | 处理 trace 的方式 | 决策对象 |
|---|---|---|
| SmartAD(Tang 2026) | 按学生容量挑选教师轨迹(capacity-aligned trajectory selection) | 选哪些轨迹 |
| SAD(Liu 2025,Structured Agent Distillation) | 把轨迹切成 reasoning / action 片段,分别加损失 | 各片段权重 |
| Agent Distillation(Kang 2025,retrieval + code tools) | 教师轨迹加"first-thought prefix"改写,学生用 self-consistent action generation | 轨迹怎么改写、怎么解码 |
共同点:**目标分布 = 教师轨迹分布**,训练 = 最大似然模仿;区别只在"选哪些、各片段多重、怎么改写"。

## 3. 它们在我们设定下"理论上不行"的共同原因
用我们 8/30 机理笔记的分解:ΔScore = Σ_g w_g [Gain_g − Damage_g],Gain_g ≈ D_g·T_g·U_g(缺口×可示范性×解锁率),
Damage 是每行训练数据对所有其它能力的全局干扰。
1. **它们只有 Gain 侧的旋钮,没有 Damage 侧的旋钮。** 选轨迹(SmartAD)、加权片段(SAD)、改写(Kang)都只改变
   "学什么",不决定"学生原有的哪些行为该让位、哪些该保留"。最大似然对一个状态的全部学生行为整体替换。
2. **few-shot + 预算下 Gain 集中在 D≈0 处。** 教师在少样本任务上的示范大多落在学生本来就会的状态
   (D≈0),token 花在没有缺口的地方;而 Damage 均匀落在所有类别。⇒ 这正是我们 9 月初 BFCL 上
   全部基线一致低于 base 2–5 分的机理(mechanism-sustained-improvement §1)。
3. **它们是 off-policy 的。** 轨迹来自教师自己走过的状态,不是学生会走到的状态;学生在自己分布上
   的错误位置(divergence)从未被教师覆盖(SmartAD 的容量对齐只是过滤,不改变状态来源)。
4. **它们不对教师 token 定价。** 没有"这一笔购买的边际收益"概念,预算只是一个上限。
对应我们已经拿到的经验证据:
- 纯纠正片段做 CE 会装上"总想调用"反射(Irrel 82.7→3.6),多轮/记忆归零——整体替换的伤害是全局的(CRCD B 阶梯);
- 剂量曲线:目标轴随剂量涨,但每档剂量 Irrel 掉 7–11 点(CRCD 2.3);
- 保留锚点 + 累计事件池 + 自迭代:46.06→47.82 单调上升(CRCD 2.5/2.6)——Damage 被抑制时改进才可持续;
- "CE 还是配对偏好"取决于该状态上是否存在一个已胜任的策略可被覆盖(9/3 机理发现)——
  即"该不该替换"是逐状态、逐行为的决策,而不是全局超参;
- 后果优先(consequential-first)在 3 个种子上稳健;dU 适合做选择而不是加权。

## 4. on-policy 思路(arXiv 2511.10643,Black-Box On-Policy Distillation / GAD)能给什么
GAD:学生当生成器,判别器区分学生与教师回复,判别器充当随学生共同演化的 on-policy 奖励;
在黑盒、纯文本设定下超过序列级 KD。它解决的是"没有 logits 时怎么在学生自己的样本上学"。
搬到 agent:
- 我们不需要对抗判别器——agent 有 verifier 和环境回报,"像不像教师"不是目标,"任务成不成"才是;
- 但 GAD 的核心洞见成立:**监督必须落在学生自己的轨迹/状态上**(on-policy),否则学生分布上的
  错误永远得不到覆盖。三个对标工作都没有这一层。
- 教师在 on-policy 设定下的角色变成:在学生走到的状态上给出示范/纠正(我们的 intervention mining
  和 BBOPD 一脉),并且每次询问都是一笔可定价的购买。

## 5. 我们的 novelty(顺着这条线一句话)
**教师文本不是要复制的目标,而是学生自身若干行为的一组"可替换项";替换哪些、替换多少,
由学生的学习回报决定;在哪里向教师提问,由这笔购买对同一替换问题的边际收益决定。**
- 三个对标 = 我们的退化特例:全部替换份额 a_ij ≡ 1(整体模仿),再叠加各自的选择/加权/改写;
  可以写成一个命题:任何 a≡1 的方法其期望更新必含全局 Damage 项,与选择/加权无关;
  RTD 的逐来源份额允许 a=0(保留)到 a=1(替换)之间的任何点,并由回报选。
- on-policy:示范购买发生在学生访问的状态上(acquisition A(Q) 选状态),而不是教师自己的轨迹上。
- 预算:每笔购买按边际增益定价,失败购买照记账。

## 6. 建议的研究/实验形状
1. 主表:三个 benchmark × {SmartAD, SAD, AgentDistill(Kang), STaR(零教师参照), RTD},同一预算 B。
2. 归因(已有 D0–D3 配对设计):只改"替换决策"其余全同。
3. 新增一个轴:**示范来自哪里**——教师自己走的轨迹(对标工作的做法)vs 学生访问状态上的示范
   (我们的做法),其余固定;这一列直接回答"on-policy 思想带来多少"。
4. 显式报告 Damage:各类别相对 base 的变化(而不只是总分),对标工作的伤害应可见。
5. 理论:命题"a≡1 ⇒ 期望更新含全局 Damage 项",作为三个对标工作的共同缺陷的形式化。
