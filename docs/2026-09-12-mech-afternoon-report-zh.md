## 2. 最重要的发现:训练目标缺少终止监督(实现缺陷,已修)

`native_pair` 在渲染监督目标时,把原生模板产出的三个标记**主动剥掉**了:

| 标记 | token id | 含义 |
|---|---|---|
| `<\|tool_response>` | 50 | 一批工具调用结束,交给执行器取 observation |
| `<turn\|>` | 106 | 无调用的文本回合结束 |
| `<eos>` | 1 | 部署停止符 |

后续 `encode_rows` 用 `add_special_tokens=False` 编码,**没有任何东西把这些标记补回来**。保存的 `compatibility.json` 里如实写着 `no_terminal_supervision: true`。

受影响范围:

| 银行 | 保留练习 | 可训练练习 | 缺交接标记 | 缺文本回合结束 |
|---|---:|---:|---:|---:|
| R1 C | 22 | 22 | 22 | 0 |
| R1 D | 22 | 22 | 22 | 0 |
| R2 C | 63 | 59 | 56 | 3 |
| R2 D | 64 | 61 | 56 | 5 |

**含义**:今天所有臂(C 与 D、两轮、全部种子)都在"从未被教过在哪里停下"的条件下训练。D 种子 1 的塌缩形态——反复输出同一个调用直到上限——与这个缺陷高度一致。按既定原则,**实现缺陷导致的结果不能用来否定机制**,所以 R1/R2 的全部训练结果现在只能作为"缺陷条件下的观测",不能作为机制结论。

已修:目标必须以对应的原生终止标记结尾(调用→`<|tool_response>`,文本→`<turn|>`),否则报错;同时扩大了禁止混入的标记集合。156 个相关测试通过(mech2@61867b1)。

## 3. 另外两项核查:没有问题

- **冻结参考分布**:确认来自未截断的全词表 logits、温度 T=1,**没有**继承评测解码的 T=0.001 / top-k 1。顺带删掉一个从未生效的 softcap 条件分支。
- **曝光与归一化**:两臂**完全匹配**,没有错配。R1 = 26 × (512+99) = 15,886;R2 = 10 × (512+512+512+49) = 15,850;512 上限按 pass 逐臂生效,尾批算清楚就对得上。之前担心的 "C 611 / pass vs D 706 / pass" 是**可用池大小**,不是曝光量。损失按每步实际监督 token 数归一化,参考项对全词表求和而不是除以词表大小。

## 4. 已撤回的推断

原报告写过"base 在 96% 的监督位置已经给出教师 token,所以只有 4% 带教学信号、LoRA 只能改十几个决策"。**撤回**,理由:
1. 那是**教师强制**下的 argmax 一致率,与学生从任务起点自主执行是两个问题;
2. argmax 正确时概率仍可从 0.6 变到 0.95,梯度不为零;
3. 训练集上翻转的 token 数不能外推到未见任务上可改变的行为数。

这组数字还能支持的、**待检验**的解释是:这批练习在正确前缀下可能过于容易,没有暴露学生自主执行时的困难。

## 6. 接下来的计划

**第一步(今晚,已在跑)**:拿到修复后的 C vs D 配对结果。判读规则事先固定:
- 以 4 个种子的 pooled parent 配对为准,不看单种子;
- 塌缩的运行仍然作为结果报告,不剔除;
- 不允许用"挑中点 checkpoint"来制造结论。

**第二步(取决于第一步)**:
- 若 D 相对 C 出现**跨种子稳定**的正向差异 → 机制线重新打开,再决定是否加完整轨迹 A 臂与原位置指导 B 臂;
- 若仍然没有稳定差异 → 结论定为"在当前生成协议下靶向练习无稳定收益",并转向下面这个更具体的问题。

**第三步(方向已定,先测不训)**:改练习的**起点**而不是监督 mask。从关键选择发生之前的真实学生状态出发,不给暗示工具/参数/下一步的教师前缀;学生自主生成完整动作并接收真实 observation;教师针对这次自主尝试给简短纠正。**先只用推理验证这些新练习能否重现原缺口**——如果学生在新练习上不犯原来的错,继续训练它们就没有依据。这一步只花推理,远比再训一批 adapter 便宜。

由此得到的研究问题比原命题更具体:**专项练习是否有效,可能首先取决于它是否保留了学生必须自主作出的关键选择,而不是它在文字上是否围绕某个"能力缺口"。**

**明确不做的**:直接删掉 base 已正确的 token、只训练剩下 4%。argmax 一致无法区分"无用语法"与"重要决策";删除大量位置后重新归一化会放大每个位置的更新,可能加剧不稳定,并引入"有效剂量被改变"这一无法排除的解释。

机制验证与 Table 1 基线是两条独立的线。基线这边今晚在 LONI 上跑 3 benchmark × 3 种子 × 3 个 agent distillation baseline(B=30k)共 27 格,跑完把均值与标准差更新进 Table 1,再跑 GAD。今天基线上的教训与机制验证一致:SAD 在**训练数据完全相同**的两格上得到 60.7 与 54.3,所以 Table 1 的每一格都必须带标准差。
