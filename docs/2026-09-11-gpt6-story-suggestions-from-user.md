**可以把问题明确定位为“预算约束下的 few-shot 黑盒 agent distillation”。而且，我认为我们确实能从已有实验中提炼出一个比“换一种处理 trace 的方式”更有力度的核心机制。**

但需要调整两个判断：**比较对象不能只限于三篇轨迹蒸馏论文；我们也不应预先论证它们必然失败。** 更有说服力的研究路线是：找出它们没有直接优化、而我们的设定特别需要的量，再设计方法去优化它。

我建议把这个量定为：

> **一份教师指导经过蒸馏后，究竟能给小模型 agent 带来多少独立完成任务的能力提升。**

这能接上 RTD，也能解释过去实验为什么反复出现“示范正确，但训练无益甚至有害”。

**先把现有方法的共同局限说准确。**

三篇工作并非没有考虑 agent 行为，也不能简单归结为“都是普通 SFT”。

| 工作                          | 已经考虑了什么                                         | 尚未直接回答的问题                     |
| --------------------------- | ----------------------------------------------- | ----------------------------- |
| SmartAD                     | 用学生 NLL 选择更容易学习的正确教师轨迹，并强调 action、decision 等片段。 | 学生觉得这条轨迹容易，是否意味着学习它会提高完整任务表现？ |
| SAD                         | 利用轨迹结构，分别处理不同类型的监督信号。                           | 对某一片段加强监督，会怎样影响学生在其他状态上的决策？   |
| Kang 等人的 Agent Distillation | 从教师工具交互轨迹中学习推理与工具使用。                            | 有限教师预算下，哪些指导值得获取、重复学习或停止学习？   |

这些区别来自各自的方法设计。[SmartAD](https://aclanthology.org/2026.findings-acl.1349.pdf)、[SAD](https://arxiv.org/html/2505.13820v5)、[Agent Distillation](https://arxiv.org/html/2505.17612v2)。

它们共同留下的空间是：**教师轨迹的正确性、结构和学生似然，可以帮助构造监督，却没有直接识别“这个监督产生的参数更新，对完整任务表现有什么净作用”。**

这里“净作用”很关键。学生共享同一套参数，学会调用某个工具，也可能同时破坏该拒绝调用的情况。

理论上，降低教师模仿损失，并不自动提高任务回报。小幅更新后的回报变化取决于**更新方向与任务回报梯度是否一致**，而不只取决于教师答案是否正确。这说明现有目标存在不足，但并不能证明它们一定无效；数据充分、教师行为适合学生时，它们完全可能很好。

**我们的实验恰好把这个缺口暴露得很清楚。**

| 已有发现                            | 对新方法的直接启示                                    |
| ------------------------------- | -------------------------------------------- |
| ALFWorld 中，局部分支 ΔU≈0 的示范仍能教会行为。 | 当前动作替换的收益，不能作为学习价值的硬筛选条件。                    |
| BFCL 中，有效纠正可能伴随其他能力损伤。          | 必须评估更新对目标任务分布的净收益。                           |
| 梯度指纹能预测部分似然迁移，但原子分解没有稳定增量。      | 可以使用局部更新方向，但没有依据继续要求存在可复用的 capability atoms。 |
| RTD 的有限自采样目标会强化错误格式。            | “保持学生”不能简单实现为反复拟合少量学生样本。                     |
| AppWorld 扩数据、加曝光没有稳定改善。         | 更多轨迹和更多训练，本身不能保证更好的 agent。                   |

这些结果支持的核心区别是：

> **教师执行得好、教师能救活一条轨迹，以及学生学习教师之后变强，是三个不同的问题。**

我们最应该集中攻克第三个。

**你给的 GAD 很有启发，但需要准确借鉴。**

这篇论文先收集教师回答，再反复生成当前学生的回答，更新判别器，并通过判别器奖励训练学生。**它不需要每次更新都重新查询教师。** 这一点非常适合预算有限、需要反复利用已购文本的情况。[GAD](https://arxiv.org/pdf/2511.10643)

不过，它的判别器训练目标仍然是让教师回答得分高于学生回答。对于我们的任务：

* 学生使用另一条有效工具路径，也可能完成任务。
* 教师式回答可能需要学生尚未掌握的后续能力。
* 一条回答更像教师，不代表学习它之后的整个 agent 更好。

所以，GAD 值得借鉴的是**反馈随当前学生持续更新、已购教师文本持续复用**。我们可以进一步改变反馈所评价的对象：**评价一次教学更新，而不仅是评价一条回答。**

同时，最新文献已经压缩了一些容易想到的创新空间。SOPD 已经在学生实际访问的环境状态上查询黑盒教师，进行逐步文本蒸馏；FutureBridge-OPD 已经执行教师桥接，并检查后续学生轨迹是否改善。因此，“加入 on-policy”“让教师局部接管”“检查后续轨迹”都不能单独作为我们的核心创新。[SOPD](https://arxiv.org/html/2608.16333v1)、[FutureBridge-OPD](https://arxiv.org/html/2608.01953)

**据此，我建议将 RTD 收敛为一个机制：由学习收益决定的选择性行为替换。**

一句话描述：

> **在学生实际遇到的状态上，用完整任务反馈学习：应该把学生哪些行为的概率转移给教师指导，以及转移多少；再把这个目标蒸馏进小模型。**

这比一般的 teacher/student 混合多了一个关键自由度：**决定概率从哪里转移。**

假设面对同一个工具任务，学生可能产生三种行为：

* 一种错误调用；
* 一种有效但与教师不同的调用；
* 一种过早结束的回答。

普通混合系数控制“教师占多少”，通常会同时压低各种学生行为。我们希望学习：主要替换错误调用和过早结束，尽量保留有效的替代路径。这个决定由任务反馈训练出来，不需要手写“什么格式、什么任务该保留”的规则。

需要注意：这是目标分布希望实现的行为。共享参数训练能否实现它、是否还会干扰其他状态，仍需验证。

**具体可以这样实现，而且能合并原来的门控与 QP。**

第一步，当前学生运行少量 support tasks，收集完整状态和交互行为。已购教师文本可以反复使用，新查询受总预算限制。每轮保存当前学生的一个冻结快照，它只是参考分布，不是另一个独立训练的学生。

第二步，为每个学生行为学习一个替换系数。令：

* \(p_0(y\mid s)\)：本轮冻结学生在状态 \(s\) 下的行为分布；
* \(y^T\)：教师在该状态提供的行为；
* \(a(s,y)\)：将学生行为 \(y\) 替换为教师行为的比例。

目标分布定义为：

$$
q_a(y\mid s)
=
p_0(y\mid s)\,[1-a(s,y)]
+
\mathbf 1[y=y^T]\,
\mathbb E_{u\sim p_0}[a(s,u)].
$$

它的含义很直接：**从不同学生行为上取走不同数量的概率，统一转移给教师行为。**

这个定义有三个有用性质：

* 所有系数为零时，目标就是完整的原学生分布。
* 所有系数相同时，退化为普通 teacher/student 混合。
* 系数依赖具体行为时，可以区别对待不同的学生行为。

因此，我们能用普通混合作为严格的消融对照，而不是比较两套完全不同的系统。

第三步，系数的训练信号来自**学习后的任务表现**。

我们关心的量是：稍微增加某个替换系数，形成的蒸馏更新会让完整任务回报提高还是降低。

局部近似下，这个信号是：

$$
z(s,y)
\approx
-\eta\,h^\top P\bigl(g_T-g_y\bigr).
$$

这里，\(g_T-g_y\) 表示把监督从该学生行为转向教师行为所改变的梯度；\(P\) 是本次更新使用的预条件器；\(h\) 来自反馈任务上的完整任务回报梯度。

**它与以前 ΔU 的区别是：ΔU 问“现在替换动作能否成功”，这里问“改变训练监督后，学生是否更容易成功”。** 后者也可能包含其他任务上的损伤。

第一版不必为每条候选单独训练和 rollout。可以周期性地用**同一批反馈轨迹提供一个共享的局部回报方向**，评价这一批替换方向，再让轻量预测器摊销这些评价。预测器需要对真实训练后的收益做校准，不能把一阶近似直接当作实测收益。

第四步，用一个闭式更新控制替换幅度。

固定本轮学生快照和教师目标时，可以得到：

$$
D_{\mathrm{KL}}(q_a\Vert q_b)
\le
\mathbb E_{y\sim p_0}
D_{\mathrm{KL}}
\bigl(
\mathrm{Bern}(a(s,y))
\Vert
\mathrm{Bern}(b(s,y))
\bigr).
$$

直观上，限制“是否替换”的概率变化，就能限制目标行为分布的变化。这是数据处理不等式在这个构造下的应用。

于是，在局部学习收益与上述变化惩罚之间优化，可以得到：

$$
a_{\mathrm{new}}
=
\sigma\!\left(
\operatorname{logit}(a_{\mathrm{old}})
+
\frac{z}{\tau}
\right).
$$

**同一个系数同时决定教师剂量与替换来源，不再需要独立的剂量门控加一个大 QP。** 这是局部线性收益模型下的闭式解，不能声称等价于包含任意高阶交互的原 QP。

第五步，将目标蒸馏进学生。

实现时，保留项应利用冻结学生的软分布，并对选择性替换使用采样估计，避免把两条有限的自采样回答当成全部保留目标。这正面回应了 RTD v1.0 暴露的问题。

这里需要区分两层保证：上述公式约束的是**目标分布**；最终模型的漂移还取决于拟合误差和优化过程。因此实际策略 KL、完整任务收益和损伤仍要测量。

**采购随后自然接到同一个机制上。**

购买一份教师指导的价值，是它加入之后，能否提供当前池没有的、有正学习收益的替换机会。

这样采购和蒸馏共用同一个价值对象，不需要额外定义一套“残差/token”的含义。购买前只能使用当时可见的状态和历史预测，不能提前使用尚未购买的教师文本或梯度。

但我会先固定教师池验证上述蒸馏机制，再训练购买前的价值预测器。这样可以清楚判断提升究竟来自哪里。

另外，低能力学生可能暂时没有足够成功反馈。此时回报信号确实不能可靠区分教学价值；算法应保留非零的初始教师监督，而不是因为估计收益为零就停止学习。这个限制应明确写入方法。

**创新点应落在这一整套具体构造上，而不是“我们也用了在线反馈”。**

元学习重加权和根据学生学习表现调整教学，已有长期研究，不能据为新贡献。[Learning to Reweight](https://arxiv.org/abs/1803.09050)、[Meta Pseudo Labels](https://arxiv.org/abs/2003.10580)

我们可以尝试建立的独特贡献是：

> **针对黑盒、预算受限的 agent distillation，构造由学习后任务收益驱动的行为概率替换算子，使教师剂量、学生行为保留与购买价值共享同一优化对象，并给出可高效实现的局部更新。**

最关键的实验也因此非常明确：

**在相同教师数据、相近教师总剂量和策略变化幅度下，按学习收益选择“替换哪种学生行为”，是否优于只调整每个状态的教师剂量？**

第一轮至少比较：

* 充分调好的 SmartAD 或轨迹蒸馏；
* 真正的 SOPD；
* 真正的 GAD；
* RTD 的状态级统一混合；
* RTD 的行为级选择性替换。

再加入替换信号置换，以及具有相同环境反馈权限的简单对照。SAD 若需要教师 logits，应作为额外访问权限的参考，或明确标注其文本适配版本。

**我支持沿这条线继续 RTD：把“示范是否好”推进到“具体怎样用这份示范，才能让学生学得更好”。** 如果行为级替换在匹配剂量后仍带来稳定的学习与保留优势，我们就有了一个可以独立成立的蒸馏核心，而不只是一个更复杂的数据选择流程。
