# v2.2 设计笔记:把 learning 侧做成真正的 on-policy(2026-08-25)

## 诊断:v2.1 的 on-policy 只做了一半

把"on-policy"拆成两个正交的轴看:

| | 状态分布(在谁的状态上学) | 监督目标(学谁的行为) |
|---|---|---|
| Vanilla SFT / SAD / AgentKD | teacher 的 | teacher 的 |
| **BB-OPD** | **学生的(on-policy)** | teacher 的 |
| **v2.1** | 采集时是学生的,**训练中逐渐过期** | **学生的(已验证)** |
| 完全 on-policy | 学生的,始终新鲜 | 学生的 |

BB-OPD 修了状态轴、留着目标轴,结果 .197——我们由此得到的定律是
**目标轴是主害**(teacher 方言从目标进来照样覆写)。v2.1 反过来把
目标轴修干净了(全部自产已验证),但 learning 仍是"采集→冻结池→
离线 3 epochs"的批式:训练一开始,策略就和采数据的策略分道扬镳,
池子在 epoch 间逐渐变成 off-policy 数据;偏好对里的负例更是如此,
训到后面策略早已不产生那条负例,压它属于对着影子出拳(likelihood
displacement 文献里这是主要浪费源)。还有一个审美问题:round 边界
是我们亲手定的"不做离散阶段"原则的违背——批式轮次就是人为分段。

## 提案:v2.2,把 round 边界取消,采集与学习合并成一条连续过程

**一句话**:没有"数据集",只有一条流。策略滚动出轨迹,verifier
当场判分,判过的立刻变成一次梯度步,判分相异的新鲜对立刻走门控
偏好;ρ、配额、价格逐 rollout 更新;唯一的边界仍是 v≤0 的内生
停止。

循环体(每步):
1. 按未满配额 × ρ(q) 加权抽一个任务 q(已购示范在上下文里);
2. 用**当前** θ 采一条轨迹,verifier 判分;
3. 成功 → 剥提示,立即做一次 NLL 梯度步(锚性质自动成立:数据
   永远是当前策略的新鲜自产,出处纯度按构造最大);
4. 若同任务此刻恰有新鲜失败轨迹 → 取首分叉轮做门控 OR 步
   (负例是当前策略真的会犯的错,压得其所);
5. 回写 ρ(q)、配额、价格;全体 v≤0 即停。

四道防御原封不动且更自然:锚不再需要"占比保护"(全部数据都是
锚性质的);门控的 EMA 在流式里天生连续;分歧掩码不变;许可条件
由采集方式按构造满足。**零新常数**:没有 round 数、没有池大小、
没有 replay 比例,调度完全由价格决定。

## 与文献的关系(learning 侧)

- **ReST / ReST-EM**(Gulcehre 2023; Singh 2023):批式的
  生成-过滤-训练迭代,与 v2.1 round 同构;v2.2 是其连续极限,
  且加了预算定价、验证门控与防覆写机构。
- **Online DPO / OAIF**(Guo 2024)与 iterative DPO 系:已证明
  新鲜负例显著优于冻结负例——正是第 4 步的依据。
- **SPIN**(Chen 2024):自博弈用旧策略当负例,但仍离线批式。
- **BB-OPD**(Ye & Dong 2025):状态 on-policy 的对照物;v2.2 与
  它构成干净的 2×2 消融(状态轴 × 目标轴),Table 3 的故事因此
  更完整:BB-OPD 证状态轴不够,v2.1 证目标轴是关键,v2.2 证两轴
  全修 + 新鲜性的增量。

## 验证计划(增量式,不推倒 v2.1)

- **A(staleness 消融,最小)**:同一批 V1 轨迹,离线 3 epochs
  (= 现 V2)vs 单 epoch 流式顺序(近似新鲜)——先量池子过期的
  代价有多大;
- **B(fresh negatives)**:V2 的偏好对换成"训练时现采的失败"
  (每对多花一次采样,不花 teacher token);
- **C(完整 v2.2)**:连续循环 vs v2.1 round-1,同预算同任务集,
  3 种子。
判定标准照旧:AppWorld 池化 partial ×3 种子,对照 v2.0 的
.284±.037 与 V2(round-1,在跑)。

## 风险

流式单样本梯度步方差大(批式的隐式平均没了)——对策是保留既有
的梯度累积窗口(工程常数,appendix),这不引入新的方法常数。
若 A 显示池子过期代价可忽略,则 v2.2 只按审美收益(去掉 round
分段)决定是否采纳,不为改而改。

## 补:两处正式化(回应 8/25 晚讨论)

### 采集-部署上下文漂移的三件套

行为策略是 μ = π_θ(·|x, h(d_q)),训练与部署的目标策略是
π_θ(·|x)——这是一次可以被精确处理的 proposal 偏移,而非只能默认。

1. **命名与修正**:我们的 NLL 步的标准名字是 **verifier-filtered
   self context distillation**(把自身带提示策略蒸馏进无提示权重,
   Snell 2022 的 context distillation + 拒绝采样)。要做严格修正,
   给每条轨迹乘截断重要性比 w(τ) = min(π_θ(τ|x)/π_θ(τ|x,h), 1)
   ——两个密度都是学生自己的,黑盒约束不破;截断取 1(V-trace
   约定,非调参)。
2. **脚手架毕业(endogenous annealing)**:每轮采集先用无提示
   π(·|x) 采;只有无提示全失败的任务才动用已购提示。随学生变强,
   任务逐个"毕业"到纯 on-policy 采集,提示的使用份额自然衰减到 0,
   漂移随之消失。无任何退火常数——毕业条件就是"无提示已能成功"。
3. **极限形态**:毕业完成后循环退化为纯 on-policy RFT(采集分布
   = 部署分布),提示只是打冷启动的临时脚手架。

### 更新规则与 on-policy RL 的关系

verifier 是 0/1 奖励,则:
- 我们的"成功轨迹 NLL"= 正优势的 REINFORCE(RFT 恒等式),配上
  上面的 w(τ) 后是**离策略修正的策略梯度**;
- GRPO 的组内基线(k_s 条同题样本,A_j = r_j − r̄)会给失败轨迹
  负权重、token 均匀下压——这正是我们已证会塌的形态(无门 .630,
  风格对 −.087);我们的门控 + 首分叉 OR 是同一负梯度方向的
  **保护版估计器**:只在正例已可学(门)、只从分叉处(掩码)、
  只沿成功轴(许可)。
- 由此 v2.2 的完整目标可以写成一条式子:
  L = −E[w(τ)·1[V=1]·log π_θ(τ|x)] + β·E[门控·首分叉 OR],
  解释为"带截断 IS 修正的验证奖励策略梯度 + 位移保护的负通道"。
  对审稿人"为何不用 RL"的回答从辩解变成定理式陈述。

### 增量实验(D 系)

- **D1**:V2 池加 w(τ) 重权重训(单臂,便宜)——量 proposal 偏移
  的真实代价;
- **D2**:round-2 用毕业式采集(无提示优先)——看漂移收缩速度;
- **D3**:同预算下 naive GRPO(组基线、无保护)对照我们的保护版
  ——预测它在 4B 塌回地板;若命中,是"小模型上保护式负通道优于
  朴素策略梯度"的正面证据,可进论文。
