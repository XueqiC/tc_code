# 从理论推导能力原子:定义、唯一性、novelty,以及它在蒸馏里的作用

2026-09-05 01:50。目标:不从"我们想要什么"出发,而从问题设定出发推导原子应该是什么,并证明它在蒸馏阶段有可证的作用。记号沿用 METHOD.md(T/S 归属上标)。

## 1. 设定

- 学生 π_θ,可训练参数 θ∈R^d(LoRA),基点 θ0。
- 监督单元 u=(s_u, y^T_u, Q_u):teacher 在状态 s_u 的续写及其验证后的效用。购买一个单元的成本 c_u(teacher output token)。
- 训练算子 A:单元 u 在 θ0 处诱导一次真实更新 δ_u = A(u; θ0)(pairwise / CE / 任何固定训练器,含优化器)。
- 行为:一组固定探针 j=1..m,每个探针有连续边际 m_j(θ)(例如 teacher 侧 ℓ^T_j(θ),或 ℓ^T_j−ℓ^S_j),结果 r_j(θ)=1[m_j(θ)>0] 或其平滑版 Φ(m_j/σ)。
- 度量:H = diag(F)+εI,F 为 θ0 处学生 rollout 的经验 Fisher。‖δ‖_H² = δ^T H δ 是策略 KL 的二阶近似:KL(π_θ0‖π_θ0+δ) ≈ ½‖δ‖_H²。

**局部线性响应假设(A1)**:在信任域 ‖δ‖_H ≤ ρ 内,Δm_j(δ) = g_j^T δ + O(ρ²),g_j = ∇m_j(θ0)。

## 2. 推导:原子是什么

把探针梯度堆成 G∈R^{d×m},响应算子 R(δ)=G^T δ∈R^m。可购买的监督只能产生 S=span{δ_u} 里的更新(加上噪声)。我们要的"原子"是一组方向,使得:(i)监督能激发它们,(ii)它们对行为有最大可预测作用,(iii)在参数重参数化下不变。

**命题 1(定义即最优解)。** 记 D=[δ_1..δ_n]。在 H 度量下考虑降秩回归
  min_{rank(R̂)≤K} Σ_i ‖G^T δ_i − R̂ x_i‖², x_i = C^T H δ_i, C^T H C = I, span(C)=S。
其解 R̂ = A Σ V^T,右奇异向量给出参数方向 U=CV(H-正交),左奇异向量给出探针响应模式 B=AΣ。等价地,(U,B)是 H 度量下"监督更新空间"与"探针梯度空间"的典型相关方向(CCA)。**原子 := (u_k, b_k, σ_k)**:方向、它引起的行为模式、可激发强度。

**命题 2(规范不变性)。** 若把 LoRA 参数做任意可逆重参数化 θ=Tφ,则 H→T^T H T,δ→T^{-1}δ,g→T^T g,而 x_i、R̂、B 不变,U 协变。所以原子是**行为空间**的对象,参数坐标只是表示——这正式解决了"参数方向 ≠ 能力"的问题。指纹稀疏字典没有这个性质(单位范数、无度量、无行为配对),这是它失败的理论原因。

**命题 3(为什么不是任务向量/影响函数/梯度相似)。** 任务向量(θ_task−θ0)是 S 中的一个点,没有行为配对,不分解;影响函数/数据归因给出 (单元→固定目标损失) 的标量分数,没有低秩基,不能用于控制;梯度相似选数据用 g_u^T g_v,没有度量、没有探针侧。原子是**双线性对象 (购买侧 × 测量侧)** 的低秩分解,同时回答"买什么"和"控制什么",这是 novelty 的核心。

**识别性(A2)**:要能分离因子,S 必须包含对比方向(同 prompt 不同目标);否则边界模式和家族模式在单事件源上共线,只能识别它们的和(今天的秩 1 现象)。这给出源设计的必要条件。

## 3. 层级结构从哪里来

对 tool-calling agent,探针梯度有一个可证的共享分量:所有"应调用"探针的 teacher 侧梯度都包含 ∂/∂θ log P(call | s),所有"应弃答"探针都包含它的负号。因此 G 的列共享一个秩 1 分量 g_b(边界模式),其余按 API 家族分块(参数模式共享词表/格式),再加个体残差。故 R̂ 的自然结构是
  R̂ = b_0 u_0^T (全局边界) + Σ_f B_f U_f^T (家族块) + 残差,
K 不是自由参数,而是"1 + 家族数 + 少量"。这也解释了今天所有 BFCL 臂 Irrel/Rel 同时反向漂:任何未加约束的更新都激发 u_0。

## 4. 原子在蒸馏里的作用:两个可证的结论

### 4.1 信任域整形优于全局 KL(帕累托)

设训练器提出 δ0。全局 KL 信任域解的是 min L(δ) s.t. ‖δ‖_H² ≤ ρ²,它对所有方向一视同仁。原子版:令 δ = Ux + δ⊥,预测收益 J⁺(x)=Σ_{j∈missing} w_j (Bx)_j,预测损伤 J⁻(x)=Σ_{j∈retained} w_j [−(Bx)_j]_+,解
  min_x ‖x − x0‖² − α J⁺(x) s.t. J⁻(x) ≤ τ, ‖x‖² + ‖δ⊥‖_H² ≤ ρ²,
其中 x0 = U^T H δ0。这是一个小 QP(K 维),KKT 给闭式:x = x0 + α B_+^T w − μ B_−^T w,再投影到球。

**命题 4。** 在 (A1) 且响应秩 K 下,对任意损伤预算 τ,原子约束更新的预测收益 ≥ 全局 KL 更新在同一实际损伤下的预测收益;严格大于当且仅当 x0 在损伤模式(如 u_0)上有非零分量。证明:全局 KL 是等比例缩放 δ0,收益与损伤按同一比例下降;原子版只缩损伤模式、保留其余,是前者的松弛。**推论**:当损伤集中在秩 1 边界模式时(今天的情形),原子版退化为"单独限制 u_0 的幅度、其余不动"——这正是 9/3 自适应锚点臂经验上得到帕累托改进的机制,理论和数据对上了。

### 4.2 预算分配是残差上的注水

设因子 k 的残差 r_k = [ρ_k − J_k]_+,购买针对因子 k 的单元每 token 带来预测响应 σ_k/c_k,并有递减回报(剂量–响应凹,来自信任域)。在总预算 B 下最大化 Σ_k gain_k(t_k) s.t. Σ t_k ≤ B 的解是**注水**:对每个因子买到边际收益/token 相等为止,残差为 0 的因子不买。这把"买什么"从启发式(ΔU 大优先、便宜优先)变成由 (σ_k, c_k, r_k) 决定的闭式规则,而今天 BF-6 的负结果恰好说明:在没有因子分解时,ΔU 与成本的启发式互相抵消,随机最好。

### 4.3 购买前的可预测性(P5 的理论前提)

原子在购买前的用处依赖 x_u 能被便宜特征预测:x_u = C^T H δ_u,而 δ_u = A(u;θ0) 依赖 y^T(购买后才知道)。但 u_0 分量只依赖 s_u 是"应调用还是应弃答"(状态可判),家族分量只依赖 s_u 的 API 家族——即层级的前两层**在购买前可预测**,只有残差层不可。这给出一个可检验的推论:原子层级越粗,采购越可预测;并且解释了为什么"细粒度原子"在采购上没用。

## 5. 假设与失效方式(写在前面,防止事后合理化)

- A1 线性只在 ‖δ‖_H ≤ ρ 内成立;mirror 臂 λ→5 时 Λ 位移 ~1.8 nat 显然出界,所以塌。原子模型必须配一个校准过的 ρ(P2 pilot 的任务)。
- 结果 r_j 是边际过阈值:原子在边际上线性,在 0/1 上不线性;功效来自 frontier 探针。
- 可加性(命题 4 的隐含前提)在大剂量下会失败;P3 的组合臂是必要检验。
- 若 R̂ 的秩 K=1 且没有家族块被识别(所有增益都在 u_0),那"原子"退化为"边界模式控制",仍有 4.1 的用处,但 novelty 收缩为"带因子的信任域"。

## 6. 这套理论的 novelty 一句话

**能力原子 = 监督空间与行为空间之间、在策略 Fisher 度量下的典型迁移方向;它同时给出可购买(σ_k/c_k)、可控制(信任域整形的闭式 QP)与可认证(每因子残差与损伤界)的坐标,并且在重参数化下不变。** 相比任务向量、数据归因、梯度相似选数据、全局 KL 蒸馏,它是第一个把"买什么"和"改什么"放进同一个低秩对象里的形式化。

## 7. 它直接决定的实验设计(与新任务书 P2/P3/P4 对齐)

1. P2:源集合必须含对比源(A2);探针按四因子分层且取 frontier;响应用 teacher 侧边际;拟合分层降秩回归(rank-1 + 家族块 + 残差),对照 B0/B1/B3。判决看命题 1–3 的可预测性。
2. P3:沿 u_0、u_f 及组合做真实干预,测符号/剂量/可加性(命题 4 前提)。
3. P4:实现 4.1 的 QP 控制器(在 Adam 提出 δ0 之后、更新参数之前),与全局 KL(D0)、PCA 方向(D1)、置换(D3)同预算比较,主指标是学习–保留帕累托(命题 4 的直接检验)。
4. P5:检验 4.3——按层级预测 x_u 的可预测性随粒度递减;注水分配 vs 随机/ΔU/便宜优先,在等真实 token 下比较。
5. 跨 benchmark:同一程序在 ALFWorld(ψ 近一维 → 预期 K≈1)和 AppWorld(终止因子)复现层级结构;参数方向不共享,结构与程序共享。
