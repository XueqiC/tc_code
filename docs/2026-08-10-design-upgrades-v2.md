# 设计升级 v2:曲面的不完美怎么修,E2 怎么改成浑然一体

2026-08-10 晚,回应 PI 两问。

## 1. 曲面结果的不完美 → 四个方法升级

诊断曲面的三处不完美:饱和区优势消失、个别格平局、跨尺寸超参失稳。

**1a. 双侧供给目标(最重要,直接从 M1 机理导出)**
现在 D 只做单侧排序:最大化入规格供给。M1 已证泄漏由"喂了什么域外的
东西"决定(断供机制)——那就把它写进目标:
```
score(x) = s_T(x) − λ · s_out(x)
```
λ 是塑形旋钮:λ=0 还原当前 D;λ↑ 主动饿死域外供给。产出从单点变
**λ-扫描的 (覆盖, 泄漏) frontier 曲线族**——这同时回答饱和区问题:
覆盖饱和时,方法的价值转移到泄漏轴(sqljoin 格已证 10× 差距),λ 让
每个格子在第二根轴上重新可分。方法故事从"选得好"升级为"**塑形可调**"。

**1b. 子模选择替代排序前缀**
排序前缀不管边际递减:前 100 条如果都供给同几个原子,101 条起就在
浪费预算。facility-location 目标(每个规格原子取其最强供给的和)+
成本贪心,理论节已埋好 (1−1/e) 保证,平局格(2B×10k)正是多样性
不足的症状,子模是对症药。消融:prefix vs submodular 同预算对比。

**1c. Credit 加权供给(AgentOPSD 移植)**
块级供给按 outcome-pivotality 加权:样板块降权、关键技能块升权。
和 1a/1b 正交,三者可叠加。

**1d. 工程:超参随尺寸缩放**(lr 重跑已在路上,规则入 configs)。

## 2. E2 的重设计:把"预测"整个从设计里删掉

**反思**:四次 gate 失败的共同前提是"方法需要预测学生能力"。但回头看
问题定义——交付物是**保证**(guarantee),不是**预报**(forecast)。
预测是我们自己加进去的中间商,删掉它,设计反而闭合:

**能力的 conformal 证书(certificates, not predictions)**
- 覆盖证书:从规格内抽 n 条校准 query,行为验证(执行),给出
  分布无关的覆盖下界(Clopper–Pearson / conformal risk control):
  "以 1−δ 置信,学生在 T 上成功率 ≥ q̂"。
- 泄漏证书:域外校准样本同理给上界。
- **F(refusal)模块的阈值由 CRC 校准**——弃权率成为可调的证书参数,
  refusal 从"行为技巧"升格为"证书的执行机构"。

**为什么浑然一体**:方法从此只有一个统计原语(可交换性+分位数)贯穿
始终——**T 用 conformal 圈定,训练用供给塑形(几何),C 用 conformal
认证(行为)**。三种角色零重叠:几何=控制,conformal=认识论,
行为=真值。没有任何组件在预测它不需要预测的东西。E2 章节的叙事变成:
"预测不是正确目标(四次预注册失败为证),证书才是——而证书恰好用
边界同款机器"。

**26 年锚点(检索核实)**:CRC 能否认证 LLM 输出的界与不可能性
(arXiv:2606.29054——其"弃权下限"的不可能性结果与我们的逐题失败
账本互为镜像);tool-call 的分角色 CRC(arXiv:2607.24343,直接是
agent 工具调用场景);CAP conformal 弃权策略(PMLR v304)。挂靠齐整。
