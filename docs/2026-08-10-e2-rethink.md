# E2 重构思考:能力的几何读数为什么失败,怎么修

2026-08-10 凌晨,E3 运行期间的理论功课。基于 e2-gate v1/v2 全部证据。

## 1. 失败的原理性诊断

残差梯度 ‖∇θ ℓ(τ_ref; θ_S)‖ 测的是**"离复现参考解多远"**,而我们想要的是
**"能不能解决这个任务"**。两者错配产生两个失效模式,分别对应实测的两类误差:

- **假高(会做但残差大)= 风格漂移**。学生形成自己的解题风格后,对 teacher
  参考解的梯度变大而能力未降。已被 v2 副分析逐行证实(同一题 teacher 残差
  15.06 vs 学生自解残差 1.35)。max-over-solutions 可修。
- **假低(不会做但残差小)= exposure bias**。teacher-forced 下每个 token
  的条件预测都好(会"背"),但自由 decode 时早期偏航就崩。teacher-forced
  类指标原理上看不到 decode 失败——这是中高 decile 噪声的来源,**任何**
  纯 teacher-forced 代理都修不掉它。

根本错配:成功是**序列级、执行语义**的全局性质;梯度范数是 **token 级、
似然空间**的局部性质。相关性只在"正确解的似然盆地与执行语义对齐"时成立,
而语义等价程序越多,这个对齐越弱。

## 2. 四条修法(原理 × SOTA 谱系)

**A. 解集边际似然(style-marginalized likelihood)。**
能力分数 = max_j (1/|τ_j|) log π_S(τ_j|q),j 遍历一个**已验证解集合**
(teacher 池 + 学生历史成功解,后者 v2 已存)。对解集取 max 直接边际化掉
风格;纯 teacher-forced 前向,便宜。谱系:reasoning 评测里
"likelihood of the correct answer" 作为 accuracy 的光滑替代
(Forecasting Downstream Performance, arXiv:2605.18607);解集扩增 =
RFT/rejection-sampling 思想。**修 A 类误差,不修 B 类。今晚可离线测。**

**B. TRAK 式方向读数。**
我们 C 侧用了范数(标量),T 侧成功靠的却是方向(子空间)。TRAK
(Park et al., ICML 2023;理论分析 arXiv:2602.01312)的核心正是
**用随机投影梯度的内积预测逐例 correctness margin**——和我们的特征管线
同构,几乎零新基建。具体:用 E2 已存的逐 checkpoint 梯度特征,拟合
TRAK 式线性读出预测 success,看泛化到 held-out 题的 AUROC。
**离线可测,与 A 互补。**

**C. 生成侧不确定性(修 B 类误差的正道)。**
semantic entropy 采样聚类语义簇测不确定性;程序正确性版本已有直接先例
(Ensemble Semantic Entropy 预测 program correctness, arXiv:2603.27098;
pass@k 高效预测, arXiv:2510.05197)。代价:每 query 采样 4-8 条 + 执行。
不再"几何",但它测的才是真正的 π_S 输出分布性质。

**D. 混合估计器 + conformal 校准(建议的最终方法形态)。**
放弃"找完美代理"的问法,改成:**便宜代理分数(A+B)+ 少量行为锚点
(~10% query 采样执行)+ split-conformal 校准**,输出带覆盖保证的
{会 / 不会 / 弃权} 三值判定。这样 C 侧和 T 侧用**同一套统计机器**
(conformal),方法叙事完全对称:T = 子空间+conformal 半径,
C = 代理分数+conformal 校准。gate 的语义从"相关性 ≥ 阈值"升级为
"校准有效性 + 弃权率可接受"——更弱的假设,更强的保证,更诚实。

## 3. 建议的执行顺序

1. **E2-v3 离线**(不占训练 GPU,几十分钟):在 E2 已有 checkpoint 记录上
   测 A(解集似然,解集=teacher 参考 + v2 存的学生成功解)和 B(TRAK 读出)
   及 A+B 合成的 Spearman;预注册同一门槛 −0.5,写 amendment A2。
2. 无论 v3 过不过,**论文方法节采用 D 的形态**(A/B 作代理分数,C 作锚点,
   conformal 包装);v3 若过,代理可独立使用,锚点预算降到校准最小量。
3. C(semantic entropy)作为 E3 之后的评测侧工具引入(它同时能当
   leakage 的软测量)。

## 4. 对论文的意义

E2 的失败-诊断-重构链条本身就是一节:"能力的几何读数"是这篇论文提出的
新问题,gate 挡住天真版本、诊断出两类原理性误差、最终落到带保证的校准
估计器——这比"一次就 work"更有分量,也把 conformal 从 T 侧工具升级为
全方法的统计骨架。
