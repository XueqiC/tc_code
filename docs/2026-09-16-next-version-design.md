## 1. 核心问题(按你的表述)

> 怎样识别一种教学改变,它既能被学生学到,又能在学生自主生成和实际交互时产生有用的行为变化?

拆成三个可验证的性质,对应三个门:
- **可学**:训练包上的目标量下降(已会做);
- **可迁移且改变决策**:未见父任务的困难状态上,贪心决策向教师动作(或任何实测更优动作)移动;
- **有任务价值**:同样这些状态上,固定策略续跑到底的 EM 上升;最终 dev-500 同向。

## 2. 信号:决策价值(decision value),不是教师一致率

对每个真实学生状态 s(U0 执行记录),已有:学生拟议动作 a^S、教师独立动作 a^T(均执行核验)。用**固定策略**(U0)从三种起点续跑到底:
v_T = EM(从 a^T 续跑),v_S = EM(从 a^S 续跑),v_0 = EM(不干预)。定义 **Δ(s) = v_T − v_S**。
- Δ > 0:教师动作有实测价值——这是要教的决策;
- Δ = 0:两条路殊途同归(等价查询/合法替代/都失败)——不值得改;
- Δ < 0:教师动作更差——不能教。
这正是重分析里"一致率不代表价值"的直接修正:**材料按 Δ 分层,效果按 Δ 校验**。工具 `tools/cr_decision_value.py`(Codex 在建;零训练零教师;72 训练包约 10 分钟 GPU)。
先在现有 72 个提名包上测 Δ 的分布——如果 Δ>0 的包很少,这条线的材料本身不够,要回到采购侧(按 Δ 采购);如果足够,进入 §3。

## 3. 目标:在学生自己的前缀上做**决策对比**,并保持主干

记 ℓ(a | s, r) = −log π(a | s, r)。每个包 i 三项:
1. **主干**(与 A* 完全相同):ℓ(r^T_i | s_i) + ℓ(a^T_i | s_i, r^T_i) —— 纯 CE、token 比例、曝光与 U0 相同;
2. **决策对比**(只在 Δ_i > 0 的包上;学生前缀 r^S_i 作输入):
   L_dc,i = max(0, m − [ log π(a^T_i | s_i, r^S_i) − log π(a^S_i | s_i, r^S_i) ])
   直接推动"在自己的思路下,教师动作的对数概率超过自己原动作一个边际 m"——这是决策变化的充分条件(贪心解码在这两者之间会翻转),
   而不是 B* 那种只抬 a^T 似然的做法;a^S 已知、无需生成;
3. **保持**:同一批里的主干项本身就是教师前缀能力的锚;另加"自身思路不漂移"的**判定门**(不是训练项):训练后在留出状态上生成思路,与 U0 的一致率与后续 Δ 对比报告。

系数:L = 主干 + β · mean_i∈{Δ>0} L_dc,i,β 与 m 预注册(β=1,m=1 nat;不搜索)。分母、批次、步数与 A* 相同(3 遍规则);对比项的 token 不进主干分母,单独记账。

## 4. 对照与判读(全部预注册)

材料:现有 72 提名包(+62 修正包中 Repair≠NONE 且 Δ>0 的可并入),**按父任务切分**:36 父任务训练 / 16 父任务困难留出(不看结果,seed 固定);

| 臂 | 训练 | 回答 |
|---|---|---|

| DC-all | 主干 + 决策对比(所有提名包) | 决策对比本身是否改变未见困难状态上的决策与价值 |
| DC-value | 主干 + 决策对比(仅 Δ>0 的包) | 按实测价值选材是否优于"按差异选材" |

两配对种子、同批 U0 对照。三层判定:
- 门 1(可学):训练包 ℓ(a^T|s,r^S) − ℓ(a^S|s,r^S) 的边际 > 0 的比例上升;
- 门 2(迁移且改变决策):16 个困难留出父任务上,贪心动作 = a^T 的比例(在 Δ>0 的状态上)相对 A* 上升,CI 不含 0(父任务配对);
- 门 3(任务价值):同一状态用固定 U0 续跑 EM 上升;dev-500 同向;易留出集与教师前缀 CE 不退化(保持)。
读法表:三门全过 → 进入完整训练与更多父任务确认;门 1、2 过、门 3 不过 → 决策改了但价值未兑现,回到 Δ 的估计精度(多次采样);门 2 不过 → 决策对比也不迁移,
说明"学生前缀"这条路线在本任务上到头,材料/测床问题;任何门只在一个种子上过 → 不算。

## 5. 与之前路线的区别

- 与 A/B/C、A*/B*:目标从"抬教师动作似然"改为"在学生前缀上翻转决策";材料从"有差异"改为"有实测价值";留出从"易"改为"按父任务切出的困难"。
- 与回报梯度控制器:不估计片段收益、不做权重,价值信号是**离散的、可验证的、每包一次的续跑结果**,用于选材与判定,不是梯度权重。
- 与 SCoRe/DAgger 类工作:不新增教师纠正文本、不做多轮自我修正;贡献落在"用有限教师证据 + 固定策略续跑,识别有任务价值的决策差异,并用决策级对比让它进入自主行为"。
