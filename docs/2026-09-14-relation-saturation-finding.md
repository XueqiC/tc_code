# 四格来源目标在现有素材上的饱和度实测(训练前)
2026-09-14 12:05 CDT。**本文写于任何 adapter 训练之前,也在任何评测/确认集数字产生之前。**
全部数字来自冻结学生(gemma-4-12B-it,LoRA 初始化即 base)在 LONI A100 上对冻结关系表的前向打分,
零教师调用。作业:1023173(跨父)、1023180(同父)。

## 1. 结论

**按任务书 §8.3 的跨父任务配对,四格来源目标完全饱和,梯度恒为零。**
若照原计划训练,D0 / D1 / D2 会**按构造**得到同一个模型——那不是"无显著差异"的结果,是同义反复。

改用**同一父任务内、不同证据阶段**的配对后,饱和显著缓解,但**两个臂缓解的程度差异巨大**。

## 2. 实测分布

| | 跨父(§8.3,60 个关系) | 同父(46 个关系) |
|---|---|---|
| B 最小 / 中位 / 最大 | 37.69 / 98.14 / 137.44 | **9.50 / 33.77 / 77.74** |
| margin 最小 / 中位 / 最大 | 10.06 / 47.10 / 102.26 | **−10.57 / 15.16 / 52.14** |
| margin ≤ 0 | 0 / 120 | **3 / 92** |
| B ≤ 0 | 0 / 60 | 0 / 46 |
| **D1 损失 > 1e-6** | **1 / 60(1.7%)** | **29 / 46(63%)** |
| **D2 损失 > 1e-6** | **0 / 60(0%)** | **4 / 46(8.7%)** |

同父配对里没有一个退化(动作相同)关系。

## 3. 两点机制解读

**(a) 跨父饱和的原因是字面捷径。** 两个动作各自带着自己那道题的实体名
(`search[Indianapolis 500]` vs `search[Edward Ellsberg]`),来源判别用字符串匹配即可完成,
不需要理解任何条件。任务书 §7.4 预警过这个风险;现在实测确认,且**最小** margin 都有 10.06 nat
(≈23,000:1),饱和是全面的,不是尾部现象。

**(b) D2 比 D1 结构性地更容易饱和。** B = m1 + m2 是两个 margin 之和,
因此 D2 要拿到梯度,需要**两侧同时**接近零;而 D1 逐行判断,任一侧接近零即可获得梯度。
这就是同父配对下 D1 有 63% 的关系带梯度、而 D2 只有 8.7% 的原因。
任务书 §6.6 只说明了 m1=m2=0 处两者梯度相同;**远离零点时两者的有效样本量差一个数量级**,
这一点此前没有被量化。

**这对本轮的主比较是直接威胁**:主比较是 D2 − D1,而在同一批关系上
**D2 收到的有效监督比 D1 少一个数量级**。此时若 D2 不优于 D1,无法区分是
"联合四格目标没有额外价值"还是"D2 这一臂根本没被训练到"。

## 4. 不能做的事

- 不得按 B 的正负挑选配对(任务书 §4.2 明确禁止);上面的分布是**全量**,不是筛选后的子集。
- 不得用确认集或 dev 结果来选 τ 或配对方式。
- 不得把"关系项没有梯度"写成"交互目标被证伪"——**它根本没有被检验**。

## 5. 登记的处置(在看到任何评测结果之前)

1. **配对方式改为同父任务、跨证据阶段**,46 个关系全部纳入,不按分数筛选。
   任务书第一阶段避开同链配对的理由是"后继状态可能由前一动作产生";该顾虑针对的是
   **依赖性**,而本目标的标签是**来源**而非效用偏好,依赖性不使来源标签失效。
   此为明确的协议变更,记录在此,不追溯修改旧文档。
2. **登记 τ 变体**。τ 的唯一作用是把 margin 放进 logistic 的活跃区;当 margin 中位数是 33.77 nat 时,
   τ=1 让目标**按构造关闭**。依据**训练素材自身**的 margin 分布(不使用任何 dev/确认集结果)
   登记 τ ∈ {1, 20}:τ=1 是任务书原值,保留以在训练日志中留下饱和的直接证据;
   τ=20 使 B/τ ≈ 1.7、m/τ ≈ 0.76,落在梯度非平凡的区间。
3. **剂量固定为 doseB**(基线匹配),以保住与 37.8 的可比性;doseA 本轮不跑。
4. 单元表:D0 / D1 / D2 × seed{0,1} × τ{1,20} = 12 个训练格 + 1 个同协议 base = **13 格**。
   D0 不含关系项,两个 τ 下应当得到相同结果——这本身是一个可用的内部一致性检查。

## 6. 判读规则(同样先定死)

- 主比较仍是 **D2 − D1**,在**每个 τ 内部**分别做,按父任务配对 bootstrap(seed 271828,10,000 次)。
- 报告每个臂**实际收到非平凡关系梯度的关系数**,与成绩并列。若 D2 的有效关系数远低于 D1,
  则**不得**把"D2 不优于 D1"解释为联合目标无价值。
- 与基线(SmartAD 37.8 / SAD 37.4 / Kang 37.2,base 38.2)的正面比较使用 doseB 的结果。
- 若两个 τ 下结论不一致,如实报告不一致。
