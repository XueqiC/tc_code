# 蒸馏形式的理论分析:哪种形式最优,用我们自己的机理框架回答

2026-08-10。回应 PI:方法 v1 之后分析 on/off-policy、SFT vs 其他形式。
先给统一视角,再逐形式分析,最后给可检验预测与实验阶梯(E4)。

## 0. 统一视角:蒸馏形式 = 供给算子

我们的机理结果(M1-M3)已经给出分析工具:
- 学生的学习状态 = 原子需求向量 d_t(M2:随训练排空);
- 一步训练的效果 = 供给向量 s_t 与需求的对齐程度(核质量,M1:ρ=0.53);
- 泄漏 = 供给中落在规格外原子上的质量(M1:断供即塑形);
- 行为 vs 能力 = 格式原子 vs 技能原子的供给配比(M3:5/128 载体)。

于是每种蒸馏形式就是一个**供给算子** S:θ_t ↦ s_t,可以按三个轴分类:
| 轴 | 取值 | 含义 |
|---|---|---|
| A. 状态依赖 | off-policy(常量供给)vs on-policy(s_t 随 θ_t 变) | 供给是否追踪剩余需求 |
| B. 目标锐度 | one-hot(SFT)vs 软目标(logit KD) | 每 token 供给是否按已掌握程度自动衰减 |
| C. 奖励耦合 | 似然(模仿)vs 验证器(执行成败) | 供给方向是否指向行为能力而非风格 |

**中心论点:形式的优劣 = 供给-需求对齐效率 + 域外供给质量,两者都是我们
已经能测的量。** 这把"哪种蒸馏好"从经验比较变成机理预测。

## 1. 逐形式分析

### 1.1 Off-policy SFT(v1 现状)
供给 = 固定 teacher 轨迹的 one-hot 梯度。三个结构性弱点,全部已被我们实测:
- **供给不追踪需求**:格式原子 step 2 已排空,但每个 batch 仍在足额供给
  格式 token 的梯度(M3:后期 delta 仍全集中)→ 预算浪费在已吸收原子上;
- **exposure bias**:teacher-forced 供给对 decode 失败盲(E2 假低误差的根源);
- **风格强加**:one-hot 目标强迫学生复现 teacher 措辞,产生风格漂移张力
  (E2 v2:同题 teacher 残差 15.1 vs 自解 1.3)。
优点:实现最简、无 teacher 在环成本、供给完全可预先审计(边界过滤在
数据层即可完成)——这是它作为 baseline 与"可控性"上限的价值。

### 1.2 Logit/序列 KD(软目标)
每 token 梯度 ∝ (p_student − p_teacher),而非 (p_student − onehot)。
**机理含义:软目标 = token 级的自动需求加权**——学生已匹配的 token 梯度
自动趋零,等价于对已吸收原子自动断供。预测:
- 格式原子过供给消失 → 行为俘获变慢、CoT 挤占减轻(能力保留更多);
- 需求排空曲线(M2)在技能原子上更陡、格式原子上更平。
成本:需要 teacher logits——API teacher 不行,但我们在 hpg 上可自托管
开源 teacher(qwen3.5 系),完全可行。风险:teacher 分布的"暗知识"里
含域外倾向,软目标会把它带给学生(泄漏轻微上升的可能)。

### 1.3 On-policy 蒸馏(GKD/SOD 谱系)
学生采样、teacher 在学生访问的状态上给监督。
**机理含义:供给算子变成状态依赖 S(θ_t)**——学生错哪里,监督就落哪里,
供给自动集中于仍有需求的原子 = **自适应课程表**(M2 的吸收波会被压缩)。
- 修 exposure bias(监督建立在学生自己的 decode 分布上)——这是 E2 诊断
  出的两大误差之一的正解;
- **与我们的边界天然协同**:学生 rollout 可能漂出域,而 B̂ 恰好能在环内
  过滤 rollout —— **boundary-gated on-policy distillation** 是个文献里
  没有的组合(SOD/GKD 都没有域控制),可能是我们方法 v2 的核心新组件;
- 成本:teacher 在环(每步推理),预算从"token 数"变成"teacher 调用数",
  比较时要换算(matched teacher-FLOPs 而非 matched tokens)。

### 1.4 验证器耦合形式(RFT / 拒绝采样 / GRPO)
供给方向由执行成败而非似然决定。
**机理含义:供给直接对齐行为能力**——E2 gate 想要的"几何-行为耦合"
在训练层实现。RFT(学生自采样→验证器筛→SFT on 成功解)尤其有吸引力:
- 无 teacher 在环(只需验证器,我们已有沙箱);
- 训练目标是学生**自己的成功风格**(风格漂移张力=0);
- 供给天然在域内(采样种子来自规格内 query);
- 与 M2 仪器完美兼容(每轮 RFT 后测需求排空)。
风险:冷启动(学生初期 0% 成功率无数据可筛——需要先用 SFT 把行为
拉进域,即两阶段:SFT 起步 + RFT 精修,这恰好对应 M2 观察到的
"行为先翻转、能力后填充"的自然顺序!)。

## 2. 理论排序与可检验预测

**覆盖效率**(同预算域内能力):预测 RFT(两阶段)≥ GKD ≥ KD ≥ SFT。
依据:状态依赖供给 > 自动衰减 > 常量;验证器耦合免疫风格税。
**泄漏控制**(域外能力/行为):预测 boundary-gated 变体全面占优;
无 gate 的 on-policy 反而可能比 off-policy 差(rollout 漂移)——
这是一个**反直觉的可检验预测**,值得专门设一个对照。
**行为-能力解耦**:KD 与 RFT 都应缓解 CoT 挤占(37%<67% 的能力折损);
可用 any-answer accuracy 直接测。

每条预测都落在已有仪器上:M2 需求排空曲线(供给-需求对齐效率的直接
读数)、M1 域外供给质量、行为/能力双通道评测。

## 3. E4 实验阶梯(方法 v2 的实验)

固定:2B 学生、matched teacher-FLOPs 预算、同一规格(gsm8k-code k=50)、
3 seeds、全部挂 M2 仪器。
- E4a:SFT(v1 基线,已有)
- E4b:+ 序列 KD(hpg 自托管 qwen3.5-27B 出 logits)
- E4c:两阶段 SFT→RFT(沙箱验证器筛选,零 teacher 在环)
- E4d:boundary-gated GKD(teacher 在环,B̂ 过滤 rollout)
- 对照:ungated GKD(检验"无 gate on-policy 泄漏更差"的反直觉预测)
产出:四形式的需求排空曲线族 + (覆盖,泄漏) frontier + 行为/能力双通道
——形式选择从此有机理依据,论文 theory 节的供给算子分类 + E4 验证
构成完整一章。
