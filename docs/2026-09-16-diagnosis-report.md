## 1. 方法

- **分项损失**:同一批固定样本(训练 72 包;留出 138 包 / 70 父任务,来自未进训练的父任务、带独立教师 r^T/a^T),对 5 个 checkpoint(U0 对照、A* s0/s1、B* s0/s1)

## 5. 分析

1. **训练确实改变了条件映射,但只在存档前缀上。** B* 在 72 个训练前缀上把教师动作的 NLL 降了 59%,而在 138 个留出的学生前缀上只降了 11%(不显著);
   A* 用教师前缀训练反而在留出学生前缀上有更稳的 −15%。也就是说 B* 学的更像"这些具体前缀 → 这些动作",不是"从我自己的思路到正确动作"的一般能力。
2. **改变的概率没有跨过决策阈值。** 固定思路时,换成 A*/B* 的动作模型,138 个状态里贪心动作与 U0 不同的不超过 3 个;这正是我预期的第三行:20 步只把
   e^{−1.1} 抬到 e^{−0.9},贪心解码不变。
3. **B* 的思路分布变了,而且变差。** 它有 62% 的状态写出与 U0 不同的思路,更常直接 Finish;这些思路让任何动作模型都更少给出教师动作(−6 pp)。
   这是共享参数的间接效应:动作视图把学生错误思路当上下文、推理视图学教师文字,两者合起来没有为"产生哪种思路"提供任务价值信号,反而扰动了思路分布。
   B* 在教师前缀下的推理与动作复现也退化(L_R +0.48、L_{A|r^T} +0.28、教师思路下 NLL +0.33),说明"学生前缀"训练和"教师前缀"能力之间有干扰。
4. **对方法的含义**(你的 §4/§6):当前设计没有任何一项直接判断"学生自主产生的哪些思路提高了后续成功率"。诊断显示瓶颈不在"给定思路后的执行"
   (固定思路下 U0 已经 82% 有用、91% 与教师一致),而在"产生什么思路"——B* 恰恰把这一项做坏了。下一步的教学片段应覆盖思路形成的决策过程,
   并以任务价值(而不是教师文字的似然)选择要教的思路;这与"根据可验证的行为瓶颈决定片段范围"一致。
