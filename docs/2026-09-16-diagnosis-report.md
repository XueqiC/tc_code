## 1. 方法

- **分项损失**:同一批固定样本(训练 72 包;留出 138 包 / 70 父任务,来自未进训练的父任务、带独立教师 r^T/a^T),对 5 个 checkpoint(U0 对照、A* s0/s1、B* s0/s1)
  用 HF 模型 + 各自 LoRA 做 teacher-forced 打分:L_R = −log π(r^T|s)(推理视图目标);L_{A|r^T} = −log π(a^T|s,r^T);L_{A|r^S} = −log π(a^T|s,r^S)(动作视图目标,r^S 作输入)。
  每包求和,父任务内平均,按父任务配对 vs 对照,父任务 bootstrap 95% CI。
- **交叉诊断**(留出 138 状态):思路来源 ∈ {存档 U0 r^S、U0 重生成、B* s0 生成、B* s1 生成、教师 r^T} × 动作模型 ∈ {U0、A* s0/s1、B* s0/s1};
  动作在冻结前缀 `Thought N: {r}` 后贪心生成,重放历史后真实执行一次,记可解析 / 可执行 / 有用 / 即时决策(正确结束 / 错误结束 / 继续)/ 与 a^T 一致 / a^T 的 NLL;
  再从该动作起用固定 U0 策略续跑到底(EM/F1)。父任务内平均、按父任务配对 vs(U0 思路,U0 动作)。

## 5. 分析

1. **训练确实改变了条件映射,但只在存档前缀上。** B* 在 72 个训练前缀上把教师动作的 NLL 降了 59%,而在 138 个留出的学生前缀上只降了 11%(不显著);
   A* 用教师前缀训练反而在留出学生前缀上有更稳的 −15%。也就是说 B* 学的更像"这些具体前缀 → 这些动作",不是"从我自己的思路到正确动作"的一般能力。
2. **固定前缀时贪心动作变化很少。** 换成 A*/B* 的动作模型,138 个状态里贪心动作与 U0 不同的不超过 3 个,说明这些概率变化大多没有改变实际解码结果。
   (原稿"把 e^{−1.1} 抬到 e^{−0.9} 没跨过阈值"的说法撤回:1.1/0.9 是跨状态平均 NLL,推不出具体状态的动作概率与其竞争动作的差距。)
3. **B* 的思路分布变了;它的任务价值尚未体现为稳定的正向或负向差异。** 它有 62% 的状态写出与 U0 不同的思路,更常直接 Finish;这些思路让任何动作模型都更少给出
   教师动作(−6 pp)、局部"有用率"略降,但固定 U0 策略续跑的 EM 基本不变(换教师思路也不变;逐题对应见 §7)。所以不能写成"思路变差 → 任务失败";
   能写的是:局部拟合改变了整套生成行为——B* 在教师前缀下的推理与动作复现退化(L_R +0.47、L_{A|r^T} +0.30、教师思路下 NLL +0.33),自主思路大量改变——
   这是"不同条件下的拟合取舍",把学生 Thought 设为零权重输入并不等于只训练了后面的动作能力。
4. **对方法的含义**(按用户 08:01 修正后的口径):当前证据支持停止前缀替换,但**不足以把研究重心定为"思路生成瓶颈"**——留出集没有困难层(§7),
   "思路变差"也没有落到续跑结果上。可靠的两条约束是:纯 CE 主干已有效,作强对照;新机制必须在未见状态上证明自主行为改善,不能靠训练损失或教师一致率。
   "瓶颈在产生什么思路"降为待检假设。
