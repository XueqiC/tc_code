## 1. CRCD 方法全貌(从数据获取到蒸馏)

CRCD(Capability-Residual Correction Distillation)的出发点是:学生缺的不是"整段轨迹",而是若干**能力原子**(capability atom)——在某个状态下该做而没做对的一个决定。我们不再把 teacher 轨迹整段灌给学生,而是把监督信号压缩到"学生第一次做错的那一步"上,并只在那一步施加**差分**的、**以 base 为中心**的纠正。整条流水线如下。

### 1.1 干预事件挖掘(数据获取)

一个干预事件 e = (h, a⁻, a⁺, ΔU):
- **h**:学生自己 rollout 到某一步的历史(on-policy,不是 teacher 的历史);
- **a⁻**:学生在这一步的错误动作;
- **a⁺**:这一步的正确动作(BFCL 上用 ground-truth 调用 / 弃答,不需要 teacher);
- **ΔU = U(h, a⁺) − U(h, a⁻)**:把两种动作各自向后展开 K 条继续,用最终成功率之差衡量这一步纠正的**效用**——只有 ΔU>0 的事件才是"后果性"的,才进池。

三类挖掘器覆盖 BFCL 的三类能力:
1. **单轮事件**:同一题采 K=4 次,凡有错答的题产出事件(a⁻ = 学生错答,a⁺ = GT 调用),ΔU = 1 − u⁻;
2. **弃答事件**:对无关/界外(OOS)题,a⁺ 是拒绝调用,a⁻ 是学生的幻觉调用——补"该不调用时不调用"这个原子;
3. **有状态事件**(多轮/记忆/网页搜索):沿学生轨迹找**首次分歧点**,在该点分叉 K 条继续估 ΔU,只保留后果性的那一步。

产出的池是"事件"而不是"轨迹":每条只含一个决定点、一对(a⁺, a⁻)和它的效用权重。

### 1.2 差分纠正蒸馏(学习)

在同一批事件上比较两种学习方式(B 阶梯):
- **B2 纠正片段 CE**:只在 a⁺ 上做交叉熵;
- **B3 偏好式纠正**:以 base 为参考模型的 DPO(base-centered),让 π(a⁺|h) 相对 π(a⁻|h) 上升,而不改变 base 在其它地方的分布;
- **B4′ CE→偏好**:先 CE 再 DPO。

机制上 CE 是"把 a⁺ 写进模型",偏好式是"把 a⁺ 与 a⁻ 之间的差分方向写进模型"。后者只改动两个动作的相对概率,对 base 的其它行为几乎无梯度,所以天然带"保留"。

### 1.3 能力原子的指纹与有效性门(A 阶梯)

为了让"原子"可操作,给每个事件算 4 种梯度指纹(LoRA-B、Adam 白化、随机投影 64 维):A1 整段文本梯度、A2 响应梯度 g(a⁺|h)、A3 **差分梯度** g(a⁺|h) − g(a⁻|h)、A4 效用加权差分 ΔU·A3。用两个代理检验指纹是否"知道"原子是什么:与类别的一致性(ARI)、对学生难度 u⁻ 的预测(Spearman)。再做有效性门:按 A3 聚 8 簇,逐簇训练,测跨簇增益矩阵 G 与指纹预测的迁移 P 是否相关。

### 1.4 保留锚点(C 阶梯)

偏好式纠正虽然保留好,但剂量一大仍会把"调用/弃答"边界推歪(Irrelevance 掉)。C 阶梯把学生自己**答对**的行为做成 ΔU=0 的锚点对(chosen = 学生正确回复,rejected = 它自己的错误回复或最小翻转),混入偏好池,让优化在"该保持的地方"有显式的零位。

### 1.5 自迭代

训练出的模型再做一轮事件挖掘,残差应当收缩;每轮**从 base 在累计池上重训**(而不是从上一轮模型续训),避免漂移叠加。

## 3. 改进点(改了什么、为什么、怎么改的)

1. **CE → 偏好式差分纠正**:B 阶梯官方四点(CE 10.95 / CE→pref 9.13 / r2-CE 18.38 / pref 46.09→47.34)坐实 CE 在纠正片段上不可用;主线改为 base 中心 DPO。
2. **事件池扩容 + 弃答事件**:137→210→324,加入 OOS 弃答事件(20)与后果性有状态事件(17→20);单调改善。
