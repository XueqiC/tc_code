# 机理分析:预算化少样本特化何时、如何持续地超过强 base

(2026-08-30,应用户要求:"方法论上持续的好才是真的好"——本文回答的
不是"这次 BFCL 怎么修",而是"什么样的机制在任何 benchmark 上都能
稳定不输、有缺口就赢"。)

## 1. 一个恒等式:训练更新的收益分解

对固定 support 集与预算 B,任何"选数据→加权→微调"类方法的期望总分
变化可以写成三项之和(按官方计分权重 w_g 对类别 g 加权):

    ΔScore = Σ_g w_g · [ Gain_g − Damage_g ]
    Gain_g   ≈ D_g · T_g · U_g      (缺口 × 教师可示范性 × 上下文解锁率)
    Damage_g ≈ Σ_{g'≠g} I(g'→g) · M_{g'}   (跨类别干扰 × 训练质量)

三个可持续的结论直接从这个分解掉出来:

1. **收益上限由 D·T·U 决定,与训练技巧无关。** D_g 高而 T_g 或 U_g
   为零的类别(如实时 web_search:答案漂移使 T 无定义)投入必亏;
   这不是失败,是机制应当写出"不可教凭证"的地方。
2. **伤害项与收益项不对称:伤害是全局的。** 每一行训练数据无论目标
   多正确,都对所有其他类别施加干扰 I。base 越强的类别,Damage 的
   期望损失越大(它们没有上升空间,只有下降空间)。这就是本周所有
   baseline 一致低于 base 2-5 分的机理:它们的 Gain 集中在 D≈0 的
   类别(教师示范≈base 已会的事),而 Damage 均匀落在所有类别上。
3. **因此"稳定不输 base"的充要条件是:每一行入池数据的边际
   Gain·w 必须超过它的边际 Damage·w。** 这是行级判据,不是池级。

## 2. 我们方法的机制在这个分解下的位置

advantage 权重 (1−p̂)⁺ 的本质是把 Gain 项按 D_g 定向——这是对的,
而且是 baseline 都没有的能力。本周暴露的三个问题都不是这个机制错了,
而是它的三个输入被破坏或缺失:

- **p̂ 被测歪**(损坏的服务路径)→ 权重错定向 → 在 D≈0 处强训 →
  纯 Damage。⇒ 修复:p̂ 必须经与部署完全一致的官方路径测量
  (BFAS serving-identity 审计,已实现)。
- **高 D 类别零覆盖**(mt/irrelevance/memory 被工具性排除)→ Gain
  项系统性缺失。⇒ 修复:覆盖不变量——每个 support 任务要么按缺口
  贡献训练质量,要么携带显式排除凭证(Addendum 3,已入规格)。
- **Damage 项从未被机制感知。** 这是残留的真空:当前机制里没有任何
  项抵抗跨类别干扰(irrelevance −27 就是它的账单)。

## 3. 补全 Damage 侧:自证锚定(机制自然、零教师成本)

原则:防伤害的数据必须与方法哲学一致——不用教师 token、
verifier 过滤、来自学生自身分布。恰好存在这样一类免费数据:

**p̂ 高的任务上,学生自己的验证通过轨迹。** 它们在 advantage 权重
下天然为零(不推升 Gain),但作为"行为锚"加入训练目标的
KL/复述项(而非正目标),把已强类别的输出分布钉在原地:

    L = Σ_x a(x)·L_pos(x)  +  λ_anchor · Σ_{x: p̂(x)≥1−ε} L_self(x)

其中 L_self 是学生对自己已验证输出的负对数似然——不是模仿外部
分布,是"记住自己已经会的"。这保持了 Proposition 1 的零更新安全点
(全部 p̂=1 时 L_pos=0 且 L_self 在初始点为最优,更新仍为零),把
"优雅不退化"从定理陈述升级为逐类别的工程保证。λ_anchor 不引入
魔法数字的定法:按干扰对消原则取
λ_anchor = Σ_x a(x) / |anchor 集|(训练质量守恒,池子越激进锚越重)。

这与文献的关系一句话说清:AgentTuning 混"通用数据"防遗忘,但那是
外部语料(违反我们的黑盒/预算设定);我们的锚是学生自身验证行为,
免费、on-policy、与少样本前提相容——这是设定带来的独有优势,值得
作为机制贡献写进 method。

## 4. "类似情况"的通用操作序(任何新 benchmark)

1. 官方路径测 base 的分类分布 + 计分权重 → 得到 w_g·D_g 排序
   (headroom 地图,一次评测的成本);
2. 对高 D 类别跑 10 任务教师探针(T)与 10 任务 guided 探针(U)
   → D·T·U 预算排序,决定钱花在哪、写谁的不可教凭证;
3. 采集:p̂ 经官方路径;覆盖不变量强制每任务有交代;
4. 池子:advantage 正目标(定向 Gain)+ 自证锚(压制 Damage);
5. 训练后审计:逐类别 vs base 的Δ表——任何 base-强类别下降超过
   噪声即 fail,回到 4 调 λ_anchor,而不是发布。

这个操作序没有任何 benchmark 特定常数;四个 benchmark 共用,
就是"改个名字就能跑"的那套 pipeline 的机制内核。

  多样→伤最小;STaR 自采样放大偏差→伤最大)。✔ 框架预测正确。

  被工程放大)三重叠加。✔
- ours v2(修复截断+mt 覆盖)+12.4,新伤集中 irrelevance:恰是
