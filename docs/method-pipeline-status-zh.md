# 方法侧完整 Pipeline:机理 + 部件状态(2026-08-23)

图例:✅ 定稿(证据齐,不再动) | 🔄 在跑 | ⏳ 排队 | ⚠️ 审计中 | ❌ 未启动

**方法一句话**:预算化蒸馏。三个阶段共用一本"能力原子账本":
Stage I 建账(任务由哪些能力原子构成、各需要多少),Stage II 按边际
价值花钱(每个 token 买最缺且最不伤已有能力的监督),Stage III 用
一个目标函数把买来的监督刻进学生、同时在 token 粒度守住学生已有的
能力。三个阶段不是三个模块拼接,而是同一本账在三个粒度上的执行:
Stage I 定义价值坐标系,Stage II 在样本粒度做"收益减挤出"的取舍,
Stage III 的锚、门、掩码是同一个取舍在 token 粒度的翻版。

---

## Stage I · 确定任务(建账)

### 机理总述

从 k=50 条支撑查询(任务的唯一暴露面)提取特征,做稀疏编码,学出
一部**双视图耦合字典 [D_p; D_r]**:每个码字(我们称"能力原子")
同时有 prompt 面(这个能力在题面上长什么样)和 response 面(它在
答案里被怎样行使)。稀疏性迫使小语料被少量可复用原子解释,所以
原子天然是"任务的可复用技能单元"而不是逐题记忆。整个 Stage I 只有
这一个对象,后面所有判断都是对它的三种读数,这是"一物七用"的来源。

### 读数 1:需求配额 r_a ✅

把支撑集整体分解到原子上,每个原子的总编码质量就是任务对它的需求
配额。机理:配额给了"买多少"一个内生答案,采购到配额即饱和,不需
要人为设数据量。证据:边际规则 15 格终审;剂量 ×1 饱和定律(超配
不再涨)与之互证。

### 读数 2:边界命题(成员门) ✅

任务外的 prompt 用任务内原子重构会失败,编码质量趋零,于是它在
Stage II 的收益项里自动接近零价值,永远不会被买。机理上重要的一点
是:**门不是一个带阈值的过滤器,而是表示本身的推论**,所以没有阈值
可调,也没有误杀的代价来源。证据:任务外残留 0.000(零泄漏);把门
显式关掉,in-task 也几乎不变("门免费"),说明门只在挡本来就没价值
的东西,与机理预测一致。

### 读数 3:耦合预报(双 κ) ✅ 受控套件 / ❌ AppWorld 任务族谱

两个任务共享原子的程度在两个视图上意义不同。prompt 视图重叠 κ^p
是**混淆度**:学生会不会把 B 任务的题错认成 A 任务来答;response
视图重叠 κ^r 是**干涉度**:训练 A 时梯度沿共享原子方向走,会不会
把 B 的行为一起搬动。一阶耦合定律把这写成
ΔL_off ≈ −η·Σ_a S_a·⟨d_a, ∇L_off⟩:训练更新在原子方向上的投影,
与 off-task 损失梯度的内积决定 off-task 是被带好(建设性)、带坏
(破坏性)还是不动(解耦)。证据:受控套件三分型全中——sql κ_r=0
解耦(残留 0.000)、pandas 共享底座建设性迁移、cot 16 个共享原子
破坏性(+.38 损伤),方向全部在花钱之前被预报命中。余量:把同一
预报搬到 AppWorld 任务族(验证集第③项,未启动,不阻塞冻结)。

## Stage II · 训练数据(花钱)

### 机理总述

一条规则:候选 x 的边际价值 v(x) = 收益 − 挤出成本,贪心取
argmax,买入后更新账本(已供给 ŝ_a 上涨、配额缺口缩小),直到全体
v≤0 停止。无预算外超参:何时停、买什么、买多少全部由账本决定。

### 收益项 u(x) = Σ_a min(r_a − ŝ_a, c_a(x)) / t̂(x) ✅

机理:一条候选的价值是它能填补的**未满足配额**,除以它的 token
开销。min 使得超出配额的供给一文不值,这给了规则天然的边际递减,
也是"停止条件内生"的来源:账填满,价格归零,采购自停。证据:v1.2
边际规则对五个 selection baseline 全胜;剂量饱和定律互证。

### 挤出成本项 λ_anc·Δ_anchor + Σ_c ŝ_c·κ^r_c ✅ 已判定并重定位

机理:把耦合定律**预报的伤害预先计入价格**。40k 判定(s0/s1,
s2 在跑)给出了它的真实身份:**减伤失败**——cot ΔL +.404/+.443
与无此项的 +.38 相当,因为干涉由任务自身的需求原子携带,池里每个
候选都行使它们,选择层面无从回避,内生耦合选不掉,防伤归锚
(Stage III)。**但省钱成立**——40k 预算下 v(a)≤0 在 ~20k 自动
截停(20047/20325),in-task .66/.65 与 20k 档持平,同等效果半价。
重定位(用户已批):挤出项是**预算效率机制**(边际不值就停手),
进 RQ5 的 B*(τ) 叙事;method.tex 已同步改写。

### 自解锚(出处规则) ✅

机理:克隆之所以必败(见 Stage III 克隆地板),是 teacher 的表面
风格把学生拽离自己的分布,连带冲掉 base 已有的成功模式。锚的作用
是**分布锚定**:把学生自己已验证成功的 rollout 强制入池,训练分布
里始终有"学生自己的成功方言",teacher 的监督于是落成缺口填补而不
是分布覆写。这解释了三条定律为何长这样:出处纯度单调(.284 自产 /
.245 混合 / .202 teacher 风格——锚越像学生自己,锚定越强);剂量
×1 饱和(锚是分布标记,不是数据增强,在场即可,加倍无益);无锚
崩塌(两个台上拿掉锚全部塌回克隆地板)。

### 锚剂量曲线(支线) 🔄

gen8 首种子:10/25/50 条锚 → cot 损失中和 −.40/−.455/−.508 单调
增强,in-task 不掉;行为层(any_acc)50 条仍未翻转,说明损失层
中和先于行为层恢复,行为翻转点在更高锚占比。余种子在跑。

## Stage III · 蒸馏(刻账)

### 机理总述

一个目标:L(x) = NLL(y⁺|x) + β·1[y⁻ 存在]·ℓ_OR(带门控与掩码)。
它是 Stage II 账本在 token 粒度的执行:正例 NLL 是"把买来的监督刻
进去",门、掩码、配对许可三件套是"刻的时候不铲掉已有的字"。

### NLL 门控 ✅

机理:学生还写不出正例时就施加偏好压力,压力只能把负例概率质量
压下去而无处可去,结果是整体分布塌陷(无门 .630 的成因)。门控用
正例 NLL 的滑动平均判断"正例已可学会",压力只在此后到达——这在
无阶段划分的连续训练里**自动复现了课程式先 SFT 后偏好的时序**。
证据:门控 .660 平分显式两阶段 .668,胜无门 .630,3/3 种子。

### 分歧掩码 ✅

机理:损失只落在师生分歧的 token 上。学生已经写对的 token 不承受
梯度,已有能力在 token 粒度上被原地保护——这是挤出成本思想在最细
粒度的翻版。证据:v1.2 组件审定。

### 成功轴配对许可 ✅ 受控 / ❌ 主台步级

机理:偏好对的差异轴决定目标函数学到的判别方向。若一对样本的
主要差异是风格(teacher 腔 vs 学生腔),梯度学到的就是风格判别,
反而加速风格覆写(AppWorld 风格对 −.087 的成因);只许可"同一
prompt、成败分明"的对,梯度才对准内容正确性(gsm 内容对 +.032)。
余量:主台的步级负例(在多轮轨迹里定位失败步、构造步级成功轴对)
需要先设计步级信用分配,验证集第②项,未启动,不阻塞冻结。

### 权重平均 ✅

机理:训练末端的 checkpoint 平均落在更平的极小值上,免费收紧种子
方差。证据:v1.2 审定,主结果 std 收紧来源之一。

### 克隆地板(反面机制,方法的对照面) ✅

机理:纯克隆的失败模式是**风格捕获**——学生优先拟合 teacher 输出
中最易学的表面统计量(格式、口癖、篇幅),这部分梯度信号最强却与
任务能力无关,且直接覆写 base 分布。这解释了地板的三个反直觉性质:
与 selection 方法无关(.200-.215 五法齐平,因为病根在训练不在选
数)、与规模无关(4B/9B 同现)、与数据量无关(125× 不救)。整个
方法可以读成"对克隆地板的三重外科手术":锚保分布、门保时序、掩码
保 token。
