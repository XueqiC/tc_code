# 方法 v1.4:整体文档(连续边际规则版,2026-08-22)

## 大故事线

**Budget 被尽可能地用来提升 in-task performance。** off-task 的走向
不是优化对象:它由任务对的耦合几何决定,方法只保证不为界外能力
花钱,并能在花钱之前预报耦合后果;off-task 低是"预算没有漏损"的
证据,不是压制的结果。

## 一条原则,一条规则

**原则**:学生先试,验证器免费打分,只在学生自己失败的地方花钱买
监督;学生自身分布必须在训练分布中有锚。

**规则(v1.4 统一,无阶段无日程)**:每一轮,对每个候选监督动作
a ∈ {买示范, 买修复, 收自解, 开偏好项, 不买},以同一套量估计边际
净值
  v(a) = 预测边际能力增益 − 预测边际耦合成本,
执行 argmax v(a);全部 v ≤ 0 则停止花钱。增益项即现有 u(x)(剩余
需求 × 预测供给),成本项由双视图字典的共享原子供给 × 响应 κ 给出。
"示范 → 修复 → 免费信号 → 停"的演化自动涌现:学生成长使需求衰减、
示范的 v 下降;失败集中使修复的 v 相对上升;最终全 v≤0 自然停购。
过渡连续、由机理驱动,没有早中晚期的人为分段。

设定:support set S(k 条 query + 免费示范)+ 计费 black-box teacher
(无 logprobs)+ 开源学生 θ₀ + 预算 b。目标:
θ̂ = argmax_θ E_{q∼P_T}[Perf(θ; q)]  s.t.  Cost(θ) ≤ b。

## 核心对象:双视图耦合字典(一物七用)【已验证】

[D_p; D_r] 两个视图块,单一稀疏编码 c 同时重构题面与响应特征:
min ‖X_p−CD_p‖² + ‖X_r−CD_r‖² + λ‖C‖₁(能力剖面视图不变)。
七个角色:① capability atoms(定义:字典行 [d_p;d_r]);② 任务需求
w(编码均值,90% 质量截断);③ 供给预测(候选题面 lasso,免回归桥);
④ 任务边界(题面块重构残差 + conformal);⑤ 缺口诊断(每能力损失
曲线);⑥ 吸收观测;⑦ **耦合预报**:题面 κ = 可混淆度(门要拦多少),
响应 κ = 干扰潜力(训练会伤谁)。
效率证据:比 ridge 桥浪费减半、未满足需求减半、入库 +10%,精度持平。

## 耦合几何(实证 + 一阶定律)

三分型【已验证】:解耦(sqljoin:响应 κ=0 → 行为残留 0.000)/
建设性(pandas:底座层正迁移,低于原子分辨率,免费无害)/
破坏性(gsm-cot:题面 κ .756 + 响应 16 共享原子风格冲突 → cot 能力
.5→0)。
一阶定律:ΔL_off ≈ −η·Σ_a S_a·⟨d_a, ∇L_off⟩。预算扫描【已验证】:
破坏项随供给增长(cot 损伤 40k 处 +.38),40k 全线出现边际收益递减 +
边际耦合成本递增 → 存在最优预算区间,这是 B*(τ) 与停购项的机制基础。
注意分层【已验证】:纯度主张锚定**行为层**(执行指标);loss 层的
软风格迁移(sql 困惑度下降但不产生可执行能力)单独陈述,无害。

## 学习流程(四阶段是叙述顺序,不是行为分段)

### 阶段 I:确定任务(只用 support,零花费)
I-1 劈分 70% fit / 30% cal(cal 只定标)。
I-2 双视图梯度特征(响应视图=教什么;题面视图=计费前可得)。
I-3 耦合字典 → atoms、需求 w、每能力预算 w_a·b。
I-4 边界:题面残差,阈值=最不典型 cal 题(conformal;松弛 s≤1 纯度
    不掉【已验证】)。
I-5(可选)对参照 off-task 输出双 κ 耦合预报。

### 阶段 II:按规格购数据(计费)
覆盖目标 F(A)=Σ_a min(w_a·b, Σ_x s_a(x)) 单调次模;u(x) 是其代价
归一化边际增益,贪心继承 (1−1/e) 近优【已验证 R 稳健:R=1≈R=2】。
每轮:重拟合字典(词汇 67%→84% 随证据变细)→ 候选 lasso 预测供给
→ argmax v(a) 购买(批内工作需求扣减)→ 验货(执行检查 + 题面残差;
拒收计浪费 2-4%,预算回环)→ 训练插曲读缺口 → 先试后买(自试 3/3
一致 → 自解免费;失败才买示范/最小修复;失败尝试自动配偶好对;
候选枯竭时定向生成兜底)。
零残留机制 = 环内门 + 回购【已验证 0.000×4 预算×3 种子;开门实测
in-task 代价 ≈0 → 零泄漏免费】。

### 阶段 III:on-policy 蒸馏
训练信号按学生策略状态分层,合成单一目标一次优化:
L(x) = NLL(y⁺|x) + β·1[有 y⁻]·(分歧掩码 odds 项,NLL 门控)。
- 三层来源:自解(保留自己的行为,零成本)/ 失败(正解 + 压自己的
  错解)/ 无尝试(克隆示范,退化情形)。
- NLL 门【已验证】:odds 项仅在该行正解 NLL 低于运行均值后激活
  ("先学会再区分");.660 平分段最优,胜无门 3/3;孤立偏好阶段
  剂量曲线(4/6/12 步 = +.032/−.026/崩)判死。
- 分歧掩码:从首个分歧 token 起计偏好损失(切除 likelihood
  displacement 源头)。
- 锚定三证【已验证】:gsm 共训梯度锚 / AppWorld 混 ~1% 自解轨迹回
  base 水平(.284 vs 克隆 .20)/ token 级掩码无锚则两台皆败。
- 权重平均(探针信任域 SWA)+ 一题边距回滚【已验证 +.058,极差
  .013】;正确率探针(金标免费)【已验证:可运行率探针对崩塌失明】。

### 阶段 IV:认证部署
题面残差 + disjoint cal conformal → 覆盖 ≥1−α 边界预测器;行为层
双侧 Clopper–Pearson 证书;界内路由学生、界外拒绝/升级。
