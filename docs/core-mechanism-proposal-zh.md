# 核心机制提案:监督梯度的能力-方言分解(2026-08-25)

## 问题

现在的方法读起来像组件清单:LESS 梯度 + 耦合字典 + 次模选择 +
context distillation + 拒绝采样 + ORPO + conformal。每个组件有出处,
拼起来没有一个"属于我们的物理定律"。要一个能**生成**整套方法的
单一核心机制,而不是一个装下所有组件的框架。

## 提案的核心机制(一句话)

**监督更新分解定理**:对任何监督源,学生的期望参数更新可分解为
"能力分量"与"方言分量"两项;方言分量当且仅当训练目标取自学生
自身分布时为零,而 verifier 过滤使自身分布上的更新精确指向任务
成功方向。

形式骨架(可写成正文定理):
- 对模仿目标(teacher 文本 y~q):
  E[∇ NLL(y|x)] = ∇KL(q‖π_θ) 的方向,拆成
  **能力项**(任务相关原子上的分量)+ **方言项**(分布错配原子上
  的分量);方言项 ∝ 师生分布距离,且在小学生上占主导(可测)。
- 对自产目标(y~π_θ):score function 期望为零,
  E[∇ NLL(y|x)] = 0——自产数据在期望上**不产生任何漂移**;
- 加 verifier 过滤(只训 V=1 的样本)后,期望更新
  = ∇ E_{y~π_θ}[V(y)](REINFORCE 恒等式)——**唯一的系统性漂移
  恰好是成功率的梯度**。方言分量按构造为零,能力分量按构造满格。

这不是拼装:это一个关于"监督如何进入参数"的机制陈述,其余一切
都是它的推论。

| vdisp 选择失灵但内生停止成立 | 方言项不依赖选哪条数据(分布性质),故选择躲不开;预算只该买"提高 V=1 质量测度"的东西 |

## 由定理生成的方法(而非拼出来的)

1. **通道选择**(定理直接给出):外部行为只允许进入上下文,
   永不做梯度目标 → 示范=提示、学生自作、verifier 准入;
2. **更新规则**:w(τ)-修正的 verifier 策略梯度 + 保护版负通道
   (v2.2 那条单式)——定理告诉我们这是唯一零方言更新族;
3. **预算规则**:钱只该买"提升 E[V] 的上下文"(示范/纠错提示),
   定价 v(a)=ρ(q)·配额填补/开销,停止内生——因为定理断言买任何
   "目标"都要付方言税,买"上下文"免税;
4. **测量仪器**:双视图字典把两个分量变成可观测(方言项住在
   分布错配原子上,能力项住在需求原子上),支撑边界、耦合预报与
   证书——字典从"组件"降格为"仪表",理论地位反而清晰;
5. **脚手架毕业、轮次、门控**:全部是"保持方言项为零"在时间轴上
   的执行。

## 需要补的实验(定理的直接验证,均便宜)

- **T1 分量测量**:对克隆梯度与自产梯度,用字典投影分别测方言/
  能力分量的范数比——预测克隆的方言分量占主导、自产的趋零;
  这是定理的直接可视化(一张主图)。
- **T2 方言项与损伤的剂量关系**:混合池中 teacher 目标占比 p 从
  0→1 扫描,损伤应随方言分量范数单调(现有 .284/.245/.202 三点
  已在线上,补中间点)。
- **T3 预测性检验**:用 round-0 测得的方言分量范数预测各 baseline
  的下沉幅度(七个 baseline 当验证集)——机制若能预测排序,
  novelty 与说服力都齐了。

标题级主张从"一个预算化蒸馏管线"升级为"**小模型的能力获取由
