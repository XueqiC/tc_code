## 已实现、证据部分到位(今晚定稿)
- **技能级纠错获取 ourscorr(创新3)**:与 LLM2LLM 完全同协议,仅
  增购规则不同(失败例过字典→技能缺口 vs 错题相似度)。
  seed0 @2B×20k:**ourscorr .900 = LLM2LLM .900 战平**;⏳ 三种子 +
  纯度/效率列裁决。
- **探针精化字典 boot4**:留一方差+单锚定位低置信 atom → 定向探针购
  → 字典重拟。机制验证通过(5 atoms/450 tok/零浪费);0.8B 不加分
  (.400),⏳ 2B 判定。

## 明确划出 scope(设计完成、排期验证)
- per-atom 吸收监控(创新2)——需多轮训练曲线,AppWorld 段(后天起)
- 隐式需求补全(响应→prompt 桥接后未复测)
- k-sweep 与 query 质量鲁棒性曲线(E6c)
- AppWorld/BFCL 等大 benchmark 主表(协议已定,单 teacher 缓存池就绪)

## 实现级发现(写入论文实现细节)
1. 问什么的信号必须与账本同模态(prompt vs 响应空间错配 → 97% 浪费)
2. 免费货架用紧门选优、付费采购用宽门验货(选优门误用 → 86% 冤杀)
3. 码强度不可归一化——lasso 码质量本身就是质检信号
4. 行为停在大预算档有代价(checkpoint 选择噪声),预算感知的停用策略
   进 Table 2 最佳配置
5. HPG watchdog:长 CPU 采购段需 GPU 化打分运算(排期)

## 规模适用范围(如实声明)
0.8B 学生的梯度指纹信噪比不足以支撑技能级定向(in-task 居中,纯度
不受影响);方法的目标学生为 ≥2B(与实际部署诉求一致)。
