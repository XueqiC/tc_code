## 4. 新想法(各附最便宜的证伪实验)
1. **ΔU 作为序贯检验而非固定 K(§16.3)**——已做便宜证伪(CPU 模拟,127 个分歧):后验停止规则(P(ΔU>0)>0.8 或 <0.2)只省 20% 续跑,与 K=3 符号判定一致率仅 67%。原因是 ΔU 分布 0×70、+0.2×28、+0.4×15、−0.2×10:大多数"后果性"只是多赢一局,P(ΔU>0)≈0.6。**结论**:K=3 下符号本身低置信,方向应是对近零事件自适应加 K、并用 P(ΔU>0) 加权(已实现 AW_DDPO_WEIGHT=conf,今晚 ALFWorld 加 D_conf 臂),而不是省预算。**K=8 再估计(9/4 02:50,253/268)**:零ΔU 事件在 K=8 下 15% 翻正、7.5% 翻负、77% 仍为零,P(ΔU>0)>0.8 仅 5% → K=3 的"零"标签基本稳定,这些分歧在该状态确实不改变结果。与 CE_zero=50% 合起来:零ΔU 事件在 CE 下的价值来自泛化的 demo 模仿,不是该状态的干预价值;"后果性"衡量的是哪些纠正改变结果,CE_C 的 4 倍事件效率正来自于此。D_conf(全池 × P(ΔU>0))官方 14.9 < 均匀 A 18.7,置信加权也不成立。
2. **负教师证据(§16.1)**——已做(E 臂,官方):C 的 85 事件 + 8 条反向对(dU<−0.2:chosen=学生动作,rejected=demo 动作),47 步,**8.21%**(C 17.16、base 8.96)。只加 8 条反向对就抹掉了 C 的全部增益。**结论**:这种形式有害——反向对强化的正是学生早期 look/乱逛的失败模式("demo 动作没用"≠"学生动作对");负证据若要用,只能用来降权 demo 动作,不能把学生动作当正样本。降级。
3. **纠正片段最小化(§16.5,BFCL 侧)**——已做:偏好目标只落在 chosen/rejected 的差异 token span 上(AW_DDPO_SPAN_ONLY)。r2 池 1ep 官方 **47.52 vs 全 span 47.34**(分轴差 ≤1.5,噪声内),漂移 KL 0.0047 与全 span 相同。**结论**:在这个剂量下最小编辑既不多给增益也不少漂移——成对目标的漂移已在地板,"更小的纠正支持"没有额外空间;降级为无证据。(rai 代理 47.34 是 Memory 1 题假象,再次说明代理 Overall 不能用于小差异。)
