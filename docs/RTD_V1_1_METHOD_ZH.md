# RTD v1.1(rev 3.1):完整方法 — 2026-09-09

本文是 v1.1 的完整方法说明(独立成文),供审阅与作为实现规范。rev 2 依据用户 04:42Z 的建议,rev 3 依据用户 04:53Z 的执行修正(同批次参考、冻结曝光权重、d 为求解器输出、采购代理标注、归因与测试名称),把方法核心集中到一个具体机制:**在控制教师注入量的同时,用蒸馏之后的完整任务收益决定从学生的哪些行为上移走概率质量;再让采购选择经过这一算子后最有价值的证据。** 所有"轮"指预算轮,不是种子;全程单训练种子(seed 0)。v1.0 → v1.1 rev 2 的变化见附录 A;rev 1 → rev 2 的变化见附录 B。

## 1. 问题设定与贡献

- 目标:在教师 token 预算 B 下,把黑盒文本教师的能力蒸馏进小 agent 学生 π_θ(4B),终点是学生在官方 benchmark 上的完整任务表现(BFCL v4 Overall;ALFWorld valid_seen 成功率;AppWorld TGC)。学生可访问自己的完整分布;教师只能按状态请求续写,每次有 token 成本。
- 三个耦合决策:买什么、怎么用、何时停。
- **要建立的具体贡献**:在黑盒文本教师条件下,用**实际学生更新后的完整任务收益**决定**哪些现有行为应保留、哪些应被教师行为替换**;并把证据的采购价值定义为它对"整组证据在共享更新空间中能实现的收益"的边际改善。
- 与已有工作的区别:按验证梯度调样本权重(Learning to Reweight)与"抑制学生过量概率、补充教师缺失概率"(TIDE)都存在;本方法的新处是**合法概率转移中的选择性行为替换**(教师质量固定、只改替换对象)+ **由实际更新约束导出的证据价值**。中心化、约束优化、元梯度各有先例;它们必须在这里共同带来普通调权难以复现的"学习—保留"优势,否则不成立。
- 单种子探索;同硬件、同软件、同任务清单的对照臂;报告方向与数值;局部机制比较用同检查点、同任务的配对干预。

## 2. 对象与资源

### 2.1 状态、动作、来源分布
- 状态 s:任务提示 + 已执行历史;动作 y:学生一次完整输出(含终止)。
- 来源分布 p_t:本轮开始时冻结的学生快照在 s 上的分布;**每个提交步在每个状态从 p_t 重新采样两个动作 Y₁, Y₂**(不复用缓存样本)。
- 教师证据 ν_T(·|s):教师在 s 上的文本续写(整段,含终止),来自 bank(封存回放)或在线请求。

### 2.2 教师 bank、请求包与硬账本

### 2.3 曝光、决策窗口与折
- 每个预算轮 12 个提交步,4 个决策窗口(步 1/4/7/10)可购买新包;每窗固定曝光槽 E=40,最多 K=20 个新包、每包 1 槽,其余由累计池填充;买 0 包 = 只训练已有证据。决策步按批量混合更新,更新后新包并入当轮池;非决策步按冻结抽样规则从累计池训练。
- **曝光单位(统一计量)**:

  | 一个曝光单元 | 一条状态的教师监督记录 + 该状态的两个学生来源动作 |

  | K ≤ 20 | 至多 20 个新包对应的曝光单元,其余由旧池填充 |

## 3. 核心机制:注入量 + 来源选择的合法概率转移

### 3.1 目标分布
同一状态采两个学生动作 Y₁, Y₂。定义
a₁ = α + d, a₂ = α − d, 0 ≤ α ≤ 1, |d| ≤ min(α, 1−α),
- α(s):**注入量**——这个状态注入多少教师质量;由状态门控产生,**在采样前确定**;
- d(s, Y₁, Y₂):**来源选择**——两条学生行为中优先替换哪一条;依赖两个来源动作。
目标分布
q = ((1−α−d)/2) δ_{Y₁} + ((1−α+d)/2) δ_{Y₂} + α ν_T,
是合法分布;**无论 d 如何变化,教师质量恒为 α**——d>0 只是更积极地替换 Y₁、更多保留 Y₂,不会偷偷增加教师监督量。两个变量都可学习,不写入调用错误/格式错误/benchmark 类别规则。

### 3.2 梯度估计器
令 Ḡ_soft 为两个采样前缀上软来源梯度(每个前缀位置用冻结快照 p_t 与当前学生的完整词表分布的 KL)的平均,G_T 为教师文本梯度,G₁、G₂ 为两条硬样本的 NLL 梯度:
**ĝ_d = (1−α) Ḡ_soft + α G_T − (d/2)(G₁ − G₂)**。
- 第一项保持原学生分布;第二项安装教师行为;第三项调整哪些学生行为被替换。
- 因为 α 在采样前确定,只软化与样本无关的来源基线,所以即使 d 同时依赖两个动作,ĝ_d 仍是期望目标的无偏梯度估计(有限动作枚举已核验)。
- 设两条学生梯度有公共分量 G₁ = u(s)+e₁, G₂ = u(s)+e₂,则 G₁−G₂ = e₁−e₂:**两条行为共有的梯度分量被代数消掉**,可直接研究同状态内的行为差异,不再要求跨事件低秩编码先识别差异(它只消掉真正共有的分量,不保证所有格式/调用边界影响消失)。
- 最后一项是随来源采样刷新的更新估计器,**不**保存成反复训练的负权重 CE;不需要格式过滤。
- 软来源项在 π_θ = p_t 处逐前缀梯度为零(精确),不依赖大量样本相互抵消。

### 3.3 用真实学习收益决定 d(d 是一个小型求解器的输出)
对**本步实际提交的同一批证据**(同样的包、曝光权重 w_i、教师质量 α_i、来源采样),先构造没有来源选择的虚拟参考学生
θ_S(0) = θ − η P Σ_i w_i [ (1−α_i) Ḡ_soft,i + α_i G_T,i ],
加入来源选择后 θ_S(d) = θ_S(0) + Σ_i d_i v_i,v_i = (η w_i / 2) P (G_i1 − G_i2)。两边的证据、曝光权重、教师质量与来源采样完全相同,唯一变化是 d——这是下界成立的前提。
定义 z_i = ∇J(θ_S(0))ᵀ v_i,J 为**温度 1 随机策略从任务起点执行的期望回报**(与官方 greedy 分数是两个量,不混用;z 衡量学习作用,不是当前两条动作的奖励差)。若更新路径满足局部平滑(L_H),则对单个来源对
J(θ_S(d)) − J(θ_S(0)) ≥ d z − (L_H/2) d² ‖v‖²_H,
结论:**相同教师质量下,若两条学生行为的学习响应不同,就存在足够小的选择性转移优于均匀转移。** 回报梯度有噪声、L_H 未知,不据此声称单调提升;把估计误差写进界(|ẑ_i − z_i| ≤ ε_i)。
**本轮实现规定 d 为如下局部控制问题的解**:
d* = argmax_{|d_i| ≤ min(α_i, 1−α_i)} ẑᵀ d − (λ/2) dᵀ K d − Σ_i ε̂_i |d_i|,K_ij = v_iᵀ H v_j,
- ẑ 由 θ_S(0) 上的反馈 rollout 估计,ε̂_i 由该批 rollout 沿方向 v_i 的标准误(LOO/对半)估计;λ、H(对角预条件的逆)为冻结超参;
- 收缩到零由**联合**目标本身产生:对允许零点为内部点的坐标,零坐标条件是 |ẑ_i − λ Σ_{j≠i} K_ij d_j| ≤ ε̂_i(涉及其他坐标);**不**存在逐坐标断言 "|ẑ_i| ≤ ε̂_i ⇒ d_i = 0",也**禁止**在求解前按原始 ẑ_i 单独筛掉坐标——一个方向即使直接收益很小,也可能通过抵消其他方向的更新代价而值得使用;联合效应由 K 的交叉项体现;
- 当误差与平滑界可靠时它是有限步下界的最大化;实际超参版本称为**局部代理目标**。
研究问题:**多少反馈足以辨别有价值的来源选择,何时应收缩到均匀转移(d→0)?**
- 启动:d = 0,α 用冻结的初始监督强度;初期稀疏回报没有可用方向时教师文本蒸馏仍继续,不等门控学会才训练。
- **停梯度**:学生提交时对 α、d 停梯度(估计式对应固定教学目标的学生梯度);α 的元梯度另做计算,首版把本次求得的 d 固定——明确称为**分块更新**,不声称穿过 d*(α)(若要穿过,还需处理参考回报梯度随 α 改变的依赖)。
- **非决策步的 d**:每个决策窗口刷新一次回报梯度;窗口内其他步使用最近的反馈梯度、重新计算来源方向 v_i 并求解 d;这些步是近似控制,**记录反馈年龄**(距上次刷新的步数)。**不确定性沿新方向重算**:保存反馈梯度的逐轨迹贡献(或可重新投影的统计量),在每步的新 v_i 上重新估计 ẑ_i 的标准误 ε̂_i,不能沿用上个窗口保存的标量;它仍不覆盖反馈陈旧造成的偏差(实现约定,不设实验关口)。
- 实现约束:回报梯度只决定蒸馏目标(α、d、采购),**学生骨干只提交对应的蒸馏更新,没有 RL 步**。

### 3.4 一个决策窗口的固定顺序(两个参考点不共用)
1. 用已有采购后验(历史信息)选择、支付并揭示新包(§4);
2. 固定本步实际证据、曝光权重 w_i、注入量 α_i 与来源采样(Y_i1, Y_i2);
3. 用**这批证据**构造 d=0 的虚拟参考学生 θ_S(0);
4. 在 θ_S(0) 上估计回报梯度(温度 1 rollout),求解 d*(§3.3);
5. 提交**同一批证据**的选择性蒸馏更新 θ_S(d*);再在 θ_S(d*) 上估计回报,更新 α 的门控参数(分块更新)。
采购的参考点(历史后验)与来源选择的参考点(本步同批证据)**不能默认共用**;两批 rollout 分开记账,不互相替代。
- α(s) = σ(φ·χ(s)):χ **只用状态特征**(不含当前 Y₁,Y₂ 的长度、似然或投影,否则"采样前确定"失效;不含类别或错误类型);标量变体 α = σ(φ₀)。

## 4. 采购:证据价值来自"同一更新如何组合"

### 4.1 为什么不能只用独立插入价值
固定教师质量、共同参考梯度的一阶近似下,教师项会从来源选择中消掉;仅凭 §3 不能宣称学会了教师与学生行为的特殊匹配。真正的耦合来自**有限更新与共享的更新空间**:多个来源对的实际修正 Δθ = Σ_i d_i v_i,其局部目标含
ĝ_Jᵀ Δθ − (λ/2) ‖Δθ‖²_H,
展开二次项出现 −λ d_i d_j v_iᵀ H v_j:**两份各自有用的证据合起来可能重复推动同一方向,消耗更新空间却没有等比例收益**——这与过去"公共模式占主导、增加事件或曝光不一定改善"的结果直接相关。**下一步最值得验证的是冗余与累积干扰,不预设互补原子。**

### 4.2 采购价值:围绕同一蒸馏算子的采购近似
V(q | 𝒟) = E[ F(𝒟 ∪ {q}) − F(𝒟) | 购买前信息 ],
F 为已有证据经 §3 传输优化后、在相同曝光与更新约束下能获得的收益。新证据的价值取决于它能否**改善当前整组证据可以实现的学生更新**。本轮明确区分:
- **F̂ 评估完整更新(含教师注入)**:对证据集合 𝒜,定义 Δ_𝒜(d) = θ_𝒜(0) − θ_ref + Σ_i d_i v_i(θ_𝒜(0) 为该集合上 d=0 的一步更新,θ_ref 为共同参考点),F̂(𝒜) = max_d [ ĝ_Jᵀ Δ_𝒜(d) − (λ/2)‖Δ_𝒜(d)‖²_H − 不确定性正则 ];所有比较使用同一参考点与同一回报梯度;完整集合上它就是现有的 d 控制器,比较删包版本时则计入失去的教师学习作用(均匀注入 αG_T 的收益不会因 d 收缩到零而消失——ALFWorld 已有结果说明:选择性修正无增量不代表教师证据没有教学价值)。已购包 q 的代理边际值 = F̂(𝒟) − F̂(𝒟∖{q});删除 q 时用**预先确定的旧池证据补回其曝光单元**,其他权重不变;复用已有参考学生,不增加逐候选环境评测。必要测试:**强制所有 d=0 后,代理仍能区分预测有益与有害的教师更新。**
- **实际配对收益**:独立执行两个更新后的学生在任务上测得的表现差。
采购后验**先学习 F̂**;实际配对收益用于检验 F̂ 是否有用;**不用同一批反馈既选择 d 又证明选择后的收益预测准确**(检验用另一批反馈或留出任务)。边际价值依赖当前学生与已购集合,后验特征除包的静态公开特征外必须加入**购买前可得的当前训练上下文**(轮/步、已购集合摘要、当前 α 分布、反馈年龄等);预测能力不足时允许强收缩。这一部分称为**围绕同一蒸馏算子的采购近似**,其有效性由 V2 检验。
- 未购教师梯度不可见,不能直接算 Gram 矩阵;不假定能准确预测所有未购包的相互作用。
- 预算约束的批量采购(每窗 K≤20、E=40、Σĉ_q ≤ B_t)与硬账本执行顺序(求解 → 逐包 reserve → reveal 结算 → release → 更新 → 用实购集合构造损失)保持 v1.1 定义;V0 用同预算/同 K/同成本模型的随机抽取。

## 6. 运行协议

### 6.1 三臂(hpg B200 同机;单种子;2 个预算轮)
| 臂 | 采购 | 蒸馏 | 回答 |
|---|---|---|---|
| V0 | 随机批量采购 | 软来源估计 + 固定 α=.5,d=0 | 基准 |
| V1 | 复用 V0 的完整曝光记录(购买时间、状态曝光、包权重 w_i、重复次数) | **α+d 机制**(学习 α 与 d) | V1−V0:**自适应蒸馏的整体效果**(α 与 d 都变) |
| V2 | 联合边际收益后验 + 预算批量采购 | 与 V1 相同 | V2−V1:买什么(自适应采购整体效果) |
V0 先跑;V2 与 V0 并行;V1 随后。来源输出由各臂自己的冻结学生重采。三臂共用同一估计器实现与同一采购执行器。

### 6.2 嵌入的机制对照(冻结检查点上的配对干预,不阻塞 pipeline)
| 比较 | 固定什么 | 要证明什么 |
|---|---|---|
| 学习的 d vs d=0(同 α) | 每状态教师质量 α、证据、曝光权重 | 来源选择有额外收益——**隔离核心机制的关键比较** |
| 学习的 d vs 打乱来源对应关系 | α、门控值集合、教师目标 | 收益来自行为与转移方向的对应 |
| 联合更新控制 vs 独立控制 | 已购池、反馈量、更新预算 | 处理冗余与干扰有额外价值 |
主要观察:(1) **实际任务修复与损伤**:相同教师质量下是否修复更多、损伤更少;(2) **预测与实际更新作用**:ẑ 能否预测留出任务上的配对更新收益(不仅是似然变化);(3) **完整学生性能**:新变体是否超过 v1.1 rev 1 的软/CV 版本,以及同预算下充分调好的 CE/pairwise 基线。
- 来源估计器对照(2 硬样本 / 软 / 8 硬样本 / 语法过滤)保留为嵌入诊断,回答"改善是否符合采样噪声解释",不决定主方法。

### 6.3 每轮必报
固定任务集(两折各 20 状态 × T=1 采样 K=4)解析失败率;梯度方差;每窗购买数/支出/剩余预算/约束绑定;联合-vs-可加误差;ẑ 与实际配对收益的相关;修复/损伤计数(固定任务集,同 α);官方 Overall(10%/25%)。

### 6.4 决策表(两轮三臂 + 对照完成后)
| 结果 | 下一步 |
|---|---|
| V1 明确优于 V0,且 d 对照显示收益来自对应关系 | 选择性替换成为主贡献 |
| V2 在相近实际成本下进一步优于 V1 | 采购与蒸馏的统一框架获得支持 |
| V1 有收益、V2 无增量 | 固定蒸馏,集中改联合控制/采购估计 |
| V1 无增量 | 检查 d 是否产生实质不同的更新、ẑ 是否预测收益;可能需更多反馈或收缩到 d=0 |
| 三臂都改善但彼此接近 | 收益来自共同目标或曝光,暂不归因于自适应模块 |
三臂后补一个同已购池、复用现有强配置的 CE/pairwise 终点。ALFWorld 过去学生侧迁移信号弱,不预设来源选择在所有阶段都有明显收益;某些阶段主要靠教师注入,某些阶段来源选择额外改善保留——差异由反馈产生,不由 benchmark 名称指定。

### 6.5 不做
不加 benchmark 特定规则/类别特征;不做多步 Adam unroll;不缩减官方评测;不用跨机器差值构造噪声带;不把中心化/约束优化/元梯度工具本身当 novelty;不把负系数项固化成多轮 signed-CE。

## 7. 理论能支持什么、不承诺什么
- 支持:q 合法且教师质量恒为 α;ĝ_d 无偏(α 与 w_i 在采样前确定——若 w_i 依赖当前样本或梯度,E[w_i(G_hard−G_soft)]≠0 会破坏无偏性,故本轮冻结 w_i);G₁−G₂ 消掉公共分量;**软来源项**在 π=p_t 处逐前缀零梯度(整体更新 ĝ_d = αG_T − (d/2)(G₁−G₂) 通常不为零,α=d=0 时才整体不动);有限步下界在误差与平滑界可靠时给出选择性转移优于均匀转移的条件(超参版本 = 局部代理目标);联合更新的二次交互项 K 解释冗余/干扰;硬账本与封存视图保证预算与信息边界。
- 不承诺:单调提升;方差降低幅度;多包收益可加;未购包相互作用可预测;跨 benchmark 固定超参;ICLR 接收——需要 §6.2 的对照真的显示普通调权难以复现的学习—保留优势。
