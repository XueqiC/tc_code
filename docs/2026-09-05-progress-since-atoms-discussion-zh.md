## 0. 一句话结论

- **原子线(P2 关口):NO-GO / SIMPLIFY**。24 个真实 micro-update × 32 个探针上,参数码能预测的行为响应只有"一个公共调用/弃答边界模式 × 更新幅度";降秩、分层、稀疏字典、PCA 全部不超过置换对照。互补组合的三组联合检验(call 锚点、弃答锚点、半剂量对照)都没有系统性补偿。
- **跨 benchmark 复现(T9 ALFWorld):同一结论**。120×385 单事件迁移矩阵 rank-1 占比 0.997,列效应就是"老师命令在基座下的概率";指纹几何在去掉行列效应后有 0.60 的一阶交互预测,但稀疏字典/PCA/聚类一分不多;学生侧为零。
- **AppWorld(AW-2 五臂):CE 在任何剂量、任何阶段覆盖下都塌(0–3/57),base-centred pairwise 不塌;pairwise + 阶段分散事件 = 12/57,是迄今唯一高于 base(8/57)的 AppWorld 臂(单种子,+4 任务 ≈ 1 sd)。**
- 建议:原子线作为"参数/行为分解"收口,保留的资产是"边界/格式模式 + 幅度控制"作为蒸馏对照设计;AppWorld 的 pairwise-spread 值得继续,原子的两个后续方向(连续边际靶、ALFWorld 同协议复现)需要你拍板。

## 3. P2 执行与关口(BFCL)

### 3.1 pilot(hpg 41150531,20 min)PASS

### 3.2 24 源采集(hpg dept 41151311/12/13,各 ~21 min)
768 格全部观测;65 格变化(8.5%):+23 收益 / −42 损伤;24/24 源有变化,10/32 探针有变化。收益集中在 simple_python 的 frontier 调用探针,损伤集中在弃答探针——从原始矩阵就能看到"边界往调用侧推"的公共模式。

### 3.3 编码
训练折 H 基维 17–19;留出源在训练基上的残差分数 ≈ 0.99,即 24 个 δ 在 H 度量下几乎两两正交,编码只是很小的投影系数。

### 3.5 保留约束 LP(实测矩阵)
零损伤下只有 src_23 一个正向源;15 源有益也有害,8 源仅害;迭代找不到第二个正向方向。0/1 结果里保留探针没有 headroom,线性配方无法表达"补偿",所以互补检验必须用联合训练。

### 3.6 互补联合检验(G1,格式 (增益, 损伤))
| 源 | 单源 | + 同家族 call 锚点 | + 随机 call 锚点 | + 弃答锚点 | 半剂量单源 |
|---|---|---|---|---|---|
| src_17 | (3,1) | (0,1) | (1,2) | (2,0) | (0,2) |
| src_14 | (2,2) | (1,2) | (1,1) | (0,1) | (0,1) |
| src_04 | (1,1) | (1,0) | (1,3) | (1,2) | (1,2) |
| src_09 | (1,1) | (1,1) | (0,2) | (0,2) | (1,3) |

读法:call 锚点主要稀释纠正、不消弃答损伤;随机锚点加损伤;弃答锚点 1/4 去损伤但增益减半、2/4 更差;**半剂量丢收益却不减损伤(0/1 结果对幅度不单调)**,而联合批看起来就是半剂量的样子——锚点 = 稀释,不是补偿。互补机制 INCONCLUSIVE,按 NO-GO 处理。

### 3.7 判决
NO-GO(参数码 → 行为响应的低秩模型)/ SIMPLIFY(可预测结构 = 一个公共边界模式 × 幅度)。不进 P3–P5。定稿:docs/2026-09-05-p2-stage-report-zh.md、results/behavior_atom_v1/stage_report_p2.json。

结论边界:不能断言更大剂量、更多源、连续边际靶下也无结构(功效:65 个变化格、10 组);不能断言互补不存在,只能说线性检验对它不敏感、联合检验没看到。

## 4. T9:ALFWorld 迁移矩阵(跨 benchmark 复现)

120 源事件 × 385 目标事件(Qwen3.5-4B,LoRA r8,3 步 pairwise,lr 1e-4),bootstrap ×1000、置换 ×500。
- 结构:非对角 98.6% 为正,均值 +1.69 nat/token;rank-1 占比 0.997(去总均值后 0.68);可加行+列 R² 0.95;列效应 = 老师命令在基座下的负边际(ρ 0.74,行内 0.86)。
- 预测子(ρ / 去行列效应后 / 符号 AUROC):ψ 指纹点积 0.41 / 0.60 / 0.97;稀疏字典 0.41 / 0.61 / 0.97;PCA 0.25 / 0.56 / 0.65;同类别/同任务/同命令 ≈ 0 / ≤0.11 / 0.50;列基座边际 0.74 / 0.02 / 0.98。
- 学生侧靶 T_student:方差 0.0009 / 0.522,所有预测子 AUROC ≈ 0.52 → 迁移全在 teacher 侧。

与 BFCL 平行:可迁移的是一阶梯度几何 + 一个公共格式/边界模式,不是可命名的原子。
