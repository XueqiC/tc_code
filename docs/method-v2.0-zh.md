# 方法 v2.0(三阶段一体化定稿,2026-08-22)

**大故事线**:budget 被尽可能地用来提升 in-task performance;off-task
走向由耦合几何决定并可预报,不刻意压制。

**一条价值原理贯穿全法**:每一份监督的价值 = 落在学生欠缺处的增量
− 对学生已有能力的挤出。三个阶段是它在三个空间的投影——测量空间、
数据空间、参数空间。

## 阶段一 · 确定任务(一个对象)

对 k 条 support 样例拟合**双视图耦合字典**
min ‖X_p−CD_p‖² + ‖X_r−CD_r‖² + λ‖C‖₁,
之后所有量都是这部字典的**读数**,不再引入新组件:
- 需求 w = support 编码均值(该买什么、各买多少 → 每原子配额 w·b);
- 边界 = 题面块重构残差 + conformal 阈值(什么算界内);
- 耦合预报 = 对任意参照任务的题面 κ(可混淆度)与响应 κ(干扰
  潜力)(训练会波及谁、以何种方式)。
一次拟合,三份坐标。已删:核岭回归桥、独立门字典、独立耦合探针。

## 阶段二 · 训练数据(一条规则)

对每个候选监督动作 a ∈ {买示范, 买修复, 收自解, 停},以字典读数
估计**边际净值 v(a) = 欠缺增益 − 挤出成本**,执行 argmax v(a);
全部 v ≤ 0 即停止花钱,余款不花。
- 欠缺增益 = min(剩余配额, 预测供给)/成本(候选题面 lasso 编码
  即预测供给);
- 挤出成本 = 锚份额稀释 + 共享原子供给 × 响应 κ。
原有组件全部成为该规则的推论:
- **先试后买**:免费动作(收自解)每 token 价值无穷大,永远优先;
- **配额**:增益项的 min(·) 截断,预算次模覆盖的 (1−1/e) 保证随之
  继承;
- **归属门 = 定理**:界外题面在需求原子上的编码近零(lasso 幅度即
  相关性),故 v ≈ 0,argmax 永不选中——门不再是模块,是规则的
  推论;执行验证只负责验货(货不对板不入库,钱计浪费);
- **纠错轮 / 停购 / 阶段演化**:随学生状态(需求衰减、失败集中、
  边际耦合成本上升)自然涌现,无轮次结构、无剂量旋钮、无阶段边界。

## 阶段三 · 蒸馏(一个目标)

语料行按"是谁的行为"自带标签,单一损失按标签行事:
L(x) = NLL(y⁺|x) + β·1[存在成功轴负例 y⁻]·(NLL 门控 · 分歧掩码
odds 项)。
- 自解行(学生已验证行为)= 出处纯净的 ×1 锚,只做 NLL 保持;
- 带负例的行:负例必须与正解**在成功轴上分歧**(执行结果不同),
  风格分歧对自动禁用;odds 项在该行正解 NLL 低于运行均值后激活
  ("先学会再区分"),损失只计分歧 token 之后;
- 其余行 = 克隆(空尝试的修复,退化情形)。
收尾做探针信任域内的权重平均与一题边距回滚。
**阶段三不做任何选择——它只是执行阶段二买单时定好的账**;挤出成本
在购买时已付,训练侧无需保护性补丁。已删:独立偏好阶段、token 级
掩码、absorption-focus、curriculum、需求加权。

## 阶段四 · 认证部署(不变)

题面残差 + conformal → 覆盖 ≥1−α 边界;行为层 Clopper–Pearson 双侧
证书;界内路由、界外拒绝/升级。零泄漏是"预算无漏损"的证据。

## 支撑定律(全部有实验出处,见 grand-synthesis)

锚定三定律(出处纯度单调 / 剂量 ×1 饱和 / 无锚必坏)、克隆地板
不变性、对比轴 = 成功轴、NLL 门、耦合三分型与一阶定律、零泄漏免费、
字典效率(浪费减半)、预算边际结构、R/k 稳健性。

## 最小验证集(每条 ≥2 台)

① 挤出成本项显式实现 vs v1.4(gsm 40k + AppWorld);② 成功轴步级
负例的主台偏好;③ 耦合预报器在 AppWorld 任务族上的分辨率;
④ 官方协议全表(test_normal TGC/SGC + τ-bench/BIRD/DS-1000)。
