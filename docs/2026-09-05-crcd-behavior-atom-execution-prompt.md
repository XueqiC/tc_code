# CRCD 下一阶段 Coding Agent 执行 Prompt

请将本文件全文作为任务指令。你是本项目的 research coding agent。你的任务是实现并验证下面的研究计划，而不是为既有方法寻找正面叙事。允许结论是没有增量、测量功效不足或方法需要收缩。所有“预期结果”都是待检验假设，禁止作为调参目标。

## 0. 本轮目标、执行范围与停止点

项目目标是：给定少量目标任务示例，在黑盒文本教师和教师调用预算约束下，将小模型蒸馏成表现更好的 agent。当前研究重心是如何蒸馏，以及购买什么教师监督。不要混入另一个 scaling-down-law 项目。

本轮核心问题：

> 能否从实际学生更新及其行为收益、损伤中，学到少量可干预的方向，并利用这些方向改善同一批数据的蒸馏效果？

研发顺序是：行为迁移预测 → 方向干预验证 → 固定数据蒸馏 → 真正的预算采购。不能跳过前面的机制关口，直接启动大规模在线 acquisition。

## 4. P1：现有迁移矩阵的 teacher/student 拆解

目标：分清原始结果来自公共效应、压低学生输出，还是存在更细的教师行为迁移信息。尽量只用已有更新与评分结果；缺数据时先报告最小补取成本。

### P1.1 三个不同的响应对象

对于 source i 的真实更新 delta_i，分别构造：

\[
M^T_{ji}=\ell^T_j(\theta_0+\delta_i)-\ell^T_j(\theta_0),
\]

\[
M^S_{ji}=\ell^S_j(\theta_0+\delta_i)-\ell^S_j(\theta_0),
\qquad M^{diff}=M^T-M^S.
\]

显式注明 ell 是完整序列 log-prob 还是长度归一化分数。梯度和评估使用相同定义。原始 teacher log-prob 变化与对称差分核不是同一个响应对象。

### P1.2 基线与分析

至少比较：

1. 原始 Fisher 差分指纹核。
2. teacher-only、student-only 指纹核。
3. 匹配响应的一阶基线：teacher-probe 梯度乘真实 source 更新，以及差分-probe 梯度乘真实 source 更新。
4. source 更新范数、probe 初始 margin、teacher/student 长度、类别和类别组合特征。
5. 公共方向/rank-1 模型；PCA-32 仅作为历史结果复核，不继续扫大 K。
6. 现有稀疏字典结果，作为历史对照，不继续优化其重构分数。

所有可部署的预测只使用训练折拟合的特征转换、均值、标准化和残差模型。source 或 target 身份的固定效应只对已观测身份可用，不能读取留出行/列的真实均值再预测它。

报告原始指标与控制类别、长度和公共效应后的配对增量。完整矩阵双中心化仅用于描述性诊断。不要因为要检验残差信号，就在后续训练中强制删除公共方向。

采用按父任务/模板组划分的 source 留出。置信区间至少按 source/task 组重采样；若宣称跨 probe 总体不确定性，使用相应双向分组方法。不能把 25,080 个矩阵格子当作独立样本。

输出 Spearman、符号 AUROC、误差及置信区间，另列每种指标的有效样本数和退化行。正负类不齐或相关性不可定义时填 NA，不填 0。多次重抽样不是多个训练 seed。

### P1 判决

- teacher 侧在简单基线外保留增量：继续 P2，重点检查真实收益与损伤。
- 总体相关性高、控制公共效应后无增量：允许 P2 做 rank-1/小 rank 可行性检查，但不扩大细粒度字典。
- 一阶基线不稳定或数值底噪主导：先修测量；不能用不可靠矩阵训练新方法。
- teacher-only 表示更好，不等于已证明应从训练 loss 删除 student 项。

## 5. P2：行为监督迁移模型，首轮只做 BFCL

### P2.1 划分与 probe 定义

使用允许开发的现有任务。固定：

- Source 集：24 个正式教学单元，按父任务/模板组采样；单元固定为单事件或固定大小小包，二选一并全程统一，不按结果改变组成。
- P_disc：32 个与 source 无父任务/轨迹重叠的固定 development probes，覆盖应调用、应弃答、不同 API/参数形式；状态化样本若成本允许且来源合规可纳入，否则明确首轮外推边界。
- P_confirm：预留新的独立确认题，P3 才使用；不得从其效果选择方向或剂量。
- 校准集与最终测试完全不参与以上选择。

类别只用于分层采样、诊断和简单基线，不作为手写 atom 标签或 benchmark-specific loss 路由。

不能为了凑数混入训练题、校准题或同一父任务的变体。若合法数据不足，报告缺口，缩小试验，不自动生成新的教师题目。

### P2.2 micro-update 和功效 pilot

首轮复用经过审计的 BFCL 稳定训练器，固定 teacherized 数据来源。每个 source 从同一完整训练状态独立开始，保存实际 LoRA 参数差。

先最多 4 个独立 pilot 校准更新尺度，检查：

1. 参数更新及评分是否高于数值底噪。
2. 少量 development probes 是否出现可检测的正确性或错误类型变化。
3. 是否已出现大范围弃答偏移或异常 KL。

剂量用实际更新、有效 tokens、steps 和策略 KL 共同描述；相同 lr 不等于相同剂量。若扩大步数/小包才能产生可测信号，要统一正式 source 的干预定义，不能按每个 source 的结果自适应挑最优步数。

正式剂量在 pilot 后冻结。不要因为 BF16 下难测，就直接使用会造成真实训练坍塌的高 lr。若可接受尺度内多数行为无变化，报告 measurement-inconclusive；保留 likelihood 辅助诊断，但不能用它替代行为关口并宣布通过。

确定性解码的单次结果记为 r_j(theta)∈{0,1}，其差记为实测行为响应；只有固定随机协议下的重复成功频率才称为成功概率估计。随机情况下 base 和更新模型使用配对 seeds，并保存重复结果及不确定性。

### P2.3 明确数学对象与真实参数解码

设实际可训练参数维数为 d；delta_i∈R^d 是相同 LoRA 参数布局下的真实参数差。

固定正定对角度量：

\[
H=\operatorname{diag}(F)+\epsilon I.
\]

F 来自合法训练/reference rollout，阻尼、归一化及版本固定。行为预测使用保留幅度的 whitened 更新 H^(1/2)delta，不是单位范数的旧差分指纹。

在每个训练折，从训练更新的 span 构造正交基 Q。允许用小 Gram 矩阵和分块运算，避免建立 d×d 矩阵。定义：

\[
C=H^{-1/2}Q,\qquad C^T H C=I,
\]

\[
x_i=C^T H\delta_i,\qquad \delta_i=Cx_i+\delta_i^\perp.
\]

保存 C 的可实现解码器或其对已保存参数差的线性组合系数。256 维随机 sketch 只可用于检索/统计，不得未经验证逆投影成实际参数方向。LoRA 因子参数差与合并权重差不能混用。

留出 source 的投影残差单独记录；不能把未建模方向当作确定没有行为影响。训练折之外的 source 更新也不能参与 Q 的拟合，除非另列明确的 transductive 对照。

定义行为矩阵 M∈R^(m×n)，列对应 source，行对应固定 P_disc probe：

\[
M_{ji}=\widehat p_j(\theta_0+\delta_i)-\widehat p_j(\theta_0).
\]

使用最小响应模型：

\[
\min_{\operatorname{rank}(R)\le K}
\sum_{i\in\mathrm{train}}\|M_{\cdot i}-Rx_i\|_2^2
+\lambda\|R\|_F^2,
\qquad K\in\{1,2,4\}.
\]

初版 probe 权重统一，不添加一组可调任务权重。lambda 在固定小网格上按训练折内部验证选择。零更新对应零响应，不随意加自由截距或中心化偏置破坏 R·0=0。算法应真正求解约定目标，不能把任意 ridge 系数做 SVD 截断就未经说明称为最优 reduced-rank 解。

若 R=AΣV^T，则候选参数方向为 U=CV，probe 响应模式为 B=AΣ。理想局部模型下，方向 U a 的预测为 B a。这里右奇异向量定义参数方向，左奇异向量定义 probe 响应，不能反用。

这是局部、训练器及 checkpoint 条件下的响应模型，不是天然唯一的语义能力列表；近重根子空间只比较主角度/投影，不强行给每个向量命名。

### P2.4 公平模型竞赛

比较：

| ID | 模型 | 必须匹配的部分 |
|---|---|---|
| B-null | 对所有 source 预测零行为变化 | 同评估样本；检查稀疏响应下是否只是多数零效应 |
| B0 | 更新公共方向/rank-1；类别/长度/范数基线另列 | 同 source、probe、划分 |
| B1 | 更新 PCA/未中心化 SVD 前 K 方向＋行为回归 | 同 K、同正则选择预算 |
| B2 | 上述行为监督 reduced-rank 模型 | 同输入基、同数据和验证预算 |
| B3 | 打乱 source 更新—行为响应对应关系后重拟合 | 同模型复杂度；保持类别/剂量等分层结构的置换优先 |

普通 PCA 如中心化，必须显式处理均值方向及零更新响应，不允许隐藏额外 rank。B3 预先固定少量置换 seeds，并记录使用的分层条件。

按任务组留出 source，数据少时使用分组交叉验证；rank、正则、basis、预处理都在训练折拟合。测试时只能用留出 source 的更新/合法输入推断响应，不允许用 M_test 参与编码或调参。

固定 P_disc 的输出表只支持“新 source 对这组已定义 probes 的作用”。没有额外 probe 编码器就不声称预测未见 probe；P3 的独立题实验检验方向是否泛化，不冒充新题逐题响应预测。

### P2.5 指标与通过条件

主指标：分组留出实际行为响应误差，以及对各 source 总净收益/保留损伤的排序。辅指标：正向/负向/零变化比例、损伤识别、teacher/student likelihood 预测、投影残差、子空间稳定性。必须同时报告相对零变化预测的表现，避免多数响应为零时仅凭很小的 MSE 认定模型有效。

报告相对 B0、B1 的配对改善及分组置信区间。零响应样本不能为提高相关性而静默删除；仅非零子集指标必须标明条件与覆盖率。报告独立 source 数、probe 组数、发生行为变化的 source 数，而不只报矩阵格子数。

在运行前固定最小有意义效应的业务/行为尺度与计算方法；若现有噪声信息不足，用独立 pilot 估计并冻结。不要观察正式结果后决定什么幅度算成功。

阶段判决：

- GO-candidate：B2 对真实行为响应有超出 B0/B1 的一致增量，置换控制不复现，且不是由少数异常 source 主导；进入 P3 审批，不直接宣称 atom 成立。
- SIMPLIFY：rank-1 或 PCA 已解释有效结构；保留简单子空间，停止复杂字典。
- NO-GO：在有足够测量分辨率时，行为监督模型不改善预测，或只在 likelihood 上胜出；不进入昂贵控制器实验。
- INCONCLUSIVE：效应太稀疏、CI 太宽、分组太少或测量不稳定；报告最小补测方案，不把“不显著”自动当作无效，也不无限补数据。

P2 结束即提交首批报告，不自动开始以下阶段。

## 6. P3：直接干预验证，批准后执行

选最多 3 个方向：公共方向、B2 预测有益的方向，以及 B2 与 B1 判断差异最大的方向。选择规则只看 discovery/development 数据，不能看 P_confirm。

使用 pilot 冻结的安全尺度，测 0.5×、1×、2× 三个局部剂量；超出已校准安全范围的档位跳过并说明。增加一个两方向组合，在相同总 H 范数或同一信任域预算下与单方向比较。另设 no-op 和匹配范数的随机可实现方向控制。

从同一 base 副本实际施加参数方向，重新运行 checker/环境；禁止用预测 B a 充当干预结果。先检查在 P_disc 的剂量与符号复现，再对预留 P_confirm 做冻结确认。确认后这些题不能继续被反复调参并仍称独立确认集。

记录真实正确率/错误类型、teacher/student 分数、更新范数、策略 KL。组合的可加性是待检验假设，不是原子定义赋予的保证；报告组合预测误差与负迁移。

GO：行为方向的收益/损伤在独立题及有限安全剂量下复现，并具有简单基线解释不了的价值。只有极小步长 log-prob 变化则停留在局部梯度坐标结论；不能进入“能力安装已验证”的表述。

## 7. P4：同一批数据的蒸馏控制，批准后执行

### P4.1 首版实现原则

不先重写完整 mirror loss。复用经过调优的稳定训练器及全局 KL/信任域，在其提出的真实参数增量上做低维修正。

设训练器提出 delta_0，学习方向 U 满足 U^T H U=I。将其分解为 U 内分量和正交补。初版只改变 U 内的系数，正交补保留；全局回退/缩放机制在所有对照相同。

用小型正则化优化或固定低维搜索选择系数：靠近原更新、提高预先定义的缺失行为集合的预测收益、限制保留集合的预测损伤，同时限制实际更新范数、系数幅度和开发 probe KL。集合及容忍度在开发数据上预先定义，不看测试/校准反馈。

必须先写清可执行目标、约束和 infeasible/fallback 行为，再实现。预测约束不是实际能力保证；未建模正交补仍可能伤害其他行为，不能称“保护所有 off-atom 能力”。

控制发生在 Adam 提出参数增量之后，不把原始梯度投影冒充实际更新控制。明确 moments 的固定处理方式：默认按同一真实 batch 梯度更新 moments，方向修正不反写为伪梯度；PCA/B2/置换对照完全相同。保存回退、步数和状态，避免撤回参数却重复累积 moments。

响应模型只在其 reference checkpoint 和剂量范围附近有效。第一版先做短训练段；若累计漂移超出校准范围，回退到基线训练器或停止，不在整个 38-step 训练中无条件复用 base 上的 R。需要刷新时，先报刷新样本/评估/计算预算，并在对照中计入相同开销，不能免费持续读取 probe 答案优化。

### P4.2 实验臂与评价

- D0：稳定原训练器＋全局 KL，充分但小预算调参。
- D1：同一控制器＋PCA 方向及其拟合响应。
- D2：同一控制器＋行为监督方向及其响应。
- D3：必要时使用打乱映射，检验正确响应结构是否必要。

固定训练池、初始化、训练次序、seed、batch、有效 loss token 口径、训练段长度、信任域、调参预算和 checkpoint 选择规则。方向/响应是主要变化项，不能让 D2 同时拥有更小 lr、更多 probe 或更频繁评估。

比较目标成功率—保留损伤 Pareto 曲线；同时报告 overall、相关性/弃答、状态化能力、KL、steps、训练 tokens、重复曝光及几何发现/刷新成本。相同 lr 或 steps 不是所有成本相等，分别报告，不事后只挑有利口径。

先单训练 seed 筛查；只给最终两臂补两个预先固定的配对 seeds。训练 seed、采样 seed、rollout seed 分开报告。

通过标准：D2 相对调好的 D0/D1 在相近更新预算下提供可复现的学习—保留优势，并非仅靠几乎不更新接近 base。若只有调低 lr/global KL 有效，就归因于稳定性，不归因于 atom。

BFCL 通过后，再分别在 ALFWorld 初始学生和已有胜任 checkpoint 上做小规模确认，重新测量各自响应，不默认 BFCL 方向跨模型或跨环境通用。不得手工指定 benchmark→loss 的主方法路由。

## 8. 并行收尾：旧 mirror 与 AppWorld 覆盖问题

### 8.1 BFCL gentle / lrmatch

复用正在运行的结果，确认两臂输入和唯一键修复状态。除了分数，读取：错误弃答/调用比例、正确调用相对弃答的 margin、candidate KL、实际 probe KL、lambda 和每事件位移。

- 只有低 lr 恢复：支持 lr 是重要因素，不证明 mirror 有性能优势。
- 两者恢复：gentle 的整组改动有效，不能归因到其中一个项。
- 两者仍塌：暂停新压力扫描，检查目标方向、候选概率质量、实际参数变化。
- 低 lr 接近 base 但不学习：记为稳定性恢复，不记为蒸馏成功。

选择 checkpoint 必须使用预先固定规则，不按官方测试最高分挑点。

### 8.2 AppWorld early / spread / late

先利用已挖掘任务的交集做源匹配审计；17/40 的部分 spread 与完整 early 池不能直接比较后果性比例。

读取已有作业时记录源任务、阶段分布、有效训练 tokens、steps、正/负/零效用比例、上下文长度、thinking 和输出 cap。保留一致状态事件，检查是否包含有效推进和正确终止行为。

本轮不自动新增四臂全量训练。若已有作业无法隔离覆盖效应，提交最小 early-vs-spread 对照配置：同源任务、匹配数量和剂量、相同保守训练设置。若需要额外匹配效用/动作组成，应作为独立归因对照，而不是把所有因素一次改变。

评价重复文档调用、首次业务操作位置、有效状态推进、正确 complete_task、平均步数、最终成功率。必须区分“阶段覆盖修复了循环”与“更小剂量修复了循环”。

简单 spread 若恢复性能，应进入后续强基线；不得把覆盖修复本身当作新 atom 的收益。

## 9. P5：真正的数据购买，先出设计，后申请预算

只有 P4 有学习—保留价值后，才启动新的在线预算实验。查询对象定义为 q=(s,L)，选择状态与 continuation 长度，而不是把已购买轨迹切成行后假装逐行付费。

### 9.1 合法的预购买预测

查询前仅能使用 state、student continuation、已有购买历史、可免费取得的环境反馈和对应成本估计。教师回复、其梯度、Q 和验证结果在购买后才可用。

先从小型合法 bootstrap 历史研究：是否可用简单检索/学生特征预测教师证据可能诱导的更新，再通过已验证的响应模型估计净学习价值。不要先训练复杂 posterior encoder。如果只能用购买后的梯度选对数据，就标为离线 oracle 选数，不宣称在线 acquisition。

### 9.2 最小对照与公平成本

之后需要的最小基线是：随机状态＋短教师 continuation、简单阶段/多样性覆盖、正确成本口径的廉价优先、行为预测 acquisition。现有全 ΔU>0 且几乎全 turn-0 的池不能证明正效用过滤或首分歧策略优劣。

固定真实 query/output budget 与一致的开发选定训练剂量规则。分别报告含 bootstrap 固定开销的端到端曲线与清楚标注的边际/摊销曲线。不把 retained target tokens 当作实际教师计费 tokens。

对当前 random/residual/token 的旧回放，只先补齐剂量与来源分析：更多行带来更多 steps 是混杂；等行数/等步数也不等有效训练 token。需要额外训练时先报最小控制，不能立即增加一批新 selector。

多次查询可能联合解锁新状态；一步预测价值非正不是全局停止证书。认证保持独立，不借用 development probes 包装最终证书。

## 10. 代码、测试、调度与文档要求

先在现有结构上设计接口。建议新增的职责包括：参数差保存/重放、行为 response schema、微更新 runner、P1 分析、低秩拟合、干预 runner、可选更新控制器。不要为了符合建议名称重复造已有模块。

为便于真正执行，提供一个薄 CLI 入口（例如新建 `tools/behavior_atom_experiment.py`，若仓库已有统一入口则复用），至少支持以下子命令：

| 子命令 | 输入 | 输出/动作 |
|---|---|---|
| `audit` | 项目配置、已有 run 清单 | 有效性、split、成本与依赖报告 |
| `decompose` | 历史迁移矩阵、梯度/更新索引、分组 manifest | P1 三侧响应与基线预测 |
| `pilot` | reference checkpoint、pilot source/probe manifest | 剂量与功效报告，不自动扩大运行 |
| `collect` | 冻结剂量、正式 source/probe manifest | 独立更新及原始行为响应 |
| `fit` | 已采集响应、参数差、固定 folds | B-null/B0/B1/B2/B3 交叉拟合与判决 |
| `intervene` | 冻结方向、剂量和确认 manifest | P3 干预；默认仅 dry-run |
| `distill` | 固定训练池、控制器/基线配置 | P4 对照；默认仅 dry-run |
| `report` | 已完成阶段产物 | Markdown 与 JSON 报告 |

各子命令暴露 `--config`、`--manifest`、`--output-dir`、`--dry-run`、`--resume`，不适用参数明确拒绝；`collect` 必须依赖 pilot 的 machine-readable pass 与冻结配置 hash。提供首批配置文件和使用仓库实际 Python/launcher 环境的逐条完整命令，将它们写入运行报告。这些是需要实现或适配的接口，不是假设脚本已经存在；未经实际执行不得把命令列为完成。

至少覆盖以下测试：

1. 内容键/参数布局/缓存变化可以使旧缓存失效。
2. split 按父任务隔离，包含故意重叠的失败测试。
3. delta 保存重放一致，zero delta 与 no-op 响应正确。
4. C^T H C≈I，参数编码解码与正交残差正确。
5. R 的 source/probe 维度、零输入响应、SVD 左右方向正确。
6. 人工已知低秩响应可恢复；打乱映射失去预测力。
7. 修改测试响应不会改变拟合基、rank、加载和预测，防止标签泄漏。
8. 不把不能计算的 AUROC/相关性写成 0。
9. 控制器关闭时与原训练器一致；开启时 moments/fallback 规则一致；正交补处理可检查。
10. 教师事务去重、失败重试、reasoning 包含关系和共享轨迹计费正确。

所有新 runner 提供 dry-run，打印模型数、source/probe 数、最大 rollout 数、依赖、GPU/环境成本估计和新增教师 token。调度依赖使用 job ID、exit code 与机器可读完成状态，不通过 grep 日志里的 FINAL 字符串决定成功。测试 OOM/中断后的幂等恢复，不静默改变 batch、截断或精度。

在项目实际路径中更新 canonical Method、EXPERIMENT_PLAN、RESULTS_LEDGER、PROJECT_STATE：区分历史观察、新假设、实现完成、测量有效和性能验证。Method 明确删除“稀疏字典已验证”“lambda 必归零”“候选 KL 自动保护全策略”等过强结论，但保留历史版本和证据来源。

## 11. 强制汇报格式

每个阶段结束提供：

1. 一句话判决：GO-candidate / SIMPLIFY / NO-GO / INCONCLUSIVE / BLOCKED。
2. 本次检验的具体假设，以及哪些变量固定、哪些改变。
3. 实际执行：commit、数据/split/config hash、训练/采样/评估 seeds、作业 IDs、完整可复现命令。
4. 有效样本：独立 source/probe/父任务组数、无效/缺失数量、实际行为变化数。
5. 主结果表：模型、rank、响应误差、净收益排序、损伤、置信区间、训练与评估开销。
6. 对照解释：新模型是否超过 rank-1、类别和 PCA；置换能否复现；teacher/student 两侧分别发生什么。
7. 数值与实现检查：底噪、delta 范数、KL、keys/caches、优化器、上下文和评分设置。
8. 成本：真实教师 input/output/reasoning 口径、估计部分、外部演示、训练/环境开销，不能只报保留样本数。
9. 结论边界：支持什么、不支持什么、哪些只能算探索结果，不得将不显著写成等价。
10. 下一步最多三项，按优先级列出需要的计算资源、教师预算及预期能排除的解释。

附带机器可读 `stage_report.json`，至少包含：stage、decision、reason、valid_runs、invalid_runs、metrics、confidence_intervals、costs、artifacts、blocking_issues、next_actions。报告中的每个数都指向可核查产物。

现在从 P0 开始：先给出仓库与作业审计、最小改动清单、P1/P2 dry-run 和资源边界，然后在既有授权范围内执行。不要启动 P3–P5，不新增付费教师调用，不为了得到正结果扩大试验。
