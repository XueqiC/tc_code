# 两条离线路线的完整分析汇总
**路线 1:失败定位 · 路线 2:教学证据读取器**
截至 2026-09-13 17:30 CDT。本文汇总最终结论,**取代**此前分批追加的版本。
所有数字为最终值;所有撤回集中列在 §5,不在正文中反复穿插。

---

## 0. 两句话结论

**路线 1(已完成)**:在 200 题 / 814 段 episode 上,失败可以**零残留**地分类。
补齐四个记录字段后,"observation → 查询构造"这一类从 **0 变成 155 段、覆盖 51 个独立父任务**,
**且完全靠对已存轨迹的离线回补得到,没有重跑任何 rollout**。
但要强调:这些是**候选教学案例**,不是已证实的根因。

**路线 2(已完成,负结果)**:第一代读取器的 null **是仪器造成的**,不是机制结论;
第二代(有序键值 + 预训练表示)**有了分辨力**——能测出 2e-6 的绑定差异、并在 50/87 个案例上选出不同材料——
**但选出来的并不更好**:G1 相对 G0 在已标注证据口径上**精确为 0**。原型已冻结,资源转给 I/P/L。

## 1. 路线 1:离线失败定位

### 1.1 做法
输入:200 题检查报告,**814 段 episode**,五种上下文
(autonomous / replay / closed-book / supplied-entity / must-retrieve)。
逐 episode 判定四种**可观察情况**,允许多标签、允许"日志不足以判断",
并记录**最早的可观察偏离点**;所有判定带引用。

**记录粒度补齐**(本轮新增四个字段,均为对已存轨迹的纯函数):
每步 observation 与 supporting fact 的匹配位置;查询与上一步 observation 的字符串重叠;
显式的步/episode 结束原因;该步是否已集齐全部标注证据。
**关键性质**:它们可**离线回补**到既有记录上,**零 GPU、零教师调用**。

### 1.2 失败细分(零残留)

| 细类 | n | 占比 |
|---|---:|---:|
| 成功 | 320 | 39.3% |
| A1 未结束,答案从未出现 | 137 | 16.8% |
| B2 答错,答案从未出现 | 112 | 13.8% |
| B3 明确弃答(全部在闭卷) | 89 | 10.9% |
| A2 未结束,答案曾可见 | 75 | 9.2% |
| B4 EM 假失败 | 42 | 5.2% |
| B1 答错,答案曾可见 | 39 | 4.8% |

**去掉闭卷对照后:341 段失败中 141 段(41%)gold 字符串曾出现在某次 observation 里。**
(n=24 的初版这个比例是 25%,**分布确实随样本变化**。)

### 1.3 四种教学关系的判定结果

| | 回补前 | 回补后 |
|---|---:|---:|
| S1 observation → 查询构造 | 0 | **155** |
| S2 查询结果 → 检索调整 | 9 | 9 |
| S3 多段证据 → 答案 | 2 | 2 |
| S4 已完成状态 → 正确结束 | 0 | 3 |
| 不可判(unjudgeable) | 14 | **6** |

**S1 的 155 段来自 51 个独立父任务。** 父任务数才是统计瓶颈,51 个足以支撑父任务级聚合。

### 1.4 最早可观察偏离点(814 段)
`empty_retrieval 480`、`unjudgeable 151`、`observation_to_query 73`、`answer_score_mismatch 68`、
`none_observed 24`、`step_limit 8`、`result_to_retrieval_adjustment 3`、`multiple_evidence_to_answer 2`。

**必须区分**:`empty_retrieval` 中**闭卷那一支是按设计关掉检索**(固定回一句
"No matching page or passage was found."),**不是失败**;其余才是真实的 Wikipedia 检索落空。

### 1.5 两个专项核查
**(a) `action_format_failure` 不是 harness 缺陷。**
144 段带此标记的 episode 里,规范动作 **662** 次、带尾随内容 38 次、**真正无法解析仅 8 次**;
`format_failures` 在 97/144 段中恰为 1 次;可恢复性检查显示那 8 次里**只有 1 次**
响应中存在格式正确的 `Action:` 行而解析器没取到。**集中在闭卷(65/144)**,
即强迫凭记忆作答、容易长篇议论的条件。→ **不当教学对象,不计入"学生不会"。**

**(b) 重放不是确定性的。** 逐题看:`action_match` **16/24**、`observation_match` **17/24**、
两者同时匹配 16/24,**12 题记录了 first_divergence**。
必须拆成两个命题:**环境可重放**(相同动作取回相同 observation)与
**策略可重放**(学生重新生成相同轨迹);**后者在三分之一的题上不成立**。

### 1.6 路线 1 的限制(明确写出)
- "答案字符串从未出现"**不等于检索失败**:比较题、计算题、是非题在证据充分时也可能不出现 gold 串;
- "最早偏离是空检索"**不等于该次空检索导致最终失败**:合法探索可以先落空再恢复;
- S1 的 155 段是**候选**,需逐条核验:查询没复用 observation 的词,也可能用了正确别名或另一条合法路径;
- 闭卷答对只能称"**闭卷可答**",不足以认定训练数据污染。

## 2. 路线 2:教学证据读取器

### 2.1 第一代(哈希 unigram)——null,但**仪器本身没有分辨力**
四条件:N 无 support / O 正确 support 一次读取 / R 正确 support 递归读取 / M 绑定被扰动。
初次结果:**O = R = M,87 个状态上选择完全相同,逐项配对差 0.000**。

**五层结构核查(零 GPU,用同一批 87 状态)**:

| 层次 | 结论 |
|---|---|
| 输入 | M **确实**改了对应关系(循环错位,键值多重集不变、配对打破),87/87 标记为已改变 |
| 表示 | 每条记录**先编成完整关系再聚合**,"先加总再归一化"这一实现**并不存在**;但扰动仅造成 L2 中位数 **6.1e-4** 的变化 |
| 读取 | **真正原因**:注意力**几乎均匀**。62 条 support,均匀权重 0.0161,偏离均匀最大值中位数仅 **6.6e-4**;O 更是精确均匀 |
| 排名 | 未四舍五入的分数**从不**相同(0/87);排序 82–84/87 相同 |
| 预算 | **放大器**:可用 15 条只选 2 条,把残差量化掉 → 选择 87/87 相同 |

**→ 这个 null 只能读作"当前测量在该量级上没有分辨力",不能读作机制结论。**

**放宽评分(合法替代证据可得分)后**:可评分状态 **6 → 87**;
N 遗漏 .770 / 覆盖 .230;**O = R = M 全部 .722 / .278**;失败位置覆盖 N **.286** → O/R/M **0**。
配对差仍为 **R−O = R−M = O−M = 0.000**(87 配对全部精确为零)。

### 2.2 第二代(有序键值记忆 + 预训练表示)——仪器有分辨力,结论仍为负
**改动**:key = 任务与决策状态,value = 该状态的行动 / 结果 / 已有教学证据;
**每条记录先编成完整关系再聚合**;表示改用本地 Gemma-4-12B 最后一层最后一个 token 的隐状态
(404 条请求 / 170 万 token / 约 6 分钟 / **不截断**)。support 真实获得的执行反馈**允许进入**读取器;
确认题答案、相关性标注、事后失败分类**仍然禁止**。

**正对照(硬要求)**:植入已知大小的绑定差异,要求仪器必须测得出。
→ 可分辨的最小绑定差异 **2e-6**(约 4e-6 RMS L2),比旧仪器测不出的 6.1e-4 **低两个数量级**。

**注意力尺度审计**(温度 0.1 事先冻结于合成开发材料,报告记录
`parameter_search_performed: false`、`perturbation_optimization_performed: false`):

| 指标 | 中位数 | 最小 | 最大 |
|---|---:|---:|---:|
| 归一化熵 | 0.982 | 0.556 | 0.987 |
| 有效 support 占比 | 0.928 | 0.160 | 0.946 |
| **每案例**最大权重 / 均匀权重 | **1.463** | 1.195 | 13.539 |

→ **多数案例仍接近均匀,少数案例才出现真正集中;中位案例最受关注的 support 只有 1.46 倍。**
**"预训练 embedding 不保证集中"。**

**结果**(86 个三条件都可评分的公共案例上重算,均值与配对差**逐位一致**):

| 条件 | 遗漏率 | 预算内覆盖 | 失败位置覆盖 |
|---|---:|---:|---:|
| G0 当前状态直接读取 | 0.738372 | 0.2616 | 0.1429 (7 例) |
| G1 保留配对,一次读取 | 0.738372 | 0.2644 | 0.1429 (7 例) |
| G2 保留配对,递归读取 | 0.734496 | 0.2682 | 0.0 (7 例) |

配对差:**G1 − G0 = +0.000000**(86 对中 6 对非零、相互抵消);**G2 − G0 = −0.003876**(11 对非零)。

**选择重合度——这是与第一代性质不同的关键证据**:

| 比较 | 排序相同 | 选择相同 | 分数相同 |
|---|---:|---:|---:|
| G1 vs G0 | 1 / 87 | 37 / 87 | 0 / 87 |
| G2 vs G0 | 2 / 87 | 15 / 87 | 0 / 87 |
| G2 vs G1 | 10 / 87 | 38 / 87 | 0 / 87 |

旧仪器是 **87/87 选择完全相同**;现在 **G1 相对 G0 在 50/87 个案例上选出不同材料**。
**→ 不能再用"仪器分辨不出来"解释这个 null。**

### 2.3 路线 2 的结论与限制
1. **保留绑定确实改变了读取器选什么**,**但按已标注证据口径并不更好**(G1−G0 精确为 0)。
2. **G1 ≠ G0 只说明"新增输入改变了输出",不能证明"正确绑定"被利用**——
   那需要**第二代读取器自身的绑定扰动对照**,第一代的 M 不能替代。
3. 失败位置覆盖 0.1429 → 0 落在 **7 个案例**上,很可能只对应一个案例的变化,**不作稳定损伤论**。
4. **数值扰动可检测只证明计算有灵敏度**,不代表表示理解了教学关系。
5. 多数案例注意力仍近均匀,因此多数案例上的 null **仍部分**可归因于仪器。

**当前可写的结论:新版读取器确实改变了选择,尚无可靠的选择质量增益。原型冻结,资源转给 I/P/L。**

## 3. 两条线合起来说明什么

- 路线 1 提供了**可用的教学素材来源**(51 个独立父任务的候选状态),这是 I/P/L 的输入;
- 路线 2 说明**自动找材料这一支目前没有增益**,因此**不能把它当作 I/P/L 的前置条件**——
  两者已刻意解耦,I/P/L 不等读取器胜出;
- 两条线都**没有**回答核心问题:**同样有效的教学动作,放回真实工具反馈的上下文中学习,
  能否带来"拆开单独教"与"普通连续片段"所没有的收益。** 这只能由 I/P/L 六个 adapter 回答。

## 4. 与 Table 1 的关系(动机,不是机制结论)
Table 1 已封存:ALFWorld 上三方法均高出 base 1.7–2.4;HotpotQA 上三方法三种子均值**全部低于 base**。
逐题比对:HotpotQA 475/500 结果相同,ALFWorld 124/140 相同。

**按评审口径,能写的动机只有**:
> 在当前预算与配置下,已有的轨迹蒸馏没有带来可靠的 HotpotQA 整体提升,
> 因此值得直接检验**局部教学的上下文组织**是否影响学习与迁移。

**不能写**:三方法机制相同、失败原因相同、或根因在查询构造(见 §5)。

## 5. 撤回清单(完整)

**路线 1**
1. ~~"70% 的失败是检索侧"~~ → 应为**字符串可见性**描述;大样本上是 59 / 41。
2. ~~"最早的空检索导致了最终失败"~~ → 合法探索可先落空再恢复。
3. ~~"S1 拿到 15 个教学案例"~~ → 是**候选**,当时仅来自 5 个父任务;测量规则改变是首要解释。
4. ~~"重放是确定性的"~~ → **实打实的错误**;逐题 action_match 仅 16/24。
5. ~~"闭卷答对 = 训练数据污染"~~ → 只能称"闭卷可答"。
6. ~~"扩到 200 题只会放大实例数,方向不会变"~~ → 分布确实变了。
7. ~~"action_format_failure 占四分之一 episode"~~ → 真正无法解析仅 8 次,非 harness 缺陷。

**路线 2**
8. ~~"递归注意力在当前仪器下不成立"~~ → 当前测量在该量级**没有分辨力**。
9. ~~"只要形状像 support 就行"~~ → M 保留原词汇,任意形状的 support **未检验**。
10. ~~"最大权重/均匀权重中位数 0.966"~~ → **标错指标**;那是全部 5,394 个权重比值的分布中位数
    (均值按构造 = 1.0),每案例最大值实为 **中位 1.463 / 最小 1.195 / 最大 13.539**。
11. 均值表与配对差"不一致" → **不同样本集**(G0 86 例 vs G1/G2 87 例);86 公共案例上重算后逐位一致。
12. ~~"G1 ≠ G0 ⇒ 正确绑定被利用"~~ → 只说明新增输入改变了输出。
13. ~~"失败位置覆盖 0.143 → 0 是稳定损伤"~~ → 落在 7 个案例上。

**流程与判断**
14. ~~"候选必须全部买到目标,这条规则是对的"~~ → 评审不认可,已撤销该要求;
    改为允许用已验证示范建包,但必须完整报告购买成功率与未覆盖候选。
15. ~~"三种方法并不直接教'根据已有证据构造下一次查询'"~~ → **轨迹蒸馏本来就能**在
    observation 条件下监督下一次查询。
16. ~~"475/500 成败相同 ⇒ 三者机制相同 / 失败原因相同"~~ → 成败相同不等于轨迹或学习机制相同。
17. ~~"gold 未出现 / 未结束 ⇒ 根因在查询构造"~~ → 单凭这两项不足以定位根因。
18. ~~"两次在同一点失败 = 确定性缺陷"~~ → 第三次直接跑通;更可能是该位置命中率高。
