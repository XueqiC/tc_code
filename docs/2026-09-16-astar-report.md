## 1. 命题与设计

命题(你的 §4):**在同一批确有教学差异的决策状态上、监督相同的正确推理与动作时,仅将动作训练前缀换成学生自己产生的思路,是否改善自主执行?**

| 项目 | A* | B* |
|---|---|---|
| 正确推理监督 | 学 s → r^T | 完全相同 |
| 动作监督 | 学 (s, r^T) → a^T | 学 (s, r^S) → a^T |
| 动作、终止标记与出现次数 | 相同 | 相同 |
| 归一化分母与系数 | 相同 | 相同 |
| 学生错误 Thought | 不作监督目标 | 只作输入(零权重,不进分母) |

实现:A* 一条序列(目标 `Thought N: r^T` + `\nAction N: a^T` + 边界 + 格式尾);B* 两个视图(推理视图目标 `Thought N: r^T`;动作视图掩码 `Thought N: r^S`,目标 `\nAction N: a^T` + 边界 + 格式尾)。
A* 作批次参照,B* 同包同批;逐包、逐批 reasoning / action / boundary / formatting 目标 token 数与全局分母恒等(代码断言,写入 freeze_receipt.equality_invariant);
λ=0 纯 CE、token 比例权重;两臂都从 U0 seed-0 LoRA 起、AdamW 新状态、lr 1e-5、clip 1;两种子只改批次顺序;对照 = U0 原样合并同批评测。
剂量按新银行曝光定:3 遍规则(与 U0 主干一致)→ 20 步(每遍目标 token 3,272 = reasoning 2,272 + action 856 + 边界/格式 144;20 步 × ~530 = 10,789),不复制 113 步。

## 6. 判读与分析

**预注册判读:第 4 行——所有配对的 dev / conf EM 与局部有用率 / 续跑 EM 区间都含 0 → "停止投入这个条件化机制;保留结果与材料"。**
分析器措辞:未检出稳定优势,也未建立等价。

分析:
1. **这次检验是干净的。** 材料的教学差异经 gap 打分确认(d 中位 0.99 nats/token,漏结束类 1.49);A*/B* 的逐段目标 token 数与分母逐批恒等,每步分母序列完全相同;
   剂量按曝光算出(20 步,3 遍),训练损失单调下降但没有记忆到零;B* 的损失比 A* 高出的 0.27 正好等于动作占比 × d——B* 确实在学一个更难的条件分布。
2. **学了更难的条件分布,自主执行没有变。** dev-500 上 B*−A* −0.3 ± 1.0;局部有用率反而略低(2 个父任务变差、0 变好),续跑 EM 略低,续跑完成率略高——
   都在噪声内且方向不一致。20 步的动作监督(每步 ~140 个动作 token)也许太少,但这正是"按曝光定剂量"的结果;把剂量加大会回到上一轮"记忆 62 包"的境地。
3. **新材料本身没有可靠增益。** A*/B* 相对对照 +0.8 / +0.5(CI 含 0);72 个有差异的状态、每父任务 ≤2,对 500 题的 dev 集只能移动 1 pp 量级。
   这与今天上午到晚上反复看到的一致:在 HotpotQA + gemma-4-12B 上,任何 ≤100 回合量级的补充材料都落在 ±1–2 pp 的噪声里。
4. **conf-32 的 +4.7 是 3 胜 1 负**,不能作证据;若要确认必须用更大的独立父任务集。
5. **对论文叙事的含义**:条件差距(教师前缀掩盖的动作学习缺口)是真实且可测的(前置检查 + gap),但把它作为训练前缀切换的目标,在本设置下没有转化为自主执行的改善。
   这一条候选贡献("有限教师预算下识别缺口并用学生前缀训练提高迁移")在当前证据下不成立;可写成"缺口存在但简单的前缀条件化不足以利用它"的负结果,配以完整账本。

建议(需你定):按你的四行表执行第 4 行——停止对该条件化机制的投入,保留结果与材料(72 包 + 243 独立教师回合是可复用的银行);
若继续这条主线,唯一还没排除的是"剂量"维度(20 步 vs 更多遍数)与"材料规模"维度(52 父任务),但两者都会碰到 dev-500 的 ±1–2 pp 噪声天花板,需要先解决评测分辨率(更多独立父任务)。
