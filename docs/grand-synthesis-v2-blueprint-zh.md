# 大总结:项目全部洞见 → 方法 v2.0 蓝图(2026-08-22)

## 第一部分:洞见清单(带证据广度)

### A 类:跨台验证,可作方法基石

**A1 锚定定律(最强洞见,三条子定律)**
监督必须包含学生自身分布的锚,且:
- **出处纯度单调**:锚只能来自被保存的分布(base 的已验证行为)。
  AppWorld:纯 base 锚 .284 > 混合 .245 > 漂移锚 .202(数量补不了
  质量:19 行纯 > 123 行混)。
- **剂量 ×1 饱和**:AppWorld 锚 ×4 = .282 ≈ ×1 = .284;gsm 10 条 cot
  锚即在 loss 层完全中和破坏耦合(ΔL −.40 ×3 种子)。恢复力强,
  超越力无——锚是保底不是引擎。
- **无锚必坏**:gsm 孤立偏好阶段崩(剂量曲线 4/6/12 步)、无门统一
  判负;AppWorld 克隆全家崩(.197 铁板)、token 掩码无锚无效(两台
  同败)。
证据广度:**gsm + AppWorld,双台多角度,项目最扎实**。

**A2 克隆地板不变性(主台)**
AppWorld 上 full/random/LESS/SmartAD 全部 .197(embedding .218),
选择方法零区分度;两个规模(4B/9B)、125 倍数据都不改变。
**"买什么"在 agent 台不是杠杆,"怎么训"才是。** gsm 侧弱同构
(基线们在 .64-.67 平局带内挤压)。广度:主台强证 + gsm 弱证。

**A3 对比轴 = 成功轴(偏好对的有效性条件)**
gsm:同风格、差内容的对 +.032(3/3);AppWorld:同上下文、差风格
的对 −.087(把锚定模型打回克隆地板)——压风格差异 = 训练风格捕获。
推论:轨迹失败不可归因于首步(信用分配)。广度:双台正反例,扎实。

**A4 NLL 门 / "先学会再区分"**
odds 项须在正解 NLL 低于运行均值后逐行激活:gsm .660(门)vs .630
(无门)配对 3/3;0.8B 压力测试系列最高。广度:gsm 两个规模;
AppWorld 未单独测门(aw11 的失败由 A3 主导,门未被否定)。

### B 类:主要在受控套件验证(机制可信,待主台平移)

一阶定律 ΔL_off ≈ −η·Σ S_a⟨d_a,∇L_off⟩,预算扫描证实破坏项随
供给增长(cot 40k +.38)。**AppWorld 的风格捕获 = 破坏性耦合的
主台实例(与 base 分布的耦合),锚 = 中和项——A1 与 B1 由此统一。**

**B2 零泄漏免费**:环内门+回购 → 残留 0.000(×4 预算×3 种子,

## 第二部分:归并为三条设计原理

**P1(价值原理)** 每一份监督的价值 = 它落在学生欠缺处的增量
− 它对学生已有能力的挤出。克隆失败因为第二项为负且巨大(A2);
偏好对失败当对比轴错位时第二项爆炸(A3);锚定有效因为它把第二项
清零(A1)。

**P2(几何原理)** 挤出与增益都住在原子空间里,且**在花钱之前可测**:
题面 κ 预报可混淆(门),响应 κ 预报干扰(训练),需求-供给差预报
增益(u(x))。双视图字典是同时给出三者的唯一对象(B1/B2/B3)。

**P3(动态原理)** 上述两个量随学生状态演化(需求衰减、失败集中、
边际耦合成本上升,B4),因此方法必须是**一条连续的边际决策规则**
而非固定管线;所有"阶段"都应从规则中涌现(v1.4 已确立,禁离散
分段)。

## 第三部分:方法 v2.0 蓝图

**一句话**:在双视图原子空间上,以连续边际规则花每一分钱——
v(a) = 欠缺增益(需求×供给)− 挤出成本(锚耗损 + 耦合供给),
argmax 执行,全负即停;训练侧永远保持出处纯净的 ×1 锚。

与 v1.4 的差异(全部由本周主台证据驱动):
1. **挤出成本项显式化**(v1.4 只有耦合成本):任何动作对锚份额的
   稀释计入成本——克隆地板(A2)由此在规则内部被自动规避,不再
   依赖"经验上要混自解"的叙述;
2. **锚运营三规则入法**(A1):出处 = 被保存分布的已验证行为;
   剂量 ×1(随即饱和);迭代时锚集只增不换;
3. **偏好动作的合法性判据入法**(A3):仅当对的分歧位于"成功轴"
   (执行结果不同)才允许 odds 项;风格分歧对自动禁用——这把 aw11
   的教训变成规则而非补丁;
4. **部署不变**:边界/证书(B2)原样,零泄漏继续作为"预算无漏损"
   的证据而非目标。

**v2.0 待验证的最小集**(每条 ≥2 台):
- 挤出成本项的显式实现 vs v1.4(gsm 40k 档 + AppWorld);
- 成功轴判据下的主台偏好(步级信用分配,替代 turn-0 风格对);
- 耦合预报器在 AppWorld 任务族上的分辨率(B1 平移);
- 官方协议全表(test_normal TGC/SGC + τ-bench/BIRD/DS-1000 上线)。

**主表叙事(当前最强版本)**:agent 台上示范克隆系统性摧毁 base
(全部基线 .197-.25 < base .28-.30,规模与数据量不救);我们的锚定
分层是唯一不伤且均值上超 base 的训练方式(9B .321 vs .303,对克隆
+.124);同时在受控套件与最强基线并列、方差最小、零泄漏免费、浪费
减半。故事完全对齐大故事线:budget 全部转化为 in-task,一分不漏、
一分不挤。
