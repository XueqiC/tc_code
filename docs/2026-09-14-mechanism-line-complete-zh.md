## 1. 要验证什么

**核心问题**:学生拿到已有证据之后,如何作出下一步有用的决策。

三个可分离的子问题,本轮各做了一个:
1. **材料怎么组织才能被学会** → I/P/L 三臂;
2. **材料能不能被自动找到** → 读取器 G0/G1/G2;
3. **条件对应能否直接作为监督目标** → 交互蒸馏四格算子。

三者**刻意解耦**:I/P/L 不等读取器胜出,读取器不等交互目标成立。

## 2. 方向①:I/P/L 教学组织(本轮核心结果)

### 2.1 素材与对照设计
- **教师素材**:24 条教学链 / **24 个不同父任务**(一父一链),全部
  `stop_reason = correct_executed_continuation`:教师在真实上下文提出后续动作 → **工具真实执行** → 取得有效后续;
- 花费 **14,058 output token / $0.084**,停止原因是**达到目标条数**而非预算耗尽;
- 验证只要求教师示范**正确且可执行**,**未**用"能否救活原学生"筛选。

三臂**共享同一批素材**:

| 臂 | 组织方式 | 独立父任务 | 练习数 | 监督 token |
|---|---|---|---|---|
| **I** | 把操作集合拆开单独教 | 24 | 98 | **6,023** |
| **P** | 同样操作目标放回真实交互上下文 | 24 | 24 | **6,023** |
| **L** | 固定协议切连续片段(对照) | 24 | 31 | **6,023** |

**共享 98 个监督操作、监督 token 完全相同、曝光匹配在 3.19% 以内、I 与 P 渲染 token 级不同**
(构造器在两臂渲染完全相同时会拒绝产出)。**变量只有组织方式。**

训练:I/P/L × **2 个配对种子**(同种子下比较,差异不来自初始化或数据顺序),剂量冻结
(与 18 个已归档 Table 1 格子同一套 LoRA rank / 优化器 / 学习率 / 监督 token 预算),
**不搜超参、不换 loss、不按确认集挑中点 checkpoint**;
监督前缀 = **推理前缀**(含模板打开的思考通道)。

### 2.2 结果(EM,200 个父任务,± 为半极差)

| 臂 | local_completion | changed_condition | full_tasks |
|---|---|---|---|
| **I** | .4825 ± .0025 | .4600 ± .0050 | .4925 ± .0025 |
| **P** | .4850 ± .0050 | .4575 ± .0025 | .5025 ± .0175 |
| **L** | **.4975** ± .0025 | **.4700** ± .0100 | **.5075** ± .0025 |

**跨臂极差**:local **1.50** / changed **1.25** / full **1.50** 个百分点。
**n=200、p≈0.5 时单点标准误 = 3.54 个百分点。**

### 2.3 判读(必须克制)
1. **三臂在全部三层上均未分开** —— 所有差异都远在噪声之下。
2. **名义最高的是对照臂 L**,且在三层上都最高,**与"保留依赖上下文(P)更好"的假设方向相反**。
   但它同样在噪声内,**正确表述是"没有证据支持 P 更好",不是"L 更好"**。
3. **方向一致性也不存在**:P 在 full_tasks 上高于 I,在 changed_condition 上低于 I。
4. **两个种子是筛选轮**,不足以做显著性结论;但极差 1.5 点 / 标准误 3.5 点的关系说明
   **即使补种子,也不太可能在这个量级上翻出差异**。

**这一轮回答的是**:在当前预算与素材下,**把同样有效的教学动作放回真实工具反馈的上下文中学习,
并没有带来"拆开单独教"或"普通连续片段"所没有的收益**。

## 3. 方向②:教学证据读取器

### 3.1 第一代(哈希 unigram):null,但**仪器本身没有分辨力**
四条件 N / O / R / M 初次结果:**O = R = M,87 个状态上选择完全相同,逐项配对差 0.000**。

**五层结构核查(零 GPU)**:

| 层次 | 结论 |
|---|---|
| 输入 | M **确实**改了对应关系(循环错位),87/87 标记已改变 |
| 表示 | 每条记录**先编成完整关系再聚合**;扰动仅造成 L2 中位数 **6.1e-4** 的变化 |
| 读取 | **真正原因**:注意力**几乎均匀**(62 条 support,均匀权重 .0161,偏离均匀最大值中位数仅 **6.6e-4**) |
| 排名 | 未四舍五入分数**从不**相同(0/87);排序 82–84/87 相同 |
| 预算 | **放大器**:可用 15 条只选 2 条,把残差量化掉 → 选择 87/87 相同 |

→ **该 null 只能读作"当前测量在该量级没有分辨力",不是机制结论。**

放宽评分(合法替代证据可得分)后:可评分状态 **6 → 87**;N 遗漏 .770/覆盖 .230;
**O = R = M 全部 .722/.278**;失败位置覆盖 N **.286** → O/R/M **0**。

### 3.2 第二代(有序键值 + Gemma 预训练表示):仪器有分辨力,结论仍为负
- key = 任务与决策状态,value = 该状态的行动/结果/已有教学证据;**先编完整关系再聚合**;
- 表示 = 本地 Gemma-4-12B 最后一层最后一个 token 隐状态(404 条请求 / 170 万 token / 约 6 分钟 / **不截断**);
- support 真实获得的执行反馈**允许进入**;确认题答案、相关性标注、事后失败分类**仍禁止**。

**正对照(硬要求)**:可分辨的最小绑定差异 **2e-6**(约 4e-6 RMS L2),
比旧仪器测不出的 6.1e-4 **低两个数量级**。

**注意力尺度审计**(温度 0.1 事先冻结于合成开发材料,
`parameter_search_performed: false`、`perturbation_optimization_performed: false`):

| 指标 | 中位数 | 最小 | 最大 |
|---|---:|---:|---:|
| 归一化熵 | 0.982 | 0.556 | 0.987 |
| 有效 support 占比 | 0.928 | 0.160 | 0.946 |
| **每案例**最大权重/均匀权重 | **1.463** | 1.195 | 13.539 |

→ **多数案例仍接近均匀,少数才真正集中;"预训练 embedding 不保证集中"。**

**结果**(86 个三条件都可评分的公共案例,均值与配对差逐位一致):

| 条件 | 遗漏率 | 预算内覆盖 | 失败位置覆盖 |
|---|---:|---:|---:|
| G0 | 0.738372 | 0.2616 | 0.1429 (7 例) |
| G1 | 0.738372 | 0.2644 | 0.1429 (7 例) |
| G2 | 0.734496 | 0.2682 | 0.0 (7 例) |

**G1 − G0 = +0.000000**(86 对,6 对非零相互抵消);**G2 − G0 = −0.003876**。

**选择重合度(与第一代性质不同的关键证据)**:

| 比较 | 排序相同 | 选择相同 | 分数相同 |
|---|---:|---:|---:|
| G1 vs G0 | 1/87 | 37/87 | 0/87 |
| G2 vs G0 | 2/87 | 15/87 | 0/87 |

旧仪器是 **87/87 选择完全相同**;现在 **G1 相对 G0 在 50/87 个案例上选出不同材料**。
**→ 不能再用"仪器分辨不出来"解释这个 null。**

### 3.3 结论与限制
**保留绑定确实改变了读取器选什么,但按已标注证据口径并不更好。**
限制:(a) G1≠G0 只说明**新增输入改变了输出**,**不能证明"正确绑定"被利用**
(需第二代自身的绑定扰动对照);(b) 失败位置 .1429→0 落在 **7 个案例**上,**不作稳定损伤论**;
(c) 数值扰动可检测只证明**计算有灵敏度**;(d) 多数案例注意力仍近均匀,多数案例上的 null **仍部分**归因于仪器。

**原型已冻结,停止继续调。**

## 4. 方向③:交互蒸馏四格目标(未能检验)

四格交互 `B = ℓ11 + ℓ22 − ℓ12 − ℓ21`,训练臂 D2 需要标签 `t_e = 1`。

**可测性(12 对关系,两种打分)**:

| | full-turn | action-only |
|---|---|---|
| 与 0 不可区分 | **0/12 = 0.0%** | **0/12 = 0.0%** |
| matched beats swapped | 4/12 | 3/12 |
| **经核验的排他绑定** | **0** | **0** |

**B 在数值上完全可测**,但**没有有效绑定标签**——因此 4/12、3/12 这两个比例
**不能称作"绑定准确率"**,也**不能与 50% 随机基准比较**(没有标签就没有该基准)。

**根因是结构性的**:能构造的 12 对**全是 progress 对**(同一任务连续两步:
第 k 步 `search[X]` vs 第 k+1 步 `finish[答案]`),**不是目标对调的对称关系**。
progress 对的交叉项**天然可能仍然正确**(检索前直接作答模型可能本就会答;检索后再检索只是冗余),
**所以排他性一个都核验不出来**。
**注**:目标对调本身**也不自动解决问题**——交换后仍可能只是重复查询已知信息;**对称不等于排他**。
真正需要的是"**在原有任务目标下有依据判断正确 assignment 更好**";
若两种分配都成功、只差一步,而目标**无步骤成本**,**不得临时加惩罚造标签**。

**Thought 捷径证据(降级表述)**:full-turn 与 action-only 的 B **12 对中 5 对符号相反**
(最极端 −55.18 vs +12.24)。由 `B_full = B_Thought + B_Action`,这只说明
**Thought 部分足以改变总体排序**;原因可能是文字匹配、**也可能是计划/事实内容确实与某状态更相容**、
或长度与表达差异,本轮分不开。且 **action-only 仍然条件化于候选 Thought**。
可写"**避免完整 Thought 分数主导执行关系的衡量**",**不可写**"已排除 Thought 文字污染"。

**标签可获得性(零教师花费的离线挖掘)**:
- 已购买素材:扫描 **1,830 个父任务组合**,合格跨目标关系 **0 对**;
- 200 题池:**6 个严格候选**(如 Kinnie/Frijj 1952 vs 1993、Me Naiset/Marie Claire 周刊 vs 月刊),
  其中 **4 个两侧都缺教师示范**,配齐 6 个约需 **5,860 token**;
- **提出的问题与推导答案仅供审计,不冒充已购买的教师输出。**

**该清单尚不足以让四格监督担当方法核心。**

## 7. 工程过程(影响可复现性,必须记录)

本轮为拿到 ① 的结果,排除了四个真实缺陷:

1. **CUDA OOM(两轮六格,约 23 GPU·h 无产出)**。逐步剖面定位:
   `checked_score_action`(**只做校验、结果随即丢弃**)建了**用不到的计算图**,
   其 checkpoint 重放留住 Gemma `shared_kv_states`,扫描里 48 个 source 每个留一份。
   改为 `torch.no_grad()` 后:**基线 60.03 → 23.13 GiB**、**step 13 刷新峰值 77.79 → 23.13 GiB**
   (尖峰完全消失),对角线/动作/诊断/RNG 状态**逐位相同**,剂量未动。
2. **导出拒绝本地快照路径**(把 `HP_MODEL_PATH` 当 Hub 仓库 ID 校验)→ 接受本地目录、
   仍记录 `google/gemma-4-12B-it` 为身份,摘要对同一批字节计算。
3. **vLLM 后端不兼容**:合并后是 `gemma4_unified`(多模态),强制 `--attention-backend FLASH_ATTN`
   不支持多模态前缀注意力 → 去掉强制后端,让 vLLM 自选。
4. **policy 身份不匹配**(`generated` 与 `scoring` 两个哈希完全不同)——**仍未解决**,
   频率低,本轮六格无一撞上;诊断已能打印两边身份,**已归档格子无法据此认证不受影响**。

**并且**:所有 checkpoint 全程未丢失,最终结果是靠"**从已保存 checkpoint 续跑导出+评测、不重训**"拿到的。
