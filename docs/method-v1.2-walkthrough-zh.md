# 方法 v1.2:学习流程(统一版;三个阶段,按执行顺序)

**总原则(一句话)**:学生先试,验证器免费打分,只在学生自己失败的
地方花钱买监督——完整示范是"对空尝试的修复"这一退化情形,因此整个
方法是计费黑盒 teacher 下的 on-policy 蒸馏。

设定:support set S = k 条 query 及其 teacher 示范(不计费)+ 按 token
计费的 black-box teacher(无 logprobs,只有硬标签文本)+ 开源学生 +
预算 b。默认参数以 k=50, b=20000 为例。标注:【已验证】= 3 种子外部
评测证据;【验证中】= 已实现,判定实验在跑。

## 三个阶段,各一句话

- **阶段 I(技能提取与预算分配)**:用学生自己的梯度几何,把任务分解
  成一部技能词汇,并按任务需求把预算分到每个技能上。
- **阶段 II(数据获取)**:在视图不变的稀疏编码上,贪心最大化一个
  预算受限的次模技能覆盖目标——学生先试,自解免费,失败才买。
- **阶段 III(on-policy 蒸馏)**:训练信号按学生自身策略状态分层
  ——自解处保留自己的行为、失败处用正解压自己的错解、无行为处克隆
  示范——三层合成单一 ORPO 目标一次优化;终态取探针信任域内的
  checkpoint 平均。

## 概念定义(自有概念定义,标准方法说明)

- **梯度特征(gradient feature)**:样例喂给学生,一次前向+反向但不
  更新,取梯度(LoRA B 矩阵)拼接、随机投影、归一化。含义:「这条
  样例会把学生参数往哪个方向推」(数据选择文献标准做法,LESS)。
  每条样例有两个视图:**响应视图**(对示范回答算损失)与**题面视图**
  (把题面文字当预测目标算损失,不需要 teacher 回答,计费前可得)。
- **【定义 1】双视图共享编码字典(two-view coupled dictionary)**
  【验证中】:一部字典、两个视图块 [D_p; D_r],要求每条双视图已知的
  样例(support 示范、已购样例)用**同一个稀疏编码 c** 同时重构题面
  特征 (≈cD_p) 与响应特征 (≈cD_r):
  min ‖X_p−CD_p‖² + ‖X_r−CD_r‖² + λ‖C‖₁。
  原则:**技能剖面是视图不变的**——题面/响应是同一潜在技能组合的两个
  投影。候选题只有题面 → 对 D_p 块做 lasso,得到的 c 就是其预测技能
  供给(共享编码约束替代了此前的核岭回归桥;coupled dictionary 在
  图像超分辨中为成熟谱系)。
- **【定义 2】capability atom**:字典的一行 [d_p; d_r],解释为任务的
  一种可复用技能;编码幅度 |c_a(x)| 度量样例 x 练该技能的强度。
- **【定义 3】任务需求 w**:k 条 support 编码(绝对值)均值,归一化;
  每技能预算 = w_a·b。
- **任务归属(membership)**:题面块重构残差 ‖x_p − c·D_p‖——
  任务边界 = 技能词汇能表达的范围;阈值 = 最不典型的真题(cal 上
  conformal 校准),与技能字典是同一个对象。

## 阶段 I:技能提取与预算分配(只用 support,不消耗预算)

I-1. **劈分**:k 条固定 70% fit + 30% cal;cal 只定阈值与探针,绝不
     参与拟合。
I-2. **特征**:每条 (query, 示范) 计算题面视图与响应视图梯度特征。
I-3. **字典与分配**:对 fit 条的双视图拼接特征学共享编码字典(基向量
     数 = min(64, 样本数/2), α=0.05)→ atoms(定义 2)、需求 w
     (定义 3)、每技能预算 w_a·b。
I-4. **归属阈值**:cal 各算题面块残差,最大者为过滤阈值(可选松弛
     s·std 扫纯度-性能曲线;实测 s≤1 纯度不掉,默认 s=0【已验证】)。

## 阶段 II:数据获取(计费;×R 轮,默认 R=2 各半预算)

一句话:**贪心最大化预算受限的次模技能覆盖**。定义覆盖
F(A)=Σ_a min(w_a·b, Σ_{x∈A} s_a(x)):modular 供给过 min(·) 凹截断,
故 F 单调次模;每轮 buy argmax u(x)=Σ_a min(r_a, ŝ_a(x))/t̂ 恰是其
代价归一化边际增益,继承预算次模最大化的 (1−1/e) 型近优保证
(Khuller et al. 1999 / Krause–Guestrin 谱系)——不是新算法,是发现
现有规则本来就是那个算法。

II-0. **初始化**:已购集 = ∅;剩余需求 r = 各技能预算;平均样例开销
      t̂=200 初始;批大小 B=8(固定超参)。
II-1. **重拟合字典**:support + 已购样例的双视图特征上重学共享编码
      字典(词汇随证据变细;k=50 词汇恢复率 67%,一轮购后 84%
      【已验证】)。
II-2. **候选编码**:候选题面对 D_p 块 lasso → c(x) 即预测供给 ŝ(x)
      (无回归桥【验证中】);编码幅度不归一化——lasso 给无关样例的
      幅度天然小,这就是相关性信号【已验证】。
II-3. **选取**:按 u(x) 从高到低,批内工作需求即时扣减防重复计分;
      每轮至多 B 条;t̂ 更新为已购均值。需求清零后按每 token 编码
      密度继续(统一准则 u′,验证等价【已验证】)。
II-4. **验货**:执行检查 + 题面残差过 I-4 阈值;未过的计浪费
      (实测 2-4%),预算继续分配。环内门 + 回购是纯度机制
      (越界残留 0.000 ×4 预算 ×3 种子【已验证】)。
II-5. **本轮预算未尽 → 回 II-1**;尽则进 II-6。
II-6. **训练插曲与缺口**:用已购语料训中间学生(阶段 III 配方);
      每技能损失曲线免费给出缺口(后 1/3 均损 > 前 1/3 的 50%)
      【已验证,与 rollout 版等精度且免 rollout】。
II-7. **纠错轮(先试后买)**【验证中】:候选按 预测编码·缺口 重排;
      购买前学生自试短名单(每题采样 3 次):3/3 一致且可执行 →
      自解免费入库,预算下移;失败才买——(a) 常规示范,或 (b) 对已购
      题的学生错解买 teacher **最小修复**(≤5% 预算);所有失败尝试
      与其正解自动配成偏好对,供阶段 III,零额外开销。候选枯竭时
      teacher 参照缺口技能的 support 例题定向出新题(受控套件上判定
      中性,保留给候选贫瘠场景【已验证】)。

## 阶段 III:on-policy 蒸馏

一句话:**训练信号按学生自身策略状态分层,合成单一 verifier 锚定的
ORPO 目标一次优化**。对每道已获取的题,学生与它的关系决定它贡献什么
梯度:

| 学生策略状态 | 语料来源 | 目标中的贡献 |
|---|---|---|
| 自己能做对(3/3 一致) | 自解(零 teacher 成本) | NLL(保持自己的行为) |
| 尝试过但做错 | 修复/示范 + 自己的错解 | NLL(正解) + β·分歧掩码 odds 项(压自己的错误模式) |
| 给不出可解析尝试 | 完整示范 | NLL(行为克隆,退化情形) |

L(x) = NLL(正解|x) + β·1[存在学生错解]·(分歧掩码 odds 项)。
这就是计费黑盒下 on-policy 蒸馏的实现:teacher 无 logprobs、每 token
计费,于是"对学生轨迹的教师监督"只能以修复/示范文本的形式购买,
"压低学生自身失败模式"只能以免费偏好项的形式实现;随学生变强,
第一层占比增大、第三层缩小,训练自动越来越 on-policy。SFT 是"无
负例的偏好学习"退化情形,与总原则同构【验证中;分段式小剂量版已
验证 +.032 配对 3/3】。

III-1. **组装语料**:示范 ∪ 纠错修复 ∪ 自解(teacher 成本递减)。
       (自产**对题**当额外正例判定中性——自产数据的边际价值在
       负例【已验证】。)
III-2. **统一目标训练**:等算力(轮数 = min(8, max(3, round(3b/token))),
       lr 2e-4,累积 8;无样例加权【已验证无增益】);带负例的行
       多出偏好项:分歧 token 之后才计损失(likelihood displacement
       的源头是共享前缀上的序列级压力,ICLR'25);无单独偏好阶段,
       无剂量旋钮。
III-3. **技能级观测**:每行按主 atom 记损失 → 每技能吸收曲线
       (II-6 的输入,免费)。
III-4. **安全网(无新常数)**:每 4 步 cal **执行正确率**探针(金标
       = 执行 teacher 示范,免费;只测可运行率对正确率崩塌失明
       【已验证】),跌破一道探针题即停并回滚该段。
III-5. **权重平均与回滚**【已验证 +.058,种子极差 .025】:每 8 步
       探针;终态 = 近优探针 checkpoint 与最终态的平均(SWA),探针
       不降才采纳;仅当最优比终态好出超过一道探针题才回滚。

---

*(学成学生可选配 conformal 部署门:题面块残差 + 分位阈值,界外拒答、
界内覆盖率有分布无关下界——部署配置,不在学习流程内。)*

**数据流小结**:fit 只拟合、cal 只定标;偏好负例全部免费来自学生
自身失败;teacher 只在买示范/修复/定向出题时计费;所有阈值要么是
统计约定要么从 support 估计,无逐 benchmark 调参。
